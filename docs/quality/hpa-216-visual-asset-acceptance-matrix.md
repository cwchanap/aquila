# HPA-216 visual-asset acceptance matrix

This matrix is self-contained: every criterion names its owning current source
and an executable command. The HPA-233 gate retains deployment evidence for an
immutable candidate; it does not replace the runtime, publisher, or migration
tests listed here. Run commands from the repository root with dependencies
installed. Remote release-gate commands additionally require the protected
workflow's exact environment and retained evidence.

## Manual visual-review cases

The reviewer records these IDs in the strict `notes` array of the final review
record. Each is a human judgement that automated checks cannot honestly claim.

| Case  | Review procedure and justification                                                                                                                                                                                  |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| VR-01 | On the protected preview desktop route, inspect initial background/portrait composition, speaker identity, crop, contrast, and clipping. This catches perceptual/layout defects beyond a DOM ready-state assertion. |
| VR-02 | Repeat representative scenes on the protected preview mobile viewport. Confirm portrait placement, readable dialogue, and responsive composition rather than relying only on desktop geometry.                      |
| VR-03 | Inspect a scene transition with normal and reduced-motion preferences. Confirm that the sequence feels continuous and does not flash, reset, or create a distracting motion change.                                 |
| VR-04 | Exercise a planned omitted/unavailable visual key. Confirm the authored fallback remains legible and the reader continues without a blocking error.                                                                 |
| VR-05 | Use direct open, a choice, a bookmark/return, and progression through one representative story path. Confirm the visual interpretation remains narratively appropriate after navigation.                            |
