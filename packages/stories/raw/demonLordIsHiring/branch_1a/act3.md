# 第三幕：計畫書第二版

**旁白**：奧德里克在第一個週六準時抵達。

**旁白**：他沒有破門，而是敲門。進來之後先遞上一份「討伐計畫書」，一式兩份，請魔王簽收。

**旁白**：然後他用四分鐘穿過了七層機關。

**旁白**：第七層的旋轉刀陣，勇者花了十二年才學會怎麼滾過去。奧德里克是走過去的。

**旁白**：他停在王座前，劍尖抵地，呼吸平穩，鎧甲上一道刮痕都沒有。

**旁白**：魔王的披風才披到一半。

**奧德里克**：陛下，依照計畫書第三條，我現在可以結案了。

**魔王**：(內心)來了。

**奧德里克**：不過，我讀了貴城的契約。第十二條寫著，宿敵的職責是「定期來訪」。如果我今天結案，下個月就沒有來訪的對象，這樣算違約。

**魔王**：⋯⋯所以？

**奧德里克**：所以我建議，每次討伐到這裡就暫停。我回去寫報告，您回去加強機關。下個月再來。

**旁白**：他頓了一下，視線落在第七層的方向。

**奧德里克**：老實說，我在騎士團十五年，從來沒有遇過一個讓我想再來一次的地方。

**瑟琳**：這部分我們同意。

**魔王**：我還沒說話。

**瑟琳**：您的表情說了。

**旁白**：那天晚上，魔王把第七層的刀陣拆掉重做。加了兩組刀片，把延遲改成三秒，想了想，又把延遲拿掉。

**旁白**：他一路弄到天亮。手腕痠，眼睛乾，指甲縫裡都是機油。

**旁白**：三百年來第一次，他覺得機關不夠用。

**旁白**：早上，瑟琳把一杯熱茶放在工作台邊，順手翻開月曆。下個月第一個週六，已經畫好了紅圈。

**旁白**：紅圈旁邊有一行小字：「奧德里克，計畫書第二版。」

**魔王** [touched]：(內心)⋯⋯第二版。

**旁白**：他把披風送洗了。
