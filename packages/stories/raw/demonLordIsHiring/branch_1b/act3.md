# 第三幕：我的志願

**旁白**：托比每天下午四點來。

**旁白**：他不走正門，走廚房的側門，因為那裡離山路比較近。他會先跟門口的石像鬼打招呼，把頭盔推正，然後大喊一聲：「魔王，受死吧！」

**旁白**：魔王會從王座上站起來，展開披風，念完那段每年重寫的開場白。一個字都不省。

**旁白**：然後他們打二十分鐘。木劍敲在披風上，不痛。魔王倒下的時候倒得很慢，讓托比有時間喊完招式的名字。

**旁白**：五點二十分，瑟琳會在門口咳一聲。

**托比**：今天先這樣。明天再來打你。

**魔王**：我等你。

**旁白**：他說這句話的時候很認真。跟開場白一樣認真。

**旁白**：兩個月後，托比帶來一張作文紙。題目是「我的志願」，右上角用紅筆寫著一個大大的「甲」。

**托比**：老師說要給主管看。

**旁白**：字歪歪的，有幾個字用注音代替。

**旁白**：「我的志願是打倒魔王。魔王住在山上，房子很大。他很強，但是他每次都讓我贏，然後假裝沒有讓我。我覺得他是一個很好的魔王。」

**旁白**：「等我長大，我要真的打贏他。所以他要活很久。」

**魔王** [touched]：(內心)⋯⋯

**旁白**：魔王把作文還給他，在聯絡簿上簽名。簽名還是擠不進格子。

**魔王**：你寫錯一個字。「魔」的下面是鬼，不是石。

**托比**：喔。

**瑟琳**：陛下。

**魔王**：我知道。

**旁白**：那天晚上，作文被裱了框，掛在王座後面。原本掛在那裡的，是一幅三百年前的戰爭畫。

**旁白**：月底，東邊山腳寄來一個木箱。打開是一整箱蕪菁，土還沒拍乾淨。

**旁白**：隔天下午四點，魔王挑了最大的一顆，讓托比帶回去給他媽媽。

**托比**：這是戰利品嗎？

**魔王**：是。

**旁白**：托比把蕪菁抱在懷裡，頭盔又滑下來一點。他沒有空手去推，就這樣歪著頭盔走下山。

**魔王**：(內心)明天四點。
