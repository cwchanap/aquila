# 第三幕：錄取通知

**旁白**：魔王親手寫了錄取通知。

**旁白**：他寫了三份草稿。第一份太正式，第二份太長，第三份寫到一半，他發現自己的嘴角是翹的。最後寄出去的那份只有一行：「恭喜琳瑟小姐錄取本城宿敵一職。」

**旁白**：收件地址他想了很久，最後寫的是城堡西翼，二樓，第三個房間。

**旁白**：瑟琳的房間。

**旁白**：隔天早上，瑟琳準時出現，手上抱著資料夾，跟過去一百一十年的每一天一樣。

**瑟琳**：陛下，今日行程。九點，例行公文。十點，地牢巡視。下午三點，宿敵來訪。

**魔王**：嗯。

**瑟琳**：另外，她託我轉達：希望週休二日，討伐固定在週二下午，結束後要能準時下班。

**魔王**：⋯⋯可以。

**瑟琳**：她也說，請您不要手下留情。

**旁白**：下午三點，正門打開。金色捲髮，圓框眼鏡，手上是一把細劍。

**神祕應徵者**：魔王，受死吧。

**旁白**：魔王站起來，展開披風。開場白他念得很順，連那口水都沒喝。

**旁白**：她只出了一招。繞到他的左側——披風補過洞的那一邊——在他抬手的瞬間，劍尖輕輕點在他的肩上。

**旁白**：三百年來，沒有人發現他的左肩抬不太高。

**神祕應徵者**：您輸了。

**魔王**：⋯⋯妳作弊。

**神祕應徵者**：我做了很多功課。

**旁白**：她收起劍，扶了一下快要滑掉的假髮。

**神祕應徵者**：下週二再來。還有，請記得吃午餐。您今天又沒吃。

**旁白**：她從正門離開。

**旁白**：五分鐘後，側門打開。瑟琳端著一個托盤進來，上面是一杯茶和一個便當，放在王座的扶手上。

**瑟琳**：勇者寄來的蕪菁今天到了。我燉了肉。

**旁白**：魔王打開便當。熱氣撲上來，有點燙。

**魔王** [touched]：瑟琳。⋯⋯謝謝。

**瑟琳**：為什麼謝我？我只是祕書。

**旁白**：她的領口上，又沾著一根金色的頭髮。

**魔王**：(內心)下週二。

**旁白**：他放下筷子，拿起筆，在月曆的週二畫了一個紅圈。
