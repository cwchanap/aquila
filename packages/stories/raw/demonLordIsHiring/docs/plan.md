# 《魔王徵才中》/ The Demon Lord Is Hiring — 企劃

## Premise

在位三百年的魔王把反派當成一份正經職業：每年重寫開場白、每季保養陷阱、勇者來訪前一晚把披風送洗。某個週二，勇者寄來一封極有禮貌的辭職信——膝蓋不好，要回東邊山腳種蕪菁。面對一張空白的月曆，任職一百一十年、從不慌張的祕書瑟琳早已貼好徵才公告（「待遇面議，可被擊敗」），隔天就在改裝成面試間的王座廳舉行面試。應徵者三位：一位能力過剩、會問遣散費和勞保的聖騎士；一位帶著家長同意書和聯絡簿、九歲半的小勇者；以及一位戴著金色捲髮、字跡跟瑟琳一模一樣的「神祕應徵者」。視角鎖定魔王（第三人稱貼近），冷面辦公室喜劇，所有人都非常認真。

## Acts

| act | location | beats |
| --- | --- | --- |
| act1「辭職信」 | 王座廳（黃昏） | 勇者的辭職信由瑟琳念出（陷阱維護得好、台詞不重複、膝蓋不好、種蕪菁、附記會寄一箱）；有禮貌的勇者不會回來；月曆上的紅圈；「魔王沒有勇者，就只是住在很大房子裡的人」；瑟琳：「職位出缺，就徵才」——公告早已貼好；明天面試三位 |
| act2「三場面試」 | 王座廳改裝的面試間（早晨） | 聖騎士奧德里克：屠龍十一條、問「第一次就成功算試用期通過嗎」、問勞保（瑟琳昨天辦的）——他能贏，而魔王要的不是能贏的人；小勇者托比：家長同意書（五點半前回家吃飯、請不要嚇他）、「你看起來很寂寞」、請魔王在聯絡簿上簽名；瑟琳去倉庫拿茶葉，神祕應徵者「琳瑟」出現：瑟琳的字跡、金髮下的黑髮、知道所有內部資訊、「您需要一個不會走的人」；瑟琳回來，領口沾著金髮；選擇 |
| branch_1a/act3「計畫書第二版」 | 王座廳（不另設背景） | 奧德里克四分鐘破七層機關，卻依契約「定期來訪」條款主動暫停；魔王熬夜重做刀陣，三百年來第一次覺得機關不夠用；月曆紅圈「計畫書第二版」；他把披風送洗了 |
| branch_1b/act3「我的志願」 | 王座廳（不另設背景） | 托比每天四點來打二十分鐘，五點二十瑟琳咳一聲；作文「我的志願」得甲：「他每次都讓我贏，然後假裝沒有讓我」「所以他要活很久」；作文裱框掛在王座後；勇者的蕪菁寄到，最大一顆當戰利品讓托比帶回家 |
| branch_1c/act3「錄取通知」 | 王座廳（不另設背景） | 錄取通知寄到西翼瑟琳的房間；瑟琳轉達宿敵的條件（週休二日、週二下午、準時下班、不要手下留情）；琳瑟一招擊中魔王左肩的舊傷；「請記得吃午餐」；瑟琳端來蕪菁燉肉便當；「為什麼謝我？我只是祕書。」月曆週二畫上紅圈 |

Backgrounds: 2 (throne room at dusk; the same throne room rearranged as an interview room). Endings inherit the interview-room background.

## Endings

- **b1a 錄取聖騎士**：宿敵比他強，卻選擇每個月回來——魔王重新開始努力。
- **b1b 錄取小勇者**：每天四點的二十分鐘；一篇得甲的作文讓魔王決定要活很久。
- **b1c 錄取神祕應徵者**：兩人都不點破；她準時來擊敗他，準時回來替他送便當。
