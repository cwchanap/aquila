# 第三幕：計画書・第二版

**ナレーション**：オルドリックは｜第一《だいいち》｜土曜日《どようび》、｜定刻《ていこく》どおりに｜現《あらわ》れた。

**ナレーション**：｜彼《かれ》は｜扉《とびら》を｜破《やぶ》らなかった。ノックをした。｜中《なか》に｜入《はい》るとまず「｜討伐計画書《とうばつけいかくしょ》」を｜正副《せいふく》｜二部《にぶ》｜差《さ》し｜出《だ》し、｜魔王《まおう》に｜受領《じゅりょう》のサインを｜求《もと》めた。

**ナレーション**：それから、｜七層《ななそう》の｜罠《わな》を｜四分《よんぷん》で｜突破《とっぱ》した。

**ナレーション**：｜第七層《だいななそう》の｜回転刃《かいてんば》を｜転《ころ》がり｜抜《ぬ》けられるようになるまで、｜勇者《ゆうしゃ》は｜十二年《じゅうにねん》かかった。オルドリックは｜歩《ある》いて｜通《とお》り｜抜《ぬ》けた。

**ナレーション**：｜彼《かれ》は｜玉座《ぎょくざ》の｜前《まえ》で｜立《た》ち｜止《ど》まり、｜剣先《けんさき》を｜床《ゆか》についた。｜呼吸《こきゅう》は｜乱《みだ》れず、｜鎧《よろい》には｜傷《きず》ひとつない。

**ナレーション**：｜魔王《まおう》はまだ、マントを｜半分《はんぶん》しか｜羽織《はお》れていなかった。

**オルドリック**：｜陛下《へいか》。｜計画書《けいかくしょ》｜第三条《だいさんじょう》に｜基《もと》づき、｜本件《ほんけん》はこの｜時点《じてん》で｜完了《かんりょう》とすることができます。

**魔王**：（｜心《こころ》の｜声《こえ》）｜来《き》たか。

**オルドリック**：ただ、｜御城《おしろ》の｜契約書《けいやくしょ》を｜拝読《はいどく》しました。｜第十二条《だいじゅうにじょう》に、｜宿敵《しゅくてき》の｜職務《しょくむ》は「｜定期的《ていきてき》な｜来訪《らいほう》」とあります。｜私《わたし》が｜本日《ほんじつ》ここで｜完了《かんりょう》させれば、｜来月《らいげつ》は｜来訪《らいほう》する｜相手《あいて》がいなくなる。これは｜契約違反《けいやくいはん》にあたります。

**魔王**：……つまり？

**オルドリック**：つまり、｜毎回《まいかい》この｜段階《だんかい》で｜一時中断《いちじちゅうだん》することをご｜提案《ていあん》します。｜私《わたし》は｜戻《もど》って｜報告書《ほうこくしょ》を｜書《か》き、｜陛下《へいか》は｜罠《わな》の｜強化《きょうか》に｜取《と》り｜組《く》まれる。そして｜来月《らいげつ》、また｜参《まい》ります。

**ナレーション**：｜彼《かれ》は｜少《すこ》し｜言葉《ことば》を｜切《き》り、｜第七層《だいななそう》のほうへ｜視線《しせん》をやった。

**オルドリック**：｜正直《しょうじき》に｜申《もう》し｜上《あ》げますと、｜騎士団《きしだん》での｜十五年間《じゅうごねんかん》、もう｜一度《いちど》｜来《き》たいと｜思《おも》える｜場所《ばしょ》に｜出会《であ》ったことは｜一度《いちど》もありませんでした。

**セリン**：その｜条件《じょうけん》で、｜当方《とうほう》は｜合意《ごうい》いたします。

**魔王**：｜余《よ》はまだ｜何《なに》も｜言《い》っていない。

**セリン**：お｜顔《かお》に｜書《か》いてございます。

**ナレーション**：その｜夜《よる》、｜魔王《まおう》は｜第七層《だいななそう》の｜刃《は》の｜罠《わな》を｜取《と》り｜壊《こわ》し、｜一《いち》から｜組《く》み｜直《なお》した。｜刃《は》を｜二組《ふたくみ》｜増《ふ》やし、｜遅《おく》れを｜三秒《さんびょう》に｜変《か》え、｜少《すこ》し｜考《かんが》えてから、｜遅《おく》れそのものをなくした。

**ナレーション**：｜作業《さぎょう》は｜夜明《よあ》けまで｜続《つづ》いた。｜手首《てくび》はだるく、｜目《め》は｜乾《かわ》き、｜爪《つめ》のあいだには｜機械油《きかいあぶら》が｜入《はい》りこんでいた。

**ナレーション**：｜三百年《さんびゃくねん》で｜初《はじ》めて、｜罠《わな》が｜足《た》りないと｜思《おも》った。

**ナレーション**：｜朝《あさ》になると、セリンが｜作業台《さぎょうだい》の｜端《はし》に｜熱《あつ》いお｜茶《ちゃ》を｜置《お》き、ついでのようにカレンダーをめくった。｜来月《らいげつ》の｜第一《だいいち》｜土曜日《どようび》には、すでに｜赤《あか》い｜丸《まる》がついていた。

**ナレーション**：｜赤《あか》い｜丸《まる》の｜横《よこ》に、｜小《ちい》さな｜字《じ》で｜一行《いちぎょう》。「オルドリック｜様《さま》　｜計画書《けいかくしょ》｜第二版《だいにはん》」

**魔王**：（｜心《こころ》の｜声《こえ》）……｜第二版《だいにはん》。

**ナレーション**：｜彼《かれ》はマントをクリーニングに｜出《だ》した。
