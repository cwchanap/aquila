# 第三幕：計画書・第二版

**ナレーション**：オルドリックは第一土曜日、定刻どおりに現れた。

**ナレーション**：彼は扉を破らなかった。ノックをした。中に入るとまず「討伐計画書」を正副二部差し出し、魔王に受領のサインを求めた。

**ナレーション**：それから、七層の罠を四分で突破した。

**ナレーション**：第七層の回転刃を転がり抜けられるようになるまで、勇者は十二年かかった。オルドリックは歩いて通り抜けた。

**ナレーション**：彼は玉座の前で立ち止まり、剣先を床についた。呼吸は乱れず、鎧には傷ひとつない。

**ナレーション**：魔王はまだ、マントを半分しか羽織れていなかった。

**オルドリック**：陛下。計画書第三条に基づき、本件はこの時点で完了とすることができます。

**魔王**：（心の声）来たか。

**オルドリック**：ただ、御城の契約書を拝読しました。第十二条に、宿敵の職務は「定期的な来訪」とあります。私が本日ここで完了させれば、来月は来訪する相手がいなくなる。これは契約違反にあたります。

**魔王**：……つまり？

**オルドリック**：つまり、毎回この段階で一時中断することをご提案します。私は戻って報告書を書き、陛下は罠の強化に取り組まれる。そして来月、また参ります。

**ナレーション**：彼は少し言葉を切り、第七層のほうへ視線をやった。

**オルドリック**：正直に申し上げますと、騎士団での十五年間、もう一度来たいと思える場所に出会ったことは一度もありませんでした。

**セリン**：その条件で、当方は合意いたします。

**魔王**：余はまだ何も言っていない。

**セリン**：お顔に書いてございます。

**ナレーション**：その夜、魔王は第七層の刃の罠を取り壊し、一から組み直した。刃を二組増やし、遅れを三秒に変え、少し考えてから、遅れそのものをなくした。

**ナレーション**：作業は夜明けまで続いた。手首はだるく、目は乾き、爪のあいだには機械油が入りこんでいた。

**ナレーション**：三百年で初めて、罠が足りないと思った。

**ナレーション**：朝になると、セリンが作業台の端に熱いお茶を置き、ついでのようにカレンダーをめくった。来月の第一土曜日には、すでに赤い丸がついていた。

**ナレーション**：赤い丸の横に、小さな字で一行。「オルドリック様　計画書第二版」

**魔王**：（心の声）……第二版。

**ナレーション**：彼はマントをクリーニングに出した。
