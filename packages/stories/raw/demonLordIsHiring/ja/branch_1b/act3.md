# 第三幕：将来の夢

**ナレーション**：トビーは｜毎日《まいにち》、｜午後四時《ごごよじ》にやってくる。

**ナレーション**：｜正面《しょうめん》の｜扉《とびら》ではなく、｜厨房《ちゅうぼう》の｜勝手口《かってぐち》から｜入《はい》ってくる。｜山道《やまみち》からはそちらのほうが｜近《ちか》いからだ。まず｜入口《いりぐち》のガーゴイルにあいさつをして、｜兜《かぶと》をまっすぐに｜直《なお》し、それから｜大声《おおごえ》で｜叫《さけ》ぶ。「｜魔王《まおう》、かくごしろ！」

**ナレーション**：｜魔王《まおう》は｜玉座《ぎょくざ》から｜立《た》ち｜上《あ》がり、マントを｜広《ひろ》げ、｜毎年《まいとし》｜書《か》き｜直《なお》している｜口上《こうじょう》を｜最後《さいご》まで｜述《の》べる。｜一字《いちじ》たりとも｜省《はぶ》かずに。

**ナレーション**：それから｜二人《ふたり》は｜二十分間《にじゅっぷんかん》｜戦《たたか》う。｜木《き》の｜剣《けん》がマントを｜叩《たた》く。｜痛《いた》くはない。｜魔王《まおう》が｜倒《たお》れるときはとてもゆっくり｜倒《たお》れるので、トビーは｜必殺技《ひっさつわざ》の｜名前《なまえ》を｜最後《さいご》まで｜叫《さけ》ぶことができる。

**ナレーション**：｜五時二十分《ごじにじゅっぷん》になると、セリンが｜戸口《とぐち》でひとつ｜咳払《せきばら》いをする。

**トビー**：きょうはここまで。また｜明日《あした》、たおしに｜来《く》るね。

**魔王**：｜待《ま》っている。

**ナレーション**：そう｜言《い》うとき、｜彼《かれ》は｜本気《ほんき》だった。｜口上《こうじょう》と｜同《おな》じくらい｜本気《ほんき》だった。

**ナレーション**：ふた｜月後《つきご》、トビーは｜一枚《いちまい》の｜作文用紙《さくぶんようし》を｜持《も》ってきた。｜題《だい》は「しょうらいのゆめ」。｜右上《みぎうえ》には、｜赤《あか》ペンで｜大《おお》きな｜花丸《はなまる》が｜描《えが》かれていた。

**トビー**：｜先生《せんせい》が、｜上司《じょうし》の｜人《ひと》に｜見《み》せなさいって。

**ナレーション**：｜字《じ》はがたがたで、ところどころ、｜漢字《かんじ》のかわりにひらがなで｜書《か》いてあった。

**ナレーション**：「ぼくのしょうらいのゆめは、｜魔王《まおう》をたおすことです。｜魔王《まおう》は｜山《やま》の｜上《うえ》にすんでいて、｜家《いえ》がとても｜大《おお》きいです。｜魔王《まおう》はとても｜強《つよ》いけど、いつもぼくをかたせてくれて、それから、かたせてないふりをします。ぼくは、｜魔王《まおう》はとてもいい｜魔王《まおう》だと｜思《おも》います。」

**ナレーション**：「｜大《おお》きくなったら、ほんとうに｜魔王《まおう》に｜勝《か》ちます。だから｜魔王《まおう》は、ながいきしないといけません。」

**魔王**：（｜心《こころ》の｜声《こえ》）……

**ナレーション**：｜魔王《まおう》は｜作文《さくぶん》を｜返《かえ》し、｜連絡帳《れんらくちょう》にサインした。｜署名《しょめい》はやはり、マスに｜収《おさ》まりきらなかった。

**魔王**：｜一字《いちじ》まちがえている。「｜魔《ま》」の｜下《した》は「｜鬼《おに》」だ。「｜石《いし》」ではない。

**トビー**：あ。

**セリン**：｜陛下《へいか》。

**魔王**：わかっている。

**ナレーション**：その｜夜《よる》、｜作文《さくぶん》は｜額《がく》に｜入《い》れられ、｜玉座《ぎょくざ》の｜後《うし》ろに｜掛《か》けられた。もとはそこに、｜三百年前《さんびゃくねんまえ》の｜戦《いくさ》の｜絵《え》が｜掛《か》かっていた。

**ナレーション**：｜月末《げつまつ》、｜東《ひがし》の｜山《やま》のふもとから｜木箱《きばこ》が｜届《とど》いた。｜開《あ》けると、かぶがぎっしり｜詰《つ》まっていた。｜土《つち》もまだ｜落《お》としきれていない。

**ナレーション**：｜翌日《よくじつ》の｜午後四時《ごごよじ》、｜魔王《まおう》はいちばん｜大《おお》きなかぶを｜選《えら》び、お｜母《かあ》さんに｜持《も》って｜帰《かえ》るようにとトビーに｜渡《わた》した。

**トビー**：これって、せんりひん？

**魔王**：そうだ。

**ナレーション**：トビーはかぶを｜胸《むね》に｜抱《かか》えた。｜兜《かぶと》がまた｜少《すこ》しずり｜落《お》ちる。｜押《お》し｜上《あ》げる｜手《て》が｜空《あ》いていないので、｜彼《かれ》は｜兜《かぶと》を｜傾《かたむ》けたまま｜山《やま》を｜下《お》りていった。

**魔王**：（｜心《こころ》の｜声《こえ》）｜明日《あした》の、｜四時《よじ》。
