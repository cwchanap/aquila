# 第三幕：採用通知

**ナレーション**：魔王は採用通知を自らの手で書いた。

**ナレーション**：下書きは三枚になった。一枚目は堅苦しすぎ、二枚目は長すぎた。三枚目を半分ほど書いたところで、自分の口角が上がっていることに気づいた。最後に送ったのは、たった一行だった。「リンセ殿　当城の宿敵としての採用、おめでとう。」

**ナレーション**：宛先には長いこと悩んだ。結局書いたのは、城の西翼、二階、三番目の部屋だった。

**ナレーション**：セリンの部屋だ。

**ナレーション**：翌朝、セリンはいつもの時刻に、ファイルを抱えて現れた。この百十年の、毎日と同じように。

**セリン**：陛下、本日のご予定です。九時、定例の決裁。十時、地下牢の巡回。午後三時、宿敵のご来訪。

**魔王**：うむ。

**セリン**：それから、ご本人より伝言を預かっております。週休二日制を希望。討伐は毎週火曜の午後に固定。終了後は定時で退勤できること、とのことです。

**魔王**：……よかろう。

**セリン**：また、手加減は無用、とのことでした。

**ナレーション**：午後三時、正面の扉が開いた。金色の巻き髪、丸眼鏡、そして手には細身の剣。

**謎の応募者**：魔王、お覚悟を。

**ナレーション**：魔王は立ち上がり、マントを広げた。口上はすらすらと出た。あのひと口の水さえ、飲まずに済んだ。

**ナレーション**：彼女が繰り出したのは、ただの一手だった。彼の左側――マントの穴を繕ったほうへ回りこみ、彼が腕を上げたその瞬間、剣先で肩をそっと突いた。

**ナレーション**：三百年間、誰ひとり気づかなかった。彼の左肩が、あまり高く上がらないことに。

**謎の応募者**：陛下の負けです。

**魔王**：……ずるいぞ。

**謎の応募者**：企業研究は、入念にしてまいりましたので。

**ナレーション**：彼女は剣を収め、ずり落ちかけたかつらをそっと直した。

**謎の応募者**：では、また来週の火曜日に。それから、お昼はきちんと召し上がってください。今日もまた抜かれましたね。

**ナレーション**：彼女は正面の扉から出ていった。

**ナレーション**：五分後、通用口が開いた。セリンが盆を手に入ってくる。お茶が一杯と、弁当がひとつ。彼女はそれを玉座の肘掛けに置いた。

**セリン**：勇者様からのかぶが、本日届きました。お肉と一緒に煮込んでおきました。

**ナレーション**：魔王は弁当のふたを開けた。湯気がふわりと立ちのぼり、少し熱かった。

**魔王**：セリン。……ありがとう。

**セリン**：なぜ私にお礼を？　私はただの秘書ですが。

**ナレーション**：彼女の襟元には、また金色の髪が一本ついていた。

**魔王**：（心の声）来週の、火曜。

**ナレーション**：彼は箸を置き、ペンを取って、カレンダーの火曜日に赤い丸をつけた。
