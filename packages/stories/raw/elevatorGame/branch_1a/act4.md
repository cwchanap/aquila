# 第四幕：一樓

**旁白**：她按下一。

**旁白**：按鈕亮了。很淡的一圈橘光，像快沒電的燈泡，但它亮了。

**旁白**：門慢慢合上，左邊那扇還是慢半拍。走廊的紅光被夾成一條線，然後消失。

**旁白**：燈管閃了兩下，變回原本那種病懨懨的白。

**旁白**：九。八。七。

**旁白**：她沒有回頭。她盯著門縫，盯著那排紅色數字，聽著身後的水聲一滴一滴。

**旁白**：五。

**旁白**：電梯停了。門開了。

**旁白**：外面是五樓，普通的五樓，感應燈亮著，誰家門口晾著一把雨傘。一陣冷從她背後經過，擦過她的手臂。視線邊緣，那雙黑色平底鞋走出去，一步，兩步，沒有聲音。

**許念**：(內心)不要看。不要看她往哪裡走。

**旁白**：門關上。水聲停了。

**旁白**：四。三。二。

**旁白**：她終於敢看鏡子。

**旁白**：鏡子裡只有她。頭髮亂，眼睛紅，左邊的鞋帶鬆著。角落的地板是乾的。

**許念**：(內心)乾的。

**旁白**：叮。

**旁白**：大廳和她離開的時候一樣。燈管嗡嗡響，收音機還在播老歌，管理員的夾克還掛在椅背上。

**旁白**：她走出電梯，腿軟得像借來的。她扶著信箱牆，鐵皮的冰涼貼在掌心，那種冷很正常，很人間。

**許念**：(內心)回來了。期末報告。我愛期末報告。

**旁白**：櫃台上的電子鐘亮著綠色的數字。一點五十八分。

**許念**：(內心)壞了吧。這棟樓什麼都是壞的。

**旁白**：手機震了一下。方芮的訊息。

**旁白**：「我到大廳了，妳人呢？」

**旁白**：許念抬起頭。

**旁白**：大廳裡沒有人。櫃台後面沒有，信箱前面沒有，玻璃門外的騎樓也沒有。只有她，和她被燈管拉得很長的影子。

**旁白**：她撥過去。響一聲就通了。

**許念**：芮芮，我在大廳。

**方芮**：我也在大廳啊。

**旁白**：方芮的聲音很近，很清楚，還帶著哭過的鼻音。背景裡有日光燈的嗡嗡聲，還有收音機，在放同一首老歌。

**方芮**：妳剛剛不是從電梯走出來嗎？我看到妳了。妳就站在信箱那邊，背對我。

**旁白**：許念站在信箱前面。

**旁白**：她的手還貼在鐵皮上。

**方芮**：念念？妳轉過來啊。妳幹嘛不轉過來？

**許念**：(內心)如果妳走出去，不要回頭。

**許念** [scared]：(內心)可是我沒有走出去。我按了一。

**旁白**：她身後，電梯的門還開著。

**旁白**：有很輕的一聲。

**旁白**：滴。
