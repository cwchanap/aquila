# 第四幕：回家的人

**旁白**：她走了出去。

**旁白**：腳踩上磨石子地的那一刻，她才發現——沒有聲音。不是很小聲，是沒有。球鞋的膠底踩在地上，應該要有一點摩擦、一點回音，可是什麼都沒有，像走進一張照片。

**許念**：(內心)不要回頭。

**旁白**：身後，電梯門開始關。那個聲音她聽得見：左邊那扇慢半拍，喀，喀，合上。

**旁白**：然後是纜線。很長，很沉。往下。

**旁白**：兩邊的鐵門都關著，門牌被紅光吃掉了數字，只剩一塊一塊的空白。她一扇一扇走過去，然後停下來。

**旁白**：第三扇門。灰色的腳踏墊，角落被洗衣機壓出一個缺口。鞋櫃上一雙白色帆布鞋，鞋帶塞在鞋子裡——她的習慣，方芮念了她一整年。門把上掛著乾燥花圈，方芮在市集買的，買回來才發現顏色很醜。

**許念**：(內心)我家。九樓之三。

**許念**：(內心)這裡是十樓。

**旁白**：門裡面有聲音。

**旁白**：她踏進這條走廊以後聽見的第一個聲音。很悶，隔著鐵門，像隔著一層水。是方芮的笑，帶著哭過的鼻音。

**方芮**：妳嚇死我了妳知道嗎？電話講一半就不講話，我在大廳等了十分鐘……

**旁白**：另一個聲音回答她。有點沙，句尾往下掉，像沒睡飽。

**旁白**：「我不是回來了嗎。」

**旁白**：她自己的聲音。

**旁白**：她舉手敲門。指節撞在鐵門上，用力到骨頭發疼。

**旁白**：沒有聲音。

**許念** [scared]：芮芮！

**旁白**：她喊出來了。她感覺得到喉嚨在震，肺裡的空氣全部擠出去。可是走廊裡什麼都沒有，像那兩個字一離開嘴巴，就被誰接走了。

**方芮**：妳聲音怎麼怪怪的？

**旁白**：「感冒吧。」那個聲音說。「電梯裡很冷。」

**旁白**：腳步聲走近門邊。

**旁白**：貓眼暗了一下。有人從裡面往外看。

**旁白**：許念站在紅光裡，站在自己家門口，離那一小圈玻璃不到半公尺。她沒有後退，也沒有回頭。她看著它暗下去，又亮回來。

**旁白**：「沒人。」她的聲音說。「大概是隔壁。」

**旁白**：腳步聲走遠了。客廳的電視打開，罐頭笑聲響起來，一陣一陣，笑完了安靜，安靜完了再笑。

**許念**：(內心)同一段。

**旁白**：走廊的紅光沒有變。窗外沒有變。背後那個她不能回頭去看的方向，也什麼都沒有變。

**旁白**：身後很遠的地方，有人輕輕叫了一聲。

**旁白**：「念念。」

**旁白**：是方芮的聲音。

**許念**：(內心)有人叫名字，不要回頭應。

**旁白**：她把額頭靠在冰冷的鐵門上。

**旁白**：門的另一邊，有人用她的聲音說晚安。
