# 《電梯遊戲》The Elevator Game — 企劃

凌晨兩點，台北一棟四十年老大樓。大三學生許念睡不著，被室友方芮激了一句，就照著網路上流傳的「電梯遊戲」一個人搭電梯：依序按四、二、六、二、十，再按五；五樓若有女人走進來，不能跟她說話，不能看她的臉；之後按一，若電梯往上，就會抵達「另一個十樓」，那裡按鈕不再回應，想回來只能按一，只能按一次；走出去就不能回頭。方芮躲在九樓客廳的沙發上，全程只在電話裡。恐怖靠聲音、重複和細小的不對勁，不見血。五樓的女人整篇只開口一次，用的是許念的聲音。

## Endings

- **b1a「按一」**：她回來了——或者沒有。大廳一切照舊，時間沒動，方芮也在大廳，看得見她的背影，她卻看不見方芮；身後的電梯傳來一聲滴水。曖昧、不安。
- **b1b「走出去」**：她回到了「家」門口，在另一個十樓；有人戴著她的聲音先回家了，方芮沒有發現。只有她被留在無聲的紅光裡。恐懼，不見血。
