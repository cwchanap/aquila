# 第四幕：一階

**ナレーション**：彼女は一を押した。

**ナレーション**：ボタンが光った。切れかけの電球のような、ごく淡いオレンジの輪。それでも、光った。

**ナレーション**：ドアがゆっくりと閉じていく。左の扉はやはり半拍遅れる。廊下の赤い光が一本の細い線に挟まれ、そして消えた。

**ナレーション**：蛍光灯が二度ちらつき、もとの病人じみた白に戻った。

**ナレーション**：九。八。七。

**ナレーション**：彼女は振り返らなかった。ドアの合わせ目を見つめ、赤い数字の列を見つめ、背後で一滴、また一滴と落ちる水音を聞いていた。

**ナレーション**：五。

**ナレーション**：エレベーターが止まった。ドアが開いた。

**ナレーション**：外は五階だった。ごく普通の五階。人感センサーの明かりが点いていて、どこかの家の前に傘が一本干してある。冷たいものが彼女の背後を通り過ぎ、腕をかすめた。視界の端で、あの黒いフラットシューズが出ていく。一歩、二歩。音もなく。

**許念**：（心の声）見ちゃだめ。どっちへ行くのか、見ちゃだめ。

**ナレーション**：ドアが閉まる。水音が止んだ。

**ナレーション**：四。三。二。

**ナレーション**：ようやく、鏡を見る勇気が出た。

**ナレーション**：鏡に映っているのは彼女だけだった。髪は乱れ、目は赤く、左の靴紐はほどけたまま。隅の床は乾いていた。

**許念**：（心の声）乾いてる。

**ナレーション**：チン。

**ナレーション**：ロビーは、彼女が出ていったときのままだった。蛍光灯はジーッと鳴り、ラジオはまだ古い歌を流し、管理人のジャンパーも椅子の背に掛かったままだ。

**ナレーション**：エレベーターを降りる。脚に力が入らず、借り物のようだった。郵便受けの壁に手をつくと、金属の冷たさが手のひらに貼りついた。ごく普通の冷たさ。ちゃんと、この世の冷たさだった。

**許念**：（心の声）帰ってきた。期末レポート。愛してる、期末レポート。

**ナレーション**：カウンターの上のデジタル時計が、緑の数字を灯している。一時五十八分。

**許念**：（心の声）壊れてるんでしょ。このビルは何もかも壊れてる。

**ナレーション**：スマホが一度震えた。方芮からのメッセージだ。

**ナレーション**：「ロビー着いたよ。どこにいるの？」

**ナレーション**：許念は顔を上げた。

**ナレーション**：ロビーには誰もいなかった。カウンターの奥にも、郵便受けの前にも、ガラス扉の外のアーケードにも。いるのは彼女と、蛍光灯に長く引き伸ばされた彼女の影だけだった。

**ナレーション**：電話をかける。一回目のコールでつながった。

**許念**：芮芮、わたし、ロビーにいる。

**方芮**：わたしもロビーにいるよ。

**ナレーション**：方芮の声はすぐ近くで、とてもはっきりしていて、泣いたあとの鼻声がまだ残っていた。その後ろに、蛍光灯のジーッという音。それからラジオが、同じ古い歌を流している。

**方芮**：いまエレベーターから出てきたじゃん？　見えてるよ。郵便受けのとこに立ってるでしょ、こっちに背中向けて。

**ナレーション**：許念は郵便受けの前に立っていた。

**ナレーション**：手はまだ、金属に触れたままだった。

**方芮**：念念？　こっち向いてよ。なんで振り向かないの？

**許念**：（心の声）もし外に出たら、振り返っちゃだめ。

**許念**：（心の声）でも、わたしは外に出てない。一を押したのに。

**ナレーション**：彼女の背後で、エレベーターのドアはまだ開いていた。

**ナレーション**：ごくかすかな音がした。

**ナレーション**：ぽたり。
