# 第一幕：第一位客人

**旁白**：雨從黃昏開始下，到了亥時還沒有要停的意思。

**旁白**：山上的雨不是落下來的，是橫著掃過來的，一陣一陣拍在竹簾上，像有人在外面不耐煩地翻書。

**旁白**：小滿蹲在紅泥爐前，往炭裡添了一塊。砂銚裡的水剛開始冒泡，細細的，一粒一粒浮上來。

**溫伯**：蟹眼。還早。

**旁白**：師父沒有回頭。他坐在櫃台後面擦一只舊壺，擦了快一個時辰，壺早就亮得能照人了。

**小滿**：(內心)他今晚擦什麼都擦很久。

**旁白**：水聲變粗，泡泡大了一圈，翻上來就破。

**溫伯**：魚眼。溫壺。

**旁白**：小滿提起砂銚，把滾水澆在壺身上。熱氣騰起來，糊了她一臉。壺是紫砂的，比她還老，壺蓋上有一道金補的細裂，像一條睡著的蛇。

**旁白**：置茶，沖水，蓋上壺蓋，數到五。

**旁白**：第一泡，倒掉。

**旁白**：茶湯淌進茶盤底下的竹槽，琥珀色的，帶一點紅。

**小滿**：(內心)每次都覺得可惜。

**溫伯**：可惜？

**旁白**：小滿嚇了一跳。她什麼都沒說出口。

**溫伯**：妳倒第一泡的時候，嘴角都往下撇。七年了。

**溫伯**：茶葉一路曬、炒、揉、焙，沾了灰，沾了手汗，沾了路上的風。第一泡把這些帶走。總得有人替後面的先苦過一遍。

**小滿**：那它也太倒楣了。

**溫伯**：嗯。是倒楣。

**旁白**：師父放下舊壺，看了門口一眼。

**旁白**：門框上有三道刻痕。最低的是小滿的，旁邊歪歪扭扭刻了個「滿」字。上面兩道高得多，刻得很深，一個是「硯」，一個是「遲」。

**小滿**：(內心)問過一次是誰。那天他煮糊了一整壺茶。之後就不問了。

**旁白**：敲門聲。

**旁白**：三下，不輕不重，像是算好了力氣。

**旁白**：小滿拉開門閂。風雨灌進來，燈火矮了半截，又撐了回來。

**旁白**：門外站著一個男人。斗笠壓得很低，蓑衣往下淌水，背上用油布裹著一個長條的東西。

**小滿**：(內心)劍。裹得再厚，那個形狀都是劍。

**沈硯**：溫伯。

**旁白**：他沒有看小滿，越過她的肩膀，看著櫃台後面的老人。

**溫伯**：進來。地上濕，脫鞋。

**旁白**：男人頓了一下，好像這句話讓他想起了什麼。他彎腰脫鞋，把斗笠掛在門邊一根釘子上。那根釘子小滿從來不知道是做什麼用的。

**小滿**：(內心)現在知道了。

**旁白**：斗笠底下是一張三十歲上下的臉，眉骨很高，嘴唇抿得很緊，像一道收好的刀口。

**溫伯**：小滿，泡茶。

**旁白**：她回到爐邊重新溫壺。男人在靠窗那張桌子坐下，油布包橫放在膝上，沒有解開。

**沈硯**：他來了嗎？

**溫伯**：還沒。

**沈硯**：他會來嗎？

**溫伯**：會。這裡是他家。

**沈硯**：早就不是了。

**旁白**：師父沒接話。小滿把第一泡倒進竹槽，男人的視線跟著那道茶湯走了一段，又收回去。

**旁白**：第二泡，她用公道杯勻了，倒進他面前的小杯。

**沈硯**：天亮，一線關。

**溫伯**：我知道。他託人送來的信，我也看了。

**沈硯**：您不攔？

**溫伯**：我攔過你們一次。攔不住的東西，我不攔第二次。

**旁白**：男人端起茶杯，沒有喝，只是握著。熱氣從他指縫裡往上爬。

**沈硯**：十年前那一晚，我在關口跟白鷺門主的兒子比劍。他輸了。我收了劍，留了他一口氣。

**沈硯**：天亮，人死在原地。

**沈硯**：阿遲當夜就走了。帶走我的劍，留下他自己的，在門口刻了一句：人是我殺的。

**旁白**：他說這幾句的時候，聲音一點起伏都沒有，像在念一張別人寫的帖子。

**沈硯**：我不是來問為什麼的。十年夠久了，我只是來把事情做完。

**旁白**：他把茶喝了，杯底輕輕放回桌上，然後抬頭，第一次正眼看她。

**沈硯**：妳是？

**小滿**：小滿。

**沈硯**：節氣。

**溫伯**：撿到她那天是小滿。

**沈硯**：⋯⋯撿到我那天，他在磨墨。撿到阿遲那天，他去晚了一步。

**旁白**：他看著門框上那兩道刻痕，看了很久，然後起身上了閣樓。

**旁白**：油布包一直背在身上，沒有放下。

**小滿**：(內心)他背的是另一個人的劍。

**小滿**：(內心)背了十年。
