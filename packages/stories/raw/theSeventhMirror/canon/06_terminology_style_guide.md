## 2. 系統術語用語紀律（STYLE RULES）

下列規則直接引自 `final_polish.md §8`，為全書強制規範。

### 2.1 四條核心規則

1. **首次出現：中文解釋＋系統欄位。**
   當一個系統術語第一次在正文出現時，必須伴隨**人類可讀的中文解釋**，並在終端／文件脈絡中帶出英文系統欄位。讀者第一次接觸該詞時，必須能從中文句子理解它指什麼。

2. **後續正文：優先使用中文。**
   第一次解釋過後，敘述、對話、內心獨白**優先使用中文說法**。英文代碼只在必要時（例如該詞本就是專有名詞、或前後文緊鄰終端畫面）保留。

3. **終端畫面才使用英文欄位。**
   `TOKYO-7`、`M-00`、`G07／12`、`BCP CUTOVER`、`MAR-CONT`、`KAGAMI-01` 等英文欄位名，**只出現在螢幕、文件、紀錄、終端機顯示**等畫面元素中。正文敘述不得無故切換成英文代碼。

4. **不讓人物用作者層縮寫講話。**
   角色對話不得使用作者層級的縮寫或系統代稱（例如不能讓琴音說「`TOKYO-7` 的 lease 到期了」）。角色只能用他們認知範圍內的人類語言談論這些概念。作者層縮寫限於旁白與終端畫面。

### 2.2 一致性禁令

> **禁止同一概念在不同章使用三種未定義名稱。**（final_polish §8）

任何一個系統概念，全書累計**不得以超過兩種未定義名稱**出現。第三種出現前，必須先在正文裡完成中文解釋＋系統欄位的首次綁定。違反此規則的章節視為 canon 漂移，須在 Phase 5 對齊。

### 2.3 角色認知層級與語言（final_polish §1.2 / §7.2 / §7.3）

角色能說出哪些詞，受其循環認知層級限制：

| 角色 | 語言限制 |
|---|---|
| 澪 | 不在對話中使用 `TOKYO-7`、`M-00`、`KAGAMI`、`lease`、`continuity` 等作者層代碼；她用「東京方案」「母親」「那套系統」「他們那邊」稱呼 |
| 琴音 | **不得使用循環語言**（`這一輪`、`上一輪`、`下一輪`、`測試`）。canon_decisions A1 已鎖定。她只有低強度熟悉感，沒有輪次記憶 |
| 日下部 | 只有語言／方向／危險碎片；不得完整說出第二輪 |
| 千田 | 無前輪記憶；不得以第一人稱宣稱記得前輪（canon_decisions A1 Task 7-adjacent） |

部分概念有「對外普通名稱」與「真相內部名稱」兩層。前期只能使用對外名稱；內部名稱須等真相揭露章節才能出現。

## 4. 用語一致性檢查清單

撰寫或潤飾正文時，逐章對照下列檢查項：

- [ ] 本章是否出現本檔未登錄的新角色名稱？若有，先補登 `characters.md` 與本檔 §1。
- [ ] 本章首次出現的系統術語，是否完成「中文解釋＋系統欄位」綁定？
