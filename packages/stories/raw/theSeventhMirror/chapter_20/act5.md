# 第五幕：第一個接收者

```bg
Tsukuba research facility M-zone, controlled incident archive room, night, cold fluorescent lighting, long table with sealed document boxes and terminal screens, muted sterile palette, visual-novel background art, wide shot
```

**旁白**：00:05。同一間檔案室。鐵櫃的封條剛貼回去。法律顧問翻到目錄下一頁。凪原沒有離開。她站在原地。像從走進這間房間到現在，她的腳就沒有挪過位置。

**旁白**：指定專家的終端還亮著。日下部靠在牆上。他換了一個姿勢——左肩抵著牆面。不是放鬆。是身體在告訴他已經坐太久了。

**旁白**：澪的水杯空了。她沒有去倒。她看著凪原。

**朝倉澪** [exhausted]：（內心）⋯⋯她要說媽媽為什麼特殊了。⋯⋯為什麼是媽媽。為什麼不是其他十六個人。為什麼只有她能拼出完整的海。⋯⋯聽。先聽。

**凪原唯**：函館暴露者共十七人。事故後，多數暴露者出現以下反應——無法區分記憶來源。只記得碎片。出現混亂、失語或昏迷。七日後事件發生時，才知道自己曾提前看見部分內容。

**旁白**：她的聲音平。像在讀臨床摘要。不帶情緒。不帶判斷。

**凪原唯**：朝倉紗英不同。

**旁白**：她頓了一下。不是猶豫。是分段。像在論文裡換了一節。

**凪原唯**：她能分開記錄三種東西。過去。當下。尚未發生的片段。她的記錄有日期。有時間順序。有來源標記。其他暴露者——沒有。她的模式成為第一份穩定基準。

**朝倉澪** [determined]：（內心）⋯⋯過去。當下。尚未發生。⋯⋯媽媽能分開這三種。其他人不能。⋯⋯她不是最聰明的。她不是最強的。她只是——能分開。能記住哪個是記憶、哪個是現在、哪個是還沒來的。⋯⋯這就是「穩定」。這就是他們說的「基準」。⋯⋯能分辨的人——才能被當成參照。不能分辨的人——只能被當成樣本。

**日下部悟**：穩定基準。具體是什麼意思。

**凪原唯**：意思是——她的神經反應模式可以被其他模型引用。她能接收訊號。能翻譯。能輸出可重複的結構。其他暴露者的反應不穩定——每次接收的內容不同，無法建立可重複的參照。

**日下部悟**：所以你們用她的模式當標準。

**凪原唯**：是。

**旁白**：她沒有辯護。沒有補充。一個字。是。

**旁白**：法律顧問在目錄上寫了一行。指定專家在終端上打開了一份舊檔。程式碼截圖。黑白。字很小。

**指定專家**：早期程式欄位。名稱——MOTHER_REF_00。

**旁白**：螢幕上那幾個字。等寬字體。綠底黑字。像很久以前的終端機。

**朝倉澪** [shocked]：（內心）⋯⋯MOTHER_REF_00。⋯⋯Mother。Reference。⋯⋯母親。參照。⋯⋯不是 M-00。不是基準母體。最一開始——是 Mother Reference。⋯⋯母親參照。

**指定專家**：後來被行政文件翻成——基準母體。再簡寫為——M-00。

**旁白**：他念出來的時候沒有看任何人。他在看螢幕。在核對版本雜湊。

**凪原唯**：這個詞是工程術語。Mother Reference 指的是第一份可供後續模型引用的穩定基準。不是因為她是妳母親。

**旁白**：房間裡安靜了一秒。

**朝倉澪**：可是你們知道她是。

**旁白**：澪的聲音沒有升高。沒有發抖。她只是把那句話放在桌上。像放下一張查核報告。

**朝倉澪**：你們知道她是某個人的母親。你們知道她有兩個孩子。你們知道她被登記死亡了十年。你們用了「Mother」這個詞。然後你們說——不是因為她是母親。

**朝倉澪** [angry]：（內心）⋯⋯她說不是因為她是母親。她說是工程術語。⋯⋯也許一開始是。也許 Mother Reference 真的只是程式碼裡的命名習慣。⋯⋯可是它落在了一個真正的母親身上。一個有女兒的母親。一個有兒子的母親。一個被你們宣告死亡十年的母親。⋯⋯她說不是因為她是母親。可是她知道。她一直知道。

**旁白**：凪原看著澪。她的表情沒有變。眼鏡後面的眼神沒有波動。但她沒有立刻回答。她停了兩秒。像在確認要不要接這句話。

**凪原唯**：術語命名先於身分確認。這是事實順序。

**日下部悟**：記錄。術語命名——工程來源。身分確認——後續事實。兩者順序由文件支持。不由口述判斷。

**內閣法律顧問**：已記錄。

**旁白**：00:25。凪原從桌上拿起另一個文件夾。白色封面。比之前的都薄。她翻開。

**旁白**：裡面不是圖。是文字。列印。格式像研究摘要。頁首有一行標題。

**旁白**：高適配反應群備援研究。

**凪原唯**：國家並非十年毫無備援。

**旁白**：她的語氣切換了。從臨床摘要變成項目報告。像在讀另一份文件的不同章節。

**凪原唯**：曾製作數位模型。曾訓練其他接收者。曾建立合成參照。這些替代品在普通時段可以運作。接近回聲窗時——漂移。混淆記憶來源。生成模型自身的假未來。

**日下部悟**：假未來。

**凪原唯**：模型無法區分真實訊號片段和自身生成的預測。在回聲窗附近，訊號強度變化，模型的區分能力下降。它開始輸出自己編造的未來片段，而不是接收到的片段。我們稱之為漂移。

**指定專家**：這一項有離線模擬支持。數位備援在回聲窗附近確實出現漂移。模擬數據與凪原描述一致。

**日下部悟**：模擬能證明漂移存在。不能證明——真人備援也會漂移。

**指定專家**：不能。模擬只覆蓋數位模型。人類接收者的備援測試紀錄——不在這份材料裡。

**旁白**：凪原把那份研究摘要推向桌的中間。指定專家拿過去看。翻了兩頁。

**指定專家**：這份摘要不是凪原提供的。是警方在令狀範圍內保全的獨立文件。不依賴凪原口述。

**旁白**：他念出頁首的摘要內容。

**指定專家**：高適配反應群備援研究。目的——M-00 不可用時維持反應分類穩定。群組——G07。其他用途——遮蔽。

**朝倉澪** [shocked]：（內心）⋯⋯G07。⋯⋯悠真的編號。G07／12。⋯⋯備援。目的是——M-00 不可用時。維持穩定。⋯⋯他們在找替代品。媽媽不能用的時候。誰能替代。⋯⋯G07。悠真。⋯⋯其他用途——遮蔽。⋯⋯遮蔽是什麼。遮蔽了什麼。⋯⋯他不知道。指定專家也不知道。摘要只寫了「遮蔽」兩個字。沒有展開。

**日下部悟**：G07。這是朝倉悠真的編號。

**指定專家**：是。G07 是群組代碼。摘要將其列為高適配備援參照候選群。悠真具高適配背景。

**日下部悟**：能證明什麼。

**指定專家**：能證明——G07 至少有一項用途是尋找備援參照。悠真是高適配候選。

**日下部悟**：不能證明什麼。

**指定專家**：不能證明——備援是 G07 唯一用途。不能證明——研究合法或自願。不能證明——最終沒有公共記憶推送目的。

**旁白**：日下部記下了。三欄。能證明。不能證明。待查。

**旁白**：00:45。凪原合上摘要。她看著澪。第一次——她主動看向澪。不是被質問時的被動對視。是主動的。

**凪原唯**：妳的模式不同。

**朝倉澪** [determined]：什麼意思。

**凪原唯**：朝倉紗英能分開過去、當下和尚未發生的片段。悠真能接收但無法穩定輸出。妳——完整回送。整段敘事。多輪保留。這不是 G07 備援研究的設計目標。

**旁白**：她頓了一下。

**凪原唯**：妳的完整回送能力未被計畫掌握。

**朝倉澪** [shocked]：（內心）⋯⋯她說我的能力不在他們的計畫裡。⋯⋯完整回送。多輪保留。⋯⋯他們沒有見過。他們不知道為什麼。⋯⋯媽媽能分開三種時間。悠真能接收。我能——回來。整段。記住。⋯⋯三個人。三種能力。不一樣。⋯⋯她說未被計畫掌握。意思是——他們不知道我怎麼做到的。也不知道我還能做什麼。

**旁白**：01:05。檔案室。鐵櫃。封條。螢幕上的舊程式碼。MOTHER_REF_00。基準母體。M-00。G07。遮蔽。

**旁白**：澪看著那份白色封面的研究摘要。G07。備援。遮蔽。悠真的編號。弟弟的編號。出現在一份尋找媽媽替代品的研究裡。

**朝倉澪** [sad]：（內心）⋯⋯悠真畫的海。也許先在母親腦中出現過。⋯⋯他不是第一個看見那片海的人。媽媽才是。⋯⋯他畫的海——是媽媽翻譯過的海。是 M-00 標準化之後的海。⋯⋯他以為那是他自己的夢。⋯⋯可是那不是他的夢。那是媽媽的夢。被塞進模板。被塞進他腦裡。⋯⋯他以為自己在畫自己看見的東西。⋯⋯他畫的是媽媽替他看見的東西。

**旁白**：01:10。凪原把所有文件夾收回鐵櫃。封條貼回。法律顧問在目錄上簽了最後一行時間。

**旁白**：距下一次星期一 06:13——約五日五小時三分鐘。
