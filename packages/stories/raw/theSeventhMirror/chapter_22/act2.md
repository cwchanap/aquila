# 第二幕：兩條線還沒有分開

```bg
Tsukuba research facility M-zone, system security group workstation, mid-morning, multiple laptop screens showing KAGAMI-01 topology diagrams and dependency graphs, cold blue-white monitor glow, folding table covered with printed schematics, visual-novel background art, medium shot
```

**旁白**：09:00。系統安全組的工作區。

**旁白**：千田把螢幕轉過來。不是轉給澪看——澪坐在走廊盡頭，看不到這個螢幕。他轉給日下部和指定專家看。

**旁白**：螢幕上是一張拓撲圖。不是普通的網路圖。是 KAGAMI-01 的 CAL／PHASE 匯流排架構。

**千田浩介**：先看這張。

**旁白**：他用筆指著圖的最上方。

**千田浩介**：M-00。神經參照源。所有人都在看這裡。所有人都在想——M-00 把訊號往外送。往下送。送給臨床。送給公共。

**旁白**：他的筆往下滑。經過一個標著 KAGAMI-01 CAL／PHASE BUS 的方塊。然後分出兩條支線。

**千田浩介**：左邊。CLINICAL CAL BRANCH。臨床校準支線。下面掛著 G07 REMOTE 和 LEGACY HUMAN UNITS。右邊。CONSENSUS BRANCH。一致性支線。下面是 PUBLIC FANOUT。

**旁白**：他停了一下。然後他的筆回到 M-00 的位置。但他沒有停在那裡。他繼續往上畫。畫到 M-00 的上方。畫了一個箭頭。

**千田浩介**：重點在這裡。

**旁白**：箭頭從 KAGAMI-01 指回 M-00。方向是向上的。從鏡島回到紗英。

**千田浩介**：PHASE ERROR。ECHO SUPPRESSION。STABILITY RETURN。

**旁白**：他放下筆。看著日下部。

**千田浩介**：KAGAMI-01 不是單向管道。它和 M-00 之間是一個雙向閉環。M-00 向外提供穩定參照。鏡島沿同一條閉環把相位修正、回聲抑制和穩定刺激校準回傳給 M-00。

**千田浩介**：紗英多年來的神經和醫療穩定——已經依賴這個回傳。

**旁白**：日下部沒有說話。他在看圖。他的手指停在桌面上。

**指定專家**：確認。依存圖的離線副本顯示同一結構。M-00 的雙向依存不是推論。是架構層級的事實。

**旁白**：千田把螢幕切到下一頁。一張更簡化的圖。只有三個方塊和兩條線。

```text
M-00 ⇄ 共用穩定閉環
        ├── 遠端臨床校準
        └── 一致性層 → 東京公共輸出
```

**千田浩介**：簡化版。臨床和公共——在 COMMIT-GATE 之前——共用同一條上游閉環。還沒有分開。

**旁白**：他用筆在兩條支線的分岔點畫了一個圈。

**千田浩介**：安全方案本應在這裡先拆開。先替各臨床單元建立本地影子參照。再把臨床支線從共用閉環拆出來。保留 M-00 的醫療回傳。最後才切一致性層和公共 fanout。

**千田浩介**：可是 R4 所在的可能未來——不是在正常狀態下操作。是在極端失敗包絡裡。

**日下部悟**：先不講 R4。先把架構講完。

**千田浩介**：好。

**旁白**：千田切回完整拓撲圖。他指著雙向箭頭。

**千田浩介**：如果有人在這裡——在共用段——硬切。

**旁白**：他的筆在 M-00 和 KAGAMI-01 之間畫了一條橫線。像一把剪刀。

**千田浩介**：下游的臨床單元失去 M-00 的相位參照。遠端病人失去校準。同時——M-00 也失去鏡島回傳的穩定節奏。

**千田浩介**：兩邊一起斷。

**旁白**：走廊裡安靜了。外部醫療組的人抬頭看了一眼。然後低下頭繼續寫。他們不應該聽到這些。但走廊沒有隔音。

**朝倉澪** [exhausted]：（內心）我坐在走廊盡頭。我聽到了。他沒有說給我聽。但走廊沒有隔音。

**旁白**：千田的筆停在拓撲圖的雙向箭頭上。

**朝倉澪** [exhausted]：（內心）雙向。不是一條只從母親往外送的線。系統也一直沿著同一條線——把穩定她的節奏送回去。

**旁白**：她的背靠著牆。牆很涼。

**朝倉澪** [exhausted]：（內心）如果切斷——母親也會受傷。不只是別人。是母親。

**旁白**：09:20。千田開始列操作變體。他在螢幕上打字。一個一個。不刪除。不淘汰。不排序。

**旁白**：完整本地影子參照後切離。分批醫療移管。延長 CAL LOCK。取消 public route。封鎖 consensus branch。切公共末端。切一致性支線。切共用閉環。使本地簽署鏈失效。轉入離線保護模式。

**旁白**：十餘個變體。螢幕上的列表越來越長。每個變體旁邊標著前提、失敗點、公共風險和個體風險。

**指定專家**：變體之間有重疊。需要歸納。

**千田浩介**：歸納方式——按共同瓶頸和倫理結構。不按技術細節。

**旁白**：09:45。歸納開始。千田和指定專家把十餘個變體分成三堆。三個方案家族。

**旁白**：A 家族。完整安全切離。

**千田浩介**：A 家族的核心——所有活動接收者先完成身分與位置確認。個別醫療評估。建立各自本地影子參照。至少完成一個睡眠清醒週期的安全交接。然後把臨床支線從共用閉環拆出來。回收或失效全部離線授權載體。在 COMMIT-GATE 前停用一致性與公共路徑。

**旁白**：他頓了一下。

**千田浩介**：最符合 R1。傷害風險最低。

**旁白**：他翻到風險頁。

**千田浩介**：瓶頸——部分身分、位置與法人仍未知。每人影子參照必須個別生成，不能複製。高負荷真正出現在回聲窗附近，平時測試不足以證明星期一安全。缺失載體使最終配置可能被覆蓋。

**千田浩介**：星期一前未必能完成。

**旁白**：B 家族。保留過濾，延後或阻止提交。

**千田浩介**：B 家族——凍結 commit。保留 M-00 原始過濾。禁用 public route。延長 CAL LOCK。把提交推遲到回聲窗後。

**旁白**：風險頁。

**千田浩介**：不需立即硬切。可維持臨床閉環。問題——缺失載體可重授權。emergency override 可能恢復。本地狀態若被改寫，遠端凍結不足。一旦 commit 進入不可逆前段，B 家族失效。

**旁白**：C 家族。閉環硬切。

**千田浩介**：C 家族——切公共末端。切一致性支線。切共用 CAL／PHASE BUS。使本地簽署鏈失效。

**旁白**：他放下筆。他的聲音變平了。像在讀一份已經知道結論的報告。

**千田浩介**：只有最後一類——切共用閉環——在邏輯隔離不可驗證、本地重授權成功、commit 已逼近時，能高概率保證 public fanout 無法重新接通。

**千田浩介**：代價——M-00 與遠端高依存單元失去雙向穩定閉環。

**旁白**：10:30。三個方案家族的前提、失敗點、公共風險與個體風險全部列印。裝入三個信封。封口。編號。A-01。B-01。C-01。

**旁白**：日下部走過來。他看了一眼三個信封。然後他看著千田。

**日下部悟**：候選封存。解封需要三方在場。

**千田浩介**：可以。

**旁白**：指定專家在最後一頁簽名。千田在最後一頁簽名。日下部在最後一頁簽名。三個簽名。三層封緘。

**旁白**：信封被放進獨立保管箱。鎖扣扣上。喀的一聲。

**旁白**：10:45。走廊裡的氣氛鬆了一點。系統安全組的人靠在椅背上。外部醫療組還在寫。未來資料組早已合上資料夾——三頁元資料沒有什麼好整理的。

**旁白**：澪還坐在走廊盡頭。她聽到了大部分。不是全部。但足夠。

**朝倉澪** [exhausted]：（內心）三個家族。A 是最安全的。但星期一前做不完。B 是延後。但缺失載體可以把它推翻。

**旁白**：保管箱的鎖扣還扣著。喀的一聲留在走廊裡。

**朝倉澪** [exhausted]：（內心）C 是硬切。切斷共用閉環。母親和遠端病人一起斷。未來的我——在那個失敗包絡裡——選了 C。先讓悠真安全。然後切。不等待其他人。

**旁白**：她閉上眼睛。額頭靠著牆。牆很涼。和昨晚的玻璃一樣涼。

**朝倉澪** [exhausted]：（內心）兩條線還沒有分開。臨床和公共。病人和公共輸出。在 COMMIT-GATE 之前——它們共用同一條上游。

**旁白**：螢光燈的嗡聲填進安靜的走廊。

**朝倉澪** [exhausted]：（內心）所以切上游的時候——兩邊一起斷。不是選擇犧牲誰。是結構上無法只傷一邊。

**旁白**：11:05。日下部走到走廊中間。他的聲音不大。但所有人都聽到了。

**日下部悟**：候選封存完成。十分鐘休息。之後進入紅區評估。

**旁白**：澪睜開眼睛。她看著天花板。螢光燈的嗡聲沒有停。

**朝倉澪** [exhausted]：（內心）紅區。就是——如果硬切——誰會受傷。誰會被寫成代價。

**旁白**：距下一次星期一 06:13——約三日十九小時八分鐘。
