# 第三幕：一張家屬請求，怎麼變成施工門禁

```bg
Hospital safety conference room, morning, long table with laptops and printed evidence folders, large monitor showing work order chain diagrams, cold fluorescent lighting, muted institutional palette, visual-novel background art, wide shot
```

**旁白**：09:40。醫院安全會議室。長桌。螢幕。三台筆電。日下部坐在主位。指定專家坐在他旁邊。司法保全人員在角落記錄。澪坐在長桌末端。她面前沒有筆電。只有一杯水。

**旁白**：螢幕亮了。指定專家調出第一份資料。

**指定專家**：琴音的家屬應用——FAMILY-ASSIST。權限範圍。接收病人設備通知。完成家屬身分確認。申請臨床支援。參與照護流程。接收任務摘要。

**旁白**：他頓了一下。

**指定專家**：不能直接發出施工門禁。不能取得承包商制服。不能領用刀具。不能進入工程交接區。

**朝倉澪** [determined]：（內心）這是她的正常權限。只有這些。沒有更多。

**指定專家**：但她提交了一條請求。緊急臨床根恢復請求。從 FAMILY-ASSIST 介面發出。時間——第三輪星期一 20:47。

**旁白**：螢幕切換。下一份資料。

**指定專家**：請求被接收後——沒有進入正常臨床支援流程。而是被一個特權代理攔截。代理名稱——

**旁白**：螢幕上出現一行字。

**指定專家**：FAMILY-STABILITY／CASE-G07-03。ROLE——PRIVILEGED BROKER。OPERATOR ID——SEALED。

**朝倉澪** [shocked]：（內心）SEALED。操作者身分被封緘。前台日誌不顯示真人。只有案件別名。

**指定專家**：特權代理將琴音的緊急臨床根恢復請求——轉換為關聯承包商緊急臨床資產回收工單。

**旁白**：螢幕上出現工單鏈。請求。轉製。工單。三層。

**指定專家**：工單生成——一次性施工門禁。臨時承包人員路線。制服與工具櫃權限。任務推送至琴音家屬裝置。

**旁白**：他調出領用記錄。

**指定專家**：制服——維修服。工具袋——標準承包商配備。門禁——施工側門。一次性。時段——21:00 至 21:30。

**朝倉澪** [exhausted]：（內心）一張家屬請求。變成了施工門禁。變成了維修服。變成了工具袋。變成了——21:04 那個穿著維修服的人。

**旁白**：10:05。指定專家調出琴音裝置的二次驗證記錄。

**指定專家**：琴音的家屬裝置完成了工單的二次驗證。時間——20:55。裝置序號與琴音登記的設備一致。

**日下部悟**：裝置在她手裡。

**指定專家**：是。不是第三方代用。是她的裝置。

**旁白**：10:15。21:04 影像。施工側門。便衣。沒有完整臉部。身高。步態。穿著維修服。提著工具袋。

**指定專家**：影像中的進出時間、取件位置、封緘物外形——與工單編號相符。

**日下部悟**：工單。門禁。制服。工具。裝置二次驗證。影像。五條交叉。同一個人。

**朝倉澪** [exhausted]：（內心）五條。不是身高。不是步態。不是模糊側臉。是工單、門禁、制服、工具、裝置。五條。都指向同一個人。

**旁白**：10:30。日下部調出最後一份資料。角色代理套件的轉送通知模板。

**旁白**：螢幕上出現兩行字。

**指定專家**：HOLDER TRANSFERRED。DEFAULT RECEIVING——WANGAN CENTRAL。CLINICAL ROOT WITH PERSONAL EFFECTS。

**朝倉澪** [shocked]：（內心）灣岸中央。那些東西。她之前說過灣岸中央。我也聽她說過那些東西。她不應該知道這些。可是——模板在這裡。

**日下部悟**：這是支援套件的轉送通知模板。持有人受傷時——預設接收路徑是灣岸中央。臨床根隨私人物轉移。

**旁白**：他看了一眼澪。

**日下部悟**：這能解釋——琴音為何會知道灣岸中央。為何把千田的私人物稱作「那些東西」。

**朝倉澪** [determined]：可是——前輪的實際通知呢。

**日下部悟**：本輪沒有千田受傷轉送。不存在前輪事件訊息。模板存在——具體通知仍只存在於妳的記憶。

**朝倉澪** [exhausted]：（內心）模板在這裡。她對灣岸中央的熟悉感有來源。她把載體稱作「那些東西」也有來源。可是——第一輪和第二輪的實際通知——白光之後——不存在了。只剩她的片語回聲。和我的記憶。

**旁白**：10:50。會議室裡安靜了一陣。指定專家合上筆電。司法保全人員封存所有記錄。

**日下部悟**：11:10。正式詢問開始。琴音以成年人身分。辯護人在場。

**朝倉澪** [determined]：我不在場。

**日下部悟**：妳不在場。

**旁白**：11:10。正式詢問室。門關上了。澪站在走廊裡。她看不見裡面。她聽不見內容。只有門上方的一盞小燈亮著——紅色。表示詢問進行中。


**朝倉澪** [exhausted]：（內心）她在裡面。琴音在裡面。辯護人在她旁邊。日下部在對面。我在外面。

**旁白**：她坐在走廊的椅子上。椅子很硬。塑膠的。她什麼都不能做。只能等。

**朝倉澪** [exhausted]：（內心）不要回她。不要質問她。不要在病房裡展示懷疑。不要使用前兩輪記憶。讓程序走。讓程序走完。

**旁白**：12:05。門上的紅燈滅了。門開了。日下部走出來。他的表情沒有變。但他的腳步比進去時慢了半拍。

**旁白**：他在澪面前停下。他沒有坐下。他站著。

**日下部悟**：她取得辯護人。辯護人在場。她有限承認。

**朝倉澪** [determined]：⋯⋯她說了什麼。

**日下部悟**：她說——我穿了那件衣服。

**旁白**：他頓了一下。

**日下部悟**：她說——我去拿了東西。

**旁白**：再頓。

**日下部悟**：她說——我到交接點時，持有人沒有來。

**朝倉澪** [shocked]：（內心）持有人沒有來。千田沒有出現。第三輪——千田沒有去灣岸施工交接區。所以她只取走了載體。沒有發生衝突。沒有刀傷。沒有流血。

**朝倉澪** [exhausted]：（內心）可是她穿了那件衣服。她去了。她準備好了。

**日下部悟**：她沒有提到輪次。沒有說「這一輪」。沒有說「上一輪」。沒有說「又一次」。只說——那晚持有人沒有來。

**朝倉澪** [determined]：⋯⋯她知道自己是第幾輪嗎。

**日下部悟**：正式詢問不討論這個。辯護人在場。只談當輪可證事實。

**旁白**：12:10。司法保全人員從詢問室走出來。手裡拿著封存的筆錄。辯護人跟在後面。最後——琴音走出來。

**旁白**：她看見了澪。她停了一秒。她的嘴唇動了一下。什麼都沒說。她低下頭。跟著辯護人走了。

**旁白**：澪看著她的背影。她的肩膀很低。頭髮遮住了半邊臉。她走路的樣子——像一個很累的人。不是演戲的累。是真的累。

**朝倉澪** [exhausted]：（內心）她承認了。她承認穿了那件衣服。承認去拿了東西。承認到了交接點。可是——她沒有說為什麼。她沒有說美空。她沒有說支援代理。她只說了三句。然後——持有人沒有來。

**旁白**：12:20。休息。醫療換班。琴音和澪被分開。不以疲勞或探視權逼迫供述。

**旁白**：走廊。螢光燈。空的椅子。門上的紅燈已經滅了。

**旁白**：距下一次星期一 06:13——約二日十七小時五十三分鐘。
