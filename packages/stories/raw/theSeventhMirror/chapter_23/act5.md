# 第五幕：如果床上的是悠真

**旁白**：15:00。受控家屬會談室。不是詢問室。牆上沒有錄影紅燈。但角落的攝影機亮著。桌子比詢問室的小。四張椅子。琴音坐在左邊。辯護人坐在她旁邊。澪坐在對面。日下部站在門邊。

**旁白**：藤川真理坐在長桌末端。她的手放在膝蓋上。手指沒有握緊。也沒有鬆開。像一個人已經把所有力氣用完了，只剩下姿勢。

**旁白**：外部醫師先開口。他看著真理。

**外部醫師**：外部醫療確認。在替代橋接建立以前——不會拔除卡匣。這是醫療判斷。不是調查讓步。

**旁白**：真理點了一下頭。很慢。

**藤川真理**：⋯⋯好。

**旁白**：15:10。日下部把一份遮蔽過的決議放在桌上。面向琴音和辯護人。只有兩行可見。

**日下部悟**：多方安全會議決議。遮蔽版。

**旁白**：琴音低頭看。紙上的字很大。

**旁白**：G07／03。HIGH IRREVERSIBLE RISK。R4 STATUS。NOT PRE-AUTHORIZED。

**旁白**：琴音看著那兩行。她的嘴唇動了一下。沒有發出聲音。

**朝倉澪** [exhausted]：（內心）她在看。她在看 R4。她在看——能保護悠真、卻會把美空留在紅區的方案。她在看——它沒有被預授權。

**旁白**：辯護人看完後點頭。

**辯護人**：確認。安全披露範圍——只限直接關係美空設備安全的資訊。安全披露不等於不起訴或免責。

**旁白**：琴音沒有看辯護人。她還在看那兩行字。

**朝倉澪** [exhausted]：（內心）她還在看。她在看 NOT PRE-AUTHORIZED。她在看——有人已經拒絕過了。

**旁白**：15:20。琴音抬起頭。她看著澪。她的聲音很輕。但不是詢問室裡那種平的、空的聲音。是另一種。

**白石琴音** [sad]：美空九歲的時候——失蹤了兩天。

**旁白**：她停了一下。

**白石琴音** [sad]：找回來了。可是——沒有醒。之後就沒有醒過。

**朝倉澪** [exhausted]：（內心）九歲。四年。現在十三歲。長期意識障礙。一直在閉環上。

**白石琴音** [sad]：根憑證裝上去之前——中央參照中斷過一次。十三點四秒。

**旁白**：她的手指在桌面下收緊了。

**白石琴音** [sad]：她沒有本地影子。什麼都沒有。十三點四秒——呼吸、自律、腦電——全部嚴重失穩。她差一點——

**旁白**：她沒有說完。她把那句話吞回去了。

**朝倉澪** [exhausted]：（內心）差一點死掉。她差一點死掉。琴音親眼看過。十五歲。十五歲的琴音站在那裡——看著九歲的妹妹差一點停止呼吸。

**旁白**：會談室裡很安靜。空調的聲音很輕。

**白石琴音** [sad]：所以——任何人要拿走根憑證——我不能再讓那十三點四秒發生。

**旁白**：她看著澪。直直地看著。

**白石琴音** [sad]：如果床上的是悠真——妳也會做。

**旁白**：澪沒有立刻回答。她看著琴音的眼睛。琴音的眼睛裡沒有攻擊。沒有計算。只有——一個已經把所有退路都用完的人，把最後一張牌推出來。

**朝倉澪** [exhausted]：（內心）她問我。如果床上的是悠真。如果悠真十三歲。長期意識障礙。閉環上。有人要拿走唯一撐住他的東西。

**旁白**：她的喉嚨很乾。

**朝倉澪** [exhausted]：（內心）我會做嗎。我會穿上那件衣服嗎。我會去拿那個東西嗎。我會帶著刀去阻止一個可能不肯交出來的人嗎。

**旁白**：她閉了一下眼睛。

**朝倉澪** [exhausted]：我知道。

**旁白**：她睜開眼睛。

**朝倉澪** [exhausted]：我已經做過選擇了。

**旁白**：琴音的表情沒有變。但她的肩膀——鬆了一點。不是放鬆。是——第一次，她沒有被拒絕。

**朝倉澪** [exhausted]：R4 能保護悠真。

**旁白**：她頓了一下。

**朝倉澪** [exhausted]：美空和紗英在紅區。如果 R4 預授權——她們會成為代價。

**旁白**：她看著琴音。

**朝倉澪** [exhausted]：我已經反對過了。我反對讓它成為預授權路線。

**旁白**：琴音看著她。看著她。看了很久。

**朝倉澪** [exhausted]：（內心）她在確認。她不是在確認我比較善良。她在確認——我是不是真的拒絕過一項能保護悠真、卻會傷害美空的東西。

**旁白**：琴音的手指在桌面下鬆開了。不是因為釋懷。是因為——她第一次失去了確定性。她一直相信所有外部調查者都會為了自己的家人犧牲美空。現在她面前的人——已經用正式程序拒絕過了。

**白石琴音** [shocked]：⋯⋯妳拒絕了。

**朝倉澪** [exhausted]：是。

**旁白**：會談室裡很安靜。琴音低下頭。她的頭髮垂下來。遮住了她的臉。

**旁白**：15:45。日下部看了一眼時間。他沒有催。他站在門邊。像一堵牆。

**旁白**：澪看著琴音。她知道——這不是正式詢問。這是會談室。這裡可以說正式詢問裡不能說的話。

**朝倉澪** [exhausted]：琴音。

**旁白**：琴音沒有抬頭。

**朝倉澪** [exhausted]：我記得另外兩次發生了什麼。

**旁白**：琴音的手指停住了。

**朝倉澪** [exhausted]：那不能拿來定妳的罪。但我不能假裝自己沒看過。

**旁白**：琴音沒有說話。她的肩膀很僵。她的呼吸很淺。

**朝倉澪** [exhausted]：（內心）她不會承認。她不能承認。前兩輪的傷害不能冒充當輪物證。可是——我必須讓她知道。我知道。我不是只看見這一次。

**旁白**：16:00。藤川真理一直沒有說話。她坐在末端。她的眼睛看著琴音。看了很久。

**旁白**：然後她開口了。聲音很輕。很平。像在陳述天氣。

**藤川真理** [sad]：妳為什麼不告訴我？

**旁白**：琴音抬起頭。她看著母親。她的眼睛紅了。但沒有眼淚。

**白石琴音** [sad]：因為妳會叫我停。

**藤川真理** [sad]：我讓妳陪她。不是讓妳替她決定該犧牲誰。

**旁白**：琴音沒有回答。她的嘴唇抿成一條線。她的手在桌面下握著自己的手腕。很緊。

**朝倉澪** [exhausted]：（內心）短。很短。三句話。可是——這三句話比我在詢問室裡聽到的所有承認都重。母親第一次知道。女兒瞞了她。女兒替她做了不該由她獨自做的選擇。

**旁白**：16:15。辯護人看了一眼時間。他輕聲說。

**辯護人**：休息。

**旁白**：日下部點頭。琴音站起來。她的膝蓋很僵。她沒有看澪。也沒有看真理。她跟著辯護人走出會談室。門關上。

**旁白**：真理還坐在原位。她的手還放在膝蓋上。她看著空了的椅子。

**藤川真理** [sad]：⋯⋯她從十五歲就開始了。

**旁白**：澪沒有回答。她不知道該說什麼。

**朝倉澪** [exhausted]：（內心）十五年。十五歲開始陪美空。十五歲開始學設備照護。十五歲開始——替母親承擔不應該由她獨自承擔的選擇。四年。她只有十九歲。

**旁白**：16:25。真理站起來。她走向門口。她停了一下。沒有回頭。

**藤川真理** [sad]：⋯⋯她說得對。我會叫她停。

**旁白**：她走了。門關上。會談室空了。攝影機的燈還亮著。

**旁白**：16:30。澪坐在原位。她的手放在桌面上。指尖碰著桌面的邊緣。很輕。像在確認什麼是實的。

**朝倉澪** [exhausted]：（內心）如果床上的是悠真。我也會做。我已經看過我會怎麼做。這是真的。這是我能給她的唯一誠實。

**旁白**：空調的聲音填進會談室的縫隙。

**朝倉澪** [exhausted]：（內心）可是——理解她的動機，不代表千田可以被傷害。不代表憑證濫用沒有發生。不代表載體取走沒有責任。

**旁白**：她站起來。膝蓋很僵。她走向門口。

**朝倉澪** [exhausted]：（內心）她動搖了。不是因為我比較善良。是因為——我已經拒絕過了。她第一次遇到一個不會為了自己的家人犧牲美空的人。

**旁白**：她打開門。走廊的螢光燈和會談室一樣亮。

**旁白**：距下一次星期一 06:13——約二日十五小時十三分鐘。
