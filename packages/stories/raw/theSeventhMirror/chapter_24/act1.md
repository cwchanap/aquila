# 第一幕：第五版不寫一個人的名字

**旁白**：06:30。臨時共同安全會議室。星期六。第三輪。悠真失蹤事件第十二日。

**旁白**：澪睡了不到三個小時。不是在床上。是在會議室角落的摺疊椅上。有人替她蓋了一條薄毯。她不記得是誰。醒來的時候毯子滑到地上。螢光燈已經亮了。

**朝倉澪** [exhausted]：（內心）06:30。距星期一 06:13。約一日二十三小時四十三分。還在倒數。

**旁白**：會議室被重新整理過。昨晚的證物袋都封好了。長桌。筆電。封好的文件。牆上的螢幕亮著——版本系統的介面。最上面一行。

**旁白**：KAGAMI-SAFE／R5。

**旁白**：下面是一排空欄位。第一個。

**旁白**：AUTHOR。

**旁白**：06:35。人陸續到了。日下部坐在澪對面。他的罐裝咖啡沒有打開。外部醫師坐在末端。獨立系統安全人員站在螢幕旁邊。患者權利代表坐在另一側——她昨晚就到了。獨立的。不隸屬任何一方。司法保全在門邊。院內臨床保管方在角落。千田透過遠端音訊連線。喇叭裡有很輕的電流聲。

**旁白**：凪原唯坐在長桌的另一端。內閣法律顧問在她旁邊。她沒有看螢幕。她在看桌面。

**朝倉澪** [exhausted]：（內心）她還在。她還沒有被問詢。她在這裡——因為她的職務體系和這份文件有關。可是她不能簽。她不是患者權利。不是外部醫療。不是系統安全。她是——設計了舊系統的人。

**旁白**：06:40。獨立系統安全人員把螢幕上的空欄位投射到牆上。AUTHOR。空白。游標在閃。

**獨立系統安全人員**：版本系統要求填入作者。R5 需要一個 AUTHOR 欄位。

**旁白**：房間裡安靜了一秒。然後——所有人看向澪。

**朝倉澪** [exhausted]：（內心）他們看我。所有人。外部醫療。系統安全。司法保全。患者權利代表。甚至——凪原也抬起了頭。他們看我。因為我拒絕了 R4。因為我提出了替代方案。因為我推動了美空的局部影子。因為——他們覺得這份文件應該由我寫。

**旁白**：她看著螢幕。AUTHOR。空白。游標在閃。像在等一個名字。

**朝倉澪** [determined]：不。

**旁白**：她的聲音不大。但會議室裡只有空調的聲音。

**朝倉澪** [determined]：第四版就是因為只有一個人知道得太多，才會變成那樣。

**旁白**：沒有人反駁。外部醫師點了一下頭。很輕。像在確認一個臨床判斷。

**朝倉澪** [exhausted]：（內心）R4。預授權。一個人可以決定所有患者的去留。一個人可以覆寫醫療。一個人可以代替所有人說「可以」。那就是——母體。不是紗英。是權力本身。如果 R5 也由一個人寫——它只是換了一個母體。

**旁白**：06:45。千田的聲音從喇叭裡傳出來。很穩。像在讀文件。

**千田浩介**：工程方不單獨署名。

**旁白**：他頓了一下。

**千田浩介**：R2 是我一個人設計的。R2 的公共授權與臨床根放在同一個卡匣——是我的決定。控制方利用了這一點。如果 R5 也只由工程方署名——它會重複同樣的錯誤。技術作者不能自動取得患者決定權。

**旁白**：外部醫師接上來。他的語氣很平。臨床的。

**外部醫師**：技術作者負責規格的正確性。不負責患者的醫療判斷。不負責患者是否同意。這是兩件事。不能因為一個人寫了文件——就假定他替患者做了決定。

**朝倉澪** [exhausted]：（內心）他說的對。千田寫了 R2。R2 被利用了。不是因為千田是壞人。是因為——一個人的名字放在 AUTHOR 欄位上，就等於把所有責任和所有權力集中在一個人身上。然後——那個人就變成了瓶頸。變成了弱點。變成了可以被替換、被繞過、被脅迫的單點。

**旁白**：06:50。患者權利代表開口。她的聲音溫和但精確。每一個字都像在測量過之後才放下的。

**患者權利代表**：委員會多數也不能替患者同意。即使在場所有人都投同一個方向——也不構成患者本人的同意。患者權利不是多數表決的結果。每一名患者的資料用途、撤回與安全暫停，必須由患者本人或獨立代表確認。任何模糊均被解讀為不授權。

**旁白**：她頓了一下。

**患者權利代表**：因此 AUTHOR 欄位不能由單一人填入。也不能由在場多數代填。它必須反映——起草、審查、同意、保全和執行是不同權限。由不同人持有。

**朝倉澪** [exhausted]：（內心）她說的不是抽象原則。她說的是——紗英。如果這份文件由一個人寫，那個人就會替紗英決定她的資料怎麼用。替美空決定她的影子怎麼驗證。替葵決定她什麼時候可以被找到。一個人。一個名字。一個 AUTHOR。

**旁白**：06:55。日下部站起來。他走到螢幕前。他沒有碰鍵盤。他只是指著空欄位。

**日下部悟**：AUTHOR——改。

**旁白**：獨立系統安全人員點頭。他在鍵盤上輸入。游標移動。AUTHOR 被刪除。替換。

**旁白**：螢幕上出現新的欄位。

```text
AUTHORSHIP                         FEDERATED／NO SINGLE OWNER
DRAFTED BY                         MEDICAL + SYSTEM SAFETY
PATIENT-RIGHTS ATTESTATION         REQUIRED
LEGAL／EVIDENCE ATTESTATION        REQUIRED
OPERATIONS ATTESTATION             REQUIRED FOR PUBLIC CHANGES
```

**獨立系統安全人員**：AUTHORSHIP——FEDERATED。NO SINGLE OWNER。起草由外部醫療與獨立系統安全共同負責。患者權利證明、法律司法證明、公共營運安全證明——各自獨立。不可由其他人替代。

**旁白**：他頓了一下。

**獨立系統安全人員**：不是多數表決。是——每一項權限只能由真正擁有該權限的人簽自己的部分。

**朝倉澪** [exhausted]：（內心）聯邦式。不是一個名字。是一組名字。每一個名字只簽自己有權簽的那一行。醫師不能替系統安全簽。系統安全不能替患者同意。家屬不能替其他患者。警方不能替醫療判斷。公共營運不能替患者權利。任何一個領域缺席——相關範圍便不能生效。

**旁白**：07:05。獨立系統安全人員繼續輸入。螢幕上的欄位一行一行出現。

```text
TARGET CENTRAL DYNAMIC REFERENCE   NONE
TRANSITION INPUTS                 MULTI-SOURCE／M-00 ENDPOINT LIMITED／REVOCABLE
PATIENT ROOT                       PATIENT-BOUND／LOCAL

PATIENT SAFETY ENVELOPE            LOCAL／PATIENT-SPECIFIC
NETWORK TRANSITION ENVELOPE        NON-SEMANTIC／EXPIRING

RAW NEURAL EXPORT                  PROHIBITED
R5 PUBLIC PRIVILEGE                NONE

TARGET PUBLIC DOMAIN               SEPARATED
CURRENT TOKYO PUBLIC DOMAIN        EXTERNAL HOLD／NOT CONTROLLED BY R5

TARGET CENTRAL FAILBACK            HUMAN-AUTHORIZED
CURRENT CENTRAL FALLBACK           ACTIVE／PATIENT-SPECIFIC

STATUS                             PROVISIONAL
VALIDATION                         PASSIVE／STAGE-1
ACTIVE SWITCH                      PROHIBITED
```

**旁白**：澪看著螢幕。TARGET 和 CURRENT。分開。兩行。並排。

**朝倉澪** [exhausted]：（內心）TARGET CENTRAL DYNAMIC REFERENCE——NONE。目標。沒有中央動態母體。CURRENT CENTRAL FALLBACK——ACTIVE。現況。中央回退仍在運作。目標和現況不是同一行。不能寫成同一行。不能假裝目標已經是現況。

**旁白**：07:10。外部醫師指著螢幕上的兩行。

**外部醫師**：目標——無中央動態母體。現況——中央回退仍在運作。這兩行必須分開。不能把目標寫成已生效的現況。患者仍在中央閉環上。美空仍在使用中央 fallback。紗英仍在雙向穩定閉環中。R5 不能假裝這些已經不存在。

**朝倉澪** [determined]：（內心）他說的對。如果 R5 寫 MOTHER_REFERENCE = NONE——那就是謊話。不是目標的謊話。是——把目標偽裝成現況的謊話。第四版就是這樣。它把「一個人可以決定所有患者」寫成已經生效的授權。R5 不能犯同樣的錯。

**旁白**：07:15。凪原抬起頭。她第一次看著螢幕。她的表情沒有變化。但她的手指——在桌面下收緊了一下。

**凪原唯**：目標無中央動態母體。現況仍在過渡。這份文件——誠實嗎？

**外部醫師**：它區分了目標與現況。這比 R4 誠實。

**旁白**：凪原沒有追問。她低下頭。回到桌面。

**朝倉澪** [exhausted]：（內心）她問的不是技術問題。她問的是——如果目標是沒有母體，那她設計的系統算什麼？她花了十年維護的東西算什麼？答案——算過渡。算正在被拆除的東西。不是被否定。是被——規定怎麼拆。

**旁白**：07:20。獨立系統安全人員完成最後一個欄位。他退後一步。看著螢幕。

**獨立系統安全人員**：R5 標頭完成。PROVISIONAL。PASSIVE。STAGE-1。ACTIVE SWITCH PROHIBITED。不聲稱無母體現況已完成。不聲稱可承受完整回聲窗。不聲稱所有患者可在星期一前切離。

**旁白**：他頓了一下。

**獨立系統安全人員**：R5 PUBLIC PRIVILEGE——NONE。R5 自身沒有公共權限。沒有 public fanout。沒有一致性層。沒有 Domain-P。沒有將患者資料送入公共提示的路徑。東京公共域仍由外部 hold 控制。不被 R5 接管。

**朝倉澪** [exhausted]：（內心）沒有公共權限。R5 不是新的中央。它不是——取代舊母體的新母體。它是一份過渡規格。規定怎麼拆。規定每個人只簽自己的部分。規定目標和現況不能混在一起。

**旁白**：07:25。會議室裡安靜了一陣。空調的聲音填進來。螢幕上的欄位還亮著。游標不再閃。AUTHORSHIP——FEDERATED。NO SINGLE OWNER。

**旁白**：澪看著那行字。她想起第四版。R4。預授權。一個人的名字。一個人可以覆寫所有人。一個人可以決定誰被寫成代價。

**朝倉澪** [exhausted]：（內心）第五版的設計裡沒有母體。但所有人仍在母體留下的系統裡。

**旁白**：07:30。日下部在記錄上寫下最後一行。

**日下部悟**：R5 標頭建立。AUTHORSHIP FEDERATED。目標與現況分開。PROVISIONAL。主動切換禁止。下一步——紗英的限制性同意。

**旁白**：他簽名。時間戳。司法保全在門邊記錄。每一項。時間戳。

**旁白**：07:35。會議室裡的人開始站起來。外部醫師收起夾板。患者權利代表整理她的文件。獨立系統安全人員關掉螢幕。螢光燈還亮著。

**朝倉澪** [exhausted]：（內心）沒有母體。不是——已經沒有母體。是——設計裡不再有一個母體。目標裡不再有。可是現況裡——紗英還在閉環上。美空還在中央 fallback。葵還沒有被找到。所有人仍在母體留下的系統裡。今天的任務——不是假裝已經離開。是——規定怎麼離開。

**旁白**：07:40。澪站起來。膝蓋很僵。她看了一眼螢幕。暗了。最後的畫面還殘留一秒。AUTHORSHIP。FEDERATED。NO SINGLE OWNER。

**旁白**：她走向門口。走廊的螢光燈和昨天一樣亮。和每一輪一樣亮。

**旁白**：距下一次星期一 06:13——約一日二十二小時三十三分鐘。
