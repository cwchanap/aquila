# 第六幕：營運方沒有失聯

**旁白**：15:40。公共營運安全室。不是 C2。是另一棟樓的另一間房。牆上三個螢幕。法院。醫療聯盟。媒體安全編輯室。桌上筆電。封好的文件。Manifest 的草稿在主螢幕上。

**旁白**：澪坐在桌邊。日下部在她對面。獨立系統安全人員站在螢幕前。佐伯達也坐在側邊——他負責家屬證據的驗證與遮蔽審查。藤川真理在另一側。她的手裡捏著一張紙。是美空的夢話錄音文字。

**朝倉澪**：（內心）15:40。距 23:50——約八小時十分。Manifest 還沒公開。草稿在螢幕上。核心頁。普通人可讀的摘要。封緘附件分開。多方簽署——每一方只簽自己的事實。

**旁白**：15:50。獨立系統安全人員把核心頁投射到牆上。

**獨立系統安全人員**：公開核心頁。package——TOKYO-7 bundle hash。operations status——present。authorization——denied。ordinary services——active。protective filtering——active。TOKYO-7 denied。public action required——none。

**旁白**：他頓了一下。

**獨立系統安全人員**：不顯示六之七。不顯示 S7。不顯示 HSM 類型。不顯示撤回路由。只顯示——revocation issued。not fully acknowledged。

**旁白**：16:00。佐伯達也看著螢幕。他的手指在桌上點了一下。像在核對清單。

**佐伯達也**：公開摘要——普通防災警報、交通服務、保護性訊號過濾仍正常。被拒絕的是指定 TOKYO-7 套件。公眾不需前往任何設施。這三句夠了。

**旁白**：藤川真理抬起頭。她的聲音很輕。像已經說過太多次。

**藤川真理** [determined]：夠了嗎。只說「被拒絕」——媒體會寫「真偽未定」。主管機關會說「未完成調查」。如果——

**旁白**：她停了一下。她看著澪。

**藤川真理** [determined]：如果把我們知道的全放進去呢。澪記得千田死過兩次。R4。她知道 06:13 會發生什麼。如果把它放進證據——放進 Manifest——媒體就不能只寫「真偽未定」了。

**旁白**：房間裡安靜了一秒。佐伯的眉頭壓低了。他沒有立刻反駁。他看著澪。

**朝倉澪**：（內心）她看著我。她不是在提議。她是在——求。她的女兒還在昏迷。她保存著美空的夢話錄音。她比任何人都想讓世界聽見。她認為——如果我把記得的一切放進去——世界就會相信。可是——

**旁白**：16:05。澪看著藤川。然後她看著螢幕。Manifest 的草稿。operations status——present。authorization——denied。

**朝倉澪** [determined]：那是我知道的，不是現在所有人能共同證明的。

**旁白**：她的聲音不大。可是房間裡只有空調的聲音。

**朝倉澪** [determined]：不能因為這次我相信自己，就把它寫成所有人必須相信的證據。

**旁白**：藤川的手指在紙上收緊了。她沒有說話。她的嘴唇動了一下。然後——她低下頭。

**朝倉澪**：（內心）我記得千田死過兩次。我記得 R4。我記得 06:13。可是——只有我記得。只有我能從裡面確認。交通紀錄不能驗證它。醫院資料不能驗證它。法院不能驗證它。營運方不能驗證它。如果我把它放進公共證據——它就不是證據了。它變成——所有人必須相信我的話。那和 R4 有什麼不同。一個人知道得太多。一個人的全貌變成所有人的真相。我不能做那件事。

**旁白**：16:10。佐伯點了一下頭。很輕。像在確認一個證據等級判斷。

**佐伯達也**：跨輪記憶——不列入公共事實證據。只列入受保護調查附錄。供當輪行動風險判斷。不供公開。

**旁白**：他頓了一下。

**佐伯達也**：公共證據只用當輪可共同驗證的資料。交通。門禁。工單。醫院轉移。患者依存。法院與醫療 hold。bundle hash。營運拒絕。

**旁白**：16:20。獨立系統安全人員完成核心頁。多方簽署範圍確認。公共營運方——operations present。bundle authorization denied。ordinary services active。法院——hold 有效。外部醫療——患者依存未解除。raw filter 仍需維持。患者權利代表——未完成個別安全切離。獨立系統安全——exact bundle hash。公開欄位與封緘附件一致。

**旁白**：16:35。Manifest 上線。核心頁。公開。

**旁白**：螢幕上的最後一行亮著。public action required——none。

**旁白**：16:40。主管機關發布反駁。不是長文。是一段制式聲明。文件屬未完成調查資料。公開可能危害患者與關鍵基礎設施安全。

**旁白**：公共營運方以自身簽章回應。不是透過澪。不是透過日下部。是——營運方自己的簽章。普通警報、交通調度與原始訊號過濾仍正常。被拒絕的是具體 TOKYO-7 bundle。

**旁白**：17:00。媒體反應分裂。部分媒體先只發布 Manifest 原文。部分要求核驗 bundle hash 後才報道。部分接受主管機關說法——暫稱文件「真偽未定」。授權安全編輯室可查驗封緘附件。不能公開患者位置及 HSM 路由。

**朝倉澪**：（內心）分裂。不是勝利。不是失敗。是——分裂。有人相信。有人等。有人說「真偽未定」。這就是公開。公開不是按下一個輿論勝利按鈕。是——把事實放出去。然後——等它被核驗。等它被反駁。等它被分裂。等它自己站穩。

**旁白**：17:20。第七曙光的視訊連線進來。家屬那端。不只佐伯和藤川。還有其他家屬。聲音交疊。

**旁白**：有人希望公開所有姓名。有家屬說——孩子已經失蹤這麼久了。如果連名字都不公開——世界怎麼會知道他們存在。

**旁白**：醫療與患者權利代表要求繼續遮蔽。公開精確位置會讓患者暴露。公開姓名可能讓未成年人被重新識別。

**旁白**：佐伯的聲音從視訊傳出來。短。像在讀清單。

**佐伯達也**：患者安全優先於即時輿論效果。

**旁白**：他頓了一下。

**佐伯達也**：名字留到 06:13。不是因為不重要。是因為——現在公開名字，保護不了他們。只會讓他們被消費。

**旁白**：17:40。最終選擇。患者安全與共同可驗證性——優先於即時輿論效果。姓名繼續遮蔽。位置繼續遮蔽。Manifest 只證明拒絕。不證明誰在裡面。

**朝倉澪** [exhausted]：（內心）這是對的。可是——不容易。藤川低下頭的時候。有家屬在視訊裡沉默的時候。他們想讓世界知道自己的孩子存在。他們等了太久。可是——現在公開名字——保護不了他們。只會讓他們變成另一條新聞。另一個留言。另一個被消費的名字。06:13。06:13 才是——那些被當成代價的人，自己被世界聽見的時刻。不是一份文件。是——他們自己。

**旁白**：17:50。澪看著螢幕。Manifest 還亮著。operations status——present。authorization——denied。ordinary services——active。protective filtering——active。TOKYO-7 denied。public action required——none。

**旁白**：核心句在摘要的最上面。

**旁白**：營運方沒有失聯。它正在拒絕。

**朝倉澪** [exhausted]：（內心）營運方沒有失聯。它正在拒絕。可是——23:50。舊 continuity HSM 不認得這個拒絕。它只認得——有或者沒有。它會把我們的「不」——重新命名成「沒有」。然後——用替代份額填上去。Manifest 讓世界知道我們在拒絕。它不能讓系統聽見我們在拒絕。

**旁白**：18:10。日下部收起文件。他看著螢幕上最後一行。public action required——none。他沒有說話。他把椅子推回桌邊。

**旁白**：他走了。門關上。腳步聲在走廊裡變遠。

**旁白**：距下一次星期一 06:13——約十二小時三分鐘。
