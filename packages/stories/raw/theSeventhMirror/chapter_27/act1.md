# 第一幕：只一起對時

```bg
KAGAMI command room, wall of eight patient node panels transitioning from HOLD to ANNOUNCE status, center console displaying distributed switch clock epoch announcement, pre-dawn grey light bleeding through reinforced window edges, cold fluorescent lighting mixing with faint grey, muted cool palette, visual-novel background art, wide shot
```

**旁白**：05:50:00。KAGAMI 指揮。螢幕中間。一行字。

**旁白**：冷氣太強了。澪的肩膀從凌晨三點就沒放下來過，現在已經僵成兩塊石頭。螢幕的冷光打在她臉上，把眼底的青黑照得更深。

**旁白**：DISTRIBUTED SCHEDULE EPOCH — ANNOUNCED。LOCAL EXECUTION。

**朝倉澪** [exhausted]：（內心）05:50。來了。

**朝倉澪** [exhausted]：（內心）不是 anchor。不是 fanout。是——epoch。只是 epoch。

**旁白**：八個 patient node 窗格同時變化。不是同時變成同一個畫面。是——每個窗格各自開始讀自己預載的 signed local schedule。各自的 monotonic clock。各自的 skew 檢查。

**旁白**：螢幕上。一個一個。很慢。像八個人在各自的房間裡各自翻開各自的課表。

**旁白**：M-00——SCHEDULE HASH MATCH。LOCAL CLOCK VERIFIED。CLOCK SKEW WITHIN LIMIT。STAGE CEILING VERIFIED。MEDICAL GO YES。ACK TYPE PATIENT-NODE。

**旁白**：G07／03——SCHEDULE HASH MATCH。LOCAL CLOCK VERIFIED。CLOCK SKEW WITHIN LIMIT。STAGE CEILING VERIFIED。MEDICAL GO LIMITED。ACK TYPE PATIENT-NODE。

**旁白**：G07／08——SCHEDULE HASH MATCH。LOCAL CLOCK VERIFIED。CLOCK SKEW WITHIN LIMIT。STAGE CEILING VERIFIED。MEDICAL GO YES。ACK TYPE PATIENT-NODE。

**朝倉澪** [exhausted]：（內心）三個了。紗英。美空。葵。

**朝倉澪** [exhausted]：（內心）各自的時鐘。各自的確認。不是 KAGAMI 在控制。是——KAGAMI 只說了「用這個 epoch」。後面——各自回答。

**旁白**：G07／05——SCHEDULE HASH MATCH。LOCAL CLOCK VERIFIED。CLOCK SKEW WITHIN LIMIT。STAGE CEILING VERIFIED。MEDICAL GO YES。ACK TYPE PATIENT-NODE。CONDITIONAL HANDOFF PACKAGE AVAILABLE。

**旁白**：LEGACY／04——SCHEDULE HASH MATCH。LOCAL CLOCK VERIFIED。CLOCK SKEW WITHIN LIMIT。STAGE CEILING VERIFIED。MEDICAL GO YES。ACK TYPE PATIENT-NODE。CONDITIONAL HANDOFF PACKAGE AVAILABLE。

**旁白**：ACTIVE／C——SCHEDULE HASH MATCH。LOCAL CLOCK VERIFIED。CLOCK SKEW WITHIN LIMIT。STAGE CEILING VERIFIED。MEDICAL GO LIMITED。ACK TYPE PATIENT-NODE。MAX COMPARE。

**朝倉澪** [exhausted]：（內心）六個。六個 patient-node ACK。

**朝倉澪** [exhausted]：（內心）medical go 不一樣。有的 YES。有的 LIMITED。可是——都回應了。不是中央替他們回答。

**旁白**：第七個窗格。LEGACY／02。畫面不同。不是 patient-node ACK。是——guardian console。

**旁白**：LEGACY／02——TRANSITION PROHIBITED。CURRENT SUPPORT RETAIN。ACK TYPE GUARDIAN HOLD。PATIENT CONSENT NOT INFERRED。

**旁白**：ACTIVE／D——TRANSITION PROHIBITED。CURRENT SUPPORT RETAIN。ACK TYPE GUARDIAN HOLD。PATIENT CONSENT NOT INFERRED。

**朝倉澪** [exhausted]：（內心）兩個 guardian HOLD。LEGACY／02。ACTIVE／D。

**朝倉澪** [exhausted]：（內心）沒有相容 patient root。guardian console 只確認——還在。還在臨床支援裡。沒有失聯。可是——不代表患者同意。不啟動 handoff。只保證——被計入了。沒有被倒數當成失蹤。

**旁白**：螢幕底部。總覽。

**旁白**：ACTIVE CASES ACCOUNTED 8。PATIENT-NODE ACK 6。GUARDIAN HOLD ACK 2。UNACCOUNTED 0。

**朝倉澪** [exhausted]：（內心）八個人。零失蹤。

**朝倉澪** [exhausted]：（內心）可是——六個和兩個不一樣。不是同一種 ACK。不是同一種回答。系統沒有把它們壓成同一行。

**旁白**：05:50:40。右上角的安全視訊亮了。悠真。他坐在床上。不是躺著。他的臉——比上次清楚一點。眼皮還是重的。可是——他在看鏡頭。

**朝倉澪** [exhausted]：（內心）悠真。

**旁白**：他的聲音從視訊喇叭傳出來。很輕。很短。像在省力氣。每個字都像從乾掉的喉嚨裡刮出來的。

**朝倉悠真**：不要把我的錄音放回那條線。

**朝倉悠真**：只用你們做出來的時間。

**朝倉澪** [exhausted]：（內心）他在說——聲音不當 timing source。夢話不接回臨床 bus。

**朝倉澪** [exhausted]：（內心）只給了 phase order。七個階段的順序。不是即時生理訊號。不是神經波形。是——歷史 handshake 重建出來的本地 schedule。不是悠真的聲音。

**旁白**：視訊面板角落的狀態欄。

**旁白**：G07／12。STATUS SAFE-DETACHED。CLINICAL BUS NONE。TIMING SOURCE NONE。

**朝倉澪** [exhausted]：（內心）safe-detached。沒有 clinical bus。沒有 timing source。

**朝倉澪** [exhausted]：（內心）他不重新接入。他只——從安全距離——確認了兩件事。不要用他的錄音。只用做出來的時間。

**旁白**：05:51:00。千田的音訊連線。他的聲音從喇叭傳出來。很平。像在讀一行他已經讀過很多次的註解。

**千田浩介**：他們只一起對時。

**旁白**：他頓了一下。

**千田浩介**：後面每一步，各自回答。

**朝倉澪** [exhausted]：（內心）只一起對時。不是一起回答。不是一起接收。不是一起變成同一個人。

**朝倉澪** [exhausted]：（內心）是——對時。確認自己的時鐘。確認自己的 schedule hash。然後——各自回答。CONTINUE。SAFE PAUSE。DENY。每個人——自己決定。

**朝倉澪** [exhausted]：（內心）時鐘不替他們決定。時鐘只——告訴他們，什麼時候輪到。

**旁白**：05:51:20。ANNOUNCE 結束。螢幕上八個窗格的狀態欄同時更新。

**旁白**：STAGE ANNOUNCE COMPLETE。NEXT SAMPLE。AUTO ADVANCE NO。

**朝倉澪** [exhausted]：（內心）沒有 auto advance。沒有人被自動推進。

**朝倉澪** [exhausted]：（內心）ANNOUNCE 結束了。SAMPLE 要開始了。每個人——採自己的樣本。自己的腦電。自己的呼吸。自己的 local root。沒有任何一個患者的樣本被送給另一個人。

**旁白**：pre-dawn 的灰色光從窗邊滲進來。比一分鐘前亮了一點。還不是早上。可是——不再是純粹的夜。冷氣的嗡鳴聲在寂靜裡顯得很大，像一個不肯離開的訪客。

**旁白**：八個窗格。六個 patient-node。兩個 guardian HOLD。沒有共同 YES。沒有共同 NO。只有——同一個 epoch。不同的時鐘。各自準備回答。
