# 第五幕：只有兩個人換手

**旁白**：06:04:00。螢幕上八個窗格的狀態欄同時更新。六個停在既定位置。兩個——亮了。

**旁白**：G07／05——HANDOFF ELIGIBLE。LEGACY／04——HANDOFF ELIGIBLE。

**朝倉澪** [exhausted]：（內心）兩個。只有兩個。不是全部。不是——八個人一起衝過終點。是——兩個人的風險比較說：留在中央撐過 06:13 峰值的風險，比換手更高。所以——換手。不是因為他們準備好了。是因為——不換更危險。

**旁白**：螢幕中間。風險比較畫面。兩條曲線。一條標著 CENTRAL PEAK EXPOSURE。一條標著 CONTROLLED HANDOFF。兩條線在 06:13 的位置交叉。交叉之後——中央那條爬得更快。

**旁白**：CONTROL QUIET WINDOW——OPEN。CENTRAL PEAK RISK——HIGHER THAN HANDOFF RISK。LOCAL ROOT——READY。PATIENT／PROXY CONSENT——VALID。HOT STANDBY——RETAINED。ABORT RULES——ACTIVE。

**朝倉澪** [exhausted]：（內心）quiet window。不是新的實驗。是——G07 既有臨床維護功能。平時用於定期降低中央輸入、讓本地根接管。只是——從來沒有在 06:13 峰值前用過。現在用。因為——留在中央的風險更高。不是為了證明什麼。是——醫療判斷。

**旁白**：06:04:30。G07／05 的窗格放大了。同意狀態欄。一行一行。

**旁白**：PRIOR ASSENT——VALID。法定代理 CONSENT——VALID。RIGHTS CONSENT——VALID。PATIENT-BOUND ROOT——STAGE-1。CONSENT-STATE ROOT——LOCKED。

**朝倉澪** [exhausted]：（內心）G07／05。十六歲。吹奏樂部。不是——匿名測試槽位。是一個人。有名字。有年紀。有——在失蹤以前的生活。名字被法律遮蔽了。螢幕上只有編號。可是——同意狀態欄裡每一項都是有效的。prior assent——本人事前同意。法定代理——監護人確認。rights consent——獨立權利代表確認。三層。都有效。

**旁白**：06:05:00。handoff 開始。螢幕上 G07／05 的窗格。local patient root 的狀態從 READY 變成 CONTROL-READY。中央 active input 的數值開始下降。不是瞬間歸零。是——依預簽 slope 分段降低。像在慢慢放手。

**旁白**：外部醫療的遙測數據並排顯示。心率。血氧。腦電。自律。全部在邊界內。

**朝倉澪** [exhausted]：（內心）慢慢放手。不是抽走。是——分段降低。讓本地根一點一點接。外部醫療在旁邊看著。任何一項超出邊界——abort。立刻。不問理由。

**旁白**：06:06:15。G07／05 的窗格。中央 active input 的數值——降至零。local control 的狀態欄——PRIMARY。

**旁白**：CENTRAL ACTIVE INPUT——ZERO。LOCAL CONTROL——PRIMARY。HOT STANDBY——RETAINED。

**朝倉澪** [exhausted]：（內心）零。中央輸入——零。本地控制——primary。可是——hot standby 還在。沒有切斷。沒有——永久分離。是——本地接管了。中央退到備用。如果本地出問題——中央隨時回來。隨時。

**旁白**：06:06:30。LEGACY／04 的窗格。同意狀態欄。

**旁白**：LIMITED SELF-CONSENT——VALID。PATIENT-BOUND ROOT——STAGE-1。CONSENT-STATE ROOT——LOCKED。

**朝倉澪** [exhausted]：（內心）LEGACY／04。成人。函館早期暴露案例。不是未成年人。不需要法定代理。可是——只有 limited self-consent。不是完整代理鏈。是——本人有限的自我同意。有效。可是——有限。螢幕上標著 limited。系統沒有把它當成完整同意。只當成——夠了。在這個窗口裡。在這個風險比較下。夠了。

**旁白**：06:07:00。LEGACY／04 的 handoff slope 開始降低。比 G07／05 慢。外部醫療的遙測——出現了一個標記。

**旁白**：BRIEF REVERSIBLE FLUCTUATION。WITHIN ABORT THRESHOLD。

**朝倉澪** [exhausted]：（內心）波動。可逆的。在 abort 閾值內。不是——差點死亡。不是——戲劇性崩潰。是——一個短暫的、可逆的波動。外部醫療看到了。他們做了什麼？

**旁白**：螢幕上。外部醫療的回應欄。

**旁白**：HANDOFF SLOPE——REDUCED。MEDICAL ADJUSTMENT——APPLIED。PATIENT STATUS——WITHIN ENVELOPE。

**朝倉澪** [exhausted]：（內心）他們降低了 slope。不是 abort。不是——驚慌。是——調整。把降低速度放慢。讓本地根有更多時間適應。然後——回到邊界內。繼續。

**旁白**：06:08:15。LEGACY／04 的窗格。中央 active input——降至零。local control——PRIMARY。hot standby——RETAINED。

**旁白**：兩個窗格並排。同樣的狀態欄。同樣的結果。

**朝倉澪** [exhausted]：（內心）兩個人。都過去了。本地接管。中央退到備用。hot standby 保留。可是——這只是急性窗口。三分鐘的 settle。不是——長期分離。不是——痊癒。是——急性窗口完成了。本地在這三分鐘裡撐住了。三分鐘以後呢？不知道。延遲風險——沒有排除。

**旁白**：06:08:30。SETTLE。螢幕中間。總覽畫面。一行一行。

**旁白**：G07／05——LOCAL CONTROL PRIMARY。CENTRAL ACTIVE INPUT ZERO。CENTRAL HOT STANDBY RETAINED。ACUTE HANDOFF WINDOW COMPLETE。EXTERNAL MEDICAL WITHIN ENVELOPE。LONG-TERM SEPARATION NOT ESTABLISHED。POST-WINDOW REVIEW REQUIRED。

**旁白**：LEGACY／04——LOCAL CONTROL PRIMARY。CENTRAL ACTIVE INPUT ZERO。CENTRAL HOT STANDBY RETAINED。ACUTE HANDOFF WINDOW COMPLETE。EXTERNAL MEDICAL WITHIN ENVELOPE。LONG-TERM SEPARATION NOT ESTABLISHED。POST-WINDOW REVIEW REQUIRED。

**朝倉澪** [exhausted]：（內心）long-term separation——NOT ESTABLISHED。post-window review——REQUIRED。系統沒有說「成功」。沒有說「完成」。只說——急性窗口完成了。長期分離——沒有建立。窗口後——還要複查。這不是——終點。是——一個急性窗口的結果。

**旁白**：螢幕底部。全體總覽。

**旁白**：LOCAL-CONTROL PRIMARY——2。CENTRAL HOT STANDBY RETAINED——2。CENTRAL／TRANSITION SUPPORT——6。ACUTE CATASTROPHIC INSTABILITY——0 OBSERVED。IMMEDIATE IRREVERSIBLE INDICATOR——0 OBSERVED。DELAYED HARM——NOT YET EXCLUDED。

**朝倉澪** [exhausted]：（內心）零。急性災難性失穩——零。立即可逆指標——零。可是——延遲傷害——NOT YET EXCLUDED。沒有排除。不是「沒有」。是——還不知道。三分鐘的窗口看不出延遲傷害。要等。要觀察。要——複查。系統沒有替他們宣佈安全。只說——目前沒看到急性災難。

**旁白**：06:11:30。千田的音訊連線。他的聲音從喇叭傳出來。很平。像在讀一行他已經讀過很多次的註解。

**千田浩介**：兩個人過去了。

**旁白**：他頓了一下。

**千田浩介**：另外六個人沒有被逼著跟上。

**朝倉澪** [exhausted]：（內心）兩個人過去了。六個人——沒有被逼著跟上。不是——八個人一起衝過終點。不是——全部成功或全部失敗。是——兩個人的風險比較說換手更安全。六個人的狀態說停在這裡更安全。兩種結果。同一個時間框架。沒有人被倒數強迫前進。沒有人被自動推進。

**旁白**：dawn 的灰色光從窗邊照進來。比十分鐘前亮了。窗邊的影子更短了。不是——早上。可是——很近了。

**旁白**：螢幕上八個窗格。兩個 LOCAL CONTROL PRIMARY。六個 HOLD／SAFE PAUSE／COMPARE。沒有共同 YES。沒有共同 NO。只有——同一個 epoch。不同的結果。各自停在自己能停的地方。
