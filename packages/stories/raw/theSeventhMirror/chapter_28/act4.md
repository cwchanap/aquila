# 第四幕：母親只是患者

**旁白**：澪不在每一張床邊。她不能。五名 downstream patients 分散在不同患者節點——有的在鏡島外部神經醫療區，有的在合作長期復健中心，有的在法院監督下的獨立醫療病房。她能看見的是更新。是螢幕。是外部醫師透過視訊回報的進度。是 Survivor Care Trust 每週寄到家屬端的摘要——不帶研究語言，只有患者安全狀態與下一個里程碑。

**朝倉澪** [exhausted]：（內心）第一週。ACTIVE／C。補足 settle history。這是——第一個。

**旁白**：外部醫師的視訊回報。簡短。臨床。

**外部醫師**：ACTIVE／C 的 settle history 已經補足。patient-specific bridge 可以啟用。M-00 outgoing support 移除。non-human fallback 保留。

**朝倉澪** [exhausted]：（內心）五——變四。第一個。不是——痊癒。只是——不再需要另一名人類大腦作共同 clinical endpoint。她——不需要再撐著 ACTIVE／C。母親——少了一個人靠著她。

```text
PATIENT MEDICAL FUNDING    ACTIVE／NOT PENDING VERDICT
```

**朝倉澪** [exhausted]：（內心）Trust。法院監督。不等待——政府互相推責。不等待——承包商否認。不等待——外國機構爭議。不等待——最終判決。醫療——先走。這是——第八天上午就建立的。現在——還在。

**旁白**：第二週初。ACTIVE／D。

**外部醫師**：patient-bound local root 完成。先作 Stage-0——passive。再進 non-human clinical bridge。不進 aggressive handoff。

**旁白**：螢幕更新。


**朝倉澪** [exhausted]：（內心）四——變三。ACTIVE／D。有了——自己的 root。自己的 bridge。不再——靠母親。可是——下游還有三個。美空。葵。LEGACY／02。

**旁白**：第二週後半。美空。

**旁白**：外部醫師的回報出現一次延遲。不是——排程延遲。是——醫療延遲。

**外部醫師**：藤川美空原訂 transition 出現一次自律波動。血壓與心律不穩定。不是急性災難性失穩。可是——今天不是正確的日子。

**朝倉澪** [exhausted]：（內心）延期。美空——延期。不是——失敗。是——今天不安全。所以——今天不做。三十日是 outer limit。不是——預定使用期。任何醫療延期——優先於排程整齊。

**旁白**：約四十八小時後。自律波動回落。外部醫師確認可以繼續。

**外部醫師**：Domain-C 加入完整睡眠／清醒資料。drift model 改良。以 patient-specific Domain-C bridge 取代 M-00 common endpoint。普通 central 與 non-human fallback 保留。

**旁白**：螢幕更新。

```text
DOWNSTREAM DEPENDENCIES    3 → 2
CURRENT DOWNSTREAM LIST    葵／LEGACY／02
NEXT SAFETY MILESTONE      葵 — AOI-LOCAL BRIDGE
```

**朝倉澪** [exhausted]：（內心）三——變二。美空。Domain-C bridge。她——不再靠母親的 common endpoint。可是——她沒有醒。沒有——意識改善證據。不要求她醒來。她只是——有了自己的橋。不是——靠另一個人撐著。

**旁白**：第三週後半。葵。

**旁白**：又是延遲。這次——感染。與鎮靜調整。

**外部醫師**：水瀨葵原訂 bridge 因感染與鎮靜劑量調整延後。AOI-LOCAL 需要額外被動觀察。不急。

**朝倉澪** [exhausted]：（內心）葵。又延期。感染。鎮靜。這些——是普通醫療理由。不是——循環。不是——訊號。是一個十四歲的女孩——感染了。鎮靜劑量——要調。這些——比排程重要。

**旁白**：數日後。感染控制。鎮靜穩定。AOI-LOCAL 完成額外觀察。

**外部醫師**：patient-specific bridge 建立。AOI-LOCAL 脫離 common endpoint。仍未醒。不宣稱能辨認母親。

**旁白**：螢幕更新。

```text
DOWNSTREAM DEPENDENCIES    2 → 1
CURRENT DOWNSTREAM LIST    LEGACY／02
NEXT SAFETY MILESTONE      LEGACY／02 — BEDSIDE ADAPTER
```

**朝倉澪** [exhausted]：（內心）二——變一。葵。沒有醒。不宣稱——能辨認母親。佳乃——不會因為第八天出現就要求再試一次。她——只是等。等——葵自己的醫療時間。最後一個。LEGACY／02。

**旁白**：第四週初。LEGACY／02。姓名封緘。

**朝倉澪** [exhausted]：（內心）中止。第一次——中止。不是——失敗。是——timing 不對。所以——停下。沒有——為了期限繼續。沒有——為了讓 downstream 早一天變零而硬走。停下。返回。修正。再來。

**旁白**：修正後。第二次。

**外部醫師**：修正完成。第二次建立 legacy patient-specific bridge。姓名保持封緘。仍需高度醫療及 non-human fallback。

**朝倉澪** [exhausted]：（內心）零。downstream——零。五個——都走了。不是——痊癒。不是——全部 local-primary。是——不再需要另一名人類大腦作共同 endpoint。母親——不再被任何人靠著。可是——她還是患者。她——還是需要普通生命支持。現在——要等。二十四到四十八小時。verification。

**旁白**：最後 bridge 後。二十四到四十八小時。

**旁白**：post-bridge verification。ordinary 與 non-human fallback 核對。M-00 outgoing support 停止演練。紗英生命支持與普通神經醫療確認。法院、醫療、患者權利、系統安全及家屬程序——全部在場。

**旁白**：沒有象徵性拔線。沒有——儀式。只有——記錄變更。

**患者權利代表**：downstream M-00 dependencies 確認為零。各 patient-specific bridge 及 fallback 確認穩定。M-00 outgoing clinical phase support 停止。紗英普通生命支持保留。轉入普通患者監測。

**朝倉澪** [exhausted]：（內心）退役。M-00——退役。不是——刪除。不是——抹掉她被用過的證據。是——不再用她了。operational registry——RETIRED。patient registry——朝倉紗英。historical audit——保留。永久。她曾被這樣使用——不能被改寫。也不能被抹除。她——現在。只是。患者。只是——朝倉紗英。

**旁白**：紗英的床邊。澪在那裡。悠真也在。他從外部醫療區過來——坐在床的另一側。

**旁白**：沒有人預期她會醒。retirement 不直接造成清醒。醫師只能說——清醒窗口在 role retirement 之後出現。不能說——retirement 令她醒來。共用負荷停止。藥物調整。刺激下降。睡眠週期。自然神經波動。這些——都可能是原因。沒有——單一因果。

**旁白**：可是她醒了。

**旁白**：不是——睜開眼就坐起來的那種醒。是——眼皮動了。然後——張開。很慢。像——很重的東西被推開。

**朝倉澪** [shocked]：（內心）她——張開眼睛了。母親——張開眼睛了。

**旁白**：紗英的視線。很短。很慢。她追視——先看見澪。然後——轉過去。看見悠真。

**朝倉澪** [sad]：（內心）她——看見我們了。她——認得。她——認得我和悠真。

**旁白**：她開口。聲音很小。像——在節省最後的能量。像——每一個字都要從很遠的地方拉回來。

**朝倉紗英**：第八天了嗎？

**朝倉澪** [sad]：已經快一個月了。

**旁白**：紗英閉了一下眼。又張開。

**朝倉紗英**：那就別再數了。

**旁白**：她轉向悠真。悠真坐在那裡。他沒有哭。也沒有笑。只是——看著她。

**旁白**：她好像在問。沒有說完整。

**朝倉悠真** [determined]：我在。

**旁白**：紗英看著他。看了很久。然後——她再次閉上眼睛。

**朝倉澪** [sad]：（內心）她——閉上了。不是——死亡。不是——系統又把她占走了。不是——被拉回去。是——她真的累了。她——累了。她撐了很久。比——任何人應該撐的都久。現在——她可以——只是累了。可以——閉眼。可以——休息。不是——因為系統需要她。是——因為她真的累了。

**旁白**：呼吸仍在。心律仍在。監測器上的數字——平穩。普通。像一個——睡著的人。

**外部醫師**：清醒窗口已結束。生命徵象穩定。長期預後——未知。

**朝倉澪** [sad]：（內心）未知。不是——好。不是——壞。是——未知。她可能——再醒。可能——不會。可能——醒得更久。可能——只是這一次。我不知道。悠真——不知道。醫師——不知道。可是——這一次的不知道。不是——制度替她寫好的死亡。不是——被維持在半昏迷裡的不知道。是——普通的不知道。是——一個人的預後——還沒有走完。

**旁白**：清醒窗口不得被用作循環研究。不得——訊問父親。不得——訊問外星訊號。不得——擴張新的 consent。醫師已經確認。患者權利代表已經確認。那是一段——屬於她自己的時間。不是——證據採集窗口。

**旁白**：澪坐在床邊。悠真坐在另一邊。房間很安靜。只有監測器的聲音。普通的。規律的。像——一個人在睡覺。

**朝倉澪** [sad]：（內心）她說——別再數了。她——不想再數了。第八天。第七天。第幾輪。第幾次。她——不想再數了。我——也不想。可是——我還沒學會。我還——會在早上看手機。還——會聽見電車廣播的時候心跳變快。還——會在 06:13 醒過來。可是——她說了。別再數了。也許——有一天。我會——學會。也許——不會。可是——她說了。那就——夠了。現在——夠了。

**旁白**：窗外。普通的光。不是白光。不是——06:13 的那種。只是——白天的光。一個月的光。

**旁白**：母親只是患者。不是——M-00。不是——source endpoint。不是——共同臨床端點。只是——朝倉紗英。一個——累了的人。在睡覺。
