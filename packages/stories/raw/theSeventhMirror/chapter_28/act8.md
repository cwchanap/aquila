# 第八幕：七十年

**旁白**：約半年後。某個普通夜晚。朝倉家。客廳。

**旁白**：悠真已經睡了。他的房間門關著。裡面沒有聲音。有時候——夜驚。有時候——安靜。今晚——安靜。

**旁白**：母親仍在復健醫療區。不在這裡。她的房間——空著。床鋪整齊。沒有人睡。

**旁白**：澪獨自在客廳。

**朝倉澪**：（內心）晚上。普通的晚上。沒有——倒數。沒有——白光。沒有——06:13。只是——晚上。

**旁白**：矮櫃上。那台機器。

**旁白**：以舊短波機外殼改裝的 wideband analog comparison receiver。外殼磨損。邊角的金屬已經氧化成深褐色。旋鈕旁邊——一條白色的頻率刻線。母親留下的。她用白色漆畫的。很細。像指甲刮過去的痕跡。

**旁白**：外接 active antenna。線從機身背面接出來，沿著牆角走到窗戶邊緣，伸出去。down-converter。beat detector。獨立類比錄音輸出。不連 KAGAMI。不含患者資料。不含私鑰。不含控制功能。

**朝倉澪**：（內心）媽媽留下的。

**朝倉澪**：（內心）她年輕的時候喜歡天文。喜歡短波。這台機器——是她改裝的。白色刻線——是她標的頻率。她標的那個位置——不是——隨便標的。是——prior source band。是——函館那一夜的方向。

**朝倉澪**：（內心）它不是——循環密鑰。不是——患者資料庫。不是——只對我有反應的東西。它只是一台——類比比較接收器。在 KAGAMI 的數位處理鏈以外。用來——確認 prior source band 是否還有訊號。

**旁白**：機器的喇叭。平時——只有靜電。偶發的窄帶聲。像——遠處的收音機在找台。像——空氣在振動。

**旁白**：今晚——不一樣。

**旁白**：它發出了——一輪多音序列。

**旁白**：不是——語音。不是——單音。是——好幾個頻率同時出現。數學的。規律的。像——幾個音叉同時被敲響。像——座標在唱。

**朝倉澪**：（內心）⋯⋯

**朝倉澪**：（內心）來了。

**旁白**：她沒有動。她坐在矮桌前面。筆電螢幕亮著。Prior-Source Open Monitoring Network 的儀表板。公開監測網。已經運作數月了。多國天文台。大學。民間接收者。訊號安全代表。患者／神經安全代表。他們——預先公布了觀測窗口。依 prior source direction。依天體幾何。依舊資料。

**朝倉澪**：（內心）不是——只對我。不是——只有這台機器聽得到。

**旁白**：螢幕上。公開網路。一個一個。先後出現。

**旁白**：SITE-01——DETECTION／PENDING。

**旁白**：SITE-07——MATCH／LOW CONFIDENCE。

**旁白**：SITE-12——MATCH／SPECTRAL。

**旁白**：HOME-A——HASH COMMITTED。

**朝倉澪**：（內心）SITE-01。SITE-07。SITE-12。HOME-A。不是我。不是——只有朝倉家。是——多站。其他台站——也收到了。同一個 RF pattern。同一個觀測窗口。

**朝倉澪**：（內心）它不是——外星文明只向我家頒發的獎勵。是——既定窗口裡的既定觀測。多站獨立接收。

**旁白**：她做的第一件事——

**朝倉澪**：（內心）靜音。

**旁白**：她的手伸過去。把機器的喇叭靜音。多音序列停了。不是——訊號停了。是——她不再讓它播放。本地 RF 記錄——仍在跑。類比錄音輸出——仍在跑。只是——喇叭靜了。

**朝倉澪**：（內心）保留本地 RF 記錄。建 acquisition hash。發送 public commitment。raw capture 送入 DISTRIBUTED SIGNAL SAFETY QUARANTINE。等其他台站獨立確認。

**旁白**：她的手指在筆電上動。很快。不是——慌張。是——練習過的。觀測網有程序。她知道程序。

**旁白**：螢幕上。她的操作。

**旁白**：LOCAL RF CAPTURE——PRESERVED。ACQUISITION HASH——COMMITTED。PUBLIC COMMITMENT——SENT。RAW CAPTURE——DISTRIBUTED SIGNAL SAFETY QUARANTINE。MULTI-SITE CONFIRMATION——PENDING。

**朝倉澪**：（內心）沒有——收到母親聲音。沒有——收到父親訊息。沒有——收到未來的自己。沒有——看見倒數。沒有——被拉回 06:13。

**朝倉澪**：（內心）只有——多音序列。數學的。沒有——七秒 offset。沒有——06:13 倒數。沒有——白光。沒有——已知完整回送。不是——那一輪的東西。是——新的。

**旁白**：她靠回椅背。等。不是——等答案。是——等其他台站獨立確認。等——SITE-01 從 PENDING 變成 DETECTED。等——SITE-07 的 confidence 提高。等——多點交叉排除設備故障、單一造假、普通網路內容和 KAGAMI 殘留。

**朝倉澪**：（內心）不壟斷。不等於——不設安全邊界。公開驗證。不等於——把未知訊號直接塞給所有人。

**旁白**：第一時間公開的——不是完整音訊。不是——可自動播放的 raw waveform。

**旁白**：螢幕上。公開頁面。

**旁白**：ACQUISITION TIME。FREQUENCY／SPECTRUM METADATA。RECEIVER CONFIGURATION。HASH／MERKLE COMMITMENT。MULTI-SITE DETECTION COUNT。NON-RECONSTRUCTABLE PREVIEW。SAFETY STATUS——UNASSESSED。

**朝倉澪**：（內心）公開的是——時間、頻率、設備配置、hash、多站計數、不可重建的預覽。不是——完整 RF／IQ。不是——可以播放的音訊。安全狀態——未評估。

**朝倉澪**：（內心）原始資料——進 DISTRIBUTED SIGNAL SAFETY QUARANTINE。多國。民間。學術。加密分散保存。無單一刪除者。不自動播放。存取——需訊號及神經安全程序。各站——以自己直接觀測驗證。

**旁白**：她等著。客廳很安靜。機器的喇叭靜了。只有——筆電風扇在轉。只有——窗外遠處的電車。只有——普通的夜晚。

**旁白**：其後數週。多點獨立接收。安全審查。逐步資料開放。

**旁白**：螢幕上。公開頁面更新了。

**旁白**：SOURCE FAMILY——CONSISTENT WITH PRIOR HAKODATE BAND。POWER／COHERENCE——LOWER。HIGH-COHERENCE PHASE——NOT DETECTED。KAGAMI AMPLIFICATION——NONE。KNOWN NEURAL COUPLING——NONE OBSERVED。SAFETY——NOT PROVEN。

**朝倉澪**：（內心）source family——和函館一致。同一個來源家族。可是——功率和相干性更低。高相干 phase——沒有偵測到。KAGAMI 放大——沒有。已知神經耦合——沒有觀察到。

**朝倉澪**：（內心）安全——仍未證明。

**朝倉澪**：（內心）可以推測——危險不是單純收到電波。舊事件的危險——可能來自高相干調變、KAGAMI 放大和人類端點網路的共同作用。現在——只觀察到低功率數學 carrier。可是——不能因此宣稱普遍安全。

**旁白**：螢幕捲動。多組模型的暫定分析。

**旁白**：SIGNAL TYPE——NARROWBAND MULTI-TONE／MATHEMATICAL。REFERENCE FRAME——PROBABLE PULSAR-RELATIVE。ORIGIN——CONSISTENT WITH PRIOR HAKODATE SOURCE。TIME OFFSET——APPROX. +70 YEARS。CONTACT WINDOW——PROBABLE／NOT PROVEN。ALTERNATIVES——OPEN。COMMAND——NONE DETECTED。FUTURE MEMORY——NONE DETECTED。

**朝倉澪**：（內心）pulsar-relative model。參考框架——可能是脈衝星相對座標。時間偏移——約七十年。接觸窗口——可能。但——未證明。替代解讀——開放。命令——沒有偵測到。未來記憶——沒有偵測到。

**朝倉澪**：（內心）不是所有團隊都同意。

**旁白**：螢幕底部。爭議區。

**旁白**：有團隊認為——它真的是星圖。有團隊認為——七十年是接觸窗口。有團隊認為——座標指向位置。有團隊認為——座標指向時間。有團隊認為——兩者都是。有團隊認為——它只是重複週期。有團隊認為——它只是觀測對齊標記。

**朝倉澪**：（內心）沒有——共識。可是——也沒有任何一方能再將原始觀測完整私有。

**朝倉澪**：（內心）hash 已經公開了。acquisition commitment 已經送了。多站已經獨立收到了。原始 RF／IQ 在分散安全隔離裡。沒有——單一刪除者。沒有——單一擁有者。沒有——單一解讀者。

**旁白**：她看著螢幕。看著 +70 YEARS。看著 PROBABLE／NOT PROVEN。看著 ALTERNATIVES OPEN。

**朝倉澪**：（內心）七十年。

**朝倉澪**：（內心）遠長於——我可以用循環立即驗證的時間。長於——當代決策者的任期。需要——跨世代科學與倫理準備。不能——被一名主角私有。不能——被一個政府私有。不能——被一個新的 continuity authority私有。

**朝倉澪**：（內心）它不是——答案。不是——政策。不是——未來記憶。不是——命令。不是——「你們通過了測試」。不是——外星文明頒發的獎勵。

**朝倉澪**：（內心）它只是——一個座標。一個——必須用七十年走到的座標。可能——真的是接觸。可能——不是。可能——這一代人走不到。可能——下一代人也不確定。可是——它在那裡。在前面。不是——被送回來的。是——在前面的。

**旁白**：她把筆電合上。客廳暗了。只有——矮櫃上那台機器的指示燈。很小的。紅色的。像——一顆很遠的星。

**旁白**：機器的喇叭仍然靜著。多音序列——已經過了。觀測窗口——已經過了。可是——記錄還在。hash 還在。多站的確認還在。分散安全隔離裡的 raw capture——還在。

**旁白**：她沒有再打開喇叭。不需要——再聽一次。她已經——聽到了。她已經——記下了。她已經——公開了。

**朝倉澪**：（內心）收音機裡沒有倒數。

**旁白**：她看著那台機器。看著母親留下的白色刻線。看著窗外的夜空。東京的光遮住了大部分的星。可是——方向是知道的。prior source direction。函館的方向。七十年後的方向。

**朝倉澪**：（內心）只有一個必須用七十年走到的座標。

**旁白**：她關了燈。客廳暗了。機器的指示燈——還亮著。紅色的。很小的。不閃。不倒數。只是——在那裡。

**旁白**：未來第一次留在前面。
