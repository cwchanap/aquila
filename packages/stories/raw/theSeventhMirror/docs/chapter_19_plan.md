# 4. 全域一致性鎖定

## 4.1 未成年人同意與本人意向

研究同意可合理涵蓋：

- 問卷；
- 非侵入睡眠監測；
- 合作設施短期評估；
- 必要交通安排；
- 災害壓力追蹤。

不能只靠「未反對視為持續」合理涵蓋：

- 長期鎮靜；
- 地下待機；
- 侵入性神經刺激；
- 未告知跨法人轉送。

悠真的安全求助不是形式完備的撤回書。

它的證據價值是：

> 研究方知道或理應知道，悠真感到不安全、不願繼續，並試圖向外求助。

這足以：

- 動搖研究自願性；
- 支持立即停止研究；
- 支持本人安否風險；
- 支持搜索必要性。

相原的說法應保持：

> 「這不是你們格式裡的撤回書。但這是孩子在說，他不想留在這裡。」

## 4.2 具名醫師的醫療安全命令

研究方提出一份具名醫師下達的短期醫療安全指示。

作者層固定：

| 欄位 | 內容 |
|---|---|
| 下達醫師 | 佐久間理人，關聯神經／睡眠醫師 |
| 初始時間 | 悠真失蹤當晚 |
| 觀察方式 | 初次視訊評估＋監測資料 |
| 初始理由 | 急性神經反應、長時間難以喚醒、抽搐風險 |
| 初始有效期 | 6 小時 |
| 後續延長 | 由值班醫師／研究安全責任人依數據續簽 |
| 本人再評估 | 後續多次只看數據，未親自見悠真 |
| 家屬說明 | 被記錄為「研究方已聯絡」，但未具體告知地下轉送與延長鎮靜 |

成熟處理：

- 初始安全處置可能真的具有醫療合理性；
- 問題在於：
  - 短期命令被反覆延長；
  - 沒有重新取得未成年後見人知情同意；
  - 本人求助未進入醫療／倫理撤回流程；
  - 研究刺激與醫療照護界線逐漸消失。

本章必須追問：

> 佐久間醫師最後一次親眼見到悠真，是什麼時候？
