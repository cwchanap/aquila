  - 相位誤差；

  1. 先替各臨床單元建立本地影子參照；

  - 使遠端臨床單元失去 M-00 相位參照；
  - 使 M-00 失去鏡島回傳的穩定節奏。

6. 若邏輯隔離無法驗證，切斷共用 CAL／PHASE 閉環；
7. 阻斷公共 fanout；
8. 使本地簽署鏈失效；
9. 不等待其他活動接收者建立本地影子參照。

R4 可能高概率阻止：

- 一致性層完成公共擴散；
- 下一個回聲窗依既定設定運作；
- `VALIDATION COHORT` 的異常一致化繼續擴大。

但它會使：

- M-00；
- 高依存 G07；
- 舊接收單元；

失去穩定閉環。

本章的倫理核心為：

> 可能未來中的澪不只接受陌生孩子受傷。  
> 她已經知道 `M-00 = 朝倉紗英`。

- 她看過具名版依存圖；
- R4 執行摘要最後只剩代碼；
- 她知道代價後仍接受。

> 她認為那個自己一定在某個時刻停止看名字，否則無法完成選擇。

正文必須保持：

> 這是澪對自己的高度可信判斷，不是已被找到的操作記錄。

本章的正式程序結果不是永久禁止所有未來硬切，而是：

```text
R4／RECONSTRUCTED
INTERIM STATUS   NOT PRE-AUTHORIZED
USE              FORENSIC／FAILURE-MODE ONLY
REVIEW           EVENT-TRIGGERED ONLY
```

意義：

- R4 不得成為預設、預先批准、自動執行的方案；
- 未撤離者不得被預先寫成正常代價；
- 若未來出現全新、已證實、即時的大規模死亡風險：
  - 必須由當時的多方人員重新決策；
  - 不得以「未來澪已接受」作授權；
  - 不得由倒數自動替人作決定。

澪的核心書面聲明為：

> **若一個方案只有在人的身分被隱藏後才能執行，它不得被預先授權。**

「把名字補回去」不等於讓澪看見所有受試者私人資料。

決策介面至少必須顯示：

- HUMAN；
- 成人／未成年人；
- 年齡帶；
- 是否有法定代理人；
- 已知醫療狀態；
- 不可逆風險；
- 依法可向家屬／調查開示的姓名。

- 載體具有唯一硬體序號；

  - 更換控制器；
  - 更新本地影子模型；

2. emergency override 已啟用；

5. `VALIDATION COHORT` 中多人獨立陳述同一不存在事件；
6. 距 public fanout 只剩極短時間。

此時：

- 公共異常已超過純理論；
- 卻仍未全面擴散；
- R4 因此成為技術上可理解、倫理上仍有問題的候選。
