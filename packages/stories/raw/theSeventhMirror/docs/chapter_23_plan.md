# 5. 缺失載體的兩階段定位

## 5.1 第一階段：本地匯流排證明硬體存在

外部團隊不能只依中央 attestation，必須排除遠端代理。

控制器向安全晶片送出：

- 即時隨機 nonce；
- 物理服務埠編號；
- 本地匯流排時序挑戰；
- 控制器本地時間窗。

載體回覆：

- 不可匯出金鑰簽署的 nonce；
- 實體埠測量值；
- 符合本地匯流排延遲的回應。

可成立：

> 同一硬體安全晶片正在美空控制器的本地服務匯流排上。

仍不能得知：

- 實際藏在哪塊面板後；
- 如何安全打開；
- 如何解除病人綁定。

其他可見線索：

- 信任鏈指向 `SHADOW ROOT／SERVICE`；
- 醫院資產表沒有對應裝置；
- 機櫃後方存在非院方原生封條與未列入手冊的模組。
