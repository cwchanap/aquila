# 1. 不可變更的最終約束

下列內容已鎖定。最終潤飾不得因「再增加一點戲劇性」而推翻。

## 1.1 結構

- 全書固定 **28 章**；
- 不新增 Chapter 29；
- 七大段是七個調查／認知階段，不是七個自然日；
- 故事包含三次七日週期；
- Chapter 28 是最終章及 epilogue；
- 最終句保持：

> 收音機裡沒有倒數。  
>   
> 只有一個必須用七十年走到的座標。  
>   
> **未來第一次留在前面。**

## 1.2 角色

- 琴音只有低強度循環熟悉感，沒有完整輪次記憶；
- 日下部只有語言、方向及危險碎片，不完整記得第二輪；
- 千田沒有前輪記憶；
- 紗英保存大量 fragments，但不等於全知；
- 悠真不是穩定預言者；
- 澪是唯一完整保留兩次七日經歷的人。

## 1.3 法律與證據

- 前兩輪琴音刺傷千田是作者真相與澪記憶，不能成為第三輪刑事既定事實；
- 千田不能替澪證明 erased-loop 攻擊位置；
- R4 是可能未來的 failure-mode，不是已發生歷史；
- Witness fragment 只能證明來源、同意及完整性，不自動證明主觀內容客觀正確；
- 澪的完整跨輪記憶可被醫療記錄，但不能自動成為公共或法律證據。

## 1.4 醫療

- 不讓所有患者在 Chapter 27 同時 handoff；
- 美空與葵不在本書醒來；
- 紗英不奇蹟康復；
- `M-00` public／consensus role 可停止，clinical transition support 必須按患者安全逐步退出；
- SAFE PAUSE 不等於斷開生命支持；
- 未成年人必須有代理、患者權利及醫療程序；
- 患者模型不可被複製成新的 Mother Reference。

## 1.5 技術

必須永久分開：

```text
PROTECTIVE FILTER
CLINICAL BRANCH
TOKYO-7 CONSENSUS／PUBLIC BRANCH
OFFICIAL APP FOLLOW-UP
PATIENT WITNESS PATH
```

時間點必須永久分開：

```text

05:50       PROTECTIVE／CLINICAL PREP
06:12:53    ORDINARY MARKER／MOBILE OBJECT SEALED
06:13:00    ECHO PEAK／WHITE LIGHT
06:20       LEASE EXPIRY
```

## 1.6 終局

- 白光仍然發生；
- TOKYO-7 unified public version 沒有形成；
- official app follow-up 在 server fanout 前被取消；
- Witness fragments 是 opt-in 數位資料；
- sensory echo 是不可控現象，不能被角色挑選或編碼；
- 澪這次沒有回到上週一；
- 完整循環物理原因仍未證明；
- 新訊號的七十年解讀保持 probable／not proven。

# 16. 變更控制規則

Final Lock 前，任何新建議都必須回答：

1. 它修正的是矛盾，還是只是增加趣味？
2. 它需要在哪些前章埋伏筆？
3. 它是否增加新術語、組織、患者、密鑰或地點？
4. 它是否改變角色知道什麼？
5. 它是否改變法律證據狀態？
6. 它是否改變患者安全？
7. 它是否削弱既有 payoff？
8. 它是否值得延後正式寫作？

若答案只是：

> 更複雜、更震撼、更多謎團

則拒絕。

Final Lock 後只允許：

- 文句；
- 節奏；
- 小型場景；
- 非 Canon 細節。

不得再修改：

- 謎底；
- 角色責任；
- 患者數量；
- 循環規則；
- TOKYO-7 終局；
- Chapter 28 結尾。

# 18. Definition of Done

本次最終潤飾完成的判斷，不是：

> 每個章節看起來都很詳細。

而是：

> 任意打開一章，角色、時間、證據、醫療、技術與後續 payoff 都和全書同一版本一致。

- 琴音為何攔截？
- 悠真與紗英在哪裡？
- TOKYO-7 如何運作？
- 為何不能執行 R4？
- R5 為何不是新母體？
- 為何明確拒絕仍被判失聯？
- Lease 為何有效卻不能執行？
- 七秒取消了什麼？
- 白光為何仍發生？
- 第八天為何重要？

### 對作者

- 哪些是當輪證據？
- 哪些只存在於澪記憶？
- 每名角色此刻知道什麼？

- 哪些謎題故意保留？
- 哪些設定已禁止再新增？

所有答案都必須存在於 Canon，而不是依賴臨時回憶。
