# 第二幕：紙條

**旁白**：三號洗衣機唱完了歌。

**旁白**：那首歌只有四個音，難聽得很誠懇。她蹲下來，把濕衣服一把一把撈進籃子。

**旁白**：制服。制服。T恤。毛巾。一整排黑色彈性襪。

**以寧**：(內心)為了不用配對，我一次買了十二雙一模一樣的。這是我這輩子做過最成熟的決定。

**旁白**：然後她撈到一隻灰色的襪子。

**旁白**：羊毛的，腳跟磨得很薄，薄到快透光。不是她的。她沒有任何東西是灰色的，除了臉色。

**以寧**：(內心)機器吃了別人的襪子，再吐到我這裡。很合理。這台機器一向不太挑。

**旁白**：襪子裡有東西。硬硬的，一小塊。

**旁白**：她伸手進去，摸出一個小小的夾鏈袋。醫院藥局分裝藥丸用的那種，她一個晚上要經手幾十個。袋子裡是一張折成四折的紙，乾的。

**旁白**：她打開。藍色原子筆，字很工整，一筆一劃都像排過版。

**旁白**：「如果你撿到這個——洗衣機吃掉了我另一隻襪子，還有我大部分的勇氣。」

**旁白**：她看了兩遍。

**以寧** [flustered]：(內心)夾鏈袋。

**以寧**：(內心)誰會把紙條裝進防水的夾鏈袋，再「不小心」被洗衣機吃掉。這不是意外。這是預謀。而且預謀得很周到。

**旁白**：她沒有立刻抬頭。在病房裡她學會一件事：想知道一個人真正的狀況，就不要讓他發現你在看。

**旁白**：她抱起濕衣服走向四號，用眼角餘光看他。

**旁白**：他在看稿子。同一頁。

**旁白**：從她蹲下去到現在，至少四分鐘，那一頁沒有翻過。紅筆的筆蓋是蓋著的。一個改稿改到要咬筆蓋的人，筆蓋是蓋著的。

**旁白**：他的耳朵很紅。

**以寧**：(內心)呼吸大概每分鐘二十四下。偏快。病人自述：我在看書。

**旁白**：她把衣服丟進四號，投幣，按下四十分鐘。烘衣機轉起來，暖黃色的光照在她手上，那張紙還捏在指縫裡。

**旁白**：字很眼熟。

**旁白**：她轉頭看牆上那張使用須知。「也不要放人。」同樣工整、像排過版的字，只是換成了紅筆。

**以寧**：(內心)好。罪證確鑿。

**旁白**：她還沒想好要說什麼，他先站了起來。把稿子塞進背包，動作快得像要離開案發現場，走到門口又停住，回頭。

**紅筆**：我⋯⋯去對面買個東西。

**紅筆**：衣服先放這裡。如果——如果妳要走，不用管它。

**旁白**：他把洗衣袋留在第二張椅子上，推門出去。雨聲一下子變大，又被門關上。

**旁白**：她看著他縮著肩膀跑過馬路，跑進便利商店那片白光裡，在雜誌架前面站定。

**旁白**：背對著這邊。站得很直，一動也不動，像一個在等檢查報告的家屬。
