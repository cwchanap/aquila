# 第四幕：回信

**旁白**：她把紙條翻到背面。

**旁白**：筆尖停了很久。她寫過幾千份護理紀錄，從來不需要想這麼久。意識清楚，生命徵象穩定，主訴：無。

**旁白**：最後她寫：「襪子在我這裡，狀況穩定。勇氣的部分，機器表示沒看到，建議持續觀察。」

**以寧**：(內心)⋯⋯寫成交班紀錄了。算了。

**旁白**：她把紙條放回夾鏈袋，塞回灰襪子裡，擺在他那袋衣服上面。然後坐回第四張椅子，開始折衣服，折得非常慢。

**旁白**：五分鐘後，門開了。

**旁白**：他帶著一身雨氣進來，手上一瓶熱豆漿，看起來是隨手抓的，因為他自己好像也不知道為什麼手上有它。

**旁白**：他看見襪子，停住。坐下，打開夾鏈袋，讀。讀了很久，久到她懷疑自己寫的是外文。

**旁白**：然後他拔開紅筆的筆蓋，寫了什麼，折好，把襪子放到他們中間那張空椅子上。

**旁白**：沒有說話。

**以寧**：(內心)⋯⋯好。所以是這種規則。

**旁白**：她拿起來。「謝謝妳收治它。家屬想詢問：勇氣有沒有可能卡在三號的橡膠圈裡？」

**以寧** [smile]：(內心)他學我的格式。他是譯者，他當然會學我的格式。

**旁白**：她寫：「已檢查橡膠圈。只找到一枚十元硬幣，和一根不知道誰的頭髮。勇氣未尋獲。」放回中間的椅子。

**旁白**：他讀完，肩膀抖了一下。她很確定那是在忍笑。

**旁白**：「十元可以讓二號多轉一次。請收下，當作掛號費。」

**旁白**：「本院不收掛號費。但家屬每週都把四號讓出來，衣服沒乾就帶走，這件事本院注意很久了。」

**旁白**：這次他停了很久。紙條回來的時候，字變小了，像不太敢佔地方。

**旁白**：「我睡不著的時候會來這裡。後來發現，星期四比較睡得著。」

**旁白**：她把那行字看了三遍。外面的雨不知道什麼時候停了。

**旁白**：玻璃上還掛著水珠。天從黑變淡，變成那種洗過很多次的灰藍色，對面便利商店的燈在晨光裡忽然顯得很疲倦。

**旁白**：紙條背面寫滿了。她翻回正面，在「勇氣」那兩個字旁邊的空白處，寫下最後一行：「周以寧。小夜班。星期四。」

**旁白**：她沒有放到椅子上。她站起來，走過那張空椅子，直接把紙條放進他手裡。

**旁白**：他抬頭。近看，他的黑眼圈比她以為的還深。

**紅筆**：⋯⋯江遠。

**紅筆** [smile]：我叫江遠。抱歉，應該先寫的。我的字比我的嘴好用。

**以寧**：我知道。牆上那張也是你改的吧。

**紅筆**：它原本叫大家不要把動物放進去。我覺得人也應該寫一下。

**以寧**：很周到。跟夾鏈袋一樣周到。

**旁白**：他的耳朵又紅了。她決定這次不要數他的呼吸。

**旁白**：他把那瓶豆漿遞過來。早就不熱了，溫溫的，像四號烘到一半的衣服。

**紅筆**：這本來是買給妳的。只是在對面站太久了。

**以寧**：溫的剛好。下班之後喝不了太燙的。

**旁白**：他們一起走出去。騎樓下停著兩台機車，她的和他的，中間隔著一台別人的。

**旁白**：半年來，原來一直隔著一台別人的。

**紅筆**：那個⋯⋯另一隻襪子，我下週四帶來。湊一雙。

**以寧**：你不是說被機器吃掉了？

**紅筆**：嗯。我會想辦法讓它吐出來。

**旁白**：她笑出聲。半年來，第一次在他面前笑出聲。

**以寧** [smile]：好。星期四見。

**紅筆**：星期四見。

**旁白**：她騎出騎樓的時候，天又亮了一點。後照鏡裡，他還站在洗衣店門口，手裡捏著那張寫滿字的紙條，像捏著一份很重要的稿子。

**以寧**：(內心)下個星期四，四號讓他先用。
