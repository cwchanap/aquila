# 《凌晨三點的洗衣店》／The 3 A.M. Laundromat — 企劃

- **story_id**: `three_am_laundromat`
- **類型**：舒適系戀愛（cozy romance），短篇，單次閱讀十分鐘以內
- **視角**：第三人稱貼近，鎖定周以寧

## Premise

每個星期四，小夜班護理師周以寧下班後睡不著，凌晨三點抱著一週的制服去巷口那間 24 小時自助洗衣店。整間店只有四號烘衣機真的會烘乾東西，而一個帶紅筆、黑眼圈很深的譯者總是比她早一點點到。半年來，他們客氣地輪流讓出四號，卻從來沒有交換過名字。今晚，她從自己的洗衣機裡撈出一隻不屬於她的灰襪子，襪子裡折著一張裝在夾鏈袋裡的紙條：「如果你撿到這個——洗衣機吃掉了我另一隻襪子，還有我大部分的勇氣。」

## Acts

| act | location | beats |
| --- | --- | --- |
| act1「同一台烘衣機」 | 洗衣店內，凌晨三點，雨 | 店內生態（四號是唯一會烘乾的、三號洗衣機是她的）；他坐第二張椅子、紅筆、毛衣的洞；牆上被紅筆改正的英文告示「也不要放人」；他又提早拿出沒乾的衣服讓出四號：「它們不介意。」 |
| act2「紙條」 | 同上 | 灰襪子＋防水夾鏈袋＝預謀；她不抬頭，用餘光觀察：同一頁四分鐘沒翻、筆蓋蓋著、耳朵紅、呼吸偏快；筆跡和牆上告示相同；他說要去對面買東西，把洗衣袋留下，站進便利商店的白光裡背對這邊 |
| act3「四十分鐘」 | 同上 | 等烘衣的四十分鐘；她拿出護理師口袋裡的筆，發現自己咬筆蓋是他的習慣；「我不知道他叫什麼」；四號叮一聲——選擇 |
| branch_1a/act4「回信」 | 洗衣店內 → 天亮的洗衣店 → 騎樓下 | 她寫成交班紀錄般的回信；他回來，一句話都不說，兩人隔著空椅子傳紙條；「星期四比較睡得著」；她寫下自己的名字、親手遞過去；他說出江遠；溫掉的豆漿；另一隻襪子「我會想辦法讓它吐出來」；「星期四見。」 |
| branch_1b/act4「留在桌上」 | 洗衣店內 → 黎明前的街 → 四個月後的洗衣店 | 她把紙條按原折痕折回、擺在折衣桌正中央後離開；之後的星期四第二張椅子都空著；她被調去白班；四個月後輪回小夜，四號門上貼著紅筆寫的「故障。最近什麼都吃。」，最下面一行小字「另一隻還在找。」——她決定下週早一點來 |

## Endings

- **b1a「回信」**：小而確實的開始。名字交換了，豆漿是溫的，下週四見。
- **b1b「留在桌上」**：錯過，但門沒有關上。他還在某個她不在的星期四來這裡，而另一隻襪子（和勇氣）還在找。
