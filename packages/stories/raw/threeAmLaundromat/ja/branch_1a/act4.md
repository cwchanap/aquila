# 第四幕：返事

**ナレーション**：彼女はメモを裏返した。

**ナレーション**：ペン先が長いこと止まった。看護記録なら何千枚と書いてきたけれど、こんなに考えこんだことは一度もない。意識清明、バイタル安定、主訴なし。

**ナレーション**：結局、こう書いた。「靴下はこちらで預かっています。状態は安定。勇気については、洗濯機は『見ていない』とのこと。経過観察を推奨します。」

**以寧**：（心の声）……申し送りみたいになった。まあ、いいか。

**ナレーション**：メモをチャック袋に戻し、灰色の靴下に押しこんで、彼の洗濯物の袋の上に置く。それから四つ目の椅子に戻って、服をたたみはじめた。ものすごく、ゆっくりと。

**ナレーション**：五分後、ドアが開いた。

**ナレーション**：彼は雨のにおいをまとって入ってきた。手にはホットの豆乳のボトル。適当につかんできたように見えた。なぜそれを持っているのか、本人もよく分かっていないようだったから。

**ナレーション**：靴下に気づいて、彼は動きを止めた。座って、チャック袋を開けて、読む。長いこと読んでいた。外国語で書いてしまったのかと、彼女が不安になるくらいに。

**ナレーション**：それから赤ペンのキャップを抜いて何か書きつけ、たたみ直すと、靴下を二人のあいだの空いた椅子に置いた。

**ナレーション**：何も言わずに。

**以寧**：（心の声）……なるほど。そういうルールね。

**ナレーション**：手に取る。「入院を受け入れてくださり、ありがとうございます。家族より質問です。勇気が三号のゴムパッキンに挟まっている可能性はありますか。」

**以寧**：（心の声）私の書式をまねしてる。翻訳者だもの、まねするに決まってる。

**ナレーション**：彼女は書いた。「ゴムパッキン確認済み。十元硬貨一枚と、持ち主不明の髪の毛一本を発見。勇気は発見に至らず。」そして真ん中の椅子に戻す。

**ナレーション**：読み終えた彼の肩が、一度だけ震えた。笑いをこらえているのだと、彼女には確信があった。

**ナレーション**：「十元あれば、二号がもう一回まわります。初診料としてお納めください。」

**ナレーション**：「当院では初診料はいただいておりません。ただ、ご家族が毎週四号を譲り、乾いていない服を持ち帰っておられる件については、当院でもずっと気にかけておりました。」

**ナレーション**：今度は、彼の手が長いこと止まった。戻ってきたメモの字は小さくなっていた。場所を取るのを遠慮しているみたいに。

**ナレーション**：「眠れないとき、ここに来ていました。そのうち、木曜日は少しよく眠れることに気づきました。」

**ナレーション**：その一行を、彼女は三回読んだ。外の雨は、いつのまにかやんでいた。

**ナレーション**：ガラスにはまだ水滴が残っている。空は黒から薄れて、何度も洗ったような灰青色になっていた。向かいのコンビニの灯りが、朝の光の中で急にひどく疲れて見えた。

**ナレーション**：メモの裏はもう埋まっていた。表に返し、「勇気」の二文字の横の余白に、最後の一行を書く。「周以寧。準夜勤。木曜日。」

**ナレーション**：椅子には置かなかった。立ち上がって空いた椅子の前を通りすぎ、メモを彼の手に直接渡した。

**ナレーション**：彼が顔を上げる。近くで見ると、クマは思っていたよりずっと深かった。

**赤ペン**：……江遠。

**赤ペン**：江遠といいます。すみません、先に書くべきでした。僕は、口より字のほうが器用なので。

**以寧**：知ってます。壁の貼り紙を直したのも、江遠さんですよね。

**赤ペン**：動物を入れるな、とは書いてあったので。人のことも書いておくべきかと。

**以寧**：用意周到ですね。チャック袋と同じくらい。

**ナレーション**：彼の耳がまた赤くなった。今回は呼吸を数えないでおこう、と彼女は決めた。

**ナレーション**：彼が豆乳を差し出した。とっくに熱くはなく、ぬるくなっていた。四号で半分だけ乾かした服みたいに。

**赤ペン**：これ、本当は周さんに買ったんです。向かいで立っている時間が、長すぎただけで。

**以寧**：ぬるいくらいがちょうどいいです。仕事明けは、熱いのは飲めないので。

**ナレーション**：二人は一緒に店を出た。アーケードの下にはスクーターが二台。彼女のと、彼のと、そのあいだに知らない誰かのが一台。

**ナレーション**：この半年、二人のあいだにはずっと、知らない誰かのスクーターが一台はさまっていたのだ。

**赤ペン**：あの……もう片方の靴下、来週の木曜に持ってきます。ちゃんと一足にします。

**以寧**：洗濯機に食べられたって、言ってませんでした？

**赤ペン**：はい。なんとかして吐き出させます。

**ナレーション**：彼女は声を出して笑った。半年で初めて、彼の前で声を出して笑った。

**以寧**：うん。じゃあ、また木曜日に。

**赤ペン**：また木曜日に。

**ナレーション**：アーケードからスクーターを出したとき、空はまた少し明るくなっていた。ミラーの中で、彼はまだコインランドリーの入口に立っていた。字でびっしり埋まったメモを、とても大事な原稿のように握りしめて。

**以寧**：（心の声）来週の木曜日は、四号を先に譲ってあげよう。
