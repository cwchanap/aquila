# 第四幕：テーブルに残して

**ナレーション**：彼女はメモを、もとの折り目どおりにたたみ直した。四つ折り。角をそろえて。申し送り用紙を、ナースステーションのバインダーに挟み直すみたいに。

**ナレーション**：チャック袋に戻し、灰色の靴下に押しこみ、テーブルのちょうど真ん中に、縁とまっすぐ平行に置く。

**以寧**：（心の声）これがいちばん礼儀正しいやり方。受け取りもしないし、捨てもしない。現物はお返しします、コメントは差し控えます。

**以寧**：（心の声）それに、私は疲れてる。今日は十四床ぶんの申し送りをした。午前四時に誰かを好きになる体力なんて、もう残ってない。

**ナレーション**：乾いた服を袋に詰めこみ、ドアを押して外に出た。

**ナレーション**：雨は小降りになっていた。スクーターはアーケードのいちばん端に停めてあって、シートが濡れている。袖で二回ぬぐったけれど乾かなくて、そのまま座った。

**ナレーション**：エンジンをかける前に、向かいを見ることはしなかった。

**ナレーション**：あの背中も振り返らなかったはずだと、彼女には確信があった。

**ナレーション**：帰り道、空が白みはじめた。通りのシャッターはどこもまだ下りたままで、朝ごはんの店にだけ灯りがついていた。蒸籠から白い湯気が立ちのぼって、まるでこの街が長い長いあくびをしているみたいだった。

**以寧**：（心の声）続きは来週の木曜日。彼は二つ目の椅子、私は四つ目。いつもどおり。

**以寧**：（心の声）いつもどおりで、いい。

**ナレーション**：次の木曜日、二つ目の椅子は空いていた。

**ナレーション**：テーブルの上の灰色の靴下はなくなっていた。彼が持っていったのか、早起きのおばちゃんが気の毒に思ったのか、彼女には分からない。

**ナレーション**：その次の木曜日も、空いていた。

**ナレーション**：その次も。

**以寧**：（心の声）よかった。礼儀正しい。ちゃんと伝わったんだ。

**ナレーション**：月末に勤務表が出て、彼女は日勤に回された。昼間のコインランドリーは別世界だった。子どもがいて、おばちゃんたちがいて、スピーカーにして電話している人がいる。四号はいつも誰かが使っていた。

**ナレーション**：午前三時にここへ来ることは、もうなかった。

**ナレーション**：四か月後、彼女は準夜勤に戻った。

**ナレーション**：最初の木曜日。仕事を終え、シャワーを浴び、目を開けたまま二時五十分まで横になって、それから起き上がり、一週間ぶんの制服を抱えて家を出た。

**ナレーション**：また雨が降っていた。向かいの白い光は相変わらずにじんでいる。切れかけの蛍光灯もまだ瞬いていて、この四か月、誰も手をつけなかったらしい。

**ナレーション**：二つ目の椅子は空いていた。

**以寧**：（心の声）そりゃ、そうだ。

**ナレーション**：服を三号に入れて、いつもの癖で四号のほうへ歩いていく。

**ナレーション**：四号の扉に、紙が一枚貼ってあった。

**ナレーション**：「故障中。最近、なんでも食べます。」

**ナレーション**：赤ペン。几帳面な、活字を組んだみたいな字。

**ナレーション**：彼女はその紙の前に長いこと立っていた。医師の字を五年も読んできたのだ。一人の筆跡を見分けるくらい、難しくはない。紙はまだ白く、テープの端もめくれていない。四か月前に貼られたものではなかった。

**以寧**：（心の声）あの人、まだ来てるんだ。どこかの木曜日に。私のいない、どこかの午前三時に。

**ナレーション**：紙のいちばん下に、もう一行、とても小さな字があった。場所を取るのを遠慮しているみたいな小ささで。

**ナレーション**：「もう片方は、まだ探しています。」

**ナレーション**：ほかの人が読んでも、どこかの運の悪い誰かが靴下をなくしたとしか思わないだろう。

**ナレーション**：ポケットからペンを取り出し、キャップを口にくわえる。今度は、外さなかった。

**ナレーション**：何も書かなかった。まだ、書かない。

**ナレーション**：二号の前まで歩いて、一枚目の十元玉を入れる。あと二枚。

**以寧**：（心の声）来週の木曜日は、もう少し早く来よう。
