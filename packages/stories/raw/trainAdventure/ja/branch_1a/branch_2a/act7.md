# 第七幕：迷霧の森の入口

**李杰**：おじさん、｜俺《おれ》はここでもう｜少《すこ》し｜手《て》がかりを｜探《さが》してみます。｜何《なに》か｜役《やく》に｜立《た》つものが｜見《み》つかるかもしれない。｜先《さき》に｜行《い》っててください、すぐ｜追《お》いつきます。

**清水恵美**：（ほとんど｜間髪《かんぱつ》｜入《い》れずに、はっきりと｜焦《あせ》りのにじむ｜声《こえ》で）わ……わたし、｜李《り》さんと｜一緒《いっしょ》にいます！

**気前のいいおじさん**：（うなずいて）そうか、それもいいだろう。｜気《き》をつけてな。｜危《あぶ》ないと｜思《おも》ったら、｜駅《えき》に｜戻《もど》って｜待《ま》っててくれ。

**ナレーション**：｜気前《きまえ》のいいおじさんはリュックを｜背負《せお》い、｜森《もり》の｜方角《ほうがく》へ｜歩《ある》き｜出《だ》した。｜足音《あしおと》がホームに｜響《ひび》き、しだいに｜遠《とお》ざかって、ついには｜闇《やみ》の｜中《なか》に｜消《き》えた。

**ナレーション**：｜待合室《まちあいしつ》の｜外《そと》には、たちまち｜風《かぜ》の｜音《おと》だけが｜残《のこ》った。｜駅《えき》｜全体《ぜんたい》に、｜李杰《りけつ》と｜恵美《えみ》のふたりきり。｜異様《いよう》な｜孤独感《こどくかん》が、｜二人《ふたり》を｜包《つつ》み｜込《こ》んだ。

**李杰**：（｜心《こころ》の｜声《こえ》）よし、これで｜落《お》ち｜着《つ》いて、もう｜一度《いちど》この｜地図《ちず》をじっくり｜見《み》られる……

**ナレーション**：｜彼《かれ》が｜地図《ちず》に｜意識《いしき》を｜戻《もど》したとたん、そばの｜恵美《えみ》が｜小《ちい》さな｜声《こえ》で｜口《くち》を｜開《ひら》いた。

**清水恵美**：あの……｜李《り》さん……

**李杰**：ん？

**清水恵美**：ふ、ふたりだけに、なっちゃいましたね……ここ……すごく｜暗《くら》くて……｜寒《さむ》い……

**ナレーション**：｜李杰《りけつ》は｜手《て》を｜止《と》め、｜彼女《かのじょ》を｜振《ふ》り｜返《かえ》った。｜恵美《えみ》の｜表情《ひょうじょう》には｜不安《ふあん》がにじみ、｜視線《しせん》はときおり、｜暗《くら》いホームの｜外《そと》へさまよっていく。

**清水恵美**：やっぱり……やっぱり、あの｜人《ひと》たちに｜追《お》いつきませんか……？

**李杰**：（いぶかしげに）｜清水《しみず》さん、さっきは｜俺《おれ》と｜残《のこ》りたいって｜言《い》ってなかったか？　あの｜人《ひと》たちについていきたいなら、どうしておじさんと｜一緒《いっしょ》に｜行《い》かなかったんだ？

**清水恵美**：（｜問《と》われて｜一瞬《いっしゅん》きょとんとし、｜声《こえ》がさらに｜小《ちい》さくなる）だって……だって、あなたといたほうが｜安全《あんぜん》だと｜思《おも》って……でも……でも、｜怖《こわ》くて……

**清水恵美**：（ためらって）みんなが｜遠《とお》くへ｜行《い》ってしまったら、｜本当《ほんとう》にふたりきりになっちゃう｜気《き》がして……だから……だから｜早《はや》く｜決《き》めて、｜一緒《いっしょ》に｜追《お》いかけましょう……

**ナレーション**：その｜声《こえ》は｜怯《おび》えて｜聞《き》こえるのに、｜口調《くちょう》にはどこか｜不思議《ふしぎ》な｜冷静《れいせい》さがあって、まるでこの｜恐怖《きょうふ》が｜意図《いと》して｜演《えん》じられたもののようだった。

**李杰**：（｜心《こころ》の｜声《こえ》）｜彼女《かのじょ》の｜様子《ようす》……どうも｜引《ひ》っかかる。だが、｜言《い》っていることにも｜一理《いちり》ある。｜単独行動《たんどくこうどう》は｜確《たし》かに｜得策《とくさく》じゃない。

**李杰**：（ため｜息《いき》をついて）そうだな。｜君《きみ》の｜言《い》うとおりだ。｜行《い》こう、あの｜人《ひと》たちに｜追《お》いつこう。

**ナレーション**：｜肯定《こうてい》の｜返事《へんじ》を｜得《え》て、｜恵美《えみ》の｜顔《かお》にほっとした｜色《いろ》が｜浮《う》かんだ。だが｜李杰《りけつ》は、その｜安堵《あんど》があまりに｜早《はや》すぎることに｜気《き》づいた。まるで、こうなることを｜最初《さいしょ》から｜予期《よき》していたかのように。

**ナレーション**：｜李杰《りけつ》はすぐには｜動《うご》かず、｜壁際《かべぎわ》へ｜引《ひ》き｜返《かえ》した。｜恵美《えみ》の｜視線《しせん》を｜受《う》けながら、あの｜古《ふる》い｜羊皮紙《ようひし》の｜地図《ちず》をそっと｜壁《かべ》から｜剥《は》がし、｜丁寧《ていねい》に｜折《お》りたたんで、｜自分《じぶん》のポケットにしまった。

**李杰**：（｜心《こころ》の｜声《こえ》）どれだけ｜破《やぶ》れていようと、これが｜俺《おれ》たちの｜唯一《ゆいいつ》の｜道《みち》しるべかもしれない。

**李杰**：よし、｜行《い》こう。

**ナレーション**：そう｜言《い》うと、｜彼《かれ》は｜恵美《えみ》を｜連《つ》れて｜待合室《まちあいしつ》を｜出《で》た。ホームには、｜気前《きまえ》のいいおじさんの｜姿《すがた》はとうに｜闇《やみ》へ｜消《き》えている。

**ナレーション**：ホームの｜端《はし》から、｜細《ほそ》い｜土《つち》の｜道《みち》が｜森《もり》の｜奥《おく》へと｜続《つづ》いていた。ほかの｜人々《ひとびと》が｜去《さ》っていったのは、おそらくこの｜道《みち》だろう。

**ナレーション**：｜李杰《りけつ》と｜恵美《えみ》は｜小道《こみち》に｜踏《ふ》み｜入《い》り、｜森《もり》の｜方角《ほうがく》へ｜進《すす》んでいった。｜二《ふた》つの｜紫《むらさき》の｜月《つき》の｜光《ひかり》は｜背後《はいご》でしだいに｜遠《とお》ざかり、｜行《ゆ》く｜手《て》には、｜未知《みち》の｜闇《やみ》が｜広《ひろ》がっているだけだった。
