# 第八幕：分かれ道の謎

**ナレーション**：｜迷霧《めいむ》の｜森《もり》に｜足《あし》を｜踏《ふ》み｜入《い》れた｜瞬間《しゅんかん》、あたりの｜空気《くうき》は｜湿《しめ》って｜冷《つめ》たく、｜重《おも》たいものに｜変《か》わった。｜奇怪《きかい》な｜形《かたち》の｜木々《きぎ》が｜雲《くも》を｜突《つ》くようにそびえ、｜枝葉《えだは》が｜空《そら》の｜二《ふた》つの｜月《つき》を｜覆《おお》い｜隠《かく》している。わずかな｜隙間《すきま》から｜細《ほそ》い｜糸《いと》のような｜不気味《ぶきみ》な｜紫《むらさき》の｜光《ひかり》が｜差《さ》し｜込《こ》み、｜立《た》ちこめる｜白《しろ》い｜霧《きり》を｜照《て》らしていた。

**ナレーション**：はじめのうち｜霧《きり》は｜薄《うす》く、あたりの｜景色《けしき》をいくらかぼやけさせる｜程度《ていど》だった。だが｜奥《おく》へ｜進《すす》むにつれ、｜霧《きり》はしだいに｜濃《こ》くなっていく。

**ナレーション**：｜十分後《じゅっぷんご》には、｜視界《しかい》はほんの｜数《すう》メートルにまで｜落《お》ちた。｜紫《むらさき》の｜月明《つきあ》かりはほとんど｜遮《さえぎ》られ、あたりはいっそう｜薄暗《うすぐら》くなる。

**李杰**：（スマホを｜取《と》り｜出《だ》し、ライトをつける）｜霧《きり》がどんどん｜濃《こ》くなってきた……

**清水恵美**：（｜李杰《りけつ》のすぐ｜後《うし》ろにぴったりついて、｜小《ちい》さな｜声《こえ》で）ええ……

**ナレーション**：スマホの｜光《ひかり》は｜霧《きり》の｜中《なか》では、｜目《め》の｜前三《まえさん》メートルにも｜届《とど》かない｜範囲《はんい》しか｜照《て》らせない。｜白《しろ》い｜霧《きり》は｜流《なが》れる｜壁《かべ》のように、｜二人《ふたり》を｜取《と》り｜囲《かこ》んでいた。

**ナレーション**：さらに｜数分《すうふん》｜歩《ある》くと、｜霧《きり》は、｜足《あし》もとの｜土《つち》の｜道《みち》と、｜道端《みちばた》のぼんやりした｜数本《すうぽん》の｜木影《こかげ》しか｜見《み》えないほど｜濃《こ》くなった。

**ナレーション**：｜十数分《じゅうすうふん》ほど｜歩《ある》いたころには、｜背後《はいご》の｜風《かぜ》の｜音《おと》も｜波《なみ》の｜音《おと》ももう｜聞《き》こえなくなっていた。あたりに｜響《ひび》くのは、｜枯《か》れ｜葉《は》を｜踏《ふ》む｜自分《じぶん》たちのかさかさという｜音《おと》と、｜心臓《しんぞう》の｜鼓動《こどう》だけだ。

**李杰**：（ある｜事実《じじつ》に｜気《き》づいて｜足《あし》を｜止《と》め）｜俺《おれ》たち……あの｜人《ひと》たちを｜見失《みうしな》ったんだ。

**李杰**：（｜前方《ぜんぽう》の｜濃霧《のうむ》に｜向《む》かって｜叫《さけ》ぶ）おじさん！　どこにいるんですか？

**清水恵美**：（｜恵美《えみ》も｜勇気《ゆうき》を｜出《だ》し、｜震《ふる》える｜声《こえ》で｜叫《さけ》ぶ）｜誰《だれ》か、いませんか――？

**ナレーション**：｜森《もり》は｜二人《ふたり》の｜声《こえ》を｜呑《の》み｜込《こ》み、｜何《なん》の｜返事《へんじ》もない。こだまの｜一片《いっぺん》さえ｜返《かえ》ってこなかった。

**李杰**：（｜心《こころ》の｜声《こえ》）｜完全《かんぜん》にはぐれてしまった……｜急《いそ》がないと。

**李杰**：｜清水《しみず》さん、しっかりついてきて。｜急《いそ》がないといけない。

**清水恵美**：（うなずいて）はい……

**ナレーション**：｜二人《ふたり》はほとんど｜小走《こばし》りで、｜濃霧《のうむ》の｜立《た》ちこめる｜森《もり》を｜進《すす》んだ。｜霧《きり》は｜極限《きょくげん》まで｜濃《こ》く、｜頼《たよ》りになるのは｜足《あし》もとの｜土《つち》の｜道《みち》だけで、それで｜方向《ほうこう》を｜判断《はんだん》するしかない。

**ナレーション**：｜重苦《おもくる》しい｜空気《くうき》の｜中《なか》で、｜時間《じかん》が｜過《す》ぎていく。｜周囲《しゅうい》の｜景色《けしき》にはまったく｜変化《へんか》がなく、｜同《おな》じ｜場所《ばしょ》をぐるぐる｜回《まわ》っているかのようだった。

**ナレーション**：｜一時間《いちじかん》ほど｜急《いそ》ぎ｜足《あし》で｜進《すす》んだころ、｜李杰《りけつ》は｜前方《ぜんぽう》の｜空間《くうかん》がいくらか｜開《あ》けてきたのに｜気《き》づいた。｜霧《きり》は｜相変《あいか》わらず｜濃《こ》いが、｜先《さき》ほどのような｜圧迫感《あっぱくかん》はない。

**李杰**：（｜足《あし》を｜止《と》め、｜息《いき》を｜切《き》らして）ここは……

**ナレーション**：｜二人《ふたり》は、ある｜分《わ》かれ｜道《みち》にたどり｜着《つ》いた。

**李杰**：（｜眉《まゆ》をひそめて）おかしい……これだけ｜急《いそ》いだんだ、とっくに｜追《お》いついているはずなのに。どうして｜足跡《あしあと》ひとつ｜見当《みあ》たらないんだ？

**ナレーション**：だが、｜目《め》の｜前《まえ》の｜光景《こうけい》はさらに｜彼《かれ》を｜不安《ふあん》にさせた。｜彼《かれ》は｜素早《すばや》くポケットから｜羊皮紙《ようひし》の｜地図《ちず》を｜取《と》り｜出《だ》し、スマホの｜光《ひかり》で｜照《て》らした。

**李杰**：（｜心《こころ》の｜声《こえ》）｜地図《ちず》に｜描《えが》かれているのと｜違《ちが》う……

**ナレーション**：｜地図《ちず》にはたしかに「｜幽冥《ゆうめい》の｜都《みやこ》」へ｜向《む》かう｜分《わ》かれ｜道《みち》がひとつしか｜描《えが》かれていなかったのに、ここには……｜道《みち》が｜四本《よんほん》ある。

**ナレーション**：｜一本《いっぽん》は｜彼《かれ》らが｜来《き》た｜主道《しゅどう》で、そのまままっすぐ｜前《まえ》へ｜延《の》びている。｜左側《ひだりがわ》には｜大《おお》きさのよく｜似《に》た｜小径《こみち》が｜二本《にほん》、｜右側《みぎがわ》にも｜小径《こみち》が｜一本《いっぽん》あった。

**ナレーション**：｜李杰《りけつ》は｜地図《ちず》と｜照《て》らし｜合《あ》わせて｜分析《ぶんせき》した。まっすぐ｜進《すす》めば、｜迷霧《めいむ》の｜森《もり》の｜奥《おく》へ｜続《つづ》く｜主道《しゅどう》のはずだ。｜右《みぎ》の｜道《みち》は、｜地図上《ちずじょう》の｜方角《ほうがく》からして、おそらく「｜幽冥《ゆうめい》の｜都《みやこ》」へ｜向《む》かう｜支線《しせん》だろう。

**ナレーション**：だが、｜左《ひだり》の｜二本《にほん》の｜道《みち》は……｜地図《ちず》にはまったく｜記《しる》されていない。

**李杰**：（｜心《こころ》の｜声《こえ》）｜未知《みち》の｜道《みち》……リスクが｜大《おお》きすぎる。

**ナレーション**：｜四本《よんほん》の｜道《みち》、｜四《よっ》つの｜選択《せんたく》。どれもがまったく｜異《こと》なる｜運命《うんめい》へ｜続《つづ》いているかもしれない。｜決《き》めかねた｜彼《かれ》は、｜無意識《むいしき》のうちに、そばにいる｜唯一《ゆいいつ》の｜相談相手《そうだんあいて》へ｜顔《かお》を｜向《む》けた。

**李杰**：｜清水《しみず》さんは、どう｜思《おも》う？

**清水恵美**：（｜不意《ふい》に｜問《と》われて｜緊張《きんちょう》し、｜周囲《しゅうい》の｜濃霧《のうむ》を｜見回《みまわ》し、｜底《そこ》の｜知《し》れない｜四本《よんほん》の｜小径《こみち》を｜見《み》やって）わ、わたし……｜分《わ》かりません……

**清水恵美**：（ためらって）でも……｜前《まえ》のこの｜道《みち》がいちばん｜広《ひろ》くて、いちばん｜目立《めだ》ちます……おじさんたちも、｜大《おお》きな｜道《みち》のほうが｜安全《あんぜん》だと｜思《おも》って、この｜道《みち》を｜選《えら》んだんじゃないでしょうか……？

**ナレーション**：｜李杰《りけつ》は｜彼女《かのじょ》の｜視線《しせん》を｜追《お》って、｜前方《ぜんぽう》の｜主道《しゅどう》を｜見《み》た。｜濃霧《のうむ》の｜中《なか》でも、その｜道《みち》はもっとも｜広々《ひろびろ》として｜見《み》え、｜唯一《ゆいいつ》の「｜正《ただ》しい｜道《みち》」であるかのようだった。

**李杰**：（｜心《こころ》の｜声《こえ》）｜彼女《かのじょ》の｜言《い》うことには｜一理《いちり》ある。これ｜以上《いじょう》の｜手《て》がかりがない｜以上《いじょう》、｜主道《しゅどう》を｜行《い》くのがいちばん｜間違《まちが》いの｜少《すく》ない｜選択《せんたく》で、おじさんたちに｜追《お》いつける｜可能性《かのうせい》も｜高《たか》い。

**李杰**：（｜心《こころ》の｜声《こえ》）だが……｜右《みぎ》の｜道《みち》は、｜地図《ちず》に「｜幽冥《ゆうめい》の｜都《みやこ》」へ｜通《つう》じると｜記《しる》されている。そこには｜人《ひと》がいるのか？　｜文明《ぶんめい》の｜痕跡《こんせき》があるのか？

**李杰**：（｜心《こころ》の｜声《こえ》）それに｜左《ひだり》の｜二本《にほん》……｜地図《ちず》には｜載《の》っていないが、｜近道《ちかみち》かもしれない。それとも……｜何《なに》かが｜隠《かく》されているのか？

**ナレーション**：｜李杰《りけつ》は｜目《め》の｜前《まえ》の｜四本《よんほん》の｜道《みち》を｜見《み》て、それから｜手《て》の｜中《なか》の｜破《やぶ》れた｜地図《ちず》に｜目《め》を｜落《お》とした。｜恵美《えみ》は｜彼《かれ》の｜隣《となり》に｜立《た》ち、｜静《しず》かに｜決断《けつだん》を｜待《ま》っている。

**ナレーション**：｜濃霧《のうむ》が｜分《わ》かれ｜道《みち》をゆるやかに｜流《なが》れ、｜四本《よんほん》の｜道《みち》の｜奥《おく》はどれも｜白《しろ》に｜呑《の》まれて、｜果《は》ては｜見《み》えない。

**李杰**：（｜地図《ちず》を｜握《にぎ》りしめ、｜心《こころ》の｜声《こえ》）｜俺《おれ》はどれを｜選《えら》ぶべきなんだ……
