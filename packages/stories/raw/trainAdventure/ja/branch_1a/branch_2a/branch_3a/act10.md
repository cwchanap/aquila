# 第十幕：霧の小屋の休息

**ナレーション**：｜李杰《りけつ》が｜小屋《こや》の｜戸《と》を｜押《お》し｜開《あ》けると、｜乾《かわ》いて、ほのかに｜木《き》の｜香《かお》りを｜含《ふく》んだ｜暖《あたた》かな｜空気《くうき》が｜顔《かお》に｜触《ふ》れた。｜外《そと》の｜湿《しめ》って｜冷《つめ》たい｜濃霧《のうむ》とは、｜鮮《あざ》やかな｜対比《たいひ》をなしている。

**ナレーション**：｜屋内《おくない》に｜電気《でんき》はないが、｜壁《かべ》に｜掛《か》けられたいくつかのオイルランプが｜柔《やわ》らかな｜橙色《だいだいいろ》の｜光《ひかり》を｜放《はな》ち、｜空間《くうかん》｜全体《ぜんたい》を｜温《あたた》かく、そして｜不思議《ふしぎ》な｜雰囲気《ふんいき》にしていた。

**李杰**：（｜心《こころ》の｜声《こえ》）これは……ただの｜小屋《こや》じゃない。

**ナレーション**：｜屋内《おくない》の｜調度《ちょうど》は｜簡素《かんそ》だが、きちんと｜片《かた》づいている。｜皺《しわ》ひとつないシーツをかけた｜二人用《ふたりよう》のベッドが｜壁際《かべぎわ》に｜置《お》かれ、その｜脇《わき》には｜木製《もくせい》のナイトテーブルがあった。

**ナレーション**：｜隅《すみ》には｜簡素《かんそ》な｜小《ちい》さな｜台所《だいどころ》があり、｜陶器《とうき》の｜椀《わん》や｜皿《さら》が｜並《なら》んでいる。｜薪《たきぎ》をくべる｜簡易《かんい》なかまどまで｜備《そな》えてあった。｜反対側《はんたいがわ》には｜扉《とびら》があり、トイレと｜浴室《よくしつ》だろう。

**ナレーション**：どの｜品《しな》も、ついさっきまで｜誰《だれ》かが｜使《つか》っていたかのようで、｜塵《ちり》ひとつなく｜清潔《せいけつ》に｜保《たも》たれ、｜丹念《たんねん》に｜手入《てい》れされているという｜印象《いんしょう》を｜与《あた》える。

**李杰**：（｜心《こころ》の｜声《こえ》）こんな｜鬼《おに》のような｜場所《ばしょ》に、これほど｜快適《かいてき》な｜住《す》まいがあるなんて？　あまりに……｜異常《いじょう》だ。｜罠《わな》か？　それとも、｜何《なに》かの｜善意《ぜんい》による｜手配《てはい》なのか？

**ナレーション**：｜彼《かれ》は｜隣《となり》の｜恵美《えみ》を｜見《み》やり、どんな｜反応《はんのう》をするか｜確《たし》かめようとした。だが｜恵美《えみ》はただ｜静《しず》かに｜屋内《おくない》を｜眺《なが》めているだけで、｜目《め》には｜疲《つか》れこそあれ、｜彼《かれ》が｜予期《よき》したような｜驚《おどろ》きも｜疑問《ぎもん》も｜浮《う》かべていない。

**ナレーション**：｜彼女《かのじょ》はこうした「｜道理《どうり》に｜合《あ》わない」｜存在《そんざい》のすべてを、｜当然《とうぜん》のこととして｜受《う》け｜入《い》れているように｜見《み》えた。

**李杰**：（｜心《こころ》の｜声《こえ》）｜彼女《かのじょ》は……｜少《すこ》しも｜変《へん》だと｜思《おも》わないのか？　どうしてこんなに｜落《お》ち｜着《つ》いているんだ？

**ナレーション**：｜胸《むね》には｜疑問《ぎもん》と、｜恵美《えみ》への｜疑念《ぎねん》が｜渦巻《うずま》いていたが、｜極度《きょくど》の｜肉体的疲労《にくたいてきひろう》がそれを｜深《ふか》く｜考《かんが》える｜余裕《よゆう》を｜奪《うば》った。いまは、｜身体《しんたい》の｜生存本能《せいぞんほんのう》が、あらゆる｜理性的《りせいてき》な｜分析《ぶんせき》を｜押《お》さえ｜込《こ》んでいた。

**李杰**：（｜恵美《えみ》のほうを｜向《む》き、できるだけ｜穏《おだ》やかな｜口調《くちょう》で）｜清水《しみず》さん、｜浴室《よくしつ》があるから、｜先《さき》に｜汗《あせ》を｜流《なが》してくるといい。それから、ベッドで｜休《やす》んで。

**清水恵美**：（｜疲《つか》れで｜少《すこ》しかすれた｜声《こえ》で）｜李《り》さん……あなたは？

**李杰**：｜俺《おれ》はあとでいい。ベッドは｜君《きみ》が｜使《つか》って、｜俺《おれ》は｜床《ゆか》で｜寝《ね》るから。

**清水恵美**：（｜不安《ふあん》げに｜自分《じぶん》の｜服《ふく》の｜裾《すそ》をつかんで）そ、そんなの、いけません……わたしたち……｜一緒《いっしょ》にベッドで｜寝《ね》ればいいんです……ベッド、｜大《おお》きいですし……

**李杰**：（｜即座《そくざ》に｜断《ことわ》って）いや、｜君《きみ》が｜使《つか》ってくれ。｜床《ゆか》で｜構《かま》わない。どうせ｜俺《おれ》も｜疲《つか》れてて、どこでも｜寝《ね》られるさ。

**清水恵美**：（｜李杰《りけつ》の｜態度《たいど》が｜固《かた》いので、うなずくしかなく）じゃ……じゃあ、そうします……ありがとうございます、｜李《り》さん。

**ナレーション**：｜恵美《えみ》はベッドの｜脇《わき》にあったタオルと、｜清潔《せいけつ》そうな｜着替《きが》え｜一式《いっしき》――｜誰《だれ》が｜置《お》いていったのかは｜分《わ》からない――を｜手《て》に｜取《と》り、｜浴室《よくしつ》へ｜入《はい》っていった。ほどなく、｜中《なか》から｜水音《みずおと》が｜聞《き》こえてきた。

**ナレーション**：｜李杰《りけつ》は｜台所《だいどころ》で｜少《すこ》し｜水《みず》を｜探《さが》し、｜顔《かお》を｜洗《あら》って、いくらか｜頭《あたま》をはっきりさせた。それから｜壁《かべ》にもたれ、｜恵美《えみ》が｜出《で》てくるのを｜待《ま》った。

**ナレーション**：｜十数分後《じゅうすうふんご》、｜恵美《えみ》が｜浴室《よくしつ》から｜出《で》てきた。｜清潔《せいけつ》な｜服《ふく》に｜着替《きが》えている――｜飾《かざ》り｜気《け》のない｜白《しろ》い｜木綿《もめん》の｜長衣《ちょうい》。｜濡《ぬ》れた｜髪《かみ》が｜肩《かた》にかかっていた。

**清水恵美**：（｜小声《こごえ》で）｜李《り》さん……｜終《お》わりました……

**李杰**：（うなずいて）ああ、｜先《さき》に｜休《やす》んでくれ。｜俺《おれ》も｜浴《あ》びてくる。

**ナレーション**：｜恵美《えみ》は｜素直《すなお》にベッドの｜脇《わき》へ｜行《い》き、｜端《はし》のほうで｜身《み》を｜丸《まる》めて、｜目《め》を｜閉《と》じた。

**ナレーション**：｜李杰《りけつ》は｜浴室《よくしつ》に｜入《はい》った。｜冷《つめ》たい｜水《みず》が｜疲《つか》れた｜体《からだ》を｜洗《あら》い｜流《なが》し、｜少《すこ》しだけ｜意識《いしき》がはっきりする。｜彼《かれ》は｜壁《かべ》にもたれ、｜水《みず》が｜顔《かお》を｜伝《つた》うに｜任《まか》せた。

**李杰**：（｜心《こころ》の｜声《こえ》）｜電車《でんしゃ》に｜乗《の》ってからというもの、｜何《なに》もかもが｜馬鹿《ばか》げている……｜列車《れっしゃ》は｜未知《みち》の｜世界《せかい》へ｜走《はし》り｜込《こ》み、｜地図《ちず》にはない｜分《わ》かれ｜道《みち》があり、｜一時間近《いちじかんちか》くも｜走《はし》ったのにあの｜連中《れんちゅう》に｜追《お》いつけない……

**李杰**：（｜心《こころ》の｜声《こえ》）それに、｜清水《しみず》さんは｜森《もり》の｜中《なか》のほうがかえって｜落《お》ち｜着《つ》いている……おじさんと｜清水《しみず》さんには｜地図《ちず》の｜文字《もじ》が｜読《よ》めないのに、｜俺《おれ》だけが｜読《よ》める。そして、あの｜突然《とつぜん》｜消《き》えた｜黒衣《こくい》の｜男《おとこ》……

**李杰**：（｜心《こころ》の｜声《こえ》）｜何《なに》ひとつつながらない。まるで｜絡《から》まり｜合《あ》った｜糸《いと》だ。

**ナレーション**：｜疲労《ひろう》と｜無力感《むりょくかん》が、ふたたび｜潮《しお》のように｜押《お》し｜寄《よ》せてくる。｜彼《かれ》はこれらの｜断片《だんぺん》をつなぎ｜合《あ》わせようとしたが、｜思考《しこう》はますます｜重《おも》くなるばかりだった。

**ナレーション**：｜結局《けっきょく》、｜彼《かれ》はあきらめるしかなく、｜眠気《ねむけ》に｜呑《の》まれるに｜任《まか》せた。

**ナレーション**：｜李杰《りけつ》が｜浴室《よくしつ》から｜出《で》てきたとき、｜恵美《えみ》はもう｜深《ふか》い｜眠《ねむ》りに｜落《お》ちていた。｜二人用《ふたりよう》のベッドの｜端《はし》で｜身《み》を｜丸《まる》め、｜静《しず》かで｜青白《あおじろ》い｜寝顔《ねがお》は、｜駅《えき》のホームにいた｜気弱《きよわ》な｜少女《しょうじょ》に｜戻《もど》ったかのようだった。

**ナレーション**：｜李杰《りけつ》は｜彼女《かのじょ》を｜起《お》こさず、｜毛布《もうふ》を｜一枚《いちまい》｜取《と》って、ベッドのそばの｜床《ゆか》に｜無造作《むぞうさ》に｜敷《し》いた。｜横《よこ》になった｜瞬間《しゅんかん》、ほとんど｜間《ま》をおかずに｜昏睡《こんすい》のような｜眠《ねむ》りへ｜落《お》ちていった。

**ナレーション**：どれほど｜時間《じかん》が｜過《す》ぎたのか。

**李杰**：（はっと｜目《め》を｜開《あ》け、｜頭《あたま》の｜中《なか》は｜茫然《ぼうぜん》として）ん……？

**ナレーション**：｜全身《ぜんしん》がばらばらになったように｜重《おも》く、めまいがして、｜意識《いしき》はぼんやりしている。｜周囲《しゅうい》は｜相変《あいか》わらずランプの｜黄《き》ばんだ｜光《ひかり》に｜満《み》ち、｜小屋《こや》の｜中《なか》には｜静《しず》かな｜空気《くうき》が｜漂《ただよ》っていた。

**ナレーション**：｜彼《かれ》は｜癖《くせ》のようにベッドへ｜目《め》をやった。

**李杰**：（｜心《こころ》の｜声《こえ》）｜清水《しみず》さん……

**ナレーション**：ベッドは｜最初《さいしょ》のままきちんと｜整《ととの》っているのに、｜恵美《えみ》の｜姿《すがた》だけが｜見当《みあ》たらない。

**李杰**：（｜心《こころ》の｜声《こえ》）｜彼女《かのじょ》……いつ｜起《お》きたんだ？　トイレにでも｜行《い》ったのか？　それとも、もう｜目《め》を｜覚《さ》ましていて、｜俺《おれ》が｜疲《つか》れすぎて｜物音《ものおと》に｜気《き》づかなかっただけか？

**ナレーション**：｜李杰《りけつ》の｜頭《あたま》は｜混濁《こんだく》して、｜深《ふか》く｜考《かんが》えることができない。｜疲労《ひろう》がまた｜潮《しお》のように｜押《お》し｜寄《よ》せ、まぶたは｜重《おも》くて｜持《も》ち｜上《あ》がらなかった。

**ナレーション**：｜彼《かれ》はもがくように｜起《お》き｜上《あ》がり、｜恵美《えみ》を｜探《さが》しに｜行《い》こうとしたが、｜体《からだ》はまったく｜言《い》うことを｜聞《き》かない。

**ナレーション**：｜結局《けっきょく》、｜彼《かれ》は｜強烈《きょうれつ》な｜眠気《ねむけ》に｜抗《あらが》いきれず、ふたたび｜深《ふか》い｜眠《ねむ》りに｜落《お》ちた。

**ナレーション**：｜二度目《にどめ》に｜目《め》を｜覚《さ》ますまで。
