# 第十一幕：砕けた手がかり

**ナレーション**：｜李杰《りけつ》は｜今度《こんど》こそ｜完全《かんぜん》に｜目《め》が｜覚《さ》めた。｜半分夢《はんぶんゆめ》の｜中《なか》にいるようなぼんやりした｜状態《じょうたい》ではなく、｜意識《いしき》がはっきりと｜冴《さ》えている。

**ナレーション**：｜恵美《えみ》が｜背《せ》を｜向《む》けて、｜小《ちい》さなかまどのそばで｜忙《いそが》しく｜動《うご》いている。その｜手《て》つきは｜慣《な》れていて｜軽《かろ》やかで、｜普段《ふだん》からこういうことをしているかのようだった。

**李杰**：（｜立《た》ち｜上《あ》がって、こわばった｜体《からだ》をほぐしながら）ありがとう、｜助《たす》かるよ。

**ナレーション**：｜恵美《えみ》は｜湯気《ゆげ》の｜立《た》つお｜粥《かゆ》を｜二杯《にはい》｜運《はこ》んできて、テーブルに｜置《お》いた。｜白《しろ》い｜湯気《ゆげ》が｜薄暗《うすぐら》いランプの｜光《ひかり》の｜中《なか》をゆっくりと｜立《た》ちのぼり、｜米《こめ》の｜香《かお》りと、｜乾物《かんぶつ》のほのかな｜塩気《しおけ》を｜運《はこ》んでくる。

**ナレーション**：｜李杰《りけつ》がさじを｜取《と》ろうとしたとき、｜夜中《よなか》に｜目《め》が｜覚《さ》めたときのおぼろげな｜記憶《きおく》が、｜突然《とつぜん》はっきりしたものになった。｜思《おも》い｜出《だ》したのだ――｜恵美《えみ》がベッドにいなかった、あの｜光景《こうけい》を。

**李杰**：そういえば、｜清水《しみず》さん……｜夜中《よなか》に｜一度目《いちどめ》が｜覚《さ》めたんだけど、そのとき｜君《きみ》……ベッドにいなかった。どこに｜行《い》ってたんだ？

**ナレーション**：｜椀《わん》を｜持《も》つ｜恵美《えみ》の｜手《て》がかすかに｜震《ふる》え、お｜粥《かゆ》がこぼれそうになった。

**清水恵美**：（｜目《め》をそらして、｜彼《かれ》を｜見《み》ようとせず）え？　そ、そうでしたっけ……？　わ、わたし、たぶんお｜手洗《てあら》いに｜行《い》ってたんだと｜思《おも》います……｜李《り》さん、きっと｜疲《つか》れすぎてて、｜思《おも》い｜違《ちが》いをしたんじゃ……さ、さあ、｜食《た》べてください、｜冷《さ》めちゃいますから。

**ナレーション**：｜彼女《かのじょ》は｜慌《あわ》てて｜椀《わん》を｜李杰《りけつ》の｜前《まえ》へ｜押《お》しやると、うつむいて｜自分《じぶん》のお｜粥《かゆ》をすすり｜始《はじ》めた。この｜話題《わだい》を｜避《さ》けているのは｜明《あき》らかだった。

**ナレーション**：｜李杰《りけつ》は｜彼女《かのじょ》の｜伏《ふ》せた｜頭《あたま》を｜見《み》つめ、｜胸《むね》の｜中《なか》の｜疑念《ぎねん》がますます｜大《おお》きくなった。｜反応《はんのう》があまりに｜不自然《ふしぜん》だ――｜本当《ほんとう》にお｜手洗《てあら》いに｜行《い》っただけなら、どうしてあんなに｜緊張《きんちょう》するのか。

**李杰**：（｜心《こころ》の｜声《こえ》）｜何《なに》か｜隠《かく》している……だが、いま｜問《と》い｜詰《つ》めても｜無駄《むだ》だ。まずは｜腹《はら》ごしらえをして、｜体力《たいりょく》を｜温存《おんぞん》しよう。

**ナレーション**：｜二人《ふたり》は｜黙《だま》って、この｜簡素《かんそ》な｜朝食《ちょうしょく》を｜食《た》べ｜終《お》えた。お｜粥《かゆ》は｜熱《あつ》かったが、｜味《あじ》は｜悪《わる》くなかった。｜少《すく》なくとも、｜腹《はら》ぺこのまま｜森《もり》を｜歩《ある》くよりはずっといい。

**李杰**：おじさんたち、どうしてるかな。｜面倒《めんどう》なことになってなきゃいいけど。

**清水恵美**：ええ……｜食《た》べ｜終《お》わったら……｜早《はや》く、｜追《お》いかけましょう。｜人数《にんずう》が｜多《おお》いほうが……やっぱり、｜安心《あんしん》ですし。

**ナレーション**：｜食《た》べ｜終《お》えると、｜恵美《えみ》は｜自分《じぶん》から｜進《すす》んで｜食器《しょっき》を｜片《かた》づけ、それから｜戸棚《とだな》から｜乾燥果実《かんそうかじつ》と｜穀物《こくもつ》を｜取《と》り｜出《だ》して、｜布《ぬの》に｜包《つつ》み、｜自分《じぶん》のリュックにしまった。

**ナレーション**：｜出発《しゅっぱつ》の｜前《まえ》に、｜李杰《りけつ》はもうしばらく｜時間《じかん》をかけて、この｜小屋《こや》をもう｜一度《いちど》じっくり｜観察《かんさつ》した。どの｜隅《すみ》も｜不思議《ふしぎ》なほど｜清潔《せいけつ》で、｜埃《ほこり》もなく、｜蜘蛛《くも》の｜巣《す》もなく、｜壁《かべ》の｜隅《すみ》にさえ｜汚《よご》れひとつ｜見当《みあ》たらない。

**李杰**：（｜心《こころ》の｜声《こえ》）ここの｜主《ぬし》は……ごく｜最近《さいきん》｜出《で》ていったのか？　それとも……ずっと｜近《ちか》くにいるのか？

**ナレーション**：｜結局《けっきょく》、これといった｜手《て》がかりは｜見《み》つからなかった。｜二人《ふたり》は｜連《つ》れ｜立《だ》って｜小屋《こや》を｜出《で》ると、ふたたび｜濃霧《のうむ》に｜閉《と》ざされた｜小径《こみち》へ｜戻《もど》った。

**ナレーション**：｜濃霧《のうむ》は｜相変《あいか》わらずで、｜見通《みとお》しも｜相変《あいか》わらず｜悪《わる》い。｜紫《むらさき》の｜月《つき》の｜光《ひかり》は、｜今日《きょう》もこの｜白《しろ》い｜障壁《しょうへき》を｜通《とお》り｜抜《ぬ》けられない。まるで、｜二人《ふたり》がこの｜霧《きり》の｜世界《せかい》から｜一度《いちど》も｜出《で》たことがなかったかのようだ。
