# 第十二幕：血の跡と選択

**ナレーション**：｜李杰《りけつ》は｜砕《くだ》けた｜眼鏡《めがね》を｜拾《ひろ》い｜上《あ》げ、じっくりと｜眺《なが》めた。｜黒《くろ》の｜細《ほそ》いフレーム、｜左《ひだり》のつるは｜曲《ま》がって｜歪《ゆが》み、｜右《みぎ》のレンズは｜粉々《こなごな》に｜割《わ》れて、｜鋭《するど》い｜割《わ》れ｜口《くち》が｜薄暗《うすぐら》い｜光《ひかり》の｜中《なか》で｜冷《つめ》たくきらめいている。｜頭《あたま》の｜中《なか》で、ある｜人影《ひとかげ》がぼんやりとよぎった。

**李杰**：（｜心《こころ》の｜声《こえ》）この｜眼鏡《めがね》……ありふれたデザインだけど、どこかで｜見《み》た｜覚《おぼ》えが……？

**ナレーション**：｜懸命《けんめい》に｜思《おも》い｜出《だ》そうとするうち、｜頭《あたま》の｜中《なか》に、｜刺々《とげとげ》しい｜声《こえ》が｜響《ひび》いた――「お｜前《まえ》ら｜馬鹿《ばか》か！」。あの｜痩《や》せて｜背《せ》の｜高《たか》い｜人影《ひとかげ》が、｜鼻筋《はなすじ》の｜上《うえ》の、これとよく｜似《に》た｜黒《くろ》｜縁《ふち》の｜眼鏡《めがね》をつんと｜押《お》し｜上《あ》げていた。

**李杰**：（｜目《め》つきを｜鋭《するど》くして、｜思《おも》わず｜声《こえ》を｜上《あ》げる）これは、｜眼鏡《めがね》の｜男《おとこ》のだ！

**清水恵美**：（｜声《こえ》を｜震《ふる》わせて）｜眼鏡《めがね》の｜人《ひと》……？　あの｜人《ひと》、｜何《なに》かあったんじゃ……？

**李杰**：その｜可能性《かのうせい》は｜高《たか》い。ここで｜眼鏡《めがね》が｜見《み》つかったんだ、きっと｜近《ちか》くにいる。｜探《さが》してみよう！

**ナレーション**：｜李杰《りけつ》と｜恵美《えみ》は｜周囲《しゅうい》の｜濃霧《のうむ》の｜中《なか》を｜捜索《そうさく》し｜始《はじ》めた。このあたりは｜木々《きぎ》がいっそう｜高《たか》く｜密生《みっせい》し、｜見通《みとお》しはひどく｜悪《わる》い。｜二人《ふたり》は｜身《み》をかがめ、｜土《つち》と｜木《き》の｜根《ね》を｜隅々《すみずみ》まで｜丹念《たんねん》に｜調《しら》べていく。｜腐葉土《ふようど》の｜匂《にお》いが｜湿《しめ》った｜霧《きり》と｜混《ま》じり｜合《あ》い、｜息苦《いきぐる》しいほどだった。

**ナレーション**：｜五分《ごふん》ほどして、｜李杰《りけつ》は｜道端《みちばた》の｜太《ふと》い｜木《き》の｜幹《みき》に、｜怪《あや》しい｜暗《くら》い｜色《いろ》の｜痕跡《こんせき》を｜見《み》つけた。

**李杰**：｜清水《しみず》さん、｜見《み》てくれ、ここだ！

**ナレーション**：｜幹《みき》の、｜地面《じめん》から｜一《いち》メートルほどの｜高《たか》さに、はっきりとした｜擦《す》り｜傷《きず》がある。｜痕跡《こんせき》の｜先《さき》には、｜半《なか》ば｜乾《かわ》いた｜暗赤色《あんせきしょく》の｜染《し》みがわずかに｜付《つ》いていた――｜血《ち》の｜跡《あと》だ。｜血痕《けっこん》のそばの｜樹皮《じゅひ》は、｜何《なに》か｜鋭《するど》いもので｜裂《さ》かれたように｜切《き》れ｜目《め》が｜入《はい》っている。

**清水恵美**：（｜血痕《けっこん》を｜見《み》て、さらに｜顔色《かおいろ》を｜失《うしな》い）｜血《ち》……｜血《ち》だ……｜眼鏡《めがね》の｜人《ひと》、もしかして……｜獣《けもの》に、｜襲《おそ》われたんじゃ……？　この｜森《もり》……すごく｜恐《おそ》ろしい｜動物《どうぶつ》が……いるんじゃ……？

**李杰**：（｜心《こころ》の｜声《こえ》）｜獣《けもの》……｜確《たし》かにありえる。これだけ｜原始《げんし》のままの｜森《もり》だ、｜何《なに》が｜起《お》きてもおかしくない。｜思《おも》ったより｜危険《きけん》だぞ。

**李杰**：ここは｜確《たし》かに｜安全《あんぜん》じゃない。｜気《き》をつけないと。こうしよう、いったん｜小屋《こや》に｜戻《もど》って、｜身《み》を｜守《まも》れそうなものを｜探《さが》そう。

**清水恵美**：（リュックから、きらりと｜光《ひか》る｜包丁《ほうちょう》を｜二本《にほん》｜取《と》り｜出《だ》し、｜一本《いっぽん》を｜李杰《りけつ》に｜差《さ》し｜出《だ》して）わ、わたし……さっき｜出《で》るとき……｜台所《だいどころ》で、ついでに｜持《も》ってきたんです……｜一本《いっぽん》はあなたに……｜一本《いっぽん》はわたしに……

**ナレーション**：｜李杰《りけつ》は、｜恵美《えみ》の｜手《て》の｜中《なか》でランプの｜下《した》に｜光《ひか》る｜二本《にほん》の｜包丁《ほうちょう》を｜見《み》て、｜目《め》に｜驚《おどろ》きの｜色《いろ》をよぎらせた。この｜臆病《おくびょう》で｜気弱《きよわ》な｜少女《しょうじょ》が、これほど｜先《さき》を｜見越《みこ》して｜備《そな》えているとは？　｜彼女《かのじょ》の｜用意《ようい》は、｜彼《かれ》の｜予想《よそう》を｜超《こ》えていた。

**李杰**：｜君《きみ》……ずいぶん｜用意《ようい》がいいんだな。

**ナレーション**：｜身《み》を｜守《まも》る｜道具《どうぐ》を｜手《て》に｜入《い》れた｜二人《ふたり》は、｜勇気《ゆうき》を｜奮《ふる》って｜血痕《けっこん》の｜周辺《しゅうへん》をさらに｜一時間《いちじかん》ほど｜捜索《そうさく》した。｜眼鏡《めがね》の｜青年《せいねん》の｜手《て》がかりか、ほかの｜生存者《せいぞんしゃ》が｜見《み》つかるのを｜願《ねが》って。だが、｜濃霧《のうむ》と｜果《は》てしない｜木々《きぎ》のほかには、｜何《なに》も｜得《え》られなかった。ときおり｜聞《き》こえる｜正体不明《しょうたいふめい》の｜物音《ものおと》に、｜二人《ふたり》の｜神経《しんけい》はいっそう｜張《は》りつめていく。

**清水恵美**：（｜小声《こごえ》で）｜李《り》さん……ここ……ここ、｜危《あぶ》なすぎます……わたしたち……あまり、｜主道《しゅどう》から｜離《はな》れないほうが……

**ナレーション**：｜李杰《りけつ》はしばし｜考《かんが》えた。｜清水《しみず》の｜言《い》うとおりだ。この｜世界《せかい》について｜何《なに》も｜知《し》らないまま、｜闇雲《やみくも》に｜森《もり》の｜奥《おく》を｜探《さが》し｜回《まわ》れば、さらに｜大《おお》きな｜危険《きけん》に｜陥《おちい》るだけだろう。｜眼鏡《めがね》の｜青年《せいねん》の｜身《み》に｜起《お》きたことは｜気《き》がかりだが、｜正直《しょうじき》なところ、｜人《ひと》を｜嘲《あざけ》ってばかりいたあの｜眼鏡《めがね》の｜青年《せいねん》に、さほど｜深《ふか》い｜情《じょう》はない。｜彼《かれ》の｜最優先事項《さいゆうせんじこう》は、｜自分《じぶん》と｜清水《しみず》の｜安全《あんぜん》を｜確保《かくほ》することだった。

**李杰**：よし、｜君《きみ》の｜言《い》うとおりにしよう。このまま｜道沿《みちぞ》いに｜進《すす》む。

**ナレーション**：｜李杰《りけつ》は｜胸《むね》の｜雑念《ざつねん》を｜振《ふ》り｜払《はら》い、｜恵美《えみ》を｜連《つ》れてふたたび｜主道《しゅどう》に｜踏《ふ》み｜出《だ》した。もはや｜一瞬《いっしゅん》たりとも｜気《き》を｜緩《ゆる》められない。｜手《て》には｜包丁《ほうちょう》を｜固《かた》く｜握《にぎ》り、｜濃霧《のうむ》に｜包《つつ》まれた｜森《もり》をぐるりと｜警戒《けいかい》して｜見渡《みわた》す。

**ナレーション**：さらにかなり｜長《なが》い｜時間《じかん》｜歩《ある》くと、｜濃霧《のうむ》はいっそう｜重《おも》くなったようだった。｜二人《ふたり》は｜二《ふた》つ｜目《め》の｜分《わ》かれ｜道《みち》に｜出《で》た。

**李杰**：（｜心《こころ》の｜声《こえ》）ここは……｜地図《ちず》にない｜分《わ》かれ｜道《みち》だ。

**ナレーション**：｜目《め》の｜前《まえ》の｜光景《こうけい》は、ふたたび｜二人《ふたり》のぼろぼろの｜地図《ちず》とずれていた。｜地図《ちず》にはこの｜分《わ》かれ｜道《みち》の｜情報《じょうほう》などまったくない。しかも｜実際《じっさい》には、｜主道《しゅどう》をまっすぐ｜行《い》く｜道《みち》のほかに、この｜分《わ》かれ｜道《みち》には｜明《あき》らかな｜支線《しせん》が｜二本《にほん》ある――｜一本《いっぽん》は｜左《ひだり》へ、｜一本《いっぽん》は｜右《みぎ》へ。｜標識《ひょうしき》は｜何《なに》ひとつなく、どの｜道《みち》がどこへ｜通《つう》じるのかも｜判断《はんだん》のしようがない。｜三本《さんぼん》の｜道《みち》はどれも｜濃霧《のうむ》に｜呑《の》み｜込《こ》まれ、｜果《は》ては｜見《み》えなかった。

**ナレーション**：｜李杰《りけつ》は｜考《かんが》え｜込《こ》んだ。｜地図《ちず》の｜細部《さいぶ》を｜一《ひと》つひとつ｜必死《ひっし》に｜思《おも》い｜出《だ》し、あいまいな｜図像《ずぞう》から｜何《なに》かの｜手《て》がかりを｜見《み》つけ｜出《だ》そうとしたが、｜何《なに》も｜得《え》られない。これはまったく｜見知《みし》らぬ｜選択《せんたく》で、｜筋道《すじみち》も｜根拠《こんきょ》もなかった。

**李杰**：（｜心《こころ》の｜声《こえ》）｜左《ひだり》か？　｜右《みぎ》か？　それともまっすぐ｜進《すす》むか？　もし｜間違《まちが》えたら……

**ナレーション**：｜彼《かれ》がためらっていると、｜恵美《えみ》がそっと｜彼《かれ》の｜服《ふく》の｜裾《すそ》を｜引《ひ》いた。

**清水恵美**：｜李《り》さん……わたしたち……｜左《ひだり》の｜道《みち》に、｜行《い》きませんか……？

**李杰**：（｜振《ふ》り｜向《む》いて、いぶかしげに）｜左《ひだり》？　どうして？　｜何《なに》か｜気《き》づいたことでもあるのか？

**清水恵美**：（｜目《め》を｜泳《およ》がせ、おずおずと｜首《くび》を｜横《よこ》に｜振《ふ》って）わ、わたしにも……｜分《わ》かりません……ただ……なんとなく……そっちのほうが……なんだか……｜少《すこ》しだけ、｜安全《あんぜん》な｜気《き》がして……

**ナレーション**：｜直感《ちょっかん》？　｜李杰《りけつ》は｜恵美《えみ》を｜見《み》つめ、｜森《もり》の｜中《なか》での｜彼女《かのじょ》の｜異様《いよう》な｜落《お》ち｜着《つ》きや、｜地図《ちず》の｜文字《もじ》が｜分《わ》かっているかのようだった｜一瞬《いっしゅん》の｜違和感《いわかん》を｜思《おも》い｜返《かえ》した。｜彼女《かのじょ》の｜直感《ちょっかん》は、｜彼《かれ》の｜論理的《ろんりてき》な｜判断《はんだん》よりも｜信《しん》じるに｜値《あたい》するのだろうか？　｜彼《かれ》は｜理性的《りせいてき》な｜人間《にんげん》だが、こうした｜超自然的《ちょうしぜんてき》な｜状況《じょうきょう》を｜前《まえ》にしては、｜理性《りせい》だけがもはや｜唯一《ゆいいつ》の｜物差《ものさ》しではないように｜思《おも》えた。

**李杰**：（｜心《こころ》の｜声《こえ》）｜賭《か》けに｜出《で》るか？　それとも、｜彼女《かのじょ》の｜直感《ちょっかん》を｜信《しん》じるか？

**ナレーション**：｜彼《かれ》は｜期待《きたい》のこもった｜清水《しみず》の｜眼差《まなざ》しを｜見《み》て、それから｜濃霧《のうむ》に｜呑《の》まれた｜三本《さんぼん》の｜道《みち》へ｜目《め》を｜向《む》けた。｜左《ひだり》、｜右《みぎ》、それともまっすぐか？　どの｜道《みち》も｜未知《みち》へ｜続《つづ》いていて、｜間違《まちが》った｜選択《せんたく》は｜死《し》を｜意味《いみ》するかもしれない。｜李杰《りけつ》は｜手《て》の｜中《なか》の｜包丁《ほうちょう》を｜固《かた》く｜握《にぎ》りしめ、｜黙《だま》り｜込《こ》んだ。

**ナレーション**：｜濃霧《のうむ》は｜周囲《しゅうい》で｜渦巻《うずま》き、まるで｜決断《けつだん》を｜急《せ》かしているかのようだった。
