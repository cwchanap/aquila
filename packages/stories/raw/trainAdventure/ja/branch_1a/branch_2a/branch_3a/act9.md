# 第九幕：霧の中の小屋

**ナレーション**：｜李杰《りけつ》は｜目《め》の｜前《まえ》の｜四本《よんほん》の｜道《みち》を｜見《み》て、それから｜手《て》の｜中《なか》の｜破《やぶ》れた｜地図《ちず》に｜目《め》を｜落《お》とした。｜恵美《えみ》は｜彼《かれ》の｜隣《となり》に｜立《た》ち、｜静《しず》かに｜決断《けつだん》を｜待《ま》っている。

**李杰**：（｜心《こころ》の｜声《こえ》）｜彼女《かのじょ》の｜言《い》うことには｜一理《いちり》ある。これ｜以上《いじょう》の｜手《て》がかりがない｜以上《いじょう》、｜主道《しゅどう》を｜行《い》くのがいちばん｜間違《まちが》いの｜少《すく》ない｜選択《せんたく》だ……

**李杰**：（｜地図《ちず》をしまって）よし、｜前《まえ》の｜道《みち》を｜行《い》こう。

**清水恵美**：（うなずいて、ごく｜小《ちい》さな｜声《こえ》で）ええ……

**ナレーション**：｜李杰《りけつ》は｜決断《けつだん》を｜下《くだ》した。もう｜一度方角《いちどほうがく》を｜確《たし》かめると、｜恵美《えみ》を｜連《つ》れて、｜迷霧《めいむ》の｜森《もり》の｜奥《おく》へ｜続《つづ》く｜主道《しゅどう》へ｜踏《ふ》み｜出《だ》した。

**ナレーション**：｜濃霧《のうむ》はたちまち｜二人《ふたり》の｜姿《すがた》を｜呑《の》み｜込《こ》み、｜分《わ》かれ｜道《みち》はふたたび｜死《し》のような｜静寂《せいじゃく》に｜沈《しず》んだ。

**ナレーション**：｜二人《ふたり》は｜主道《しゅどう》をさらに｜長《なが》い｜時間《じかん》｜歩《ある》いた。｜霧《きり》はますます｜濃《こ》くなり、ついには｜視界《しかい》が｜三《さん》メートルにも｜満《み》たなくなって、｜互《たが》いの｜背中《せなか》と｜足《あし》もとの｜道《みち》がかろうじて｜見《み》えるだけになった。

**ナレーション**：｜空気《くうき》は｜湿《しめ》って｜冷《つめ》たく、｜肺《はい》に｜吸《す》い｜込《こ》むと｜土《つち》と｜朽《く》ち｜木《き》の｜匂《にお》いがした。｜世界《せかい》は、この｜果《は》てしない｜道《みち》と、｜二人《ふたり》を｜包《つつ》む｜際限《さいげん》のない｜濃霧《のうむ》だけに｜単純化《たんじゅんか》されてしまったかのようだ。

**ナレーション**：｜李杰《りけつ》は｜隣《となり》の｜恵美《えみ》にちらりと｜目《め》をやり、｜慰《なぐさ》めの｜言葉《ことば》をかけようとして、｜意外《いがい》なことに｜気《き》づいた。｜彼女《かのじょ》の｜顔《かお》から、あの｜極度《きょくど》の｜恐怖《きょうふ》の｜色《いろ》が、いつの｜間《ま》にか｜消《き》えている。

**ナレーション**：｜彼女《かのじょ》はもう｜震《ふる》えておらず、ただ｜黙《だま》ってついてくる。｜目《め》つきこそ｜相変《あいか》わらず｜怯《おび》えているが、そこには｜不思議《ふしぎ》な｜落《お》ち｜着《つ》きがあった。まるでこの｜濃霧《のうむ》のほうが、｜駅《えき》の｜開《あ》けた｜未知《みち》よりも、｜彼女《かのじょ》にとっては｜安心《あんしん》できるかのように。

**李杰**：（｜心《こころ》の｜声《こえ》）｜彼女《かのじょ》……｜落《お》ち｜着《つ》いたみたいだ。こんな｜環境《かんきょう》のほうが、｜駅《えき》にいたときよりも｜冷静《れいせい》だなんて……｜妙《みょう》だな。

**李杰**：（｜重苦《おもくる》しい｜沈黙《ちんもく》を｜破《やぶ》ろうと）そういえば……まだ｜聞《き》いてなかったな。｜君《きみ》は｜何《なに》をしているんだ？　｜学生《がくせい》かい？

**清水恵美**：（｜話《はな》しかけられて｜少《すこ》し｜我《われ》に｜返《かえ》り）あ……はい……そうです。｜李《り》さんは？

**李杰**：｜俺《おれ》？　ソフトウェアエンジニアだよ。オフィスでパソコンに｜向《む》かってキーボードを｜叩《たた》いてるだけの、あれだ。たいしたもんじゃない。

**清水恵美**：ソフトウェアエンジニア……すごそうです。

**李杰**：すごくなんかないさ、ただの｜仕事《しごと》だよ。｜東京《とうきょう》にはひとりで｜住《す》んでいて、｜両親《りょうしん》は｜上海《しゃんはい》にいる。｜大学《だいがく》を｜出《で》てから｜日本《にほん》に｜来《き》て｜働《はたら》いてるんだ。｜君《きみ》は？　｜何《なに》を｜専攻《せんこう》してるんだ？

**清水恵美**：わ、わたしは……｜歴史《れきし》と｜文学《ぶんがく》を……

**李杰**：｜歴史《れきし》と｜文学《ぶんがく》か。｜面白《おもしろ》そうだな。｜一日中《いちにちじゅう》コードと｜格闘《かくとう》してる｜俺《おれ》の｜仕事《しごと》とは、まるで｜別世界《べつせかい》だ。

**清水恵美**：そ、そんな……ただ、｜古《ふる》い｜物語《ものがたり》を｜読《よ》むのが｜好《す》きなだけで……

**ナレーション**：｜李杰《りけつ》はうなずき、｜乗車前《じょうしゃまえ》の｜夜《よる》を｜思《おも》い｜出《だ》した。パーティーがあり、｜笑《わら》い｜声《ごえ》があり、ネオンが｜灯《とも》っていたあの｜世界《せかい》は、いまや｜別《べつ》の｜次元《じげん》の｜出来事《できごと》のように｜思《おも》える。

**李杰**：この｜電車《でんしゃ》に｜乗《の》る｜前《まえ》は、｜何《なに》をしてたんだ？

**清水恵美**：わ……わたし、｜読書会《どくしょかい》に｜行《い》っていて……｜終《お》わるのが｜少《すこ》し｜遅《おそ》くなったので、｜終電《しゅうでん》に｜急《いそ》いで｜乗《の》ったんです。｜李《り》さんは？

**李杰**：｜俺《おれ》は｜同僚《どうりょう》のパーティーに｜行《い》ってたんだ。｜本当《ほんとう》はあまり｜気《き》が｜進《すす》まなかったけど、｜断《ことわ》れなくてさ。いま｜思《おも》えば、｜何《なに》か｜口実《こうじつ》をつけて｜行《い》かなきゃよかったよ。

**清水恵美**：そんなふうに｜考《かんが》えちゃだめです……｜李《り》さんのせいじゃありません……

**ナレーション**：｜二人《ふたり》はぽつりぽつりと｜言葉《ことば》を｜交《か》わした。ありふれた｜過去《かこ》の｜暮《く》らしのことを。そのささやかなやりとりは、かすかな｜火種《ひだね》のように、｜湿《しめ》った｜冷《つめ》たい｜濃霧《のうむ》の｜中《なか》で、｜二人《ふたり》に｜身《み》を｜置《お》く｜危険《きけん》をひととき｜忘《わす》れさせた。

**ナレーション**：だが、すぐに｜疲労《ひろう》が｜二人《ふたり》を｜襲《おそ》い｜始《はじ》めた。｜会話《かいわ》は｜途切《とぎ》れがちになり、やがて｜完全《かんぜん》な｜沈黙《ちんもく》に｜落《お》ちる。｜二人《ふたり》はただ｜機械的《きかいてき》に、｜一歩《いっぽ》、また｜一歩《いっぽ》と｜前《まえ》へ｜進《すす》んだ。

**ナレーション**：いつのまにか、また｜長《なが》い｜時間《じかん》が｜過《す》ぎていた。｜李杰《りけつ》が｜腕時計《うでどけい》に｜目《め》をやると、｜列車《れっしゃ》がトンネルに｜入《はい》った｜瞬間《しゅんかん》から、もう｜五時間近《ごじかんちか》くが｜経《た》っている。

**李杰**：（｜心《こころ》の｜声《こえ》）｜現実《げんじつ》の｜世界《せかい》では、いまごろ｜朝《あさ》の｜六時《ろくじ》のはずだ……

**ナレーション**：｜一睡《いっすい》もしていない｜疲労《ひろう》に、｜極度《きょくど》の｜精神的緊張《せいしんてききんちょう》と｜長時間《ちょうじかん》の｜踏破《とうは》が｜加《くわ》わって、｜二人《ふたり》の｜体《からだ》は｜限界《げんかい》に｜達《たっ》していた。｜脚《あし》は｜鉛《なまり》を｜流《なが》し｜込《こ》まれたように｜重《おも》く、｜一歩《いっぽ》ごとに｜全力《ぜんりょく》を｜振《ふ》り｜絞《しぼ》らなければならない。

**ナレーション**：｜濃霧《のうむ》がすべてを｜覆《おお》い｜隠《かく》し、いまが｜昼《ひる》なのか｜夜《よる》なのか、まったく｜判断《はんだん》できなかった。｜世界《せかい》はいつまでも｜灰色《はいいろ》にかすんだままで、｜日《ひ》の｜出《で》も｜日《ひ》の｜入《い》りもない。

**清水恵美**：（｜李杰《りけつ》の｜袖《そで》をつかみ、｜疲《つか》れで｜少《すこ》し｜弱々《よわよわ》しくなった｜声《こえ》で）｜李《り》さん……｜前《まえ》を｜見《み》てください！

**ナレーション**：｜李杰《りけつ》は｜気力《きりょく》を｜振《ふ》り｜絞《しぼ》り、｜彼女《かのじょ》の｜指《ゆび》さすほうへ｜目《め》を｜向《む》けた。｜前方《ぜんぽう》そう｜遠《とお》くない｜濃霧《のうむ》の｜中《なか》に、｜黒《くろ》い｜輪郭《りんかく》がぼんやりと｜見《み》え｜隠《かく》れしている。

**李杰**：（｜目《め》を｜細《ほそ》め、｜心《こころ》の｜声《こえ》）あれは……｜家《いえ》か？

**ナレーション**：｜二人《ふたり》は｜足《あし》を｜速《はや》めた。｜疲《つか》れきった｜体《からだ》を、｜一縷《いちる》の｜希望《きぼう》が｜突《つ》き｜動《うご》かしている。さらに｜数十《すうじゅう》メートル｜進《すす》むと、｜輪郭《りんかく》がはっきりしてきた。

**ナレーション**：｜濃霧《のうむ》の｜中《なか》、｜濃《こ》い｜色《いろ》の｜木材《もくざい》で｜組《く》まれた｜小《ちい》さな｜小屋《こや》が、｜道端《みちばた》にひっそりと｜建《た》っていた。｜小屋《こや》はいかにも｜古《ふる》く、｜板《いた》には｜一面《いちめん》に｜青《あお》い｜苔《こけ》が｜生《は》え、｜窓《まど》は｜暗《くら》くて、｜中《なか》の｜様子《ようす》は｜見《み》えない。

**ナレーション**：まるで、｜何百年《なんびゃくねん》もここで｜待《ま》ち｜続《つづ》けてきたかのように。

**李杰**：｜家《いえ》が……こんなところに？

**清水恵美**：（うなずいて、ごく｜小《ちい》さな｜声《こえ》で）はい……

**ナレーション**：｜二人《ふたり》は｜支《ささ》え｜合《あ》い、｜疲《つか》れきった｜体《からだ》を｜引《ひ》きずりながら、｜一歩《いっぽ》ずつ、その｜謎《なぞ》めいた｜霧《きり》の｜中《なか》の｜小屋《こや》へ｜歩《ある》いていった。
