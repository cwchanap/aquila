**李杰**：（｜暇《ひま》つぶしに）｜文学《ぶんがく》を｜学《まな》んでるなら、｜普段《ふだん》はどんな｜本《ほん》を｜読《よ》むんだ？　｜好《す》きな｜作家《さっか》は？
