# 第十五幕：月光の林

**ナレーション**：｜濃霧《のうむ》がしだいに｜晴《は》れ、｜目《め》の｜前《まえ》の｜視界《しかい》がゆっくりと｜開《あ》けていく。まず｜目《め》に｜飛《と》び｜込《こ》んできたのは、やわらかな｜光《ひかり》だった――｜目《め》を｜刺《さ》す｜陽光《ようこう》ではなく、｜月光《げっこう》と｜蛍火《ほたるび》のあいだのような｜銀青色《ぎんせいしょく》の｜輝《かがや》きで、｜世界《せかい》ぜんたいが｜夢《ゆめ》の｜中《なか》に｜浸《ひた》されているかのようだ。

**ナレーション**：｜濃霧《のうむ》を｜完全《かんぜん》に｜抜《ぬ》けたとき、｜目《め》の｜前《まえ》の｜光景《こうけい》に｜二人《ふたり》は｜息《いき》をのんだ。｜環状《かんじょう》の｜谷《たに》に｜抱《いだ》かれた｜静《しず》かな｜村《むら》――まるで｜桃源郷《とうげんきょう》のようだった。

**ナレーション**：｜村《むら》の｜建物《たてもの》はきわめて｜独特《どくとく》で、｜白《しろ》い｜岩《いわ》と｜太《ふと》い｜古木《こぼく》が｜絡《から》み｜合《あ》い、まるで｜大地《だいち》から｜自然《しぜん》に｜生《は》え｜出《で》たような｜住居《じゅうきょ》をいくつも｜形《かたち》づくっている。なかには｜巨木《きょぼく》の｜枝《えだ》のあいだに｜吊《つ》り｜下《さ》がった｜家《いえ》もあり、｜蔓《つる》を｜編《あ》んだ｜階段《かいだん》が｜地面《じめん》へとつながっていた。

**ナレーション**：もっとも｜目《め》を｜奪《うば》われるのは、やわらかな｜光《ひかり》を｜放《はな》つ｜植物《しょくぶつ》たちだった。ランタンのように｜建物《たてもの》のあいだや｜道《みち》の｜両側《りょうがわ》を｜飾《かざ》り、あるものは｜垂《た》れ｜下《さ》がる｜風鈴《ふうりん》のように｜風《かぜ》にそっと｜揺《ゆ》れ、あるものは｜咲《さ》きほころぶ｜花《はな》のように｜光《ひかり》をあたりへ｜降《ふ》り｜注《そそ》いでいる。｜村《むら》｜全体《ぜんたい》が、｜夢《ゆめ》のような｜銀青色《ぎんせいしょく》の｜光《ひかり》の｜輪《わ》に｜包《つつ》まれていた。

**ナレーション**：｜澄《す》んだ｜小川《おがわ》が｜村《むら》の｜中央《ちゅうおう》を｜蛇行《だこう》して｜流《なが》れ、｜水面《すいめん》には｜発光《はっこう》する｜植物《しょくぶつ》が｜映《うつ》り｜込《こ》んで、きらきらと｜波打《なみう》っている。｜水《みず》が｜石《いし》を｜叩《たた》く｜音《おと》と、｜風《かぜ》が｜木《こ》の｜葉《は》を｜鳴《な》らすさやさやという｜音《おと》が｜合《あ》わさって、｜静《しず》かな｜自然《しぜん》の｜楽章《がくしょう》を｜奏《かな》でていた。｜空気《くうき》にはほのかな｜花《はな》の｜香《かお》りが｜漂《ただよ》い、｜清々《すがすが》しく、｜心《こころ》をほぐしてくれる。

**李杰**：（｜呆然《ぼうぜん》とその｜場《ば》に｜立《た》ち｜尽《つ》くし、つぶやく）ここは……なんなんだ……

**ナレーション**：さらに｜二人《ふたり》を｜驚《おどろ》かせたのは、｜村《むら》を｜行《い》き｜交《か》う｜生《い》き｜物《もの》たちだった。｜彼《かれ》らは｜背《せ》が｜高《たか》くほっそりとして、｜平均《へいきん》の｜身長《しんちょう》はおよそ｜百七十《ひゃくななじゅう》センチほど。｜踊《おど》っているかのように｜優雅《ゆうが》な｜身《み》のこなしだった。

**ナレーション**：とがった｜長《なが》い｜耳《みみ》が、｜銀色《ぎんいろ》や｜金色《きんいろ》の｜長《なが》い｜髪《かみ》のあいだに｜見《み》え｜隠《かく》れしている。｜顔立《かおだ》ちは｜彫刻《ちょうこく》のように｜整《ととの》い、｜肌《はだ》は｜白《しろ》く｜透《す》きとおり、｜瞳《ひとみ》は｜淡《あわ》い｜緑《みどり》か｜淡《あわ》い｜青《あお》の｜色《いろ》で、｜世俗《せぞく》を｜超《こ》えたような｜透明感《とうめいかん》を｜宿《やど》していた。

**ナレーション**：｜彼《かれ》らは｜軽《かろ》やかな｜長衣《ちょうい》をまとい、｜色《いろ》は｜白《しろ》や｜薄緑《うすみどり》、｜銀灰色《ぎんかいしょく》が｜多《おお》く、｜布《ぬの》が｜微風《びふう》にそっと｜揺《ゆ》れている。｜小川《おがわ》のほとりで｜水《みず》を｜汲《く》むエルフもいれば、｜木《き》の｜下《した》で｜編《あ》み｜物《もの》をするエルフもいる。｜幼《おさな》いエルフが｜何人《なんにん》か｜追《お》いかけっこをして｜戯《たわむ》れ、その｜笑《わら》い｜声《ごえ》は｜風鈴《ふうりん》のように｜澄《す》んでいた。

**李杰**：（｜完全《かんぜん》に｜衝撃《しょうげき》を｜受《う》け、｜心《こころ》の｜声《こえ》）これは……エルフ？　おとぎ｜話《ばなし》に｜出《で》てくる、あの？　｜俺《おれ》はきっと｜夢《ゆめ》を｜見《み》てるんだ……こんなことが｜本当《ほんとう》のはずがない……

**ナレーション**：｜彼《かれ》は｜力《ちから》いっぱい｜自分《じぶん》の｜腕《うで》をつねった。｜痛《いた》みははっきりと｜伝《つた》わってくる。これは｜夢《ゆめ》じゃない。

**ナレーション**：｜隣《となり》の｜清水《しみず》は、まったく｜違《ちが》う｜表情《ひょうじょう》をしていた。｜目《め》を｜大《おお》きく｜見開《みひら》き、｜口《くち》もとにまぶしい｜笑《え》みを｜浮《う》かべ、｜全身《ぜんしん》が｜興奮《こうふん》しながらもくつろいで｜見《み》える。｜超自然的《ちょうしぜんてき》なものを｜前《まえ》にしたときにあるはずの｜恐怖《きょうふ》も｜警戒心《けいかいしん》も、まるで｜見当《みあ》たらなかった。

**清水恵美**：（｜顔《かお》いっぱいに｜輝《かがや》く｜笑《え》みを｜咲《さ》かせ、｜子《こ》どものように｜弾《はず》んだ｜声《こえ》で）きれいな｜場所《ばしょ》……｜李《り》さん、｜見《み》てください！　あの｜光《ひか》る｜花《はな》……それに、あの｜家《いえ》……

**清水恵美**：わたしたち……わたしたち、あの｜人《ひと》たちとお｜話《はな》ししに｜行《い》きましょう！

**李杰**：（｜心《こころ》の｜声《こえ》）｜彼女《かのじょ》、すごくうれしそうだ……まるで、ちっとも｜意外《いがい》じゃないみたいに。どうしてこんなにすんなりと、すべてを｜受《う》け｜入《い》れられるんだ？

**ナレーション**：｜目《め》の｜前《まえ》の｜光景《こうけい》は｜彼《かれ》の｜認識《にんしき》を｜根底《こんてい》からひっくり｜返《かえ》したが、｜李杰《りけつ》も｜一抹《いちまつ》の｜安堵《あんど》を｜覚《おぼ》えていた。｜少《すく》なくともここは｜穏《おだ》やかで｜安《やす》らかに｜見《み》え、｜危険《きけん》の｜気配《けはい》はまるでない。しかも、この｜生《い》き｜物《もの》たちは｜高《たか》い｜知性《ちせい》と｜文明《ぶんめい》を｜持《も》っているらしい。｜知性《ちせい》があるなら、｜意思《いし》の｜疎通《そつう》ができるということだ。

**ナレーション**：｜二人《ふたり》が｜近《ちか》づくべきかためらっていると、｜村《むら》のエルフたちも｜二人《ふたり》に｜気《き》づいたようだった。｜何人《なんにん》かが｜手《て》を｜止《と》め、この｜見慣《みな》れぬ｜二人《ふたり》の｜訪問者《ほうもんしゃ》を｜興味《きょうみ》｜深《ふか》げに｜見《み》つめる。

**ナレーション**：しばらくして、｜一人《ひとり》のエルフが｜笑《え》みを｜浮《う》かべ、｜自分《じぶん》から｜二人《ふたり》のほうへ｜歩《あゆ》み｜寄《よ》ってきた。｜腰《こし》まで｜届《とど》く｜銀白《ぎんはく》の｜長《なが》い｜髪《かみ》が、｜光《ひかり》の｜中《なか》でほのかな｜艶《つや》を｜宿《やど》している。｜顔《かお》には｜細《こま》かな｜皺《しわ》が｜刻《きざ》まれているが、｜若《わか》いころの｜端正《たんせい》な｜面影《おもかげ》は｜今《いま》も｜見《み》て｜取《と》れた。

**ナレーション**：｜八十《はちじゅう》に｜近《ちか》い｜老人《ろうじん》のように｜見《み》えるが、｜歩《あゆ》みはゆっくりながらも｜優雅《ゆうが》で｜確《たし》かで、｜背筋《せすじ》はまっすぐ、｜眼差《まなざ》しは｜穏《おだ》やかで｜聡明《そうめい》だった。｜銀《ぎん》の｜蔦模様《つたもよう》を｜刺繍《ししゅう》した｜白《しろ》い｜長衣《ちょうい》をまとい、｜胸《むね》には｜緑《みどり》の｜宝石《ほうせき》を｜一《ひと》つ｜下《さ》げている。

**アイラル**：（｜風鈴《ふうりん》のように｜耳《みみ》に｜心地《ここち》よい｜声《こえ》で、｜人《ひと》を｜安心《あんしん》させる｜温《あたた》かさをたたえて）お｜二方《ふたかた》、「｜月光《げっこう》の｜林《はやし》」へようこそ。

**李杰**：（｜心《こころ》の｜声《こえ》）｜言葉《ことば》が……｜通《つう》じてる？　いや、｜違《ちが》う……｜俺《おれ》たちが、｜彼《かれ》らの｜言葉《ことば》を｜理解《りかい》できてるのか？

**アイラル**：わたしの｜名《な》はアイラルといいます。｜私《わたし》たちは、あなた｜方《かた》のような｜人間《にんげん》にお｜目《め》にかかるのは、ずいぶん｜久《ひさ》しぶりです。

**李杰**：（｜胸《むね》の｜驚《おどろ》きを｜無理《むり》やり｜抑《おさ》え、｜声《こえ》が｜平静《へいせい》に｜聞《き》こえるよう｜努《つと》めながら）はじめまして、｜李杰《りけつ》といいます。こちらは｜清水《しみず》さんです。｜私《わたし》たちは……とても｜遠《とお》いところから｜来《き》ました。

**清水恵美**：（｜一緒《いっしょ》にお｜辞儀《じぎ》をして、｜礼儀《れいぎ》｜正《ただ》しく｜自然《しぜん》な｜所作《しょさ》で）はじめまして、アイラルさん。

**李杰**：あの……「ずいぶん｜久《ひさ》しぶり」とは、どういう｜意味《いみ》でしょうか？　｜以前《いぜん》にも……｜人間《にんげん》がここに｜来《き》たことがあるんですか？

**アイラル**：（｜穏《おだ》やかにうなずき、｜銀《ぎん》の｜長《なが》い｜髪《かみ》が｜動《うご》きに｜合《あ》わせてそっと｜揺《ゆ》れる）ええ。｜二年《にねん》ほど｜前《まえ》にも、｜異世界《いせかい》から｜来《き》た｜人間《にんげん》が｜何人《なんにん》か、あなた｜方《かた》と｜同《おな》じように、あの｜迷霧《めいむ》の｜森《もり》から｜出《で》てこられました。そのときの｜様子《ようす》は、ちょうどいまのあなた｜方《かた》のようでした――｜疲《つか》れ｜果《は》て、｜戸惑《とまど》い、けれど｜目《め》にはまだ｜希望《きぼう》がありました。

**李杰**：（｜心臓《しんぞう》が｜跳《は》ね｜上《あ》がり、｜声《こえ》まで｜切迫《せっぱく》して）そ、それで……その｜人《ひと》たちは、その｜後《あと》どうなったんですか？　まだ、ここにいるんですか？

**アイラル**：ここでしばらく｜体《からだ》を｜休《やす》めたあと、｜最終的《さいしゅうてき》に、ご｜自分《じぶん》たちの｜世界《せかい》へ｜帰《かえ》る｜方法《ほうほう》を｜見《み》つけられました。うれしいお｜知《し》らせをしましょう――あの｜方々《かたがた》は、｜無事《ぶじ》に｜帰《かえ》られましたよ。

**ナレーション**：｜自分《じぶん》たちの｜世界《せかい》へ｜帰《かえ》る……その｜言葉《ことば》は｜眩《まぶ》しい｜光《ひかり》のように、｜李杰《りけつ》と｜清水《しみず》の｜胸《むね》にあったあらゆる｜暗雲《あんうん》と｜絶望《ぜつぼう》を、｜一瞬《いっしゅん》で｜突《つ》き｜破《やぶ》った。｜連日《れんじつ》｜積《つ》もり｜積《つ》もった｜疲労《ひろう》と｜恐怖《きょうふ》と｜不安《ふあん》が、この｜瞬間《しゅんかん》、ようやく｜吐《は》き｜出《だ》す｜先《さき》を｜見《み》つけたかのようだった。

**李杰**：（｜喜《よろこ》びのあまり｜飛《と》び｜上《あ》がりそうになりながら、｜心《こころ》の｜声《こえ》）｜帰《かえ》れた……｜本当《ほんとう》に｜帰《かえ》れるんだ！　｜俺《おれ》たちは、｜永遠《えいえん》にここに｜閉《と》じ｜込《こ》められたわけじゃなかった！　まだ｜希望《きぼう》がある……まだ｜希望《きぼう》がある！

**ナレーション**：｜彼《かれ》は｜目《め》の｜縁《ふち》が｜一瞬《いっしゅん》で｜潤《うる》んだが、｜涙《なみだ》がこぼれないよう｜必死《ひっし》にこらえた。

**清水恵美**：（｜目《め》はもう｜潤《うる》み、｜声《こえ》も｜少《すこ》し｜詰《つ》まっているが、｜顔《かお》には｜抑《おさ》えきれない｜喜《よろこ》びを｜浮《う》かべて）よかった……｜本当《ほんとう》に……｜本当《ほんとう》によかった！

**ナレーション**：｜二人《ふたり》は｜顔《かお》を｜見合《みあ》わせ、｜互《たが》いの｜目《め》の｜中《なか》に、｜九死《きゅうし》に｜一生《いっしょう》を｜得《え》たかのような｜大《おお》きな｜安堵《あんど》と｜希望《きぼう》を｜見《み》た。この｜世界《せかい》に｜来《き》て｜以来《いらい》、｜初《はじ》めて｜耳《みみ》にした、そして｜何《なに》よりも｜大切《たいせつ》な｜朗報《ろうほう》だった。

**ナレーション**：｜二人《ふたり》の｜昂《たか》ぶる｜様子《ようす》を｜見《み》て、｜周《まわ》りのエルフたちの｜顔《かお》にも、｜善意《ぜんい》の｜微笑《ほほえ》みが｜浮《う》かんだ。｜小川《おがわ》は｜変《か》わらずさらさらと｜流《なが》れ、｜光《ひか》る｜植物《しょくぶつ》はそっと｜揺《ゆ》れ、｜村《むら》｜全体《ぜんたい》はなおも、あの｜静《しず》かで｜穏《おだ》やかな｜銀青色《ぎんせいしょく》の｜光《ひかり》の｜輪《わ》に｜包《つつ》まれていた。
