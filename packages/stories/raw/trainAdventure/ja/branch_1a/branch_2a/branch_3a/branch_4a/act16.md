# 第十六幕：エルフの導き

**ナレーション**：｜自分《じぶん》の｜世界《せかい》へ｜帰《かえ》れるという｜希望《きぼう》を｜聞《き》いて、｜李杰《りけつ》の｜気持《きも》ちは｜昂《たか》ぶってやまなかった。｜彼《かれ》は｜深《ふか》く｜息《いき》を｜吸《す》い、｜声《こえ》ができるだけ｜震《ふる》えないよう｜努《つと》めた。

**李杰**：アイラルさん、あの……その｜人《ひと》たちがどうやって｜帰《かえ》ったか、ご｜存《ぞん》じですか？　｜私《わたし》たちは、どうすればその｜方法《ほうほう》を｜見《み》つけられるんでしょうか？

**アイラル**：（そっと｜首《くび》を｜横《よこ》に｜振《ふ》り、｜銀《ぎん》の｜長《なが》い｜髪《かみ》が｜揺《ゆ》れて｜光《ひかり》の｜中《なか》できらめく）｜申《もう》し｜訳《わけ》ない、｜若《わか》い｜方《かた》。｜私《わたし》はそのことについてほとんど｜知《し》らないのです。その｜話《はなし》も……｜息子《むすこ》から｜聞《き》いたもので。あの｜人間《にんげん》たちを｜迎《むか》え、ここでの｜日々《ひび》を｜共《とも》に｜過《す》ごしたのは｜息子《むすこ》ですから、｜彼《かれ》のほうが｜詳《くわ》しいかもしれません。

**李杰**：（｜急《せ》き｜込《こ》んで｜尋《たず》ねる）では……｜息子《むすこ》さんにお｜会《あ》いできますか？　いまはどちらに？

**アイラル**：（｜遠《とお》くの｜谷《たに》へ｜視線《しせん》を｜向《む》け、わずかに｜申《もう》し｜訳《わけ》なさそうに）いまは｜村《むら》にいません。｜月光《げっこう》の｜林《はやし》の｜外《そと》にも、｜息子《むすこ》の｜力《ちから》と｜知恵《ちえ》を｜必要《ひつよう》とする｜場所《ばしょ》がたくさんありますので。けれど、じきに｜戻《もど》ってくるでしょう。

**アイラル**：（｜視線《しせん》を｜戻《もど》し、｜穏《おだ》やかに｜二人《ふたり》を｜見《み》て）｜長旅《ながたび》でさぞお｜疲《つか》れでしょう。お｜二人《ふたり》の｜服《ふく》や｜靴《くつ》を｜見《み》てごらんなさい、｜森《もり》の｜土《つち》と｜露《つゆ》がまだついている。まずはお｜二人《ふたり》のために｜用意《ようい》した｜住《す》まいでゆっくり｜休《やす》んで、｜熱《あつ》い｜湯《ゆ》を｜浴《あ》び、｜温《あたた》かい｜食事《しょくじ》をとってください。｜息子《むすこ》が｜戻《もど》ったら、｜私《わたし》がお｜連《つ》れして｜会《あ》わせましょう。

**ナレーション**：｜李杰《りけつ》と｜清水《しみず》は｜顔《かお》を｜見合《みあ》わせた。｜清水《しみず》の｜顔色《かおいろ》は｜確《たし》かに｜青白《あおじろ》く、｜目《め》の｜下《した》にはうっすらとクマがあり、｜足取《あしど》りも｜少《すこ》しふらついている。｜李杰《りけつ》｜自身《じしん》も、｜脚《あし》の｜重《おも》さと｜肩《かた》の｜痛《いた》みを｜感《かん》じていた。｜疲《つか》れた｜体《からだ》では、｜確《たし》かにこれ｜以上《いじょう》｜問《と》い｜詰《つ》める｜余力《よりょく》はない。この｜申《もう》し｜出《で》は｜願《ねが》ってもないものだった。

**李杰**：（うなずき、｜心《こころ》から）では、お｜言葉《ことば》に｜甘《あま》えます、アイラルさん。｜私《わたし》たち……｜確《たし》かに、｜休息《きゅうそく》が｜必要《ひつよう》です。

**ナレーション**：アイラルは｜微笑《ほほえ》んで｜身《み》を｜翻《ひるがえ》し、｜二人《ふたり》を｜連《つ》れて｜村《むら》の｜小道《こみち》を｜進《すす》んだ。｜路面《ろめん》は｜平《たい》らな｜白《しろ》い｜石板《せきばん》が｜敷《し》かれ、｜両側《りょうがわ》には｜光《ひか》る｜植物《しょくぶつ》がびっしりと｜植《う》えられている。ときおりエルフが｜通《とお》りかかり、そのたびに｜興味《きょうみ》｜深《ふか》げに｜二人《ふたり》を｜見《み》て、それから｜親《した》しげにうなずいて｜微笑《ほほえ》んだ。

**ナレーション**：｜二人《ふたり》は｜小川《おがわ》にかかる｜小《ちい》さな｜橋《はし》を｜渡《わた》った。｜橋《はし》は｜蔓《つる》を｜編《あ》んで｜作《つく》られているが、｜頑丈《がんじょう》で｜安定《あんてい》している。｜澄《す》んだ｜水《みず》が｜橋《はし》の｜下《した》を｜流《なが》れ、｜水底《みなそこ》の｜丸《まる》い｜小石《こいし》や、｜泳《およ》ぐ｜銀色《ぎんいろ》の｜小魚《こざかな》が｜見《み》える。｜空気《くうき》には｜花《はな》の｜香《かお》りと｜青草《あおくさ》の｜清々《すがすが》しさが｜漂《ただよ》い、｜思《おも》わず｜体《からだ》の｜力《ちから》が｜抜《ぬ》けた。

**ナレーション**：｜五分《ごふん》ほど｜歩《ある》いて、アイラルは｜二人《ふたり》を｜村《むら》はずれの｜小屋《こや》へ｜案内《あんない》した。｜小屋《こや》は｜巨大《きょだい》な｜古木《こぼく》のそばに｜建《た》ち、｜同《おな》じ｜白《しろ》い｜岩《いわ》と｜木材《もくざい》でできていて、｜屋根《やね》は｜銀緑《ぎんりょく》の｜苔《こけ》に｜覆《おお》われている。

**ナレーション**：｜外観《がいかん》は｜簡素《かんそ》で｜優美《ゆうび》、｜戸口《とぐち》の｜前《まえ》には｜光《ひか》る｜花《はな》が｜何株《なんかぶ》か｜植《う》えられ、｜窓《まど》は｜半円形《はんえんけい》で、｜温《あたた》かな｜光《ひかり》を｜透《す》かしていた。｜小屋《こや》｜全体《ぜんたい》が｜自然《しぜん》の｜中《なか》から｜生《は》え｜出《で》たように｜見《み》え、｜周囲《しゅうい》の｜環境《かんきょう》と｜完璧《かんぺき》に｜溶《と》け｜合《あ》っている。

**ナレーション**：｜木《き》の｜戸《と》を｜押《お》し｜開《あ》けると、｜中《なか》の｜光景《こうけい》に｜李杰《りけつ》も｜清水《しみず》も｜思《おも》わず｜息《いき》をのんだ――ここは、｜迷霧《めいむ》の｜森《もり》で｜泊《と》まったあの｜質素《しっそ》な｜小屋《こや》とは｜比《くら》べものにならないほど、｜豪華《ごうか》だった。

**ナレーション**：｜居間《いま》は｜広《ひろ》くて｜明《あか》るく、｜床《ゆか》はよく｜磨《みが》かれた｜白《しろ》い｜石材《せきざい》で、その｜上《うえ》にやわらかな｜絨毯《じゅうたん》が｜敷《し》かれている。｜織《お》り｜目《め》は｜芸術品《げいじゅつひん》のように｜精緻《せいち》だ。｜壁《かべ》は｜丸太《まるた》と｜白《しろ》い｜石《いし》が｜交互《こうご》に｜組《く》まれ、いくつかの｜光《ひか》る｜水晶《すいしょう》が｜埋《う》め｜込《こ》まれて、やわらかな｜光《ひかり》を｜放《はな》っていた。

**ナレーション**：｜家具《かぐ》はどれも｜丹念《たんねん》に｜彫《ほ》り｜上《あ》げられた｜逸品《いっぴん》だった――ソファには｜絹《きぬ》のような｜布《ぬの》が｜掛《か》けられ、ローテーブルはひと｜塊《かたまり》の｜透明《とうめい》な｜水晶《すいしょう》を｜磨《みが》き｜上《あ》げたもので、｜中《なか》に｜美《うつく》しい｜花《はな》びらが｜閉《と》じ｜込《こ》められているのが｜見《み》える。｜本棚《ほんだな》には、｜装丁《そうてい》の｜美《うつく》しい｜本《ほん》と、いくつかの｜繊細《せんさい》な｜置《お》き｜物《もの》が｜並《なら》んでいた。

**ナレーション**：いちばん｜驚《おどろ》かされたのは｜天井《てんじょう》だった――｜生《い》きた｜蔓《つる》で｜編《あ》まれ、｜小《ちい》さな｜光《ひか》る｜花《はな》がたくさん｜咲《さ》いていて、まるで｜逆《さか》さに｜吊《つ》るされた｜星空《ほしぞら》のようだ。｜空間《くうかん》｜全体《ぜんたい》にほのかな｜花《はな》の｜香《かお》りと｜木《き》の｜清《きよ》らかな｜香《かお》りが｜漂《ただよ》い、｜優雅《ゆうが》でありながら、｜温《ぬく》もりも｜失《うしな》っていない。

**李杰**：（あたりを｜見回《みまわ》し、｜少《すこ》しばつが｜悪《わる》そうに）こ、こんな……ありがたすぎて……｜私《わたし》たち……

**アイラル**：（｜穏《おだ》やかに｜笑《わら》って）お｜気遣《きづか》いなく。ここは、｜遠《とお》くから｜来《こ》られたお｜客人《きゃくじん》のための｜客室《きゃくしつ》です。｜長旅《ながたび》をされたのですから、｜最高《さいこう》の｜休息《きゅうそく》を｜受《う》けるのが｜当然《とうぜん》です。

**李杰**：（ふと｜思《おも》い｜出《だ》し、つい｜口《くち》を｜開《ひら》く）アイラルさん、あの……｜迷霧《めいむ》の｜森《もり》にある、あの｜小《ちい》さな｜木《き》の｜小屋《こや》のことはご｜存《ぞん》じですか？　｜私《わたし》たちは、｜昨夜《さくや》そこで｜休《やす》んだんです。

**アイラル**：（｜目《め》に、｜合点《がてん》がいったような｜色《いろ》がよぎる）ああ、あなた｜方《かた》がおっしゃるのは、｜私《わたし》たちの｜猟師小屋《りょうしこや》ですね。｜迷霧《めいむ》の｜森《もり》のあちこちに｜点在《てんざい》していて、｜私《わたし》たちの｜巡回《じゅんかい》や｜狩《か》りのときの｜補給所《ほきゅうしょ》なのです。あなた｜方《かた》がそれを｜見《み》つけて｜使《つか》えたのは、｜幸運《こううん》でしたよ。

**ナレーション**：｜李杰《りけつ》は｜腑《ふ》に｜落《お》ちた。あれは｜何《なに》か｜神秘的《しんぴてき》な｜存在《そんざい》ではなく、エルフたちの｜施設《しせつ》だったのだ。だが、｜胸《むね》の｜疑問《ぎもん》はすっかり｜消《き》えたわけではない――どうしてあの｜小屋《こや》はあんなに｜小《こ》ぎれいなのに、エルフの｜姿《すがた》がなかったのか？　ベッドも｜台所《だいどころ》も、｜使《つか》われたばかりのような｜様子《ようす》だった。それに、あの｜用意《ようい》されていた｜二本《にほん》の｜包丁《ほうちょう》……

**ナレーション**：だが｜疲労《ひろう》が、これらの｜疑問《ぎもん》をひとまず｜脇《わき》へ｜置《お》かせた。おそらく｜先《さき》に｜別《べつ》の｜巡回《じゅんかい》のエルフが｜使《つか》い、ちょうど｜入《い》れ｜違《ちが》いになっただけなのだろう。

**アイラル**：（｜部屋《へや》の｜中《なか》を｜見渡《みわた》し、｜満足《まんぞく》げにうなずいて）さて、お｜二方《ふたかた》。ここがあなた｜方《かた》の｜住《す》まいです。｜台所《だいどころ》には｜食材《しょくざい》が｜少《すこ》しあり、｜浴室《よくしつ》には｜湯《ゆ》があります――｜地下《ちか》の｜温泉《おんせん》で｜温《あたた》めているので、いつでも｜温《あたた》かいのですよ。どうぞここで、｜静《しず》かな｜時間《じかん》をお｜楽《たの》しみください。｜何《なに》かご｜入《い》り｜用《よう》なら、｜村《むら》の｜中央《ちゅうおう》にいる｜私《わたし》をお｜訪《たず》ねください。それでは、｜失礼《しつれい》します。

**ナレーション**：アイラルは｜軽《かる》く｜会釈《えしゃく》し、｜銀《ぎん》の｜長《なが》い｜髪《かみ》が｜光《ひかり》の｜中《なか》で｜優雅《ゆうが》な｜弧《こ》を｜描《えが》いた。そして、ゆっくりと｜優雅《ゆうが》に｜向《む》きを｜変《か》えて｜去《さ》っていった。｜木《き》の｜戸《と》が｜閉《し》まると、｜小屋《こや》には｜李杰《りけつ》と｜清水《しみず》の｜二人《ふたり》だけが｜残《のこ》された。

**ナレーション**：｜李杰《りけつ》はあたりを｜見回《みまわ》した。この｜家《いえ》は｜迷霧《めいむ》の｜森《もり》のあの｜小屋《こや》よりも｜広《ひろ》く、｜居間《いま》にはやわらかなソファが｜二《ふた》つと｜低《ひく》いテーブルがひとつ、｜壁《かべ》には｜木《こ》の｜葉《は》と｜花《はな》びらを｜貼《は》り｜合《あ》わせて｜作《つく》った｜飾《かざ》り｜絵《え》がかかっている。｜台所《だいどころ》の｜戸棚《とだな》はきちんと｜並《なら》び、｜木《き》のさわやかな｜香《かお》りを｜漂《ただよ》わせていた。

**ナレーション**：いちばん｜目《め》を｜引《ひ》くのは、｜家《いえ》の｜中《なか》にも｜光《ひか》る｜植物《しょくぶつ》があることだった。｜凝《こ》った｜陶器《とうき》の｜鉢《はち》に｜植《う》えられ、｜窓辺《まどべ》やテーブルに｜置《お》かれて、やわらかな｜明《あ》かりを｜提供《ていきょう》している。｜空間《くうかん》｜全体《ぜんたい》が｜温《あたた》かく｜静《しず》かで、｜思《おも》わずすべての｜警戒《けいかい》を｜解《と》きたくなる。

**清水恵美**：（｜小屋《こや》を｜眺《なが》め、｜目《め》に｜興奮《こうふん》の｜光《ひかり》を｜宿《やど》して）すごく｜心地《ここち》よさそうな｜場所《ばしょ》……｜李《り》さん、わたし、｜先《さき》にお｜風呂《ふろ》をいただいてきますね……

**李杰**：ああ、｜行《い》っておいで。｜俺《おれ》はあとでいい。

**ナレーション**：｜清水《しみず》は｜寝室《しんしつ》の｜一《ひと》つへ｜入《はい》り、しばらくすると｜水音《みずおと》が｜聞《き》こえてきた。｜李杰《りけつ》はソファに｜腰《こし》かけ、ようやく｜考《かんが》えを｜整理《せいり》する｜時間《じかん》ができた。あの｜奇怪《きかい》な｜列車《れっしゃ》、｜寂海駅《じゃっかいえき》、｜迷霧《めいむ》の｜森《もり》から、いまのエルフの｜村《むら》まで……｜何《なに》もかもが｜超現実的《ちょうげんじつてき》すぎる。

**ナレーション**：だが、あのアイラルの｜言葉《ことば》は｜彼《かれ》に｜希望《きぼう》をくれた――｜二年前《にねんまえ》のあの｜人間《にんげん》たちは｜帰《かえ》れたのだ。つまり、｜自分《じぶん》たちにも｜帰《かえ》れる｜見込《みこ》みがある。あとはアイラルの｜息子《むすこ》が｜戻《もど》るのを｜待《ま》って、｜方法《ほうほう》を｜詳《くわ》しく｜聞《き》けばいい。
