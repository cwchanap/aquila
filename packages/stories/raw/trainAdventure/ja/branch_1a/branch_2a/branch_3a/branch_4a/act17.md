# 第十七幕：燃える村の夜

**ナレーション**：｜李杰《りけつ》は｜眠《ねむ》りの｜中《なか》で、｜鼻《はな》を｜刺《さ》す｜匂《にお》いを｜感《かん》じた。はじめは｜夢《ゆめ》の｜一部《いちぶ》だと｜思《おも》ったが、｜匂《にお》いがますます｜濃《こ》くなるにつれ、｜意識《いしき》がしだいにはっきりしてきた。

**ナレーション**：｜目《め》を｜開《あ》けると、｜寝室《しんしつ》にはうっすらと｜灰色《はいいろ》の｜煙《けむり》が｜立《た》ちこめ、｜扉《とびら》の｜隙間《すきま》の｜下《した》からゆっくりと｜染《し》み｜込《こ》んでいた。｜空気《くうき》には｜木《き》の｜焼《や》ける｜焦《こ》げ｜臭《くさ》さと、｜言《い》いようのない｜刺激《しげき》が｜混《ま》ざり、｜喉《のど》がいがらっぽくなり｜始《はじ》める。

**李杰**：（はっと｜身《み》を｜起《お》こし、｜警戒心《けいかいしん》が｜一瞬《いっしゅん》で｜跳《は》ね｜上《あ》がって）｜煙《けむり》？　これは……｜火事《かじ》か？

**ナレーション**：｜彼《かれ》は｜素早《すばや》くベッドから｜飛《と》び｜降《お》り、｜寝室《しんしつ》の｜扉《とびら》へ｜駆《か》けた。｜扉《とびら》を｜開《あ》けた｜瞬間《しゅんかん》、さらに｜濃《こ》い｜煙《けむり》が｜顔《かお》に｜襲《おそ》いかかり、｜数度《すうど》｜咳《せ》き｜込《こ》んだ。｜広間《ひろま》の｜煙《けむり》は｜寝室《しんしつ》よりずっと｜濃《こ》く、｜視界《しかい》はすでにぼやけ｜始《はじ》めていた。

**ナレーション**：｜煙《けむり》の｜向《む》こうに、｜玄関《げんかん》の｜方角《ほうがく》で｜橙赤色《とうせきしょく》の｜火《ひ》が｜揺《ゆ》れているのが｜見《み》えた。｜木《き》の｜扉《とびら》の｜下半分《したはんぶん》はすでに｜燃《も》え｜始《はじ》め、｜炎《ほのお》が｜戸枠《とわく》を｜舐《な》めて、ぱちぱちと｜音《おと》を｜立《た》てている。｜熱気《ねっき》が｜顔《かお》に｜押《お》し｜寄《よ》せ、｜思《おも》わず｜一歩《いっぽ》｜後《あと》ずさった。

**ナレーション**：そのとき、もう｜一《ひと》つの｜寝室《しんしつ》の｜扉《とびら》も｜勢《いきお》いよく｜開《ひら》いた。アイラルが｜飛《と》び｜出《だ》してきた。｜銀《ぎん》の｜長《なが》い｜髪《かみ》は｜乱《みだ》れ、｜顔《かお》にはめったに｜見《み》せない｜緊張《きんちょう》の｜色《いろ》が｜浮《う》かんでいる。｜長衣《ちょうい》には｜灰《はい》がつき、｜彼《かれ》も｜煙《けむり》で｜目《め》を｜覚《さ》ましたばかりらしかった。

**アイラル**：（｜切迫《せっぱく》した｜様子《ようす》で｜李杰《りけつ》を｜見《み》て、｜声《こえ》に｜気遣《きづか》いをにじませ）｜李杰《りけつ》！　｜大丈夫《だいじょうぶ》ですか？　｜怪我《けが》は？

**李杰**：（｜数度《すうど》｜咳《せ》き｜込《こ》み、｜目《め》の｜前《まえ》の｜煙《けむり》を｜払《はら》って）｜大丈夫《だいじょうぶ》です！　｜清水《しみず》が――

**ナレーション**：｜言《い》い｜終《お》わらないうちに、｜彼《かれ》は｜身《み》を｜翻《ひるがえ》して｜清水《しみず》の｜寝室《しんしつ》へ｜駆《か》けた。｜力《ちから》いっぱい｜扉《とびら》を｜押《お》し｜開《あ》ける。｜寝室《しんしつ》の｜煙《けむり》はまださほど｜濃《こ》くないが、すでに｜焦《こ》げ｜臭《くさ》さが｜感《かん》じられた。｜清水《しみず》はまだベッドで｜眠《ねむ》っていて、｜呼吸《こきゅう》は｜穏《おだ》やか、｜危険《きけん》にはまったく｜気《き》づいていない。

**李杰**：（ベッドのそばに｜駆《か》け｜寄《よ》り、｜力《ちから》を｜込《こ》めて｜彼女《かのじょ》の｜肩《かた》を｜揺《ゆ》さぶる）｜清水《しみず》さん！　｜早《はや》く｜起《お》きて！　｜火事《かじ》だ！

**清水恵美**：（｜寝《ね》ぼけたまま｜目《め》を｜開《あ》け、｜眠気《ねむけ》の｜混《ま》じった｜声《こえ》で）ん……？　｜李《り》さん……？

**ナレーション**：｜部屋《へや》に｜立《た》ちこめる｜煙《けむり》と、｜李杰《りけつ》の｜顔《かお》に｜浮《う》かぶ｜緊迫《きんぱく》した｜表情《ひょうじょう》をはっきり｜見《み》た｜瞬間《しゅんかん》、｜眠気《ねむけ》は｜一気《いっき》に｜吹《ふ》き｜飛《と》んだ。｜彼女《かのじょ》ははっと｜身《み》を｜起《お》こし、｜目《め》に｜驚愕《きょうがく》がよぎる。

**清水恵美**：（｜煙《けむり》を｜見《み》つめ、｜声《こえ》を｜震《ふる》わせて）こ、これ……どうしたんですか？

**李杰**：（｜彼女《かのじょ》の｜手《て》を｜引《ひ》き、せかすように）｜聞《き》くな！　｜早《はや》く｜逃《に》げるぞ！

**ナレーション**：｜二人《ふたり》は｜広間《ひろま》へ｜駆《か》け｜戻《もど》った。アイラルはすでに｜濡《ぬ》れた｜布《ぬの》で｜口《くち》と｜鼻《はな》を｜覆《おお》い、｜火《ひ》の｜勢《いきお》いを｜見《み》ている。｜玄関《げんかん》の｜炎《ほのお》はますます｜激《はげ》しく｜燃《も》え｜盛《さか》り、もうそこからは｜出《で》られない。

**アイラル**：（｜二人《ふたり》を｜振《ふ》り｜返《かえ》り、｜厳《きび》しい｜声《こえ》で）｜村《むら》じゅうが｜燃《も》えています。｜裏口《うらぐち》から｜出《で》なくては、いますぐに！

**ナレーション**：｜三人《さんにん》は｜素早《すばや》く｜裏口《うらぐち》へ｜駆《か》けた。アイラルが｜力《ちから》いっぱい｜扉《とびら》を｜押《お》し｜開《あ》けると、｜外《そと》の｜光景《こうけい》に、｜全員《ぜんいん》が｜息《いき》をのんだ。

**ナレーション**：｜月光《げっこう》の｜林《はやし》ぜんたいが｜混乱《こんらん》に｜陥《おちい》っていた。あたり｜一面《いちめん》が｜炎《ほのお》と｜濃煙《のうえん》で、もともとやわらかな｜光《ひかり》を｜放《はな》っていた｜植物《しょくぶつ》は｜炎《ほのお》に｜呑《の》まれ、｜燃《も》えながらぱちぱちと｜弾《はじ》ける｜音《おと》を｜立《た》てている。｜建物《たてもの》は｜次々《つぎつぎ》と｜燃《も》え｜上《あ》がり、｜橙赤色《とうせきしょく》の｜炎《ほのお》の｜舌《した》が｜夜空《よぞら》に｜狂《くる》ったように｜舞《ま》っていた。

**ナレーション**：｜空気《くうき》には｜息詰《いきづ》まる｜煙《けむり》が｜立《た》ちこめ、｜木《き》と｜植物《しょくぶつ》の｜燃《も》える｜匂《にお》いに、｜言《い》いようのない｜刺激臭《しげきしゅう》が｜混《ま》じっている。かつて｜静《しず》かで｜穏《おだ》やかだった｜村《むら》は、いまや｜煉獄《れんごく》のようだった。

**ナレーション**：エルフたちが｜家々《いえいえ》から｜飛《と》び｜出《だ》してくる。｜子《こ》どもを｜抱《いだ》く｜者《もの》、｜老人《ろうじん》を｜支《ささ》える｜者《もの》、｜全員《ぜんいん》が｜同《おな》じ｜方角《ほうがく》――｜北《きた》へ｜向《む》かって｜走《はし》っていく。｜彼《かれ》らの｜顔《かお》には｜恐慌《きょうこう》と｜戸惑《とまど》いが｜刻《きざ》まれ、｜優雅《ゆうが》な｜振《ふ》る｜舞《ま》いは、｜生《い》き｜延《の》びようとする｜本能《ほんのう》に｜取《と》って｜代《か》わられていた。

**ナレーション**：｜澄《す》んだ｜小川《おがわ》は｜炎《ほのお》を｜映《うつ》し、｜水面《すいめん》は｜流《なが》れる｜溶岩《ようがん》のようだった。かつて｜美《うつく》しかった｜蔓《つる》の｜橋《はし》は｜燃《も》え｜始《はじ》め、｜胸《むね》を｜引《ひ》き｜裂《さ》くような、ちぎれる｜音《おと》を｜立《た》てている。

**李杰**：（｜目《め》の｜前《まえ》の｜光景《こうけい》を｜見《み》つめ、｜衝撃《しょうげき》のあまり｜言葉《ことば》も｜出《で》ず）これは……いったい、｜何《なに》が｜起《お》きて……

**アイラル**：（｜二人《ふたり》の｜腕《うで》を｜引《ひ》いて、せきたてる）ぼんやりしないで！　｜皆《みな》についていってください！　｜私《わたし》たちは｜銀月湖《ぎんげつこ》へ｜向《む》かいます！

**ナレーション**：｜三人《さんにん》は｜避難《ひなん》する｜人々《ひとびと》の｜列《れつ》に｜加《くわ》わった。｜李杰《りけつ》は｜走《はし》りながら、｜思《おも》わず｜何度《なんど》も｜振《ふ》り｜返《かえ》った。｜炎《ほのお》が｜空《そら》の｜半分《はんぶん》を｜照《て》らし、あの｜精緻《せいち》な｜建物《たてもの》が｜炎《ほのお》の｜中《なか》で｜崩《くず》れ｜落《お》ちていく。

**李杰**：（｜息《いき》を｜切《き》らして｜尋《たず》ねる）｜銀月湖《ぎんげつこ》？　それは、どんな｜場所《ばしょ》ですか？

**アイラル**：（｜走《はし》りながら｜説明《せつめい》する。｜走《はし》っているせいで｜声《こえ》が｜少《すこ》しせわしない）｜私《わたし》たちエルフの｜聖地《せいち》です。｜村《むら》の｜北《きた》の｜奥《おく》にあります。｜湖《みずうみ》の｜水《みず》は、｜地《ち》の｜底《そこ》のもっとも｜清《きよ》らかな｜泉《いずみ》から｜湧《わ》いたもので、｜古《ふる》い｜守《まも》りの｜力《ちから》を｜宿《やど》しているのです。｜村《むら》が｜襲《おそ》われたとき、そこが｜私《わたし》たちの｜避難所《ひなんじょ》になります。

**ナレーション**：｜人々《ひとびと》は｜北《きた》へ｜向《む》かう｜小道《こみち》に｜沿《そ》って｜走《はし》った。この｜道《みち》は｜来《き》たときの｜道《みち》よりもさらに｜険《けわ》しく、｜両側《りょうがわ》の｜木々《きぎ》が｜炎《ほのお》の｜明《あ》かりの｜中《なか》で、｜不気味《ぶきみ》な｜影《かげ》を｜落《お》としている。ときおり、｜遠《とお》くから｜建物《たてもの》の｜崩《くず》れる｜轟音《ごうおん》と、｜炎《ほのお》の｜咆哮《ほうこう》が｜聞《き》こえた。

**李杰**：（｜頭《あたま》の｜中《なか》を｜無数《むすう》の｜疑問《ぎもん》がよぎり）いったい｜誰《だれ》が｜村《むら》を｜襲《おそ》ったんだ？　どうしてそんなことを？

**アイラル**：（｜顔《かお》を｜曇《くも》らせて）｜分《わ》かりません。｜襲撃者《しゅうげきしゃ》は、みなが｜眠《ねむ》っているすきに｜手《て》を｜下《くだ》したのでしょう。ここは｜永夜《えいや》の｜地《ち》、｜闇《やみ》が｜襲撃者《しゅうげきしゃ》にこの｜上《うえ》ない｜隠《かく》れ｜蓑《みの》を｜与《あた》えました。｜彼《かれ》らは｜音《おと》もなく｜村《むら》に｜忍《しの》び｜込《こ》み、あちこちに｜火《ひ》を｜放《はな》つことができたのです。

**李杰**：でも……この｜火《ひ》の｜回《まわ》りは、あまりにも｜速《はや》すぎませんか？　ここは｜一面《いちめん》に｜霧《きり》が｜出《で》ていたはずで、｜本来《ほんらい》なら｜燃《も》えにくいはずなのに……

**アイラル**：（｜眉間《みけん》に｜深《ふか》く｜皺《しわ》を｜寄《よ》せて）おっしゃるとおりです。これは｜確《たし》かに、ひどく｜異常《いじょう》です。｜月光《げっこう》の｜林《はやし》は｜一年《いちねん》じゅう｜濃《こ》い｜霧《きり》に｜包《つつ》まれ、｜空気《くうき》が｜湿《しめ》っているので、たとえ｜火《ひ》がついてもこんなに｜速《はや》く｜燃《も》え｜広《ひろ》がるはずがありません。もし……もし｜襲撃者《しゅうげきしゃ》が、｜燃《も》えを｜早《はや》めるような｜何《なに》かを｜使《つか》ったのでなければ。

**ナレーション**：｜李杰《りけつ》の｜胸《むね》が｜沈《しず》んだ。もしそうなら、この｜襲撃《しゅうげき》は｜決《けっ》して｜偶然《ぐうぜん》ではなく、｜計画《けいかく》されたものだ。

**李杰**：（ふと｜何《なに》かを｜思《おも》い｜出《だ》し、｜心配《しんぱい》そうに｜尋《たず》ねる）アイラルさん、あなたの｜息子《むすこ》さんは……｜無事《ぶじ》でしょうか？　｜知《し》らせは｜届《とど》いていますか？

**アイラル**：（｜顔《かお》に｜一瞬《いっしゅん》、｜心配《しんぱい》がよぎるが、すぐに｜隠《かく》して）まだ、｜息子《むすこ》の｜知《し》らせは｜受《う》けていません。ですが、すでに｜人《ひと》をやって｜伝《つた》えさせました。あの｜子《こ》は｜強《つよ》い、きっと｜無事《ぶじ》です。

**李杰**：｜彼《かれ》は、いまどこに？　｜私《わたし》たちで｜探《さが》しに｜行《い》けませんか？

**アイラル**：（｜口《くち》ぶりを｜濁《にご》し、｜明《あき》らかにこれ｜以上《いじょう》｜話《はな》したくない｜様子《ようす》で）｜彼《かれ》は……｜重要《じゅうよう》な｜任務《にんむ》に｜就《つ》いています。｜正確《せいかく》な｜場所《ばしょ》は、｜私《わたし》にもよく｜分《わ》かりません。いま｜何《なに》より｜大事《だいじ》なのは、まず｜銀月湖《ぎんげつこ》に｜着《つ》いて、みなの｜安全《あんぜん》を｜確保《かくほ》することです。

**ナレーション**：｜李杰《りけつ》はアイラルがはぐらかしたことに｜気《き》づいたが、いまは｜問《と》い｜詰《つ》めるときではない。｜彼《かれ》は｜隣《となり》の｜清水《しみず》へ｜顔《かお》を｜向《む》け、｜無事《ぶじ》かどうか｜確《たし》かめようとした。

**ナレーション**：｜意外《いがい》なことに、｜清水《しみず》は｜顔《かお》に｜驚《おどろ》きこそ｜浮《う》かべているものの、｜当然《とうぜん》あるはずの｜恐怖《きょうふ》は｜見《み》せていなかった。｜目《め》にはむしろ｜奇妙《きみょう》な｜光《ひかり》が｜宿《やど》り、｜口《くち》もとにはあるかなきかの｜微笑《ほほえ》みがあった。

**清水恵美**：（｜息《いき》を｜切《き》らしているが、｜表情《ひょうじょう》は｜穏《おだ》やかで）｜李《り》さん……｜大丈夫《だいじょうぶ》ですか？

**李杰**：（｜息《いき》を｜切《き》らして）｜俺《おれ》は｜大丈夫《だいじょうぶ》だ。｜君《きみ》は？　｜平気《へいき》か？　｜怖《こわ》くないのか？
