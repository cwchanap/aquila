# 第十九幕：湖畔の星語り

**ナレーション**：｜天幕《てんまく》を｜張《は》り｜終《お》えると、｜二人《ふたり》ともくたくたで｜草《くさ》の｜上《うえ》にへたり｜込《こ》んだ。だが、これほど｜多《おお》くのことを｜経験《けいけん》した｜李杰《りけつ》は、かえって｜眠《ねむ》れなかった。｜目《め》の｜前《まえ》の｜穏《おだ》やかな｜湖面《こめん》を｜眺《なが》めながら、｜胸《むね》には｜複雑《ふくざつ》な｜思《おも》いが｜入《い》り｜混《ま》じっている。

**李杰**：（｜小声《こごえ》で）｜清水《しみず》さん、｜疲《つか》れてるか？　｜先《さき》に｜中《なか》で｜休《やす》むか？

**清水恵美**：（｜首《くび》を｜振《ふ》って）わ、わたしも……｜眠《ねむ》れなくて……｜李《り》さん、｜少《すこ》しだけ、｜一緒《いっしょ》にいてもらえませんか？

**李杰**：（うなずき、｜彼女《かのじょ》の｜隣《となり》に｜腰《こし》を｜下《お》ろして）ああ。

**ナレーション**：｜二人《ふたり》は｜並《なら》んで｜湖畔《こはん》の｜草地《くさち》に｜座《すわ》り、｜目《め》の｜前《まえ》の｜静《しず》かな｜景色《けしき》を｜眺《なが》めた。｜銀月湖《ぎんげつこ》の｜湖面《こめん》は｜巨大《きょだい》な｜鏡《かがみ》のように、｜空《そら》の｜二《ふた》つの｜月《つき》と｜瞬《またた》く｜星々《ほしぼし》を｜完璧《かんぺき》に｜映《うつ》している。｜湖水《こすい》は｜夢《ゆめ》のような｜銀青色《ぎんせいしょく》を｜帯《お》び、｜月光《げっこう》の｜下《した》でそっと｜波打《なみう》って、｜幾重《いくえ》もの｜波紋《はもん》を｜広《ひろ》げていた。

**ナレーション**：｜湖面《こめん》に｜浮《う》かぶ｜光《ひか》る｜花《はな》が、｜波《なみ》に｜合《あ》わせてそっと｜揺《ゆ》れ、やわらかな｜光《ひかり》を｜放《はな》っている。｜微風《びふう》が｜吹《ふ》き、ほのかな｜花《はな》の｜香《かお》りと｜草木《くさき》の｜清々《すがすが》しい｜匂《にお》いを｜運《はこ》んできた。｜遠《とお》くの｜森《もり》は｜月光《げっこう》の｜下《した》に｜深《ふか》い｜影《かげ》を｜落《お》としているが、ここはこんなにも｜明《あか》るく、｜温《あたた》かい。

**ナレーション**：｜世界《せかい》には、この｜湖《みずうみ》と｜二人《ふたり》だけが｜残《のこ》されたかのようだった。｜炎《ほのお》もなく、｜煙《けむり》もなく、｜恐怖《きょうふ》もない。あるのはただ｜静《しず》けさと、｜平和《へいわ》だけ。

**清水恵美**：（｜小《ちい》さく｜感嘆《かんたん》して）きれい……｜本当《ほんとう》に、きれい……

**李杰**：ああ。｜数時間前《すうじかんまえ》までは｜逃《に》げ｜惑《まど》っていたなんて、｜想像《そうぞう》もつかないな。それがいまは、こんなに｜美《うつく》しい｜景色《けしき》を｜見《み》ているなんて。

**清水恵美**：（｜湖面《こめん》を｜見《み》つめ、｜穏《おだ》やかな｜口調《くちょう》で）この｜世界《せかい》……｜恐《おそ》ろしいことがたくさんあるけれど、こんなに｜美《うつく》しい｜場所《ばしょ》もあって……まるで、｜人生《じんせい》みたいですね。

**李杰**：（｜彼女《かのじょ》のほうを｜向《む》いて）｜人生《じんせい》？

**清水恵美**：ええ……ときには｜暗《くら》くて、｜怖《こわ》くて、もうやめてしまいたくなるけれど……それでも、ときどき｜美《うつく》しい｜瞬間《しゅんかん》があって、｜続《つづ》けていく｜価値《かち》があるって｜思《おも》わせてくれるんです。

**ナレーション**：｜李杰《りけつ》は｜黙《だま》って｜彼女《かのじょ》を｜見《み》つめた。｜月光《げっこう》が｜恵美《えみ》の｜顔《かお》に｜降《ふ》り｜注《そそ》ぎ、｜横顔《よこがお》がひときわやわらかく｜見《み》える。その｜眼差《まなざ》しは｜遠《とお》くを｜見《み》つめ、｜何《なに》かの｜記憶《きおく》に｜沈《しず》んでいるかのようだった。

**李杰**：｜君《きみ》の｜言《い》うとおりだ。この｜数日《すうじつ》、あまりにもいろんなことがあった。ここに｜座《すわ》って｜景色《けしき》を｜眺《なが》めていると、まるで……｜夢《ゆめ》を｜見《み》ているみたいだ。

**清水恵美**：（そっと｜笑《わら》って）はい……｜夢《ゆめ》みたいに……

**ナレーション**：｜二人《ふたり》はしばし｜黙《だま》り、ただ｜静《しず》かに｜湖面《こめん》を｜見《み》つめた。ときおり｜遠《とお》くから、エルフたちの｜穏《おだ》やかな｜話《はな》し｜声《ごえ》や、｜子《こ》どもたちの｜笑《わら》い｜声《ごえ》が｜聞《き》こえてくる。｜火事《かじ》の｜恐怖《きょうふ》を｜経《へ》たあとでは、そうした｜声《こえ》がひときわ｜温《あたた》かく｜響《ひび》いた。

**李杰**：そういえば……｜清水《しみず》さん、｜前《まえ》に｜言《い》ってたよな……「あの｜人《ひと》」と｜一緒《いっしょ》に｜海《うみ》を｜見《み》に｜行《い》きたいって。その｜人《ひと》は……｜君《きみ》の｜恋人《こいびと》なのか？

**ナレーション**：｜恵美《えみ》の｜体《からだ》がかすかに｜震《ふる》え、｜李杰《りけつ》のほうへ｜顔《かお》を｜向《む》けた。その｜目《め》に、｜複雑《ふくざつ》な｜感情《かんじょう》がよぎる――｜驚《おどろ》き、｜悲《かな》しみ、そしてかすかな、｜見分《みわ》けにくいためらい。だがすぐに｜彼女《かのじょ》はうつむき、｜声《こえ》はやわらかく、｜憂《うれ》いを｜帯《お》びたものになった。

**清水恵美**：（うなずき、やさしい｜声《こえ》で）はい……そうです。｜彼《かれ》の｜名前《なまえ》は……｜翔《しょう》といいます。｜高山翔《たかやましょう》。｜高校《こうこう》のころから、ずっと｜一緒《いっしょ》でした。

**李杰**：（｜彼女《かのじょ》の｜口調《くちょう》の｜悲《かな》しみに｜気《き》づきながらも、｜穏《おだ》やかに｜尋《たず》ねる）｜仲《なか》がよかったんだな？

**清水恵美**：（｜目《め》に｜光《ひかり》が｜灯《とも》り、｜口《くち》もとに｜思《おも》い｜出《で》の｜笑《え》みを｜浮《う》かべて）はい……とても｜優《やさ》しい｜人《ひと》なんです。｜高校一年《こうこういちねん》のとき、わたしは｜新《あたら》しい｜学校《がっこう》に｜転校《てんこう》してきたばかりで、｜友達《ともだち》が｜一人《ひとり》もいなくて。｜最初《さいしょ》に｜自分《じぶん》から｜話《はな》しかけてくれて、ほかの｜子《こ》たちに｜引《ひ》き｜合《あ》わせてくれたのが、｜彼《かれ》だったんです。

**清水恵美**：｜彼《かれ》は、いつも……いつも、わたしの｜気持《きも》ちに｜気《き》づいてくれて。わたしが｜落《お》ち｜込《こ》んでいると、｜黙《だま》ってそばにいてくれて、わたしの｜好《す》きなイチゴ｜大福《だいふく》を｜買《か》ってきてくれました。わたしが｜嬉《うれ》しいときは、｜彼《かれ》も｜一緒《いっしょ》に、いっぱいに｜笑《わら》ってくれて。

**李杰**：（｜微笑《ほほえ》んで）いい｜人《ひと》みたいだな。

**清水恵美**：（うなずき、｜声《こえ》がいっそうやさしくなり、｜眼差《まなざ》しが｜遠《とお》くなる）｜約束《やくそく》してたんです……わたしが｜大学《だいがく》を｜卒業《そつぎょう》したら、｜一緒《いっしょ》に｜海外旅行《かいがいりょこう》に｜行《い》こうって。｜彼《かれ》はヨーロッパに｜行《い》きたいって｜言《い》って、｜車《くるま》を｜借《か》りて、ドライブしながら、｜小《ちい》さな｜町《まち》や｜海岸線《かいがんせん》をゆっくり｜眺《なが》めるんだって……でも、お｜金《かね》を｜貯《た》めなきゃいけないからって、｜彼《かれ》は｜卒業《そつぎょう》してからアルバイトを｜始《はじ》めて……

**ナレーション**：｜彼女《かのじょ》の｜声《こえ》はしだいに｜低《ひく》くなり、｜指《ゆび》が｜無意識《むいしき》に｜長衣《ちょうい》の｜裾《すそ》を｜握《にぎ》りしめた。｜李杰《りけつ》は｜彼女《かのじょ》の｜異変《いへん》に｜気《き》づき、｜胸《むね》に｜不安《ふあん》が｜湧《わ》き｜上《あ》がる。

**李杰**：（｜小声《こごえ》で｜尋《たず》ねる）｜清水《しみず》さん……｜大丈夫《だいじょうぶ》か？　｜何《なに》かあったのか？

**ナレーション**：｜恵美《えみ》は｜数秒《すうびょう》｜黙《だま》り、｜目《め》が｜少《すこ》し｜泳《およ》いだ。どう｜切《き》り｜出《だ》すべきか｜迷《まよ》っているようだった。｜彼女《かのじょ》は｜深《ふか》く｜息《いき》を｜吸《す》い、｜先《さき》ほどよりは｜落《お》ち｜着《つ》いた、けれどどこか｜押《お》し｜殺《ころ》した｜声《こえ》で｜言《い》った。

**清水恵美**：（うつむき、｜声《こえ》がやや｜硬《かた》い）でも……｜二年前《にねんまえ》……｜彼《かれ》が、｜交通事故《こうつうじこ》に｜遭《あ》って……

**ナレーション**：｜李杰《りけつ》の｜表情《ひょうじょう》が｜固《かた》まった。そんな｜答《こた》えを｜聞《き》くとは｜思《おも》ってもみなかった。

**清水恵美**：（｜続《つづ》ける。｜声《こえ》はとても｜小《ちい》さく、まるで｜物語《ものがたり》を｜暗唱《あんしょう》しているかのよう）とてもひどい｜事故《じこ》で……｜彼《かれ》はいま……いまも｜病院《びょういん》にいて……ずっと、｜意識《いしき》が｜戻《もど》らないままで……

**ナレーション**：これを｜話《はな》すとき、｜彼女《かのじょ》の｜視線《しせん》は｜李杰《りけつ》ではなく、｜湖面《こめん》に｜向《む》けられていた。｜表情《ひょうじょう》は｜悲《かな》しげだが、それ｜以上《いじょう》に、ある｜種《しゅ》の……｜疲《つか》れ？　それとも｜別《べつ》の｜感情《かんじょう》？　｜李杰《りけつ》には、すぐには｜見分《みわ》けがつかなかった。

**李杰**：（｜衝撃《しょうげき》を｜受《う》けて）｜二年《にねん》……ずっと｜昏睡《こんすい》？　それで……

**清水恵美**：（うなずく。｜声《こえ》はなおも、｜不自然《ふしぜん》なほど｜平静《へいせい》で）はい……お｜医者《いしゃ》さんは、いつ｜目《め》を｜覚《さ》ますか｜分《わ》からないって。わたし……｜毎週《まいしゅう》、お｜見舞《みま》いに｜行《い》ってるんです。

**ナレーション**：｜彼女《かのじょ》の｜指《ゆび》はさらに｜強《つよ》く｜握《にぎ》りしめられ、｜関節《かんせつ》がうっすら｜白《しろ》くなった。｜李杰《りけつ》は｜彼女《かのじょ》の｜目《め》の｜縁《ふち》が｜赤《あか》く｜染《そ》まり｜始《はじ》めたのに｜気《き》づいたが、｜涙《なみだ》は｜彼《かれ》の｜予想《よそう》したようにはすぐに｜溢《あふ》れなかった。｜彼女《かのじょ》は｜懸命《けんめい》に｜感情《かんじょう》を｜抑《おさ》えているようだった。

**李杰**：（｜手《て》を｜伸《の》ばして、そっと｜彼女《かのじょ》の｜肩《かた》を｜叩《たた》く）｜清水《しみず》さん……それは……｜君《きみ》にとって、きっと｜辛《つら》いことだ……

**清水恵美**：（ようやく｜彼《かれ》のほうを｜向《む》き、｜涙《なみだ》がゆっくりと｜頬《ほお》を｜伝《つた》うが、｜声《こえ》はまだ｜落《お》ち｜着《つ》いている）｜最初《さいしょ》は……｜最初《さいしょ》は、｜受《う》け｜入《い》れるのがとても｜難《むずか》しくて。でも、いまはもう……｜慣《な》れました。わたしはただ……ただ、｜彼《かれ》が｜目《め》を｜覚《さ》ましてくれたらって……

**ナレーション**：｜彼女《かのじょ》の｜涙《なみだ》はとても｜静《しず》かに｜流《なが》れた。｜取《と》り｜乱《みだ》すというより、｜慣《な》れきった｜悲《かな》しみのようだった。｜李杰《りけつ》は｜彼女《かのじょ》を｜見《み》つめ、｜強《つよ》い｜痛《いた》ましさが｜胸《むね》に｜湧《わ》いたが、｜同時《どうじ》に、｜言葉《ことば》にしがたい｜感覚《かんかく》もあった――｜彼女《かのじょ》の｜反応《はんのう》は、｜彼《かれ》が｜想像《そうぞう》していたものとはどこか｜違《ちが》う。

**ナレーション**：もしかすると、もう｜二年《にねん》もたっているから、｜感情《かんじょう》を｜押《お》し｜殺《ころ》す｜術《じゅつ》を｜身《み》につけたのかもしれない。あるいは、あまりに｜何度《なんど》も｜語《かた》ってきたせいで、この｜話《はなし》がひとつの｜決《き》まった｜台詞《せりふ》のようになってしまったのかもしれない。

**李杰**：（｜小声《こごえ》で）それだけ｜長《なが》く｜耐《た》えてきたなんて……｜本当《ほんとう》にすごいことだ。｜彼《かれ》にもきっと……｜君《きみ》がそばにいることは｜伝《つた》わってるさ。

**清水恵美**：（｜涙《なみだ》を｜拭《ぬぐ》い、｜無理《むり》に｜笑《わら》って）ありがとうございます……｜李《り》さん……｜本当《ほんとう》は……｜本当《ほんとう》は、｜彼《かれ》に｜伝《つた》わってるのかどうかも｜分《わ》からないんです……でも、それでも……それでも、｜待《ま》ち｜続《つづ》けたくて……

**ナレーション**：そう｜言《い》い｜終《お》えると、｜彼女《かのじょ》はそっと｜頭《あたま》を｜李杰《りけつ》の｜肩《かた》に｜預《あず》けた。その｜動作《どうさ》はごく｜自然《しぜん》だったが、｜李杰《りけつ》の｜体《からだ》はそれでもこわばった。｜彼女《かのじょ》の｜肩《かた》のかすかな｜震《ふる》えが｜伝《つた》わり、｜押《お》し｜殺《ころ》した｜息《いき》づかいが｜感《かん》じられる。
