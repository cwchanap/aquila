# 第二十幕：夜明けはまだ来ない

**ナレーション**：｜李杰《りけつ》は｜湖畔《こはん》に｜長《なが》く｜座《すわ》っていたが、やがて｜体《からだ》の｜疲労《ひろう》が、｜頭《あたま》の｜中《なか》の｜混乱《こんらん》を｜押《お》さえ｜込《こ》み｜始《はじ》めたのを｜感《かん》じた。｜空《そら》を｜見上《みあ》げると、｜二《ふた》つの｜月《つき》はなお｜高《たか》く｜懸《か》かり、｜永遠《えいえん》の｜夜《よる》の｜色《いろ》は｜少《すこ》しも｜変《か》わっていない。｜彼《かれ》は｜立《た》ち｜上《あ》がって｜伸《の》びをし、｜天幕《てんまく》へ｜戻《もど》って｜休《やす》むことにした。

**ナレーション**：｜彼《かれ》がそっと｜天幕《てんまく》の｜垂《た》れ｜幕《まく》をめくると、｜薄《うす》い｜帆布越《はんぷご》しに｜月光《げっこう》が｜射《さ》し｜込《こ》み、｜恵美《えみ》はまだ｜眠《ねむ》っていた。｜横向《よこむ》きに｜寝《ね》て、｜両手《りょうて》を｜頬《ほお》の｜下《した》に｜敷《し》き、｜呼吸《こきゅう》は｜穏《おだ》やかで｜静《しず》かだ。｜毛布《もうふ》が｜少《すこ》しずり｜落《お》ちて、｜華奢《きゃしゃ》な｜肩《かた》がのぞいていた。

**ナレーション**：｜李杰《りけつ》はそこで、｜気《き》まずい｜問題《もんだい》に｜気《き》づいた――この｜粗末《そまつ》な｜天幕《てんまく》は、｜本当《ほんとう》に｜狭《せま》い。せいぜい｜二《に》メートルの｜幅《はば》で、｜毛布《もうふ》を｜二枚《にまい》｜敷《し》けば、｜余《あま》った｜場所《ばしょ》はほとんどない。｜寝《ね》るなら｜恵美《えみ》の｜隣《となり》に｜寝《ね》るしかなく、｜間《あいだ》にこぶし｜一《ひと》つ｜分《ぶん》の｜距離《きょり》さえ｜空《あ》けられない。

**李杰**：（｜心《こころ》の｜声《こえ》。やや｜緊張《きんちょう》して）こ、これは……さすがに｜近《ちか》すぎるだろ……

**ナレーション**：｜彼《かれ》はためらい、いっそ｜外《そと》で｜一晩《ひとばん》｜座《すわ》って｜過《す》ごそうかと｜考《かんが》えた。だが｜湖畔《こはん》の｜夜風《よかぜ》はすでに｜冷《つめ》たくなり｜始《はじ》めており、それにこれだけのことを｜経験《けいけん》して、｜体《からだ》は｜確《たし》かに｜休息《きゅうそく》を｜必要《ひつよう》としていた。｜彼《かれ》は｜深《ふか》く｜息《いき》を｜吸《す》い、そっと｜恵美《えみ》の｜隣《となり》の｜毛布《もうふ》に｜横《よこ》になった。

**ナレーション**：できるだけ｜端《はし》に｜寄《よ》っても、｜二人《ふたり》のあいだの｜距離《きょり》は、｜心臓《しんぞう》が｜速《はや》くなるほど｜近《ちか》かった。｜恵美《えみ》の｜寝息《ねいき》がはっきり｜聞《き》こえ、｜髪《かみ》からほのかな｜花《はな》の｜香《かお》りがする――エルフの｜村《むら》のシャンプーの｜匂《にお》いだ。｜月光《げっこう》の｜下《した》では、まつ｜毛《げ》の｜弧《こ》まで｜見《み》えるほどだった。

**李杰**：（｜心《こころ》の｜声《こえ》）｜落《お》ち｜着《つ》け……｜落《お》ち｜着《つ》け……ただ｜寝《ね》るだけだ……｜俺《おれ》はもう｜二十八《にじゅうはち》だぞ、どうして｜思春期《ししゅんき》の｜男子《だんし》みたいに……

**ナレーション**：だが、｜落《お》ち｜着《つ》こうとすればするほど、｜緊張《きんちょう》が｜増《ま》していく。｜女《おんな》の｜子《こ》とこんなに｜近《ちか》い｜場所《ばしょ》で｜眠《ねむ》るのは、これが｜初《はじ》めてだった。いや、むしろ、こんなに｜親密《しんみつ》に｜触《ふ》れ｜合《あ》うのが｜初《はじ》めてだった。

**ナレーション**：｜李杰《りけつ》は｜子《こ》どものころから、｜筋金入《すじがねい》りのインドア｜派《は》だった。｜大学時代《だいがくじだい》は｜時間《じかん》のすべてを｜勉強《べんきょう》とゲームに｜費《つい》やし、｜卒業後《そつぎょうご》は｜仕事《しごと》に｜全力《ぜんりょく》を｜注《そそ》いだ。｜会社《かいしゃ》にも｜女性《じょせい》の｜同僚《どうりょう》はいたが、どう｜話《はな》しかければいいのか｜分《わ》からず、いつしか｜一人《ひとり》の｜暮《く》らしに｜慣《な》れてしまった。｜二十八年間《にじゅうはちねんかん》、｜女《おんな》の｜子《こ》の｜手《て》を｜握《にぎ》ったことさえない。

**ナレーション**：そしていま、｜若《わか》くてかわいい｜女子大生《じょしだいせい》が、すぐ｜隣《となり》に｜横《よこ》たわっている。｜体温《たいおん》が｜伝《つた》わるほど｜近《ちか》くに。｜李杰《りけつ》は｜仰向《あおむ》けの｜姿勢《しせい》のまま、ぎこちなくこわばり、｜少《すこ》しも｜動《うご》けなかった。｜起《お》こしてしまうのも、｜触《ふ》れてしまうのも｜怖《こわ》い。｜手《て》をどこに｜置《お》けばいいのかさえ｜分《わ》からなかった。

**ナレーション**：｜恵美《えみ》が｜寝返《ねがえ》りを｜打《う》ち、｜口《くち》から｜小《ちい》さな｜寝言《ねごと》を｜漏《も》らした。｜李杰《りけつ》の｜体《からだ》は｜一瞬《いっしゅん》でこわばり、｜息《いき》まで｜止《と》める。だが｜恵美《えみ》はただ｜姿勢《しせい》を｜直《なお》しただけで、またすぐ｜深《ふか》い｜眠《ねむ》りに｜落《お》ちた。

**李杰**：（｜心《こころ》の｜声《こえ》）このままじゃ｜全然《ぜんぜん》｜眠《ねむ》れない……｜何《なに》かほかのことを｜考《かんが》えよう……そうだ、｜明日《あした》やることを｜考《かんが》えよう……アイラルさんに、｜帰《かえ》る｜具体的《ぐたいてき》な｜方法《ほうほう》を｜聞《き》いて……ほかの｜人《ひと》たちの｜無事《ぶじ》も｜確《たし》かめないと……

**ナレーション**：｜彼《かれ》は｜懸命《けんめい》に｜思考《しこう》をこうした｜実際的《じっさいてき》な｜問題《もんだい》に｜集中《しゅうちゅう》させた。するとしだいに｜緊張《きんちょう》が｜引《ひ》いていく。｜疲《つか》れが｜潮《しお》のように｜押《お》し｜寄《よ》せ、まぶたはどんどん｜重《おも》くなった。｜恵美《えみ》の｜穏《おだ》やかな｜寝息《ねいき》は、むしろ｜眠《ねむ》りを｜誘《さそ》うリズムになっていった。

**ナレーション**：いつしか、｜李杰《りけつ》の｜意識《いしき》はぼんやりし｜始《はじ》めた。｜最後《さいご》に｜浮《う》かんだ｜思《おも》いは――｜彼女《かのじょ》、よく｜眠《ねむ》ってるな……。そして｜彼《かれ》も、｜夢《ゆめ》の｜世界《せかい》へ｜沈《しず》んでいった。

**ナレーション**：｜李杰《りけつ》は、｜自分《じぶん》がとても｜長《なが》く｜眠《ねむ》ったように｜感《かん》じた。｜骨《ほね》の｜芯《しん》からにじみ｜出《で》るような｜疲《つか》れが、ようやくほぐれていく。｜彼《かれ》はゆっくりと｜目《め》を｜開《あ》け、｜視界《しかい》がしだいに｜晴《は》れた。

**ナレーション**：そして、はっとした。｜天幕《てんまく》の｜外《そと》はあいかわらず｜闇《やみ》で、｜薄《うす》い｜帆布越《はんぷご》しに、｜外《そと》がなお｜永遠《えいえん》の｜夜《よる》の｜色《いろ》であるのが｜見《み》える。｜二《ふた》つの｜月《つき》は｜変《か》わらず｜空《そら》に｜高《たか》く｜懸《か》かり、｜星《ほし》は｜変《か》わらずまたたいている。まるで……｜眠《ねむ》る｜前《まえ》に｜見《み》たのと、まったく｜同《おな》じように。

**李杰**：（｜心《こころ》の｜声《こえ》。｜茫然《ぼうぜん》として）これは……いったい、どれくらい｜寝《ね》たんだ？　どうしてまだ｜暗《くら》いんだ？　まさか……｜数分《すうふん》しか｜寝《ね》てないのか？

**ナレーション**：｜彼《かれ》は｜無意識《むいしき》にポケットを｜探《さぐ》り、スマホで｜時間《じかん》を｜見《み》ようとした。だがスマホはとっくに｜電池《でんち》が｜切《き》れ、｜画面《がめん》は｜真《ま》っ｜暗《くら》だった。｜体《からだ》は｜長《なが》く｜眠《ねむ》ったと｜告《つ》げているのに、｜外《そと》の｜景色《けしき》は｜時間《じかん》が｜流《なが》れていないと｜告《つ》げている。この｜矛盾《むじゅん》した｜感覚《かんかく》に、｜頭《あたま》がしばらくついていかなかった。

**ナレーション**：｜永遠《えいえん》の｜闇《やみ》のこの｜世界《せかい》では、｜時間《じかん》はあいまいで、つかみどころのないものになる。｜日《ひ》の｜出《で》も｜日《ひ》の｜入《い》りもなく、｜光《ひかり》の｜変化《へんか》もなく、｜自分《じぶん》がどれだけ｜眠《ねむ》ったのかさえ｜判断《はんだん》できない。｜数時間《すうじかん》かもしれないし、｜十数時間《じゅうすうじかん》かもしれない。

**ナレーション**：｜彼《かれ》は｜隣《となり》へ｜顔《かお》を｜向《む》けた。｜恵美《えみ》はまだぐっすり｜眠《ねむ》っている。｜横向《よこむ》きで｜彼《かれ》のほうを｜向《む》き、｜片手《かたて》を｜頬《ほお》の｜下《した》に｜置《お》いて、｜呼吸《こきゅう》は｜穏《おだ》やかで｜静《しず》かだ。まつ｜毛《げ》が｜月光《げっこう》の｜下《した》に｜細長《ほそなが》い｜影《かげ》を｜落《お》とし、｜口《くち》もとにはうっすらと｜弧《こ》が｜浮《う》かんで、｜安《やす》らかに｜眠《ねむ》っているように｜見《み》えた。

**李杰**：（｜心《こころ》の｜声《こえ》）まだしばらく｜起《お》きそうにないな……｜先《さき》に｜外《そと》に｜出《で》よう、｜起《お》こさないように。

**ナレーション**：｜李杰《りけつ》は｜慎重《しんちょう》に｜毛布《もうふ》をめくった。ほとんど｜音《おと》を｜立《た》てないほど｜動作《どうさ》は｜軽《かる》い。ゆっくりと｜体《からだ》を｜起《お》こし、｜少《すこ》しずつ｜天幕《てんまく》の｜出口《でぐち》へにじり｜寄《よ》る。｜恵美《えみ》が｜身《み》じろぎし、｜李杰《りけつ》はすぐに｜動《うご》きを｜止《と》めて｜息《いき》を｜殺《ころ》した。だが｜彼女《かのじょ》は｜姿勢《しせい》を｜変《か》えただけで、｜目《め》を｜覚《さ》まさなかった。

**ナレーション**：｜李杰《りけつ》はほっと｜息《いき》をつき、なおも｜慎重《しんちょう》に｜動《うご》いた。ついに、｜天幕《てんまく》をくぐって｜外《そと》に｜出《で》ることに｜成功《せいこう》し、｜立《た》ったまま｜冷《つめ》たく｜澄《す》んだ｜空気《くうき》を｜深《ふか》く｜吸《す》い｜込《こ》んだ。

**ナレーション**：｜銀月湖《ぎんげつこ》は｜変《か》わらず｜穏《おだ》やかで｜美《うつく》しく、｜湖面《こめん》の｜光《ひか》る｜花《はな》は｜変《か》わらずそっと｜揺《ゆ》れている。｜周囲《しゅうい》のエルフたちは、もう｜起《お》きている｜者《もの》もいれば、まだ｜天幕《てんまく》で｜休《やす》んでいる｜者《もの》もいた。｜李杰《りけつ》はあたりを｜見回《みまわ》し、エルフたちには｜自分《じぶん》たちの｜体内時計《たいないどけい》があるらしく、この｜永遠《えいえん》の｜夜《よる》の｜影響《えいきょう》を｜受《う》けていないのだと｜気《き》づいた。

**ナレーション**：｜腹《はら》がぐうと｜鳴《な》って、｜何《なに》か｜食《た》べるべきだと｜教《おし》えてくれた。｜李杰《りけつ》は、｜昨夜《さくや》、｜小屋《こや》から｜食《た》べ｜物《もの》を｜少《すこ》し｜持《も》ち｜出《だ》してリュックに｜入《い》れたのを｜思《おも》い｜出《だ》した。リュックを｜開《あ》け、｜油紙《あぶらがみ》に｜包《つつ》んだパンを｜何切《なんき》れかと、｜乾燥果実《かんそうかじつ》を｜取《と》り｜出《だ》す。

**ナレーション**：パンは｜少《すこ》し｜硬《かた》くなっていたが、まだ｜食《た》べられた。｜李杰《りけつ》は｜湖畔《こはん》に｜座《すわ》ってパンをかじりながら、｜穏《おだ》やかな｜湖面《こめん》を｜眺《なが》めた。｜光《ひか》る｜花《はな》が｜水面《すいめん》に｜漂《ただよ》い、｜空気《くうき》には｜清々《すがすが》しい｜花《はな》の｜香《かお》りが｜満《み》ちている。｜村《むら》が｜焼《や》かれたのでなければ、ここは｜本当《ほんとう》に｜桃源郷《とうげんきょう》だった。

**ナレーション**：ささやかな｜朝食《ちょうしょく》を｜終《お》えると――いまが｜朝《あさ》なのかどうか、｜彼《かれ》にも｜確信《かくしん》はなかったが――｜李杰《りけつ》はアイラルを｜訪《たず》ねることにした。この｜先《さき》どうすればいいのか、どうすれば｜元《もと》の｜世界《せかい》へ｜戻《もど》れるのかを｜知《し》る｜必要《ひつよう》があった。

**ナレーション**：｜彼《かれ》は｜湖畔《こはん》に｜沿《そ》って｜歩《ある》き、まもなくアイラルのいるいちばん｜大《おお》きな｜小屋《こや》を｜見《み》つけた。｜数人《すうにん》のエルフが｜戸口《とぐち》で｜話《はな》していて、｜李杰《りけつ》が｜歩《ある》いてくるのを｜見《み》ると、みな｜親《した》しげにうなずいた。

**李杰**：（｜礼儀《れいぎ》｜正《ただ》しく）あの……アイラルさんはいらっしゃいますか？

**エルフの衛兵**：（｜微笑《ほほえ》んで）いらっしゃいますよ。｜長老《ちょうろう》は｜中《なか》におられますので、どうぞお｜入《はい》りください。

**ナレーション**：｜李杰《りけつ》は｜木《き》の｜戸《と》を｜押《お》し｜開《あ》け、｜小屋《こや》に｜入《はい》った。｜屋内《おくない》は｜外《そと》よりやや｜明《あか》るく、｜光《ひか》る｜植物《しょくぶつ》のランプがいくつか｜明《あ》かりを｜与《あた》えている。アイラルは｜簡素《かんそ》な｜木《き》のテーブルの｜前《まえ》に｜座《すわ》り、｜地位《ちい》の｜高《たか》そうなエルフ｜数人《すうにん》と、｜何《なに》かを｜相談《そうだん》していた。
