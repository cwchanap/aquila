# 第二十一幕：湖畔のおだやかな日々

**ナレーション**：リー・ジエが｜天幕《てんまく》の｜近《ちか》くへ｜戻《もど》ると、｜恵美《えみ》がもう｜起《お》きているのに｜気《き》づいて｜驚《おどろ》いた。｜彼女《かのじょ》は｜天幕《てんまく》の｜外《そと》の｜草地《くさち》に｜座《すわ》っていて、｜目《め》の｜前《まえ》には｜小《ちい》さな｜焚《た》き｜火《び》があり、その｜上《うえ》に｜据《す》えた｜簡素《かんそ》な｜鉄鍋《てつなべ》が、ぐつぐつと｜湯気《ゆげ》を｜立《た》てていた。

**ナレーション**：｜恵美《えみ》は｜元気《げんき》そうで、｜顔《かお》にはほのかな｜笑《え》みを｜浮《う》かべていた。｜髪《かみ》は｜少《すこ》し｜乱《みだ》れているが、｜朝《あさ》の｜光《ひかり》――いや、｜月光《げっこう》の｜下《した》では、かえってとりわけ｜愛《あい》らしく｜見《み》える。｜彼女《かのじょ》は｜木《き》べらで｜鍋《なべ》の｜中身《なかみ》をかき｜混《ま》ぜていて、その｜真剣《しんけん》な｜様子《ようす》に、リー・ジエは｜声《こえ》をかけるのがはばかられた。

**ナレーション**：｜若《わか》いエルフの｜少女《しょうじょ》がそばにしゃがみ、｜火加減《ひかげん》の｜見《み》かたを｜恵美《えみ》に｜教《おし》えていた。｜二人《ふたり》は｜楽《たの》しげに｜言葉《ことば》を｜交《か》わしていて、｜和《なご》やかな｜空気《くうき》だった。

**清水恵美**：（リー・ジエに｜気《き》づいて｜顔《かお》を｜上《あ》げ、ぱっと｜輝《かがや》くような｜笑顔《えがお》になって）リーさん！　｜帰《かえ》ってきたんですね！

**リー・ジエ**：（｜歩《あゆ》み｜寄《よ》り、｜少《すこ》し｜驚《おどろ》いて）｜起《お》きてたのか？　これは……｜料理《りょうり》をしてるのか？

**清水恵美**：（うなずき、｜少《すこ》し｜照《て》れくさそうに）はい……｜目《め》が｜覚《さ》めたらリーさんがいなかったので、｜何《なに》か｜作《つく》ろうかなって。このエルフのお｜姉《ねえ》さんが｜火《ひ》をおこしてくれて、｜作《つく》り｜方《かた》も｜教《おし》えてくれたんです。

**エルフの少女**：（リー・ジエに｜微笑《ほほえ》みかけ、｜立《た》ち｜上《あ》がって）どうぞごゆっくり。わたしはこれで｜失礼《しつれい》しますね。

**ナレーション**：エルフの｜少女《しょうじょ》は｜優雅《ゆうが》にうなずくと、くるりと｜背《せ》を｜向《む》けて｜去《さ》っていった。｜恵美《えみ》は｜鍋《なべ》をかき｜混《ま》ぜ｜続《つづ》け、いい｜香《かお》りがふわりと｜漂《ただよ》ってくる。

**清水恵美**：（うれしそうに）リーさん、いっしょに｜食《た》べませんか？　お｜粥《かゆ》を｜作《つく》ったんです。エルフのお｜姉《ねえ》さんにもらった｜香草《こうそう》と、きのこも｜入《い》れました。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）まずい……さっきパンを｜食《た》べたばかりだ……でも、こんなに｜嬉《うれ》しそうな｜顔《かお》を｜見《み》たら、｜断《ことわ》るなんてできるわけがない……

**リー・ジエ**：（｜微笑《ほほえ》んで｜腰《こし》を｜下《お》ろし）いいな。｜実《じつ》はさっき、パンをちょっとつまんだだけで、まだ｜腹《はら》いっぱいじゃないんだ。

**ナレーション**：まるきり｜嘘《うそ》というわけでもなかった。あの｜硬《かた》く｜乾《かわ》いたパン｜数《すう》｜切《き》れでは、たしかに｜腹《はら》は｜満《み》ちなかったし、いまお｜粥《かゆ》の｜香《かお》りをかぐと、｜本当《ほんとう》に｜食欲《しょくよく》がわいてくる。

**清水恵美**：（｜嬉《うれ》しそうにお｜粥《かゆ》を｜二杯《にはい》よそって）よかった！　たくさん｜作《つく》ったんです、お｜腹《なか》がすいてないかもって｜心配《しんぱい》してたから。

**ナレーション**：｜二人《ふたり》は｜椀《わん》を｜持《も》って｜湖《みずうみ》のほとりへ｜行《い》き、｜腰《こし》を｜下《お》ろした。｜銀月湖《ぎんげつこ》の｜湖面《こめん》は｜変《か》わらず｜鏡《きょう》のように｜静《しず》かで、｜空《そら》の｜二《ふた》つの｜月《つき》と｜星々《ほしぼし》を｜映《うつ》している。｜光《ひか》る｜花《はな》が｜水面《すいめん》にそっと｜揺《ゆ》れ、｜澄《す》んだ｜花《はな》の｜香《かお》りとお｜粥《かゆ》の｜香《かお》りが、あたりに｜満《み》ちていた。

**ナレーション**：リー・ジエがひと｜口《くち》｜食《た》べると、お｜粥《かゆ》はとろりと｜柔《やわ》らかくておいしく、｜香草《こうそう》ときのこの｜風味《ふうみ》もちょうどよく、｜想像《そうぞう》していたよりずっとおいしかった。｜恵美《えみ》は｜食《た》べながらこっそり｜彼《かれ》の｜表情《ひょうじょう》をうかがっていて、｜彼《かれ》がおいしそうに｜食《た》べるのを｜見《み》ると、｜満足《まんぞく》げな｜笑《え》みを｜浮《う》かべた。

**リー・ジエ**：（｜心《こころ》から）すごくおいしいよ。｜料理《りょうり》、｜上手《じょうず》なんだな。

**清水恵美**：（｜嬉《うれ》しさに｜目《め》を｜細《ほそ》めて）｜本当《ほんとう》ですか？　よかった！　｜失敗《しっぱい》してたらどうしようって｜思《おも》ってたんです……

**ナレーション**：｜二人《ふたり》はそうして｜湖《みずうみ》のほとりに｜座《すわ》り、｜静《しず》かにささやかな｜朝食《ちょうしょく》を｜味《あじ》わった。まわりからは、ときおりエルフたちの｜話《はな》し｜声《ごえ》や｜子《こ》どもたちの｜笑《わら》い｜声《ごえ》が｜聞《き》こえてきて、すべてがとても｜穏《おだ》やかで、あたたかく｜感《かん》じられた。

**ナレーション**：｜食《た》べ｜終《お》えると、リー・ジエは｜椀《わん》を｜脇《わき》に｜置《お》き、｜恵美《えみ》のほうを｜向《む》いた。

**リー・ジエ**：｜清水《しみず》さん、さっきアイラルさんに｜会《あ》いに｜行《い》ってきたんだ。いい｜知《し》らせがある。

**清水恵美**：（はっと｜目《め》を｜輝《かがや》かせて）いい｜知《し》らせ？

**リー・ジエ**：アイラルさんが、｜息子《むすこ》さんと｜連絡《れんらく》がついたそうだ。｜息子《むすこ》さんが、｜俺《おれ》たちの｜世界《せかい》へ｜帰《かえ》る｜方法《ほうほう》を｜教《おし》えてくれたって。

**ナレーション**：リー・ジエは、｜恵美《えみ》が｜大喜《おおよろこ》びするものと｜思《おも》っていた。ところが、｜彼女《かのじょ》の｜反応《はんのう》は｜予想《よそう》とは｜違《ちが》った。｜恵美《えみ》の｜顔《かお》には｜確《たし》かに｜笑《え》みが｜浮《う》かび、｜瞳《ひとみ》にも｜喜《よろこ》びがきらめいている。けれどその｜喜《よろこ》びは、｜思《おも》いがけない｜朗報《ろうほう》への｜驚《おどろ》きというより……｜確《たし》かめられたことへの｜安堵《あんど》のようなものだった。

**清水恵美**：（｜微笑《ほほえ》んで、｜落《お》ち｜着《つ》いた｜口調《くちょう》で）それはよかったです。アイラルさんは、どうすればいいと｜言《い》っていましたか？

**リー・ジエ**：「｜終焉《しゅうえん》の｜祭壇《さいだん》」という｜場所《ばしょ》へ｜行《い》く｜必要《ひつよう》があるんだ。｜古代《こだい》エルフ｜王国《おうこく》の｜遺跡《いせき》で、｜人《ひと》を｜元《もと》の｜世界《せかい》へ｜送《おく》り｜返《かえ》せる｜技術《ぎじゅつ》が｜残《のこ》ってるらしい。ただ、その｜前《まえ》にエルフの｜儀式《ぎしき》を｜受《う》けて、｜神樹《しんじゅ》に｜認《みと》めてもらわないといけない。

**清水恵美**：（うなずき、｜表情《ひょうじょう》は｜穏《おだ》やかなまま）そうなんですね……じゃあ、いつ｜行《い》くんですか？

**ナレーション**：リー・ジエは、｜恵美《えみ》の｜落《お》ち｜着《つ》いた｜反応《はんのう》を｜見《み》て、ふと｜胸《むね》に｜疑問《ぎもん》がよぎった。こんなに｜大事《だいじ》な｜知《し》らせなのに、どうして……まるで｜前《まえ》から｜知《し》っていたみたいに、｜少《すこ》しも｜驚《おどろ》かないのだろう？

**リー・ジエ**：（｜探《さぐ》るように｜尋《たず》ねる）｜清水《しみず》さん……あまり｜驚《おどろ》いてないみたいだな？

**清水恵美**：（きょとんとして、それから｜微笑《ほほえ》み）あ……そうですか？　たぶん……きっと｜帰《かえ》る｜方法《ほうほう》はあるって、ずっと｜信《しん》じてたからかもしれません。だから、はっきりした｜方法《ほうほう》を｜聞《き》いても……ああ、やっぱり、っていう｜感《かん》じで？

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）そういうものなのか……それとも、ただ｜楽観的《らっかんてき》なだけか……
