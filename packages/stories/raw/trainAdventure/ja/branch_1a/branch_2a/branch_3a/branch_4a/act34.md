**ナレーション**：ケランは｜道案内《みちあんない》をしながら、さらに｜話《はなし》を｜続《つづ》けた。

**ケラン**：｜仕事《しごと》のほかにも、｜私《わたし》たちには｜私《わたし》たちなりの｜楽《たの》しみがあります。たとえば｜音楽《おんがく》、｜舞踊《ぶよう》、そしてさまざまな｜祭《まつ》り。

**ナレーション**：｜四人《よにん》は｜歩《ある》きながら｜語《かた》り｜合《あ》い、｜空気《くうき》は｜和《なご》やかで｜楽《たの》しいものだった。
