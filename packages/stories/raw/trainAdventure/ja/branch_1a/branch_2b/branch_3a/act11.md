# 第十一幕：旅立ちの疑念

**ナレーション**：｜時間《じかん》は、この｜濃霧《のうむ》に｜閉《と》ざされた｜森《もり》の｜中《なか》で｜意味《いみ》を｜失《うしな》っていた。

**ナレーション**：｜二人《ふたり》はこの｜小屋《こや》にとどまった。｜美咲《みさき》には｜療養《りょうよう》が｜必要《ひつよう》で、｜外《そと》の｜濃霧《のうむ》と｜未知《みち》の｜危険《きけん》のせいで、しばらくは｜軽々《かるがる》しく｜動《うご》けなかった。

**ナレーション**：｜李杰《りけつ》は「｜森《もり》の｜傷病者手当《しょうびょうしゃてあ》ての｜手引《てび》き」を｜丹念《たんねん》に｜読《よ》み｜込《こ》み、｜森《もり》で｜特定《とくてい》の｜薬草《やくそう》を｜採取《さいしゅ》すれば｜傷《きず》の｜治《なお》りを｜早《はや》められると｜書《か》いてあるのを｜見《み》つけた。

**ナレーション**：｜淡《あわ》い｜青《あお》の｜光《ひかり》を｜放《はな》つエルフの｜苔《こけ》は、｜湿《しめ》った｜岩《いわ》の｜隙間《すきま》に｜生《は》えている。それに、｜古木《こぼく》の｜根《ね》もとに｜生《は》える｜銀葉草《ぎんようそう》は、｜葉《は》が｜蝉《せみ》の｜羽《はね》のように｜薄《うす》く、｜銀白色《ぎんはくしょく》の｜艶《つや》を｜帯《お》びていた。

**高橋美咲**：（｜壁《かべ》に｜手《て》をついて、｜足《あし》を｜引《ひ》きずりながら｜数歩《すうほ》｜歩《ある》き、｜驚《おどろ》きと｜喜《よろこ》びを｜浮《う》かべて）わ、あたし……｜歩《ある》けるみたい……｜本当《ほんとう》に、｜歩《ある》ける！

**李杰**：（やさしく）｜無理《むり》するなよ。｜傷口《きずぐち》はふさがったが、｜筋肉《きんにく》が｜戻《もど》るにはまだ｜時間《じかん》がかかる。あと｜数日《すうじつ》｜休《やす》んで、｜完全《かんぜん》に｜歩《ある》けるようになってからだ。

**ナレーション**：こうして｜三人《さんにん》は、この｜世《よ》から｜隔絶《かくぜつ》された｜小屋《こや》で、｜何週間《なんしゅうかん》か｜何《なん》か｜月《げつ》か｜分《わ》からない｜時間《じかん》を｜過《す》ごした。

**高橋美咲**：（｜腕《うで》や｜脚《あし》を｜動《うご》かして、ストレッチをしながら、｜肩《かた》の｜荷《に》が｜下《お》りたような｜笑《え》みで）やっと｜治《なお》った……｜本当《ほんとう》に、｜完全《かんぜん》に｜治《なお》った！
