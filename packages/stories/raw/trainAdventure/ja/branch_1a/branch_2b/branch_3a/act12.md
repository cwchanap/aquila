# 第十二幕：森の奥の目的地

**ナレーション**：｜三人《さんにん》は｜濃霧《のうむ》の｜中《なか》を｜進《すす》んだ。｜足《あし》もとの｜小径《こみち》は、はっきり｜見《み》えるときもあれば、｜落《お》ち｜葉《ば》や｜苔《こけ》に｜隠《かく》れてしまうときもある。

**ナレーション**：｜李杰《りけつ》は｜先頭《せんとう》を｜歩《ある》き、｜数歩《すうほ》ごとに｜振《ふ》り｜返《かえ》って、｜二人《ふたり》がついてきているか｜確《たし》かめた。｜霧《きり》は｜彼《かれ》らのまわりをゆっくりと｜流《なが》れ、まるで｜生《い》き｜物《もの》のように｜木《き》の｜幹《みき》へ｜絡《から》みついている。

**ナレーション**：｜周囲《しゅうい》の｜古木《こぼく》は｜雲《くも》を｜突《つ》くほど｜高《たか》くそびえ、ごつごつした｜樹皮《じゅひ》は｜深緑《しんりょく》の｜苔《こけ》にびっしりと｜覆《おお》われている。｜枝葉《えだは》は｜頭上《ずじょう》で｜編《あ》み｜合《あ》わさり、｜光《ひかり》を｜通《とお》さない｜天幕《てんまく》となって、｜紫《むらさき》の｜月光《げっこう》がわずかな｜隙間《すきま》からこぼれ｜落《お》ちるだけだった。

**ナレーション**：｜森《もり》の｜奥《おく》から、｜正体《しょうたい》の｜分《わ》からない｜鳥《とり》の｜鳴《な》き｜声《ごえ》が｜聞《き》こえてくる。｜鋭《するど》く、｜長《なが》く｜尾《お》を｜引《ひ》く｜声《こえ》だ。ときおり｜遠《とお》くで｜枝《えだ》の｜折《お》れる｜音《おと》がして、どれほど｜離《はな》れているのか｜見当《けんとう》がつかない。

**ナレーション**：｜李杰《りけつ》は、｜恵美《えみ》の｜足取《あしど》りがいつもより｜速《はや》いことに｜気《き》づいた。｜以前《いぜん》のようにおどおどと｜彼《かれ》の｜後《うし》ろにぴったりついてくるのではなく、ほとんど｜彼《かれ》の｜隣《となり》まで｜並《なら》んでいる。

**ナレーション**：｜恵美《えみ》の｜視線《しせん》は、ときおり｜前方《ぜんぽう》へ｜向《む》けられた。｜何《なに》かを｜探《さが》しているようでもあり、｜何《なに》かを｜確《たし》かめているようでもあった。

**李杰**：（｜心《こころ》の｜声《こえ》）｜清水《しみず》さん、｜最近本当《さいきんほんとう》にいつもと｜違《ちが》うな……

**李杰**：（｜心《こころ》の｜声《こえ》）なんだか……｜切羽詰《せっぱつ》まっているみたいだ。｜早《はや》くどこかへたどり｜着《つ》きたくて、たまらないような。

**ナレーション**：この｜疑問《ぎもん》は｜李杰《りけつ》の｜胸《むね》の｜中《なか》で｜渦《うず》を｜巻《ま》いたが、｜彼《かれ》はすぐにそれを｜押《お》し｜込《こ》めた。

**李杰**：（｜心《こころ》の｜声《こえ》）まあいい、｜考《かんが》えすぎかもしれない。｜山本《やまもと》さんたちのことが｜心配《しんぱい》なだけだろう。なにしろ、もうこんなに｜長《なが》く｜離《はな》ればなれなんだ。

**高橋美咲**：（｜後《うし》ろから｜追《お》いついてきて）ねえ、｜李杰《りけつ》さんって、｜普段《ふだん》どんなアニメ｜見《み》るの？

**李杰**：（｜少《すこ》し｜意外《いがい》そうに、｜振《ふ》り｜返《かえ》って）ん？　｜君《きみ》もアニメが｜好《す》きなのか？

**高橋美咲**：（｜笑《わら》ってうなずき）もちろん！　｜大好《だいす》き！　とくに｜音楽《おんがく》もののアニメ！

**ナレーション**：｜美咲《みさき》の｜声《こえ》は｜静《しず》かな｜森《もり》の｜中《なか》でひときわ｜明《あか》るく｜響《ひび》き、あたりの｜重苦《おもくる》しい｜空気《くうき》をしばし｜追《お》い｜払《はら》った。

**李杰**：｜音楽《おんがく》もの？

**高橋美咲**：そうそう！　あたし、｜東京《とうきょう》｜音楽大学《おんがくだいがく》でギターを｜習《なら》ってるの。｜普段《ふだん》は｜友達《ともだち》とバンドも｜組《く》んでて。

**高橋美咲**：｜週末《しゅうまつ》はライブハウスで｜演奏《えんそう》してるんだ。お｜金《かね》にはならないけど、めちゃくちゃ｜楽《たの》しいの！

**李杰**：（｜微笑《ほほえ》んで）｜面白《おもしろ》そうだな。｜俺《おれ》は｜普段《ふだん》、SFとミステリーのほうが｜好《す》きだ。

**高橋美咲**：おおっ！　じゃあ『シュタインズ・ゲート』は｜絶対《ぜったい》｜見《み》てるよね？　あれは｜超名作《ちょうめいさく》だもん！

**李杰**：もちろん｜見《み》たよ。しかも｜一回《いっかい》じゃなくてな。

**ナレーション**：｜二人《ふたり》は｜話《はな》すほどに｜盛《も》り｜上《あ》がり、アニメからゲーム、｜音楽《おんがく》から｜東京《とうきょう》での｜暮《く》らしへと｜話題《わだい》が｜移《うつ》っていった。

**ナレーション**：｜美咲《みさき》は、さすが｜話好《はなしず》きな｜女《おんな》の｜子《こ》で、すっかり｜元気《げんき》を｜取《と》り｜戻《もど》していた。｜最初《さいしょ》の、｜話《はな》すことさえできないほど｜弱《よわ》っていた｜姿《すがた》とは、まるで｜別人《べつじん》だ。

**高橋美咲**：そうだそうだ、｜渋谷《しぶや》に｜新《あたら》しくできたアニメグッズの｜店《みせ》、｜知《し》ってる？　めっちゃ｜大《おお》きいんだよ！

**李杰**：（｜苦笑《くしょう》して）｜渋谷《しぶや》にはあまり｜行《い》かないな……｜普段《ふだん》は｜会社《かいしゃ》で｜遅《おそ》くまで｜残業《ざんぎょう》してるし。

**高橋美咲**：えーっ、｜大変《たいへん》すぎない？　じゃあ、どこで｜息抜《いきぬ》きするの？

**李杰**：どうしてもって｜言《い》うなら……｜秋葉原《あきはばら》のほうが｜多《おお》いかな。｜週末《しゅうまつ》に｜時間《じかん》があったら、あっちのゲームセンターに｜行《い》くんだ。

**高橋美咲**：おおっ！　｜秋葉原《あきはばら》かあ！　じゃあメイドカフェは｜行《い》ったことある？

**李杰**：（｜少《すこ》し｜照《て》れて）たまに……｜行《い》く。

**高橋美咲**：（｜笑《わら》って）｜恥《は》ずかしがることないって！　あたしも｜何回《なんかい》か｜行《い》ったことあるよ！　｜雰囲気《ふんいき》、けっこう｜面白《おもしろ》いし！

**高橋美咲**：｜帰《かえ》ったら、｜渋谷《しぶや》と｜原宿《はらじゅく》を｜案内《あんない》してあげる！　｜李杰《りけつ》さんは、｜秋葉原《あきはばら》のおすすめのゲームセンターに｜連《つ》れてって！

**ナレーション**：｜美咲《みさき》は「｜帰《かえ》ったら」と｜言《い》いながら、ふいに｜声《こえ》を｜詰《つ》まらせた。

**ナレーション**：だがすぐに｜気持《きも》ちを｜立《た》て｜直《なお》し、｜東京《とうきょう》のいろんな｜楽《たの》しい｜場所《ばしょ》について｜話《はな》し｜続《つづ》けた。まるで｜言葉《ことば》で、｜防護《ぼうご》の｜壁《かべ》を｜築《きず》こうとするかのように。

**ナレーション**：｜恵美《えみ》はずっと｜静《しず》かに｜隣《となり》を｜歩《ある》き、ときどき｜相《あい》づちを｜打《う》つだけで、ほとんどの｜間《あいだ》、｜黙《だま》っていた。

**ナレーション**：｜彼女《かのじょ》の｜視線《しせん》はつねに｜前方《ぜんぽう》に｜注《そそ》がれ、｜自分《じぶん》にしか｜見《み》えない｜道《みち》しるべを｜追《お》っているかのように、ひたむきだった。

**ナレーション**：そうして｜彼《かれ》らは、｜何時間《なんじかん》も｜歩《ある》いた。｜足《あし》もとの｜小径《こみち》は｜土《つち》から｜砂利《じゃり》に｜変《か》わり、やがて｜整《ととの》った｜石畳《いしだたみ》へと｜変《か》わった。

**ナレーション**：｜周囲《しゅうい》の｜木々《きぎ》はしだいにまばらになり、｜古《ふる》い｜巨木《きょぼく》は、｜背《せ》の｜低《ひく》い｜灌木《かんぼく》に｜取《と》って｜代《か》わられていった。

**ナレーション**：いちばん｜目立《めだ》つ｜変化《へんか》は――｜霧《きり》が｜薄《うす》くなり｜始《はじ》めたことだ。

**ナレーション**：さっきまで｜伸《の》ばした｜手《て》の｜先《さき》も｜見《み》えないほど｜濃《こ》かった｜白《しろ》い｜霧《きり》が、いまは｜見《み》えない｜力《ちから》に｜払《はら》われたかのように｜晴《は》れ、｜視界《しかい》がしだいにはっきりしてきた。

**李杰**：｜前《まえ》のほう……｜何《なに》かあるみたいだ。

**ナレーション**：｜霧《きり》が｜消《き》えるにつれ、｜前方《ぜんぽう》に、いくつかの｜建物《たてもの》の｜輪郭《りんかく》が｜浮《う》かび｜上《あ》がってきた。

**高橋美咲**：（｜驚《おどろ》いて）……｜村《むら》？

**ナレーション**：｜三人《さんにん》は｜足《あし》を｜止《と》めた。｜紫《むらさき》の｜月光《げっこう》がようやくはっきりと｜彼《かれ》らを｜照《て》らし、｜前方《ぜんぽう》にぼんやり｜見《み》える｜集落《しゅうらく》も｜照《て》らし｜出《だ》す。

**ナレーション**：｜李杰《りけつ》は、｜隣《となり》の｜恵美《えみ》が｜突然《とつぜん》こぶしを｜握《にぎ》りしめたのを｜感《かん》じた。｜呼吸《こきゅう》が｜荒《あら》くなり、｜胸《むね》が｜大《おお》きく｜上下《じょうげ》している。

**ナレーション**：｜恵美《えみ》の｜目《め》に、｜複雑《ふくざつ》な｜感情《かんじょう》がよぎった――｜恐《おそ》れでも、｜驚《おどろ》きでもない。｜何《なに》か……｜期待《きたい》？　それとも……｜安堵《あんど》？

**清水恵美**：（｜聞《き》き｜取《と》れないほど｜小《ちい》さな｜声《こえ》で、｜独《ひと》り｜言《ごと》のように）やっと……｜着《つ》いた……

**李杰**：（｜振《ふ》り｜向《む》いて）いま、｜何《なん》て｜言《い》った？

**清水恵美**：（はっと｜我《われ》に｜返《かえ》り、｜目《め》にいつもの｜怯《おび》えが｜戻《もど》って、｜首《くび》を｜振《ふ》る）な……なんでも……ないです……

**ナレーション**：｜薄霧《うすきり》が｜彼《かれ》らの｜前《まえ》をゆっくりと｜流《なが》れる。まるで、｜幕《まく》を｜開《あ》ける｜序曲《じょきょく》のように。

**ナレーション**：｜前方《ぜんぽう》の｜村《むら》は｜霧《きり》の｜中《なか》にぼんやりと｜見《み》え｜隠《かく》れし、｜紫《むらさき》の｜月《つき》の｜下《した》、｜建物《たてもの》の｜輪郭《りんかく》はおぼろげで｜神秘的《しんぴてき》だった。

**ナレーション**：そして、その｜朦朧《もうろう》とした｜霧《きり》の｜向《む》こうで、｜何《なに》かが｜彼《かれ》らを｜待《ま》っているような｜気《き》がした……
