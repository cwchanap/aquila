# 第十三幕：焼き払われた真相

**ナレーション**：｜濃霧《のうむ》がしだいに｜晴《は》れ、｜目《め》の｜前《まえ》の｜光景《こうけい》が、ようやく｜三人《さんにん》の｜前《まえ》にすっかり｜姿《すがた》を｜現《あらわ》した。

**ナレーション**：それは｜確《たし》かに｜村《むら》だった。だが、｜徹底的《てっていてき》に｜破壊《はかい》された｜村《むら》だった。

**ナレーション**：｜焦《こ》げた｜炭《すみ》の｜匂《にお》いが｜鼻《はな》を｜突《つ》き、そこに｜何《なん》ともいえない｜腐臭《ふしゅう》が｜混《ま》じっている。｜空中《くうちゅう》には｜細《こま》かな｜灰《はい》が｜漂《ただよ》い、｜紫《むらさき》の｜月光《げっこう》の｜下《した》で｜黒《くろ》い｜雪片《せっぺん》のようだった。

**ナレーション**：ほとんどの｜建物《たてもの》は｜焼《や》けて｜灰《はい》となり、｜焦《こ》げた｜梁《はり》が｜斜《なな》めに｜地面《じめん》へ｜突《つ》き｜刺《さ》さっているだけだった。｜壁《かべ》は｜崩《くず》れ、｜破片《はへん》となって｜一面《いちめん》に｜散《ち》らばっている。

**ナレーション**：これらの｜建物《たてもの》は、もとはきっと｜繊細《せんさい》な｜造《つく》りだったのだろう――｜残《のこ》った｜彫刻入《ちょうこくい》りの｜窓枠《まどわく》や、｜弧《こ》を｜描《えが》く｜屋根《やね》の｜輪郭《りんかく》から、｜優美《ゆうび》な｜曲線《きょくせん》と｜細《こま》やかな｜装飾《そうしょく》があったことが｜見《み》て｜取《と》れる。だがいまは、すべてが｜炭《すみ》になっていた。

**ナレーション**：｜石畳《いしだたみ》には｜焼《や》け｜焦《こ》げた｜痕《あと》が｜一面《いちめん》に｜残《のこ》り、｜高熱《こうねつ》で｜石《いし》が｜割《わ》れて、｜下《した》の｜黒《くろ》い｜土《つち》がのぞいている｜場所《ばしょ》さえある。｜砕《くだ》けた｜瓦《かわら》や、ひしゃげた｜金属《きんぞく》の｜道具《どうぐ》が、あちこちに｜散《ち》らばっていた。

**ナレーション**：｜数棟《すうとう》の｜家《いえ》は、まだ｜形《かたち》を｜保《たも》っているように｜見《み》えた。｜外壁《がいへき》は｜煤《すす》で｜黒《くろ》ずんでいるが、｜構造《こうぞう》は｜残《のこ》っている。｜戸《と》も｜窓《まど》も｜開《あ》け｜放《はな》たれ、｜中《なか》には｜誰《だれ》もいない。｜風《かぜ》が｜吹《ふ》くたび、｜壊《こわ》れた｜戸板《といた》が｜戸枠《とわく》にぶつかって、｜低《ひく》いすすり｜泣《な》きのような｜音《おと》を｜立《た》てた。

**ナレーション**：さらに｜背筋《せすじ》の｜凍《こお》ることに、｜村《むら》のあちこちに、ぽつぽつと｜遺体《いたい》が｜転《ころ》がっていた。｜数《かず》は｜多《おお》くないが、｜一体一体《いったいいったい》が｜胸《むね》に｜重《おも》くのしかかる。

**ナレーション**：それらはみなエルフだった――｜尖《とが》った｜耳《みみ》と、すらりとした｜体《からだ》つきで｜分《わ》かる。だが、みな｜年老《としお》いており、｜肌《はだ》は｜生気《せいき》の｜艶《つや》を｜失《うしな》って｜灰白色《かいはくしょく》になり、｜枯《か》れた｜花《はな》びらのようだった。

**ナレーション**：｜一体《いったい》は｜家《いえ》の｜残骸《ざんがい》の｜中《なか》に｜倒《たお》れ、｜焼《や》け｜焦《こ》げた｜梁《はり》の｜下敷《したじ》きになっている。ほかの｜数体《すうたい》は｜通《とお》りに｜倒《たお》れ、｜腕《うで》をある｜方向《ほうこう》へ｜伸《の》ばしたまま、｜逃《に》げる｜途中《とちゅう》で｜力《ちから》｜尽《つ》きたかのようだった。

**ナレーション**：｜年老《としお》いたエルフたちは、こうして｜静《しず》かに｜廃墟《はいきょ》の｜中《なか》に｜横《よこ》たわり、｜永遠《えいえん》に｜眠《ねむ》りについていた。

**高橋美咲**：（｜失望《しつぼう》した｜声《こえ》で）なんだ……ただの｜廃墟《はいきょ》か……

**高橋美咲**：｜人《ひと》がいるかと｜思《おも》ったのに……｜食《た》べ｜物《もの》とか｜水《みず》とか、あるかなって……

**ナレーション**：｜美咲《みさき》の｜口調《くちょう》には｜少《すこ》し｜残念《ざんねん》そうな｜響《ひび》きがあったが、｜感情《かんじょう》の｜揺《ゆ》れはさほど｜大《おお》きくなかった。｜彼女《かのじょ》はあたりを｜見回《みまわ》し、ここに｜使《つか》えるものがあるか｜見積《みつ》もっているようだった。

**ナレーション**：そのとき、ずっとそばに｜立《た》っていた｜恵美《えみ》の｜足《あし》が、ふいによろめいた。

**清水恵美**：（｜声《こえ》を｜震《ふる》わせて）どうして……

**李杰**：（｜振《ふ》り｜向《む》いて）｜清水《しみず》さん？

**ナレーション**：｜恵美《えみ》の｜顔《かお》は｜蒼白《そうはく》になり、｜両手《りょうて》をぎゅっと｜握《にぎ》りしめている。｜視線《しせん》は｜廃墟《はいきょ》のあいだをさまよい、｜何《なに》かを｜探《さが》しているようでもあり、｜目《め》の｜前《まえ》の｜光景《こうけい》が｜信《しん》じられないようでもあった。

**清水恵美**：（｜声《こえ》を｜詰《つ》まらせ、｜目《め》を｜赤《あか》くして）どうして……どうして、こんなことに……

**ナレーション**：｜彼女《かのじょ》の｜体《からだ》はかすかに｜震《ふる》え、｜呼吸《こきゅう》は｜荒《あら》くなっていた。｜涙《なみだ》が｜目《め》に｜溜《た》まっているが、こぼすまいと｜懸命《けんめい》にこらえている。

**清水恵美**：（つぶやくように）わたし、｜確《たし》かに……｜確《たし》かに……

**ナレーション**：｜恵美《えみ》の｜声《こえ》はどんどん｜小《ちい》さくなっていったが、それでも｜李杰《りけつ》は、｜彼女《かのじょ》の｜次《つぎ》の｜言葉《ことば》を｜聞《き》き｜取《と》った。

**清水恵美**：（いまにも｜泣《な》き｜出《だ》しそうな｜声《こえ》で）どうやって｜翔《しょう》くんを｜助《たす》ければ……どうやったら、あの｜人《ひと》を……

**高橋美咲**：（｜気遣《きづか》って｜歩《あゆ》み｜寄《よ》り）｜恵美《えみ》？　｜大丈夫《だいじょうぶ》？

**ナレーション**：｜恵美《えみ》ははっと｜我《われ》に｜返《かえ》り、｜手《て》の｜甲《こう》で｜目《め》をぬぐった。｜深《ふか》く｜息《いき》を｜吸《す》い、｜気持《きも》ちを｜落《お》ち｜着《つ》かせようとする。

**清水恵美**：（｜声《こえ》はまだ｜震《ふる》えて）わ、わたしは｜大丈夫《だいじょうぶ》です……ただ……ここが……

**高橋美咲**：（そっと｜肩《かた》をたたいて）｜分《わ》かるよ……この｜光景《こうけい》、｜本当《ほんとう》に｜怖《こわ》いもんね……

**ナレーション**：だが｜美咲《みさき》の｜慰《なぐさ》めは、｜恵美《えみ》の｜本当《ほんとう》の｜苦《くる》しみにはまったく｜届《とど》いていなかった。｜恵美《えみ》はうなずき、まぶたを｜伏《ふ》せて、もう｜何《なに》も｜言《い》わなかった。

**李杰**：（｜心《こころ》の｜声《こえ》）｜翔《しょう》くん？　｜誰《だれ》のことだ？

**ナレーション**：｜李杰《りけつ》はその｜場《ば》に｜立《た》ち｜尽《つ》くしていた。｜焼《や》き｜払《はら》われた｜村《むら》はたしかに｜衝撃的《しょうげきてき》だが、それ｜以上《いじょう》に｜彼《かれ》の｜心《こころ》を｜引《ひ》いたのは、いまの｜恵美《えみ》の｜反応《はんのう》だった。

**李杰**：（｜心《こころ》の｜声《こえ》）｜彼女《かのじょ》は、この｜場所《ばしょ》を｜明《あき》らかに｜知《し》っている。ここの｜人《ひと》たちのことも｜知《し》っているんだ。

**ナレーション**：｜李杰《りけつ》は、ここまでの｜道《みち》のりでの｜恵美《えみ》の｜数々《かずかず》の｜異変《いへん》を｜思《おも》い｜返《かえ》した――｜森《もり》の｜中心《ちゅうしん》へ｜行《い》くと｜言《い》い｜張《は》ったこと、｜方向《ほうこう》への｜確信《かくしん》、｜道中《どうちゅう》ずっとの｜切迫《せっぱく》した｜様子《ようす》……

**李杰**：（｜心《こころ》の｜声《こえ》）｜彼女《かのじょ》は｜最初《さいしょ》から、｜俺《おれ》たちがここへ｜来《く》ることを｜知《し》っていたんだ。ずっと｜何《なに》かを｜隠《かく》している。

**ナレーション**：｜無数《むすう》の｜疑問《ぎもん》が、｜李杰《りけつ》の｜胸《むね》の｜中《なか》で｜渦《うず》を｜巻《ま》いた。｜恵美《えみ》はいったい｜何者《なにもの》なのか。このエルフの｜村《むら》とどんな｜関係《かんけい》があるのか。｜翔《しょう》という｜人《ひと》は、｜誰《だれ》なのか。

**ナレーション**：｜李杰《りけつ》は｜恵美《えみ》に｜目《め》を｜向《む》けた。｜彼女《かのじょ》は｜彼《かれ》に｜背《せ》を｜向《む》け、｜肩《かた》をかすかに｜震《ふる》わせていて、ひどく｜脆《もろ》く｜見《み》えた。

**李杰**：（｜心《こころ》の｜声《こえ》）いまはそのときじゃない……｜彼女《かのじょ》の｜様子《ようす》では……

**ナレーション**：｜李杰《りけつ》は｜深《ふか》く｜息《いき》を｜吸《す》い、｜胸《むね》の｜疑問《ぎもん》を｜押《お》し｜込《こ》めた。｜彼《かれ》は｜黙《だま》っていることにした――｜少《すく》なくとも、いまは。

**李杰**：（｜低《ひく》い｜声《こえ》で）まず、｜周囲《しゅうい》に｜生存者《せいぞんしゃ》がいないか｜見《み》てみよう。｜気《き》をつけて、｜安全《あんぜん》に｜注意《ちゅうい》するんだ。

**高橋美咲**：うん……わたし、あっち｜見《み》てくる。

**ナレーション**：｜美咲《みさき》は、｜右側《みぎがわ》の｜比較的無事《ひかくてきぶじ》な｜数棟《すうとう》の｜家《いえ》へ｜歩《ある》いていった。｜恵美《えみ》はその｜場《ば》に｜立《た》ったまま｜動《うご》かず、ただ｜目《め》の｜前《まえ》の｜廃墟《はいきょ》を｜見《み》つめている。

**ナレーション**：｜焼《や》け｜落《お》ちた｜村《むら》は、｜薄霧《うすきり》の｜中《なか》でいっそう｜寂《さび》しげに｜見《み》えた。｜三人《さんにん》はそれぞれの｜思《おも》いを｜抱《かか》え、｜倒《たお》れた｜家々《いえいえ》と｜焦《こ》げた｜遺体《いたい》のあいだには、まだ｜知《し》られざる｜秘密《ひみつ》が｜隠《かく》れていて、｜暴《あば》かれるのを｜待《ま》っているようだった。
