# 第十四幕：再会と隔たり

**ナレーション**：｜十分《じゅっぷん》ほどたつと、｜恵美《えみ》の｜気持《きも》ちはしだいに｜落《お》ち｜着《つ》いてきた。

**ナレーション**：｜目《め》は｜赤《あか》く｜腫《は》れ、まつげにはまだ｜涙《なみだ》の｜粒《つぶ》が｜残《のこ》り、｜頬《ほお》にはくっきりと｜涙《なみだ》の｜跡《あと》がある。｜彼女《かのじょ》は｜手《て》の｜甲《こう》で｜顔《かお》をぬぐい、｜深呼吸《しんこきゅう》をして、｜懸命《けんめい》に｜自分《じぶん》を｜落《お》ち｜着《つ》かせようとした。

**高橋美咲**：（やさしく｜腕《うで》を｜支《ささ》えて）ほら、｜恵美《えみ》、まず｜立《た》とう。

**ナレーション**：｜美咲《みさき》は｜恵美《えみ》をそっと｜立《た》たせた。｜恵美《えみ》の｜足《あし》はまだ｜少《すこ》しふらつき、｜美咲《みさき》の｜肩《かた》にもたれて、やっと｜立《た》っていられるほどだった。

**高橋美咲**：（｜背中《せなか》をぽんぽんとたたいて）｜恵美《えみ》、あんまり｜悲《かな》しまないで。あたしたち……きっと｜何《なに》か｜方法《ほうほう》を｜見《み》つけるから。

**高橋美咲**：｜何《なに》があったとしても、みんなで｜一緒《いっしょ》に｜立《た》ち｜向《む》かおう？　ね？

**清水恵美**：（かすれた｜声《こえ》で）ありがとう……｜美咲《みさき》……

**ナレーション**：｜恵美《えみ》の｜声《こえ》は｜疲《つか》れ｜果《は》てて｜遠《とお》く、｜分厚《ぶあつ》いガラス｜越《ご》しに｜聞《き》こえるようだった。

**ナレーション**：｜彼女《かのじょ》はそれ｜以上《いじょう》｜何《なに》も｜言《い》わず、ただ｜静《しず》かにそこに｜立《た》って、｜目《め》の｜前《まえ》の｜焼《や》け｜焦《こ》げた｜廃墟《はいきょ》をぼんやりと｜見《み》つめている。｜魂《たましい》がまだ、どこか｜遠《とお》い｜悲《かな》しみに｜沈《しず》んでいるかのようだった。

**ナレーション**：｜焦《こ》げた｜炭《すみ》の｜匂《にお》いは｜相変《あいか》わらず｜濃《こ》く、｜風《かぜ》が｜吹《ふ》くたび、｜灰《はい》が｜空中《くうちゅう》に｜舞《ま》った。｜遠《とお》くで｜壊《こわ》れた｜木《き》の｜扉《とびら》がきいきいと｜音《おと》を｜立《た》て、｜死《し》んだように｜静《しず》まり｜返《かえ》った｜村《むら》にこだました。

**ナレーション**：｜李杰《りけつ》はそばでそのすべてを｜見《み》ながら、｜迷《まよ》っていた。

**李杰**：（｜心《こころ》の｜声《こえ》）｜訊《き》くべきか？　いま｜訊《き》いたら、｜残酷《ざんこく》すぎないか？

**李杰**：（｜心《こころ》の｜声《こえ》）だが……はっきりさせなければ、これからどうすればいいのかも｜分《わ》からない。それに……｜彼女《かのじょ》は｜明《あき》らかに｜何《なに》か｜知《し》っている。

**ナレーション**：｜李杰《りけつ》は｜深《ふか》く｜息《いき》を｜吸《す》い、｜口《くち》を｜開《ひら》くことにした。ただし、｜遠回《とおまわ》しな｜訊《き》き｜方《かた》を｜選《えら》んだ。

**李杰**：（できるだけ｜穏《おだ》やかな｜口調《くちょう》で）｜清水《しみず》さん……｜君《きみ》は、｜前《まえ》にここへ｜来《き》たことがあるのか？

**ナレーション**：｜恵美《えみ》の｜体《からだ》がかすかに｜震《ふる》えた。｜冷《つめ》たい｜水《みず》をかけられたかのように。

**ナレーション**：｜彼女《かのじょ》はゆっくりと｜振《ふ》り｜向《む》き、｜赤《あか》く｜腫《は》れた｜目《め》で｜李杰《りけつ》を｜見《み》た。その｜眼差《まなざ》しには、｜驚《おどろ》きと、ためらいと、わずかな｜警戒《けいかい》があった。

**李杰**：ただ……｜君《きみ》の｜反応《はんのう》を｜見《み》て、｜君《きみ》がここに……｜深《ふか》い｜思《おも》い｜入《い》れがあるように｜見《み》えたから。

**李杰**：もし｜何《なに》か｜知《し》っているなら、いまの｜状況《じょうきょう》を｜理解《りかい》する｜助《たす》けになるかもしれない……

**ナレーション**：｜恵美《えみ》は｜長《なが》いあいだ｜黙《だま》っていた。｜視線《しせん》を｜李杰《りけつ》の｜顔《かお》からそらし、｜地面《じめん》の｜焦《こ》げた｜石畳《いしだたみ》に｜落《お》とす。

**ナレーション**：｜彼女《かのじょ》の｜指《ゆび》は、｜無意識《むいしき》のうちに｜握《にぎ》りしめられては｜緩《ゆる》められた。｜心《こころ》の｜中《なか》で、｜何《なに》かと｜葛藤《かっとう》しているかのように。

**ナレーション**：｜美咲《みさき》は｜空気《くうき》の｜変化《へんか》を｜察《さっ》し、｜口《くち》をつぐんで、ただ｜静《しず》かにそばに｜立《た》っていた。

**ナレーション**：やがて、｜恵美《えみ》は｜深《ふか》く｜息《いき》を｜吸《す》い、｜顔《かお》を｜上《あ》げた。その｜眼差《まなざ》しは｜穏《おだ》やかになっていたが、それは｜高《たか》い｜壁《かべ》を｜築《きず》いたあとの｜穏《おだ》やかさだった。

**清水恵美**：｜李《り》さん……｜時《とき》が｜来《き》たら、わたしの｜知《し》っていることを｜全部《ぜんぶ》お｜話《はな》しします。

**清水恵美**：でも、いまは……どうか、｜黙《だま》っていさせてください。

**ナレーション**：｜声《こえ》は｜静《しず》かだったが、｜疑《うたが》いを｜許《ゆる》さないきっぱりした｜強《つよ》さがあった。

**李杰**：（｜心《こころ》の｜声《こえ》）やはり、｜彼女《かのじょ》は｜何《なに》か｜知《し》っている……だが｜話《はな》すつもりはないんだ。

**ナレーション**：｜李杰《りけつ》は｜彼女《かのじょ》の｜目《め》を｜見《み》つめた。その｜瞳《ひとみ》にはもう、｜臆病《おくびょう》さと｜頼《たよ》りたい｜気持《きも》ちだけがあるのではなく、｜深《ふか》く、｜貫《つらぬ》きがたい｜隔《へだ》たりが｜一枚《いちまい》、｜加《くわ》わっていた。

**ナレーション**：かつておどおどと｜彼《かれ》の｜後《うし》ろをついてきた｜少女《しょうじょ》が、いまはまるで｜見知《みし》らぬ｜他人《たにん》になったかのようだった。

**李杰**：｜分《わ》かった。

**ナレーション**：｜李杰《りけつ》の｜口調《くちょう》は｜淡々《たんたん》としていたが、｜胸《むね》の｜中《なか》にはさまざまな｜感情《かんじょう》が｜湧《わ》き｜上《あ》がっていた。

**李杰**：（｜心《こころ》の｜声《こえ》）｜彼女《かのじょ》は｜隠《かく》している……しかも、とても｜重要《じゅうよう》なことを。

**李杰**：（｜心《こころ》の｜声《こえ》）｜目的《もくてき》が｜何《なん》なのかは｜分《わ》からないが、これからは、もっと｜用心《ようじん》しなければならない。

**ナレーション**：「｜不信《ふしん》」という｜名《な》の｜種《たね》が、｜李杰《りけつ》の｜胸《むね》の｜中《なか》で、ひっそりと｜芽吹《めぶ》いた。

**高橋美咲**：（｜空気《くうき》を｜和《やわ》らげようとするように、｜手《て》をぱん、と｜叩《たた》いて）はい、じゃあ！　せっかくここまで｜来《き》たんだし、あたりを｜見《み》て｜回《まわ》ろうよ！

**高橋美咲**：｜何《なに》か｜使《つか》えるものが｜見《み》つかるかもしれないし！

**ナレーション**：｜美咲《みさき》の｜口調《くちょう》は｜軽《かろ》やかで、まるで｜自分《じぶん》の｜楽観《らっかん》で、この｜廃墟《はいきょ》がもたらす｜陰《かげ》を｜振《ふ》り｜払《はら》おうとしているかのようだった。

**高橋美咲**：それに……ほかの｜人《ひと》たちの｜手《て》がかりも、｜見《み》つかるかもしれないよ？　｜拓海《たくみ》たちも……それに、｜山本《やまもと》さんも……

**ナレーション**：｜美咲《みさき》が｜言《い》い｜終《お》えた、まさにそのとき、｜遠《とお》くから｜突然《とつぜん》、｜聞《き》き｜覚《おぼ》えのある｜声《こえ》が｜響《ひび》いた。

**ナレーション**：｜濃霧《のうむ》の｜中《なか》、｜大柄《おおがら》な｜人影《ひとかげ》が、｜足早《あしばや》にこちらへ｜向《む》かってくる。｜足音《あしおと》は｜急《きゅう》で｜重《おも》く、｜砕《くだ》けた｜石《いし》を｜踏《ふ》んで｜乾《かわ》いた｜音《おと》を｜立《た》てた。

**李杰**：（｜驚《おどろ》いて）｜山本《やまもと》さん！？
