# 第十五幕：焼かれた村の謎

**山本浩二**：（｜美咲《みさき》に｜気《き》づいて、｜目《め》に｜驚《おどろ》きと｜喜《よろこ》びがよぎる）お｜前《まえ》さんは……あの｜怪我《けが》をしてたお｜嬢《じょう》ちゃんか！　よかった！　すっかり｜治《なお》ったみたいだな！

**高橋美咲**：（うなずいて、｜微笑《ほほえ》み）はい、｜李杰《りけつ》さんと｜恵美《えみ》が｜面倒《めんどう》を｜見《み》てくれたおかげです。

**李杰**：｜山本《やまもと》さん、こちらは｜高橋美咲《たかはしみさき》さんです。｜美咲《みさき》、こちらは｜山本浩二《やまもとこうじ》さんだ。

**山本浩二**：（｜手《て》を｜差《さ》し｜出《だ》し）｜山本浩二《やまもとこうじ》、｜建設作業員《けんせつさぎょういん》だ。｜無事《ぶじ》で｜何《なに》よりだ。

**高橋美咲**：（｜握手《あくしゅ》して）｜高橋美咲《たかはしみさき》です、｜音大生《おんだいせい》です。｜山本《やまもと》さん、お｜会《あ》いできて｜本当《ほんとう》によかったです！

**ナレーション**：｜短《みじか》い｜挨拶《あいさつ》のあと、｜李杰《りけつ》は｜待《ま》ちきれずに｜尋《たず》ねた。

**李杰**：｜山本《やまもと》さん、この｜間《あいだ》どこにいたんですか？　あの｜日《ひ》、あなたが｜影《かげ》を｜追《お》っていってから……

**山本浩二**：（ため｜息《いき》をつき、｜苦笑《にがわら》いを｜浮《う》かべて）｜話《はな》せば｜長《なが》くなるが……｜確《たし》かに、あの｜影《かげ》には｜追《お》いついたんだ。

**ナレーション**：｜山本浩二《やまもとこうじ》は｜崩《くず》れた｜石壁《いしかべ》を｜見《み》つけて｜腰《こし》を｜下《お》ろし、｜手《て》で｜顔《かお》の｜埃《ほこり》をぬぐった。

**ナレーション**：ほかの｜三人《さんにん》もそれぞれ｜腰《こし》を｜下《お》ろし、｜小《ちい》さな｜輪《わ》になった。｜廃墟《はいきょ》の｜風《かぜ》は｜相変《あいか》わらずうなりをあげ、｜焦《こ》げた｜炭《すみ》の｜匂《にお》いを｜運《はこ》んでくる。

**山本浩二**：あの｜影《かげ》はエルフだった。｜女《おんな》で、｜見《み》たところ、ずいぶん｜若《わか》かった。

**山本浩二**：｜武器《ぶき》は｜何《なに》も｜持《も》たず、ただ｜逃《に》げるばかりでな。｜俺《おれ》は｜捕《つか》まえて、いったいどういうことなのか｜聞《き》き｜出《だ》すつもりだった……

**李杰**：それで、どうなったんですか？

**山本浩二**：｜追《お》いつきかけたそのとき、いきなり｜横《よこ》から｜矢《や》が｜飛《と》んできて、｜俺《おれ》の｜脚《あし》めがけてまっすぐ｜来《き》やがった！

**高橋美咲**：（｜思《おも》わず｜声《こえ》を｜上《あ》げて）ええっ！

**山本浩二**：｜幸《さいわ》い｜反応《はんのう》が｜間《ま》に｜合《あ》って、｜身《み》をかわしたんだ。

**山本浩二**：だがかわしたその｜瞬間《しゅんかん》、｜別《べつ》のエルフが｜木《き》から｜飛《と》び｜降《お》りてきて、｜剣《けん》を｜手《て》に、そのまま｜俺《おれ》の｜首《くび》に｜突《つ》きつけた。

**ナレーション**：｜山本《やまもと》さんはそのときの｜様子《ようす》を｜身振《みぶ》りで｜示《しめ》し、｜首《くび》のあたりで｜手《て》を｜横《よこ》に｜引《ひ》く｜仕草《しぐさ》をした。｜顔《かお》にはまだ、｜少《すこ》し｜恐怖《きょうふ》の｜名残《なごり》があった。

**山本浩二**：｜捕《つか》まえるつもりが、｜逆《ぎゃく》に｜捕《つか》まっちまったよ。

**山本浩二**：その｜二人《ふたり》のエルフ――｜一人《ひとり》は｜弓《ゆみ》、｜一人《ひとり》は｜剣《けん》だ――そいつらに｜引《ひ》っ｜立《た》てられて、この｜村《むら》まで｜連《つ》れてこられた。

**李杰**：｜彼《かれ》らが｜山本《やまもと》さんをここへ｜連《つ》れてきたんですか？

**山本浩二**：（うなずき）ああ。そのときは、ここもまだ｜無事《ぶじ》で、｜焼《や》けてなどいなかった。

**山本浩二**：｜家《いえ》は｜無傷《むきず》で、｜通《とお》りはきれいで、｜村人《むらびと》もみんないた……どこにも｜暮《く》らしの｜気配《けはい》があった。

**清水恵美**：（ふいに｜顔《かお》を｜上《あ》げ、｜目《め》に｜切迫《せっぱく》した｜色《いろ》を｜浮《う》かべて）そのとき……｜村《むら》には、｜何人《なんにん》くらいいましたか？

**ナレーション**：｜恵美《えみ》の｜声《こえ》は｜少《すこ》し｜震《ふる》え、｜両手《りょうて》が｜無意識《むいしき》に｜握《にぎ》りしめられていた。｜李杰《りけつ》は｜彼女《かのじょ》の｜異変《いへん》に｜気《き》づいたが、｜何《なに》も｜言《い》わなかった。

**山本浩二**：（｜思《おも》い｜出《だ》しながら）けっこういたぞ、｜五十人《ごじゅうにん》ちょっとかな。

**山本浩二**：ほとんどは｜若者《わかもの》と｜中年《ちゅうねん》だったが、｜年寄《としよ》りや｜子《こ》どもも｜何人《なんにん》かいた。

**ナレーション**：｜恵美《えみ》はその｜言葉《ことば》を｜聞《き》いて、｜目《め》に｜複雑《ふくざつ》な｜感情《かんじょう》がよぎったが、すぐにまたうつむいた。

**李杰**：｜彼《かれ》らは｜山本《やまもと》さんに｜何《なに》をしたんですか？

**山本浩二**：｜道中《どうちゅう》ずっと、あの｜三人《さんにん》のエルフ――｜武器《ぶき》を｜持《も》ってなかった｜娘《むすめ》と、｜俺《おれ》を｜捕《つか》まえた｜二人《ふたり》な――が、｜俺《おれ》に｜話《はな》しかけ｜続《つづ》けてた。

**山本浩二**：｜何《なに》か｜質問《しつもん》してるんだろうとは｜分《わ》かったが、｜言葉《ことば》がまったく｜分《わ》からなくてな。

**山本浩二**：｜日本語《にほんご》も｜英語《えいご》も｜試《ため》したし、｜身振《みぶ》り｜手振《てぶ》りまでやったが、｜向《む》こうにも｜通《つう》じなかった。

**高橋美咲**：じゃあ、まったく｜意思《いし》の｜疎通《そつう》ができなかったんですか？

**山本浩二**：ああ。｜最後《さいご》には、｜向《む》こうも｜諦《あきら》めたみたいだった。

**山本浩二**：｜武器《ぶき》を｜持《も》った｜二人《ふたり》のエルフは、｜俺《おれ》を｜小《ちい》さな｜家《いえ》に｜閉《と》じ｜込《こ》めた――｜牢屋《ろうや》ってことなんだろうな。

**山本浩二**：｜木《き》の｜扉《とびら》に｜鉄格子《てつごうし》の｜窓《まど》、｜粗末《そまつ》なもんだが、｜俺《おれ》を｜閉《と》じ｜込《こ》めるには｜十分《じゅうぶん》だった。

**李杰**：｜虐待《ぎゃくたい》は、されませんでしたか？

**山本浩二**：（｜首《くび》を｜振《ふ》り）いや。｜閉《と》じ｜込《こ》められはしたが、｜数時間《すうじかん》おきに｜食《た》べ｜物《もの》と｜水《みず》を｜持《も》ってきてくれた。

**山本浩二**：パンに｜果物《くだもの》に、きれいな｜水《みず》……どれも｜清潔《せいけつ》だった。｜傷《きず》つける｜気《き》はないようで、ただ……｜俺《おれ》をどうしていいか｜分《わ》からなかったんだろう。

**ナレーション**：｜山本《やまもと》さんは｜言葉《ことば》を｜切《き》った。｜目《め》が｜翳《かげ》り、｜表情《ひょうじょう》も｜重《おも》くなる。

**山本浩二**：｜俺《おれ》はその｜牢屋《ろうや》に｜丸一日《まるいちにち》いた……いや、｜一日《いちにち》だと｜思《おも》ってただけかもしれんがな。

**山本浩二**：ここには｜太陽《たいよう》がなくて、｜時間《じかん》も｜分《わ》からん。とにかく、｜寝《ね》て｜起《お》きたら、｜突然《とつぜん》、｜外《そと》から｜悲鳴《ひめい》と、｜慌《あわ》ただしい｜足音《あしおと》が｜聞《き》こえてきたんだ。

**李杰**：それで、どうなったんですか？

**山本浩二**：それで……｜煙《けむり》の｜匂《にお》いがした。ひどく｜濃《こ》い｜煙《けむり》の｜匂《にお》いだ。

**山本浩二**：｜窓《まど》から｜外《そと》を｜見《み》たら、なんてこった……｜村中《むらじゅう》が｜燃《も》えていた。

**高橋美咲**：（｜息《いき》をのんで）｜火事《かじ》……ですか？

**山本浩二**：（うなずき、｜重《おも》い｜顔《かお》で）ただの｜火事《かじ》じゃない、｜誰《だれ》かが｜故意《こい》に｜火《ひ》をつけたんだ。

**山本浩二**：｜火《ひ》は｜村《むら》の｜四方八方《しほうはっぽう》から｜一斉《いっせい》に｜上《あ》がった、まるで｜計画《けいかく》されてたみたいにな。エルフたちはみんなパニックになって、あちこち｜逃《に》げ｜回《まわ》ってた。

**ナレーション**：ここまで｜聞《き》いて、｜恵美《えみ》の｜体《からだ》は｜目《め》に｜見《み》えて｜震《ふる》えた。｜彼女《かのじょ》は｜下唇《したくちびる》を｜噛《か》み、｜両手《りょうて》をさらに｜強《つよ》く｜握《にぎ》りしめた。

**李杰**：どうやって｜逃《に》げ｜出《だ》したんですか？

**山本浩二**：｜牢屋《ろうや》の｜木《き》の｜扉《とびら》が、｜混乱《こんらん》の｜中《なか》で｜破《やぶ》られたのか、｜火《ひ》で｜壊《こわ》れたのか、よく｜分《わ》からんが。

**山本浩二**：とにかく、そのどさくさに｜逃《に》げ｜出《だ》した。｜外《そと》は｜大混乱《だいこんらん》で、エルフたちは｜悲鳴《ひめい》を｜上《あ》げながら｜森《もり》へ｜走《はし》っていった。

**山本浩二**：｜俺《おれ》は｜見《み》たんだ……

**ナレーション**：｜山本《やまもと》さんの｜声《こえ》が｜詰《つ》まった。｜彼《かれ》はいったん｜言葉《ことば》を｜切《き》り、｜深《ふか》く｜息《いき》を｜吸《す》った。

**山本浩二**：｜年老《としお》いたエルフが｜何人《なんにん》か……｜足《あし》が｜遅《おそ》すぎて、な。

**山本浩二**：｜火《ひ》の｜回《まわ》りが｜早《はや》すぎて、あの｜人《ひと》たちは｜逃《に》げ｜切《き》れなかった。そのまま、そこに｜倒《たお》れて……

**ナレーション**：｜空気《くうき》が｜重《おも》くなり、｜四人《よにん》は｜沈黙《ちんもく》に｜沈《しず》んだ。｜風《かぜ》が｜廃墟《はいきょ》を｜吹《ふ》き｜抜《ぬ》け、｜低《ひく》いすすり｜泣《な》きのような｜音《おと》を｜立《た》てる。｜亡《な》くなった｜命《いのち》を｜悼《いた》んでいるかのようだった。
