# 第十六幕：失われた避難所

**山本浩二**：｜俺《おれ》も｜助《たす》けに｜行《い》きたかったが、｜火《ひ》が｜強《つよ》すぎて、とても｜近《ちか》づけなかった。

**山本浩二**：｜俺《おれ》はほかのエルフたちと｜一緒《いっしょ》に、｜森《もり》へ｜逃《に》げ｜込《こ》むしかなかった。

**李杰**：それから、どうなったんですか？

**山本浩二**：そのうち｜霧《きり》がどんどん｜濃《こ》くなって、｜俺《おれ》は｜彼《かれ》らとはぐれちまった。

**山本浩二**：｜森《もり》の｜中《なか》をひとりで｜何時間《なんじかん》も｜歩《ある》いて、｜完全《かんぜん》に｜方角《ほうがく》を｜見失《みうしな》ってな。

**山本浩二**：この｜森《もり》から｜永遠《えいえん》に｜出《で》られんのかと｜思《おも》ったそのとき、｜木造《もくぞう》の｜小屋《こや》を｜見《み》つけたんだ。

**高橋美咲**：｜小屋《こや》……？

**山本浩二**：（うなずき）ああ、｜小屋《こや》だ。｜保存状態《ほぞんじょうたい》がよくて、ベッドも｜台所《だいどころ》も、いくらかの｜備蓄《びちく》もあった。

**山本浩二**：ここを｜拠点《きょてん》にして、ひと｜休《やす》みしてから、お｜前《まえ》さんたちと、あの｜三人《さんにん》の｜学生《がくせい》を｜探《さが》し｜続《つづ》けようと｜思《おも》ってな。

**李杰**：それで、｜中《なか》に｜入《はい》ったんですか？

**山本浩二**：ああ。だが｜扉《とびら》を｜押《お》し｜開《あ》けたら、｜中《なか》にはもう｜先客《せんきゃく》がいた。

**高橋美咲**：（｜緊張《きんちょう》して）｜誰《だれ》が……？

**山本浩二**：｜若《わか》い｜男《おとこ》の｜子《こ》が、｜隅《すみ》に｜座《すわ》ってた。｜腕《うで》に｜布《ぬの》を｜巻《ま》いてな。

**山本浩二**：｜見《み》て｜分《わ》かった――お｜前《まえ》さんたちと｜一緒《いっしょ》にいた、あの｜四人《よにん》の｜大学生《だいがくせい》のうちの｜一人《ひとり》だ。

**李杰**：｜名前《なまえ》は？

**山本浩二**：｜佐藤拓海《さとうたくみ》。

**高橋美咲**：（はっと｜目《め》を｜輝《かがや》かせるが、すぐに｜複雑《ふくざつ》な｜表情《ひょうじょう》になって）｜拓海《たくみ》……｜生《い》きてたんだ……

**ナレーション**：｜美咲《みさき》の｜声《こえ》は｜自分《じぶん》にしか｜聞《き》こえないほど｜小《ちい》さく、｜安堵《あんど》と、｜心配《しんぱい》と、｜言《い》いようのない｜思《おも》いが｜入《い》り｜混《ま》じっていた。

**山本浩二**：｜向《む》こうも｜俺《おれ》を｜見《み》て｜驚《おどろ》いてたよ。

**山本浩二**：｜向《む》こうは｜俺《おれ》のことを｜知《し》ってると｜言《い》ってた。お｜前《まえ》さんたちが｜襲《おそ》われたあの｜日《ひ》、｜実《じつ》は｜引《ひ》き｜返《かえ》して、お｜前《まえ》さんを｜助《たす》けに｜行《い》こうとしたからだそうだ。

**高橋美咲**：（｜呆然《ぼうぜん》として）え……｜拓海《たくみ》が、あたしを｜助《たす》けに｜戻《もど》ろうとしてたの？

**山本浩二**：（うなずき）ああ。｜四人《よにん》は｜襲《おそ》われたあとばらばらに｜逃《に》げたが、しばらく｜走《はし》ったところで、お｜前《まえ》さんの｜傷《きず》が｜心配《しんぱい》になったそうだ。

**山本浩二**：それで｜危険《きけん》を｜承知《しょうち》で｜引《ひ》き｜返《かえ》すことにした。その｜帰《かえ》り｜道《みち》で、｜俺《おれ》がエルフを｜追《お》っかけてるのを｜見《み》たそうだ。

**李杰**：じゃあ、｜彼《かれ》もそのとき｜近《ちか》くにいたんですか？

**山本浩二**：ああ、だが｜霧《きり》が｜濃《こ》すぎてな。

**山本浩二**：｜何時間《なんじかん》も｜探《さが》したが、お｜前《まえ》さんが｜倒《たお》れた｜場所《ばしょ》がどうしても｜見《み》つからなかったと｜言《い》ってた。｜霧《きり》が｜痕跡《こんせき》を｜全部《ぜんぶ》｜隠《かく》して、｜方向《ほうこう》がまるで｜分《わ》からなかったんだと。

**山本浩二**：｜最後《さいご》には｜道《みち》に｜迷《まよ》って、｜怪我《けが》した｜腕《うで》もどんどん｜痛《いた》んで、｜捜索《そうさく》を｜諦《あきら》めるしかなかった。

**山本浩二**：もう｜絶望《ぜつぼう》しかけたとき、あの｜小屋《こや》を｜見《み》つけて、それからずっと｜中《なか》で｜養生《ようじょう》してたそうだ。

**ナレーション**：｜美咲《みさき》は｜山本《やまもと》さんの｜話《はなし》を｜聞《き》くうちに、｜表情《ひょうじょう》が｜驚《おどろ》きから｜安堵《あんど》へ、そしてゆっくりと｜怒《いか》りに｜変《か》わっていった。｜彼女《かのじょ》は｜唇《くちびる》を｜噛《か》み、｜両手《りょうて》を｜握《にぎ》りしめた。

**高橋美咲**：（｜恨《うら》みのこもった｜声《こえ》で）でも、｜襲《おそ》われたときは、｜拓海《たくみ》だってあたしを｜守《まも》ってくれなかったじゃない！

**高橋美咲**：みんな｜自分《じぶん》が｜逃《に》げるのに｜必死《ひっし》で！　もし｜本当《ほんとう》にあたしのことを｜大事《だいじ》に｜思《おも》ってるなら、どうして｜真《ま》っ｜先《さき》に｜守《まも》ってくれなかったの！？

**山本浩二**：（なだめるように）お｜嬢《じょう》ちゃん、あのときは｜何《なに》もかも｜急《きゅう》すぎて、｜誰《だれ》にも｜反応《はんのう》する｜時間《じかん》なんてなかったんだ……

**高橋美咲**：（｜深《ふか》く｜息《いき》を｜吸《す》い、｜気持《きも》ちが｜少《すこ》し｜落《お》ち｜着《つ》いて）……もういい。｜少《すく》なくとも、｜生《い》きてたんだから。

**高橋美咲**：｜拓海《たくみ》……いまも、その｜家《いえ》にいるんですか？

**山本浩二**：ああ、｜傷《きず》がまだ｜完全《かんぜん》には｜治《なお》ってなくて、｜歩《ある》くのがちと｜不自由《ふじゆう》でな。

**山本浩二**：｜俺《おれ》はお｜前《まえ》さんたちを｜探《さが》しに｜出《で》ると｜言《い》ったら、あの｜子《こ》はそこに｜残《のこ》って｜待《ま》ってる。

**高橋美咲**：じゃあ、｜早《はや》く｜行《い》こう！

**山本浩二**：（｜立《た》ち｜上《あ》がり）よし、｜案内《あんない》する。｜道《みち》のりはそう｜遠《とお》くない、｜一時間《いちじかん》ちょっとで｜着《つ》く。

**李杰**：じゃあ、｜出発《しゅっぱつ》しましょう。

**ナレーション**：｜四人《よにん》――｜李杰《りけつ》、｜恵美《えみ》、｜美咲《みさき》、｜山本《やまもと》さん――は｜焼《や》け｜焦《こ》げた｜村《むら》の｜廃墟《はいきょ》をあとにして、ふたたび｜濃霧《のうむ》の｜立《た》ち｜込《こ》める｜森《もり》へ｜足《あし》を｜踏《ふ》み｜入《い》れた。

**ナレーション**：｜山本《やまもと》さんが｜先頭《せんとう》に｜立《た》って｜道《みち》を｜案内《あんない》し、ほかの｜者《もの》はそのすぐ｜後《うし》ろについた。｜霧《きり》は｜相変《あいか》わらず｜濃《こ》く、｜見通《みとお》しは｜五《ご》メートルもなかった。

**ナレーション**：｜道中《どうちゅう》、｜誰《だれ》もあまり｜口《くち》をきかなかった。

**ナレーション**：｜美咲《みさき》の｜表情《ひょうじょう》は｜複雑《ふくざつ》で、｜眉《まゆ》をひそめたり、｜唇《くちびる》を｜噛《か》んだりしながら、｜拓海《たくみ》のことを｜考《かんが》えているようだった。｜足取《あしど》りはいつもよりずっと｜速《はや》く、｜一刻《いっこく》も｜早《はや》く｜会《あ》いたがっているのは｜明《あき》らかだった。

**ナレーション**：｜恵美《えみ》は｜相変《あいか》わらず｜黙《だま》りこくり、｜目《め》は｜虚《うつ》ろで、さっきの｜悲《かな》しみにまだ｜沈《しず》んでいるようだった。｜機械的《きかいてき》に｜前《まえ》の｜人《ひと》について｜歩《ある》き、まわりのことには｜何《なん》の｜関心《かんしん》もなさそうだった。

**ナレーション**：｜李杰《りけつ》は｜絶《た》えず｜周囲《しゅうい》の｜様子《ようす》を｜見渡《みわた》し、｜警戒《けいかい》を｜怠《おこた》らなかった。｜手《て》はずっとポケットに｜入《い》れたまま、いつでも｜不測《ふそく》の｜事態《じたい》に｜備《そな》えていた。

**ナレーション**：｜森《もり》は｜相変《あいか》わらず｜死《し》んだように｜静《しず》まり｜返《かえ》り、｜落《お》ち｜葉《ば》と｜枯《か》れ｜枝《えだ》を｜踏《ふ》む｜足音《あしおと》だけが｜響《ひび》く。ときおり｜風《かぜ》が｜吹《ふ》き、｜木《き》の｜枝《えだ》がかすかに｜揺《ゆ》れる｜音《おと》を｜立《た》てた。

**ナレーション**：｜一時間《いちじかん》ちょっと｜歩《ある》いたころ、｜濃霧《のうむ》の｜中《なか》に、｜一軒《いっけん》の｜小屋《こや》の｜輪郭《りんかく》が｜現《あらわ》れた。

**山本浩二**：ここだ。

**ナレーション**：それは｜質素《しっそ》な｜木《き》の｜小屋《こや》で、｜外壁《がいへき》は｜濃《こ》い｜茶色《ちゃいろ》の｜板張《いたば》り、｜屋根《やね》は｜苔《こけ》に｜覆《おお》われていた。｜窓《まど》からはかすかな｜明《あ》かりが｜漏《も》れていて、｜中《なか》に｜確《たし》かに｜人《ひと》がいることを｜示《しめ》していた。

**ナレーション**：｜山本《やまもと》さんは｜足早《あしばや》に｜戸口《とぐち》へ｜行《い》き、｜木《き》の｜扉《とびら》を｜押《お》し｜開《あ》けた。

**山本浩二**：（｜大声《おおごえ》で｜呼《よ》ぶ）｜拓海《たくみ》！　こいつらを｜連《つ》れてきたぞ！

**ナレーション**：｜扉《とびら》がゆっくり｜開《あ》き、｜四人《よにん》は｜一列《いちれつ》になって｜中《なか》へ｜入《はい》った。

**ナレーション**：だが｜屋内《おくない》の｜光景《こうけい》を｜目《め》にした｜瞬間《しゅんかん》、｜全員《ぜんいん》が｜凍《こお》りついた。

**李杰**：（｜息《いき》をのんで）こ……こんな、まさか……
