# 第十九幕：血の刃の奇襲

**ナレーション**：｜小屋《こや》の｜中《なか》の｜空気《くうき》は｜相変《あいか》わらず｜重《おも》く、｜気弱《きよわ》な｜眼鏡《めがね》の｜青年《せいねん》の｜遺体《いたい》は｜静《しず》かに｜床《ゆか》に｜横《よこ》たわり、｜血痕《けっこん》は｜固《かた》まって｜黒《くろ》ずみ｜始《はじ》めていた。

**李杰**：（｜心《こころ》の｜声《こえ》）｜彼女《かのじょ》は｜絶対《ぜったい》に｜何《なに》か｜知《し》っている……だがこれだけの｜人《ひと》の｜前《まえ》では、｜話《はな》さないだろう。

**李杰**：（｜心《こころ》の｜声《こえ》）｜二人《ふたり》きりで｜話《はな》したほうがいいかもしれない。ほかに｜誰《だれ》もいなければ、｜彼女《かのじょ》も｜気《き》が｜楽《らく》になって、｜本当《ほんとう》のことを｜話《はな》してくれるかもしれない。

**ナレーション**：｜李杰《りけつ》は｜深《ふか》く｜息《いき》を｜吸《す》い、｜決断《けつだん》した。

**李杰**：（｜恵美《えみ》のほうを｜向《む》き、｜声《こえ》をひそめて）｜清水《しみず》さん、｜少《すこ》し｜二人《ふたり》だけで｜話《はな》したいことがある。

**ナレーション**：｜恵美《えみ》は｜顔《かお》を｜上《あ》げ、｜目《め》に｜驚《おどろ》きがよぎったが、すぐにうなずいた。｜指《ゆび》が｜無意識《むいしき》に｜握《にぎ》りしめられ、｜関節《かんせつ》がかすかに｜白《しろ》くなる。

**清水恵美**：（｜小声《こごえ》で）はい……

**李杰**：（ほかの｜人《ひと》たちのほうを｜向《む》いて）｜清水《しみず》さんと｜話《はな》し｜合《あ》うことがあるので、ちょっと｜席《せき》を｜外《はず》します。すぐ｜戻《もど》ります。

**山本浩二**：（うなずき）ああ、｜気《き》をつけてな。あんまり｜遠《とお》くへ｜行《い》くなよ。

**高橋美咲**：（｜心配《しんぱい》そうに｜恵美《えみ》を｜見《み》て）｜恵美《えみ》、｜大丈夫《だいじょうぶ》……？

**清水恵美**：（｜無理《むり》に｜笑顔《えがお》をつくって）わ……わたしは｜大丈夫《だいじょうぶ》……です……

**山本浩二**：（｜拓海《たくみ》と｜美咲《みさき》のほうを｜向《む》いて）お｜前《まえ》さんたち｜二人《ふたり》は、どこか｜彼《かれ》を｜埋《う》めてやれる｜場所《ばしょ》を｜探《さが》してくれ。

**山本浩二**：このままにはしておけん……せめて、｜土《つち》に｜還《かえ》してやらにゃな。

**佐藤拓海**：はい、｜山本《やまもと》さん。

**ナレーション**：｜拓海《たくみ》と｜美咲《みさき》は、｜遺体《いたい》を｜運《はこ》ぶのに｜使《つか》えそうな｜布《ぬの》を、｜小屋《こや》の｜中《なか》で｜探《さが》し｜始《はじ》めた。｜山本《やまもと》さんは｜戸口《とぐち》へ｜行《い》き、｜警戒《けいかい》しながら｜森《もり》の｜奥《おく》を｜見《み》やった。

**ナレーション**：｜李杰《りけつ》は｜恵美《えみ》の｜腕《うで》にそっと｜触《ふ》れ、ついてくるよう｜合図《あいず》した。｜二人《ふたり》は｜小屋《こや》を｜出《で》て、｜濃霧《のうむ》の｜中《なか》へ｜踏《ふ》み｜出《だ》した。

**ナレーション**：｜李杰《りけつ》は｜恵美《えみ》を｜連《つ》れて｜小径《こみち》を｜森《もり》の｜奥《おく》へ｜進《すす》み、｜小屋《こや》から｜離《はな》れた。｜霧《きり》が｜二人《ふたり》のまわりを｜流《なが》れ、｜見通《みとお》しは｜五《ご》メートルもない。

**ナレーション**：｜二分《にふん》ほど｜歩《ある》いたところで、｜李杰《りけつ》は｜足《あし》を｜止《と》めた。ここまで｜来《く》ると、もう｜小屋《こや》のほうの｜物音《ものおと》は｜聞《き》こえず、｜風《かぜ》が｜葉《は》を｜揺《ゆ》らす｜音《おと》だけがした。

**ナレーション**：｜四方《しほう》には｜背《せ》の｜高《たか》い｜古木《こぼく》が｜立《た》ち｜並《なら》び、｜幹《みき》には｜苔《こけ》がびっしりと｜生《は》えている。｜地面《じめん》は｜落《お》ち｜葉《ば》で｜埋《う》まり、｜踏《ふ》むとかすかな｜音《おと》がした。

**李杰**：（｜振《ふ》り｜向《む》いて｜恵美《えみ》に｜向《む》き｜合《あ》い、｜真剣《しんけん》な｜口調《くちょう》で）｜清水《しみず》さん、はっきり｜訊《き》くよ。

**李杰**：｜君《きみ》は、｜何《なに》か｜隠《かく》してるんじゃないか？

**ナレーション**：｜恵美《えみ》の｜体《からだ》がかすかに｜震《ふる》えた。｜彼女《かのじょ》は｜顔《かお》を｜上《あ》げ、｜李杰《りけつ》の｜目《め》をまっすぐ｜見《み》つめたが、｜何《なに》も｜言《い》わなかった。

**ナレーション**：｜沈黙《ちんもく》が｜数秒《すうびょう》｜続《つづ》き、｜空気《くうき》が｜張《は》りつめた。｜恵美《えみ》の｜唇《くちびる》が｜震《ふる》え、｜何《なに》か｜言《い》いたそうなのに、どこから｜話《はな》せばいいのか｜分《わ》からないようだった。

**李杰**：｜状況《じょうきょう》はどんどん｜悪《わる》くなってる。さっきの｜眼鏡《めがね》の｜彼《かれ》……｜死《し》んだんだ。

**李杰**：もし｜何《なに》か｜知《し》っているなら、｜本当《ほんとう》のことを｜話《はな》してほしい。

**李杰**：そうすれば、｜何《なに》が｜起《お》きているのかもっとよく｜理解《りかい》できるし、｜自分《じぶん》たちの｜身《み》も｜守《まも》れる。

**ナレーション**：｜恵美《えみ》の｜目《め》がしだいに｜赤《あか》くなり、｜彼女《かのじょ》は｜下唇《したくちびる》を｜噛《か》み、｜両手《りょうて》をきつく｜握《にぎ》り｜合《あ》わせた。

**ナレーション**：｜彼女《かのじょ》は｜深《ふか》く｜息《いき》を｜吸《す》った。｜何《なに》か｜決心《けっしん》したようだった。｜口《くち》を｜開《ひら》き、｜話《はな》し｜出《だ》そうとした――

**ナレーション**：そのとき、｜李杰《りけつ》の｜視界《しかい》の｜端《はし》に、｜黒《くろ》い｜影《かげ》が｜映《うつ》った。｜恵美《えみ》の｜背後《はいご》の｜霧《きり》の｜中《なか》から、｜猛烈《もうれつ》な｜速《はや》さで｜迫《せま》ってくる！

**李杰**：（｜叫《さけ》ぶ）｜危《あぶ》ない！

**ナレーション**：｜李杰《りけつ》は｜瞬時《しゅんじ》に｜手《て》を｜伸《の》ばして｜恵美《えみ》の｜腕《うで》をつかみ、｜力《ちから》いっぱい｜横《よこ》へ｜引《ひ》いた！

**ナレーション**：｜二人《ふたり》はバランスを｜崩《くず》し、｜一緒《いっしょ》に｜地面《じめん》に｜倒《たお》れ｜込《こ》んだ。｜落《お》ち｜葉《ば》と｜泥《どろ》が｜跳《は》ね｜上《あ》がり、｜恵美《えみ》が｜小《ちい》さな｜悲鳴《ひめい》を｜上《あ》げる。

**ナレーション**：｜一筋《ひとすじ》の｜冷《つめ》たい｜光《ひかり》が、｜恵美《えみ》がいまさっきまで｜立《た》っていた｜場所《ばしょ》へ｜振《ふ》り｜下《お》ろされた！

**ナレーション**：｜李杰《りけつ》が｜素早《すばや》く｜動《うご》いたにもかかわらず、｜黒《くろ》い｜剣《けん》はそれでも｜恵美《えみ》の｜脇腹《わきばら》を｜切《き》り｜裂《さ》いた。｜服《ふく》が｜裂《さ》け、｜鮮血《せんけつ》がたちまち｜噴《ふ》き｜出《だ》して、｜彼女《かのじょ》の｜服《ふく》を｜赤《あか》く｜染《そ》めた。

**清水恵美**：（｜痛《いた》みに｜叫《さけ》んで）あっ……！

**ナレーション**：｜李杰《りけつ》と｜恵美《えみ》は｜地面《じめん》に｜倒《たお》れ、｜二人《ふたり》は｜恐怖《きょうふ》に｜満《み》ちた｜目《め》で｜顔《かお》を｜上《あ》げた。

**ナレーション**：｜黒《くろ》いコートを｜着《き》た｜男《おとこ》が、｜彼《かれ》らの｜前《まえ》に｜立《た》っていた。｜手《て》には、｜全体《ぜんたい》が｜漆黒《しっこく》の｜長剣《ちょうけん》を｜握《にぎ》っている。｜刀身《とうしん》には｜恵美《えみ》の｜血《ち》がまだ｜付《つ》いていて、｜紫《むらさき》の｜月光《げっこう》の｜下《した》で｜不気味《ぶきみ》な｜光沢《こうたく》を｜放《はな》っていた。

**ナレーション**：その｜男《おとこ》は｜黒《くろ》い｜帽子《ぼうし》をかぶり、つばを｜深《ふか》く｜下《さ》げて、｜顔《かお》の｜大半《たいはん》を｜隠《かく》していた。｜見《み》えるのは、｜冷《ひ》ややかな｜顎《あご》と、｜固《かた》く｜結《むす》んだ｜唇《くちびる》だけだ。

**ナレーション**：｜体《からだ》つきは｜普通《ふつう》で、｜動《うご》きはなめらかで｜冷静《れいせい》、まるでよく｜訓練《くんれん》された｜殺《ころ》し｜屋《や》のようだった。

**李杰**：（｜心《こころ》の｜声《こえ》）あいつだ……！

**ナレーション**：｜李杰《りけつ》の｜頭《あたま》に、あの｜光景《こうけい》がよぎった――｜新宿駅《しんじゅくえき》のホームで、｜影《かげ》の｜中《なか》にひとりで｜立《た》っていた｜黒衣《こくい》の｜男《おとこ》。

**ナレーション**：あのとき、この｜男《おとこ》は｜言《い》いようのない｜不安《ふあん》を｜彼《かれ》に｜与《あた》えた。そしていま、この｜男《おとこ》がここに｜現《あらわ》れ、｜手《て》には｜血《ち》に｜濡《ぬ》れた｜剣《けん》を｜握《にぎ》っている！

**清水恵美**：（｜震《ふる》えながら、｜信《しん》じられないという｜声《こえ》で）そんな……ありえない……どうして、あなたが……

**ナレーション**：｜恵美《えみ》の｜声《こえ》は｜衝撃《しょうげき》と｜恐怖《きょうふ》に｜満《み》ち、｜顔《かお》からは｜血《ち》の｜気《け》が｜失《う》せて、｜全身《ぜんしん》から｜力《ちから》が｜抜《ぬ》けてしまったかのようだった。

**ナレーション**：｜彼女《かのじょ》は｜体《からだ》を｜起《お》こそうともがいたが、｜脇腹《わきばら》の｜傷《きず》の｜痛《いた》みに｜息《いき》をのんだ。｜血《ち》は｜傷口《きずぐち》から｜絶《た》え｜間《ま》なくにじみ、｜彼女《かのじょ》の｜手《て》を｜赤《あか》く｜染《そ》める。

**ナレーション**：｜恵美《えみ》は｜顔《かお》を｜上《あ》げた。｜目《め》に｜涙《なみだ》をためて、｜震《ふる》える｜声《こえ》で｜尋《たず》ねた――

**清水恵美**：（｜声《こえ》を｜震《ふる》わせて）あなたなの……｜凌墨《りょうぼく》？
