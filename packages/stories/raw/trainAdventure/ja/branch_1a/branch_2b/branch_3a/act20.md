# 第二十幕：絶望の追跡

**ナレーション**：｜黒衣《こくい》の｜男《おとこ》は｜剣《けん》を｜高々《たかだか》と｜掲《かか》げた。｜剣先《けんさき》が｜紫《むらさき》の｜月光《げっこう》の｜下《した》で｜冷《つめ》たくきらめく。｜彼《かれ》はまさに、｜振《ふ》り｜下《お》ろそうとしていた――

**ナレーション**：だがそのとき、｜恵美《えみ》の｜震《ふる》える｜声《こえ》が、｜彼《かれ》の｜耳《みみ》に｜届《とど》いた。

**清水恵美**：（｜声《こえ》を｜震《ふる》わせて）あなたなの……｜凌墨《りょうぼく》？

**ナレーション**：｜黒衣《こくい》の｜男《おとこ》の｜動《うご》きが、ふいに｜止《と》まった。｜高《たか》く｜掲《かか》げた｜剣《けん》は｜宙《ちゅう》で｜凍《こお》りつき、｜時間《じかん》が｜一時停止《いちじていし》のボタンを｜押《お》されたかのようだった。

**ナレーション**：｜彼《かれ》の｜体《からだ》がかすかに｜震《ふる》え、｜唇《くちびる》が｜動《うご》き｜始《はじ》めた。

**凌墨**：（つぶやくように、かすれた｜声《こえ》で）｜恵美《えみ》……｜恵美《えみ》……

**ナレーション**：｜声《こえ》は｜小《ちい》さかったが、｜李杰《りけつ》にははっきり｜聞《き》こえた。その｜声《こえ》には｜複雑《ふくざつ》な｜感情《かんじょう》が｜満《み》ちていた――｜苦《くる》しみ、｜葛藤《かっとう》、そして｜言《い》い｜表《あらわ》しがたいやさしさ。

**李杰**：（｜心《こころ》の｜声《こえ》）チャンスだ！

**ナレーション**：｜李杰《りけつ》はためらわずに｜地面《じめん》から｜跳《は》ね｜起《お》き、｜全身《ぜんしん》の｜力《ちから》を｜込《こ》めて、｜黒衣《こくい》の｜男《おとこ》の｜腹《はら》へ｜渾身《こんしん》の｜拳《こぶし》を｜叩《たた》き｜込《こ》んだ！

**ナレーション**：｜拳《こぶし》は｜確《たし》かな｜手応《てごた》えで｜命中《めいちゅう》した。｜黒衣《こくい》の｜男《おとこ》はくぐもった｜声《こえ》を｜漏《も》らし、｜数歩後《すうほうし》ろへよろめいた。

**凌墨**：（｜苦《くる》しげに）うっ……

**ナレーション**：だが｜彼《かれ》の｜口《くち》はまだつぶやき｜続《つづ》けていて、｜目《め》はうつろに｜霞《かす》み、｜放心状態《ほうしんじょうたい》に｜陥《おちい》っているようだった。

**凌墨**：（つぶやくように）｜恵美《えみ》……どうして……｜恵美《えみ》……

**ナレーション**：｜李杰《りけつ》は｜息《いき》をつく｜暇《ひま》を｜与《あた》えなかった！　すかさず｜飛《と》びかかり、｜黒衣《こくい》の｜男《おとこ》の｜剣《けん》を｜握《にぎ》る｜腕《うで》をつかんで、｜膝《ひざ》を｜思《おも》い｜切《き》り｜叩《たた》き｜込《こ》んだ！

**ナレーション**：｜黒衣《こくい》の｜男《おとこ》の｜手《て》が｜緩《ゆる》み、｜漆黒《しっこく》の｜長剣《ちょうけん》は｜手《て》から｜離《はな》れて、｜鈍《にぶ》い｜音《おと》を｜立《た》てて｜地面《じめん》に｜落《お》ちた。

**ナレーション**：｜李杰《りけつ》はもう｜一度《いちど》｜拳《こぶし》を｜振《ふ》るい、｜黒衣《こくい》の｜男《おとこ》の｜頬《ほお》を｜強《つよ》く｜殴《なぐ》りつけた！

**ナレーション**：｜黒衣《こくい》の｜男《おとこ》の｜帽子《ぼうし》が｜吹《ふ》き｜飛《と》び、｜体《からだ》の｜均衡《きんこう》を｜失《うしな》って、｜地面《じめん》に｜倒《たお》れ｜込《こ》んだ。ついにその｜顔《かお》があらわになった――まだ｜若《わか》い｜顔《かお》で、｜二十歳《はたち》を｜少《すこ》し｜過《す》ぎたくらい、｜彫《ほ》りの｜深《ふか》い｜目鼻立《めはなだ》ちだが、いまは｜苦痛《くつう》と｜戸惑《とまど》いに｜満《み》ちていた。

**凌墨**：（｜地面《じめん》に｜倒《たお》れ、まだつぶやき｜続《つづ》けて）｜恵美《えみ》……｜恵美《えみ》……

**ナレーション**：｜李杰《りけつ》は｜素早《すばや》く｜身《み》をひるがえし、｜地面《じめん》の｜黒《くろ》い｜剣《けん》を｜拾《ひろ》おうとした。かがみ｜込《こ》み、｜両手《りょうて》で｜柄《がら》を｜握《にぎ》り、｜全力《ぜんりょく》で｜持《も》ち｜上《あ》げようとして――

**ナレーション**：だが｜剣《けん》は、びくともしなかった！

**李杰**：（｜心《こころ》の｜声《こえ》）｜何《なん》だと！？

**ナレーション**：その｜剣《けん》は、まるで｜地面《じめん》に｜溶接《ようせつ》されたかのようだった。｜李杰《りけつ》がどれだけ｜力《ちから》を｜込《こ》めても、わずかも｜動《うご》かない。｜腕《うで》には｜青筋《あおすじ》が｜浮《う》き、｜額《がく》には｜冷《ひ》や｜汗《あせ》がにじんだが、｜剣《けん》は｜微動《びどう》だにせず｜地面《じめん》に｜横《よこ》たわっていた。

**ナレーション**：｜李杰《りけつ》は｜衝撃《しょうげき》で｜言葉《ことば》を｜失《うしな》ったが、いまは｜考《かんが》えているときではないと｜分《わ》かっていた。

**李杰**：（｜息《いき》を｜切《き》らし、｜恵美《えみ》へ｜駆《か》け｜寄《よ》って）｜清水《しみず》さん！　｜逃《に》げるぞ！

**ナレーション**：｜彼《かれ》は｜素早《すばや》くしゃがみ、｜恵美《えみ》を｜助《たす》け｜起《お》こして、｜背中《せなか》に｜背負《せお》った。｜恵美《えみ》の｜体《からだ》は｜軽《かる》かったが、｜脇腹《わきばら》の｜傷《きず》からはまだ｜血《ち》が｜流《なが》れ、｜温《あたた》かい｜液体《えきたい》が｜李杰《りけつ》の｜服《ふく》を｜濡《ぬ》らしていく。

**清水恵美**：（｜弱々《よわよわ》しく）｜李《り》さん……

**李杰**：しゃべるな！　しっかりしろ！

**ナレーション**：｜李杰《りけつ》は｜恵美《えみ》を｜背負《せお》ったまま、｜脱兎《だっと》のごとく｜駆《か》けだした。｜背後《はいご》から｜凌墨《りょうぼく》の｜苦《くる》しげなうめき｜声《ごえ》が｜聞《き》こえたが、｜李杰《りけつ》は｜振《ふ》り｜返《かえ》らなかった。

**ナレーション**：｜濃霧《のうむ》の｜中《なか》を｜走《はし》る。｜枝《えだ》が｜頬《ほお》をかすめ、｜落《お》ち｜葉《ば》が｜足《あし》もとで｜舞《ま》い｜散《ち》った。｜肺《はい》が｜破裂《はれつ》しそうだったが、｜止《と》まる｜勇気《ゆうき》はなかった。

**ナレーション**：やがて、｜霧《きり》の｜中《なか》に｜小屋《こや》の｜輪郭《りんかく》が｜浮《う》かんだ。｜李杰《りけつ》は｜戸口《とぐち》へ｜駆《か》け｜込《こ》み、｜肩《かた》で｜扉《とびら》を｜押《お》し｜開《あ》けた。

**李杰**：（｜大声《おおごえ》で）｜高橋《たかはし》！

**ナレーション**：｜小屋《こや》の｜中《なか》には｜美咲《みさき》ひとりだけがいた。ベッドのそばで｜荷物《にもつ》を｜整理《せいり》していたが、｜李杰《りけつ》の｜声《こえ》を｜聞《き》いて、はっと｜振《ふ》り｜向《む》いた――

**ナレーション**：｜李杰《りけつ》の｜背中《せなか》の｜恵美《えみ》と、その｜脇腹《わきばら》から｜絶《た》え｜間《ま》なく｜流《なが》れ｜出《で》る｜鮮血《せんけつ》を｜目《め》にした｜瞬間《しゅんかん》、｜彼女《かのじょ》の｜顔色《かおいろ》はたちまち｜真《ま》っ｜青《さお》になった。

**高橋美咲**：（｜叫《さけ》んで）うそ！　｜恵美《えみ》！　その……どうしたの！？

**李杰**：（｜恵美《えみ》をベッドに｜寝《ね》かせて）｜剣《けん》で｜斬《き》られたんだ！　｜早《はや》く｜応急処置《おうきゅうしょち》の｜道具《どうぐ》を！

**高橋美咲**：は……はい！

**ナレーション**：｜美咲《みさき》はすぐに｜部屋《へや》の｜隅《すみ》の｜戸棚《とだな》へ｜駆《か》けた。｜拓海《たくみ》が｜怪我《けが》をしたとき、ここで｜包帯《ほうたい》や｜薬《くすり》を｜見《み》つけたことを｜覚《おぼ》えていたのだ。

**ナレーション**：｜彼女《かのじょ》は｜戸棚《とだな》を｜開《あ》け、｜素早《すばや》く｜探《さぐ》って、すぐに｜小《ちい》さな｜木箱《きばこ》を｜見《み》つけた。｜中《なか》には｜清潔《せいけつ》な｜布切《ぬのき》れと、｜薬草《やくそう》の｜粉末《ふんまつ》、それに｜何《なん》｜巻《ま》きかの｜包帯《ほうたい》が｜入《はい》っていた。

**高橋美咲**：（｜応急処置《おうきゅうしょち》の｜道具《どうぐ》を｜持《も》ってベッドのそばへ｜駆《か》け｜戻《もど》り）あった！

**ナレーション**：｜美咲《みさき》は｜震《ふる》える｜手《て》で｜恵美《えみ》の｜服《ふく》を｜裂《さ》き、｜深《ふか》い｜傷口《きずぐち》をあらわにした。｜血《ち》はまだ｜絶《た》え｜間《ま》なく｜噴《ふ》き｜出《だ》し、シーツを｜赤《あか》く｜染《そ》めている。

**ナレーション**：｜彼女《かのじょ》は｜布切《ぬのき》れで｜傷口《きずぐち》を｜押《お》さえ、｜止血《しけつ》しようとした。｜恵美《えみ》は｜痛《いた》みにかすかなうめき｜声《ごえ》を｜漏《も》らす。

**李杰**：（｜息《いき》を｜切《き》らし）｜山本《やまもと》さんと｜佐藤《さとう》は？　どこにいる？

**高橋美咲**：（｜慌《あわ》てて）あの｜人《ひと》たちは……｜外《そと》で｜穴《あな》を｜掘《ほ》ってて……どの｜方向《ほうこう》かは、わたし｜分《わ》からなくて……

**李杰**：くそ……

**ナレーション**：｜李杰《りけつ》は｜身《み》をひるがえして｜扉《とびら》を｜飛《と》び｜出《だ》し、｜小屋《こや》の｜外《そと》に｜立《た》って、｜力《ちから》いっぱい｜叫《さけ》んだ。

**李杰**：（｜大声《おおごえ》で）｜山本《やまもと》さん！　｜佐藤《さとう》！　どこにいる！

**ナレーション**：｜霧《きり》が｜彼《かれ》の｜声《こえ》を｜呑《の》み｜込《こ》んだ。もう｜一度《いちど》｜叫《さけ》ぶ。｜声《こえ》はさらに｜大《おお》きく、｜切迫《せっぱく》と｜恐怖《きょうふ》を｜帯《お》びていた。

**李杰**：（｜大声《おおごえ》で）｜山本《やまもと》さん！　すぐ｜戻《もど》ってきてくれ！

**ナレーション**：｜数秒後《すうびょうご》、｜遠《とお》くから｜返事《へんじ》が｜届《とど》いた。

**山本浩二**：（｜遠《とお》くからの｜声《こえ》）｜李杰《りけつ》？　どうした！？

**佐藤拓海**：（｜遠《とお》くからの｜声《こえ》）すぐ｜行《い》きます！

**ナレーション**：｜一分《いっぷん》とかからず、｜山本《やまもと》さんと｜拓海《たくみ》の｜姿《すがた》が｜霧《きり》の｜中《なか》から｜駆《か》け｜出《だ》してきた。｜二人《ふたり》とも｜手《て》には｜急《きゅう》ごしらえの｜木《き》のスコップを｜持《も》ち、｜顔《かお》は｜泥《どろ》と｜汗《あせ》にまみれていた。

**山本浩二**：（｜息《いき》を｜切《き》らし）どうした？

**李杰**：（｜切迫《せっぱく》して）あの｜黒衣《こくい》の｜男《おとこ》……また｜現《あらわ》れたんです！　｜清水《しみず》さんを｜襲《おそ》いました！

**佐藤拓海**：（｜衝撃《しょうげき》を｜受《う》けて）｜何《なん》ですって！？

**山本浩二**：あいつはどこだ？

**李杰**：｜殴《なぐ》り｜倒《たお》しましたが、｜追《お》ってくるかもしれません！　｜早《はや》く｜中《なか》へ！

**ナレーション**：｜三人《さんにん》が｜小屋《こや》へ｜駆《か》け｜込《こ》もうとしたとき、｜突然《とつぜん》――

**高橋美咲**：（｜小屋《こや》の｜中《なか》から｜凄《すさ》まじい｜悲鳴《ひめい》）きゃああああっ！

**李杰**：（｜顔色《かおいろ》が｜変《か》わり）｜美咲《みさき》！

**山本浩二**：（｜大声《おおごえ》で）｜踏《ふ》み｜込《こ》むぞ！

**ナレーション**：｜山本《やまもと》さんが｜先頭《せんとう》に｜立《た》ち、｜肩《かた》で｜思《おも》い｜切《き》り｜扉《とびら》にぶつかった！

**ナレーション**：｜扉《とびら》｜板《いた》が｜大《おお》きな｜衝撃音《しょうげきおん》を｜立《た》て、｜錠《じょう》が｜壊《こわ》れ、｜扉《とびら》がまるごと｜吹《ふ》き｜飛《と》んだ！

**ナレーション**：｜三人《さんにん》が｜小屋《こや》に｜飛《と》び｜込《こ》むと、｜目《め》の｜前《まえ》の｜光景《こうけい》に｜全員《ぜんいん》が｜凍《こお》りついた。

**ナレーション**：｜黒衣《こくい》の｜男《おとこ》、｜凌墨《りょうぼく》が｜小屋《こや》の｜中央《ちゅうおう》に｜立《た》ち、｜手《て》にはあの｜漆黒《しっこく》の｜長剣《ちょうけん》を｜握《にぎ》っていた。｜剣先《けんさき》は｜部屋《へや》の｜隅《すみ》で｜縮《ちぢ》こまる｜美咲《みさき》に｜向《む》けられ、｜彼女《かのじょ》の｜喉《のど》まで｜十《じゅっ》センチもない。

**ナレーション**：｜美咲《みさき》は｜顔面蒼白《がんめんそうはく》で、｜両手《りょうて》で｜口《くち》をきつく｜押《お》さえ、｜目《め》は｜恐怖《きょうふ》でいっぱいだった。｜体《からだ》は｜壁《かべ》にぴったりと｜張《は》りつき、｜身動《みうご》きひとつできない。

**ナレーション**：そして｜恵美《えみ》はまだベッドの｜上《うえ》に｜座《すわ》っていた。｜脇腹《わきばら》の｜傷《きず》は｜簡単《かんたん》に｜手当《てあ》てされていたが、｜血《ち》はまだにじんでいる。｜彼女《かのじょ》は｜震《ふる》える｜手《て》を｜伸《の》ばし、｜凌墨《りょうぼく》に｜向《む》かって｜叫《さけ》んだ――

**清水恵美**：（かすれた｜声《こえ》で、｜泣《な》き｜声《ごえ》まじりに）やめて！　｜凌墨《りょうぼく》！　お｜願《ねが》い……やめて！

**ナレーション**：｜凌墨《りょうぼく》は｜答《こた》えなかった。｜顔《かお》にはまったく｜表情《ひょうじょう》がなく、｜眼差《まなざ》しは｜冷《つめ》たく｜空虚《くうきょ》で、｜魂《たましい》のない｜操《あやつ》り｜人形《にんぎょう》のようだった。

**ナレーション**：｜剣先《けんさき》がかすかに｜震《ふる》えている。いつ｜突《つ》き｜刺《さ》されてもおかしくなかった。
