**ナレーション**：｜李杰《りけつ》が｜広間《ひろま》に｜戻《もど》ると、｜斎藤蓮《さいとうれん》はまだ｜長椅子《ながいす》の｜上《うえ》で｜縮《ちぢ》こまっていた。｜李杰《りけつ》が｜戻《もど》ったのを｜見《み》て、｜彼《かれ》はすぐに｜顔《かお》を｜上《あ》げた。

**李杰**：｜焦《あせ》るな。｜足《あし》がまだ｜治《なお》ってないんだ、｜急《いそ》ぎすぎると｜悪《わる》くなるだけだぞ。

**ナレーション**：｜霧《きり》は｜相変《あいか》わらず｜濃《こ》く、｜視界《しかい》は｜極端《きょくたん》に｜悪《わる》い。｜彼《かれ》らは｜手探《てさぐ》りで｜進《すす》むしかなく、｜一歩《いっぽ》ごとに｜慎重《しんちょう》にならなければならなかった。

**ナレーション**：｜時間《じかん》は、ゆっくりとした｜歩《あゆ》みの｜中《なか》で｜流《なが》れていく。｜一時間《いちじかん》、｜二時間《にじかん》。｜斎藤蓮《さいとうれん》の｜足《あし》の｜怪我《けが》のせいで、｜速度《そくど》は｜絶望的《ぜつぼうてき》なまでに｜遅《おそ》かった。

**李杰**：もうすぐ｜着《つ》くはずだ。もう｜少《すこ》し｜頑張《がんば》れ。

**ナレーション**：さらにしばらくして、｜前方《ぜんぽう》の｜霧《きり》の｜中《なか》に、ようやく｜見覚《みおぼ》えのある｜輪郭《りんかく》が｜現《あらわ》れた。

**ナレーション**：それは｜二階建《にかいだ》ての｜木造《もくぞう》の｜小屋《こや》で、｜林《はやし》の｜中《なか》の｜空《あ》き｜地《ち》に、｜静《しず》かにそびえていた。｜造《つく》りはしっかりしていて、｜小《ちい》さなポーチと、｜数段《すうだん》の｜木《き》の｜階段《かいだん》がある。｜尖《とが》った｜屋根《やね》の｜上《うえ》では、｜煙突《えんとつ》がまっすぐ｜空《そら》へ｜伸《の》びていた。

**李杰**：｜着《つ》いた。

**斎藤蓮**：（ほっと｜息《いき》をついて）やっと……

**ナレーション**：｜李杰《りけつ》は｜斎藤蓮《さいとうれん》を｜支《ささ》えて、ポーチの｜階段《かいだん》を｜上《あ》がった。｜板《いた》が｜二人《ふたり》の｜重《おも》みで、かすかにきしむ。

**ナレーション**：｜彼《かれ》は｜扉《とびら》を｜押《お》そうと｜手《て》を｜伸《の》ばしたが、ためらい、｜結局《けっきょく》ノックすることにした。

**ナレーション**：「コンコンコン」――ノックの｜音《おと》が、｜静《しず》まり｜返《かえ》った｜森《もり》の｜中《なか》でひときわ｜鮮明《せんめい》に｜響《ひび》いた。

**ナレーション**：｜数秒後《すうびょうご》、｜小屋《こや》の｜中《なか》から、かさこそと｜物音《ものおと》が｜聞《き》こえた。｜誰《だれ》かいる！

**ナレーション**：｜幼《おさな》い｜声《こえ》が｜扉《とびら》の｜向《む》こうから｜響《ひび》いた。はっきりとした｜警戒《けいかい》と｜恐怖《きょうふ》がにじんでいる。

**しっかり者の姉**：だ……｜誰《だれ》？　｜外《そと》にいるのは｜誰《だれ》……？

**ナレーション**：｜李杰《りけつ》は｜一瞬《いっしゅん》きょとんとした。この｜声《こえ》……｜聞《き》き｜覚《おぼ》えがある。

**李杰**：（｜心《こころ》の｜声《こえ》）これは……あの｜女《おんな》の｜子《こ》か？　｜列車《れっしゃ》にいた、あの｜家族《かぞく》の｜子《こ》どもか？

**李杰**：｜俺《おれ》たちは｜列車《れっしゃ》から｜降《お》りてきた｜乗客《じょうきゃく》だ。｜李杰《りけつ》という｜者《もの》だ、｜覚《おぼ》えてるかな？

**ナレーション**：｜扉《とびら》の｜向《む》こうは、｜数秒沈黙《すうびょうちんもく》した。

**しっかり者の姉**：（｜小声《こごえ》で）｜列車《れっしゃ》にいた……お｜兄《にい》ちゃん？

**李杰**：そうだ。｜霧《きり》の｜中《なか》で｜迷《まよ》ってしまって、｜仲間《なかま》が｜怪我《けが》をしてるんだ。｜中《なか》に｜入《はい》って、｜少《すこ》し｜休《やす》ませてもらえないかな？

**無邪気な弟**：（｜扉《とびら》の｜向《む》こうで｜小声《こごえ》で｜尋《たず》ねて）お｜姉《あね》ちゃん、どうしよう……

**ナレーション**：｜扉《とびら》の｜向《む》こうで、またひそひそ｜話《はなし》が｜続《つづ》いた。しばらくして、｜鍵《かぎ》の｜回《まわ》る｜音《おと》がした。

**ナレーション**：｜扉《とびら》がゆっくりと、すき｜間《ま》ほどだけ｜開《あ》いた。｜小《ちい》さな｜人影《ひとかげ》が｜扉《とびら》の｜陰《かげ》に｜隠《かく》れ、｜顔《かお》の｜半分《はんぶん》だけをのぞかせている。

**しっかり者の姉**：（おそるおそる）あなたたち……｜悪《わる》い｜人《ひと》じゃ、ないよね……？

**ナレーション**：｜李杰《りけつ》は、｜警戒心《けいかいしん》でいっぱいのその｜小《ちい》さな｜顔《かお》を｜見《み》て、｜思《おも》わず｜苦笑《くしょう》した。｜頭《あたま》をかき、できるだけ｜穏《おだ》やかな｜笑顔《えがお》をつくる。

**李杰**：｜悪《わる》い｜人《ひと》じゃないよ。｜約束《やくそく》する。

**ナレーション**：｜女《おんな》の｜子《こ》は｜李杰《りけつ》をじっと｜見《み》つめ、しばらくのあいだ、｜彼《かれ》の｜言葉《ことば》が｜信《しん》じられるか｜確《たし》かめているようだった。

**無邪気な弟**：（｜姉《あね》の｜後《うし》ろから｜顔《かお》を｜出《だ》して）あのお｜兄《にい》ちゃんだよ！　ぼく、｜覚《おぼ》えてる！

**ナレーション**：｜女《おんな》の｜子《こ》はそこでようやく｜安心《あんしん》して、｜扉《とびら》を｜開《あ》けた。

**ナレーション**：｜李杰《りけつ》は｜斎藤蓮《さいとうれん》を｜支《ささ》えて、｜小屋《こや》の｜中《なか》へ｜入《はい》った。｜室内《しつない》の｜調度《ちょうど》は｜簡素《かんそ》だが、｜塵《ちり》｜一《ひと》つなく｜片《かた》づいている。｜木《き》のテーブルが｜一《ひと》つ、｜椅子《いす》が｜四脚《よんきゃく》、｜隅《すみ》には｜石積《いしつ》みの｜暖炉《だんろ》があり、そばに｜薪《たきぎ》が｜積《つ》んである。

**ナレーション**：｜部屋《へや》の｜片側《かたがわ》には、｜清潔《せいけつ》な｜毛布《もうふ》をかけた｜一人用《ひとりよう》のベッドがあった。ベッドには、｜小《ちい》さな｜二《ふた》つの｜人影《ひとかげ》が｜起《お》き｜出《だ》したばかりの｜跡《あと》が｜残《のこ》っている。

**李杰**：｜入《い》れてくれてありがとう。そうだ、さっき｜李杰《りけつ》って｜名乗《なの》ったけど、｜君《きみ》たちの｜名前《なまえ》をまだ｜聞《き》いてなかったね。

**しっかり者の姉**：（｜少《すこ》し｜恥《は》ずかしそうに）わ……わたしは、｜小林陽菜《こばやしひな》……です……

**無邪気な弟**：（｜姉《あね》の｜後《うし》ろに｜隠《かく》れて）ぼくは｜小林翔太《こばやししょうた》！

**李杰**：｜陽菜《ひな》ちゃん、｜翔太《しょうた》くん、よろしくね。こちらは……

**斎藤蓮**：（じれったそうに｜遮《さえぎ》り）｜斎藤蓮《さいとうれん》です。もういいでしょう、｜挨拶《あいさつ》はここまでで。

**ナレーション**：｜斎藤蓮《さいとうれん》は｜足《あし》を｜引《ひ》きずってテーブルのそばへ｜行《い》き、どさりと｜椅子《いす》に｜腰《こし》を｜下《お》ろした。

**斎藤蓮**：（｜部屋《へや》の｜中《なか》を｜一瞥《いちべつ》してから、｜二人《ふたり》の｜子《こ》どもを｜見《み》て）ここには｜君《きみ》たち｜二人《ふたり》のチビだけですか？　ご｜両親《りょうしん》は？

**ナレーション**：｜斎藤蓮《さいとうれん》の｜口調《くちょう》はどこか｜高慢《こうまん》で、｜助《たす》けを｜求《もと》めている｜者《もの》のそれにはまるで｜聞《き》こえなかった。

**小林陽菜**：（うつむき、｜声《こえ》に｜泣《な》き｜声《ごえ》を｜帯《お》びて）パパとママは……いません……

**小林翔太**：（｜姉《あね》の｜服《ふく》の｜裾《すそ》をつかんで）ママは、すぐ｜帰《かえ》ってくるって｜言《い》ってた……

**李杰**：ご｜両親《りょうしん》はどこへ｜行《い》ったのか、｜教《おし》えてくれるかい？

**小林翔太**：パパ、すぐ｜戻《もど》るって｜言《い》ったのに……でも……

**ナレーション**：｜李杰《りけつ》は｜何《なに》も｜言《い》わなかった。｜斎藤蓮《さいとうれん》がきちんと｜座《すわ》れたか、｜支《ささ》えて｜確《たし》かめる。

**ナレーション**：さらに｜重要《じゅうよう》なのは、｜彼《かれ》らの｜両親《りょうしん》がいったいどこへ｜行《い》ったのか、｜戻《もど》ってくるのかということだ。

**ナレーション**：｜無数《むすう》の｜疑問《ぎもん》が｜胸《むね》に｜浮《う》かんだが、いまの｜彼《かれ》にできるのは、まず｜全員《ぜんいん》をしっかり｜休《やす》ませることだけだった。
