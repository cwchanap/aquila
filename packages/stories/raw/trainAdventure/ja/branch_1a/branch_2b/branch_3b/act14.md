# 第十四幕：つかの間の休息

**ナレーション**：｜李杰《りけつ》は｜小林智子《こばやしともこ》を｜支《ささ》えて｜小屋《こや》に｜入《はい》った。｜母子三人《ぼしさんにん》の｜再会《さいかい》で、｜小屋《こや》じゅうが｜温《あたた》かさに｜満《み》ちたが、｜李杰《りけつ》の｜注意《ちゅうい》はすぐに、ある｜別《べつ》の｜光景《こうけい》に｜引《ひ》き｜寄《よ》せられた。

**ナレーション**：｜斎藤蓮《さいとうれん》はすでに｜床《ゆか》に｜倒《たお》れて｜眠《ねむ》り｜込《こ》んでいた。｜椅子《いす》にさえ｜上《あ》がらず、そのまま｜木《き》の｜床《ゆか》に｜横《よこ》たわって、｜規則《きそく》｜正《ただ》しい｜寝息《ねいき》を｜立《た》てている。

**李杰**：（｜心《こころ》の｜声《こえ》）こいつ……｜本当《ほんとう》に｜疲《つか》れきってたんだな。

**ナレーション**：だがそれ｜以上《いじょう》に｜李杰《りけつ》を｜驚《おどろ》かせたのは、｜斎藤蓮《さいとうれん》のそばに、｜動物《どうぶつ》の｜毛皮《けがわ》で｜作《つく》ったらしい｜簡素《かんそ》な｜毛布《もうふ》が｜何枚《なんまい》かあったことだ。

**ナレーション**：その｜毛布《もうふ》は｜粗末《そまつ》ながら、｜保存状態《ほぞんじょうたい》がよく、｜傷《いた》みやカビの｜跡《あと》はない。｜斎藤蓮《さいとうれん》には｜一枚《いちまい》がかけられ、そばにはさらに｜何枚《なんまい》か、きちんと｜重《かさ》ねて｜置《お》かれていた。

**李杰**：（｜心《こころ》の｜声《こえ》）この｜毛布《もうふ》……｜誰《だれ》が｜用意《ようい》したんだ？　この｜家《いえ》は、｜明《あき》らかに｜誰《だれ》も｜住《す》んでいないように｜見《み》えたのに……

**小林智子**：（｜李杰《りけつ》の｜戸惑《とまど》いに｜気《き》づいて）この｜毛布《もうふ》……わたしたちがここに｜着《つ》いたときから、もうあったんです。ベッドのそばの｜戸棚《とだな》に｜入《はい》っていました。

**小林智子**：この｜家《いえ》……｜誰《だれ》かが｜定期的《ていきてき》に｜手入《てい》れしているみたいです。｜食《た》べ｜物《もの》も、｜毛布《もうふ》も、｜薪《たきぎ》も……｜何《なん》でもそろっていて。

**李杰**：そうですか……

**ナレーション**：｜李杰《りけつ》は｜眉《まゆ》をひそめたが、｜疲労《ひろう》のせいで、この｜問題《もんだい》を｜深《ふか》く｜考《かんが》えることができなかった。｜両脚《りょうあし》は｜鉛《なまり》を｜詰《つ》めたように｜重《おも》く、まぶたも｜勝手《かって》に｜下《さ》がり｜始《はじ》めている。

**小林智子**：｜李杰《りけつ》さん……とてもお｜疲《つか》れのようです。まず｜休《やす》んでください。

**李杰**：いえ……｜俺《おれ》はまだ、ご｜主人《しゅじん》を｜探《さが》しに｜行《い》かないと……

**小林智子**：（｜首《くび》を｜振《ふ》って）いまの｜状態《じょうたい》で｜出《で》ていっても、｜危険《きけん》に｜陥《おちい》るだけです。まず｜休《やす》んで、｜体力《たいりょく》を｜取《と》り｜戻《もど》してからにしてください。

**小林智子**：それに……｜霧《きり》がこんなに｜濃《こ》いと、｜見通《みとお》しも｜利《き》きませんし。｜少《すこ》し｜休《やす》めば、｜霧《きり》も｜薄《うす》れるかもしれません。

**ナレーション**：｜李杰《りけつ》は｜反論《はんろん》しようとしたが、｜体《からだ》の｜疲《つか》れで｜言葉《ことば》が｜出《で》なかった。｜小林智子《こばやしともこ》の｜言《い》うとおりだと｜分《わ》かっている――｜確《たし》かに、｜休息《きゅうそく》が｜必要《ひつよう》だ。

**李杰**：……じゃあ、｜少《すこ》しだけ｜眠《ねむ》らせてもらいます。ただ、｜長《なが》くはなしで。｜長《なが》くても｜一時間《いちじかん》か｜二時間《にじかん》までで。

**小林智子**：（うなずいて）はい。｜起《お》こしますね。

**ナレーション**：｜小林智子《こばやしともこ》は｜二人《ふたり》の｜子《こ》どもを｜連《つ》れてベッドに｜上《あ》がった。｜陽菜《ひな》と｜翔太《しょうた》は｜母親《ははおや》にぴったり｜寄《よ》り｜添《そ》い、まもなく｜眠《ねむ》りに｜落《お》ちた。

**ナレーション**：｜李杰《りけつ》は｜床《ゆか》に｜毛皮《けがわ》の｜毛布《もうふ》を｜一枚《いちまい》｜敷《し》き、｜戸口《とぐち》に｜近《ちか》い｜場所《ばしょ》を｜選《えら》んで｜横《よこ》になった。｜何《なに》か｜物音《ものおと》があれば、すぐに｜反応《はんのう》できるように。

**ナレーション**：｜毛布《もうふ》は｜少《すこ》しごわごわしていたが、｜意外《いがい》にも｜暖《あたた》かかった。｜李杰《りけつ》は｜目《め》を｜閉《と》じ、ほとんど｜一瞬《いっしゅん》で｜深《ふか》い｜眠《ねむ》りに｜落《お》ちた。

**ナレーション**：｜小屋《こや》には、｜五人《ごにん》の｜規則《きそく》｜正《ただ》しい｜寝息《ねいき》だけが｜残《のこ》った。｜窓《まど》の｜外《そと》の｜霧《きり》は｜相変《あいか》わらず｜濃《こ》く、｜世界《せかい》を、｜一面《いちめん》の｜茫漠《ぼうばく》の｜中《なか》に｜閉《と》じ｜込《こ》めている。

**ナレーション**：どれくらいたったのか。｜一時間《いちじかん》かもしれないし、｜二時間《にじかん》かもしれない。それ｜以上《いじょう》かもしれない。

**ナレーション**：｜李杰《りけつ》はゆっくりと｜目《め》を｜開《あ》けた。｜意識《いしき》が｜眠《ねむ》りの｜底《そこ》から｜浮《う》かび｜上《あ》がり、ここがどこなのか｜思《おも》い｜出《だ》すのに、｜数秒《すうびょう》かかった。

**ナレーション**：｜部屋《へや》の｜中《なか》は｜静《しず》かだった。｜斎藤蓮《さいとうれん》は｜相変《あいか》わらず｜床《ゆか》でぐっすり｜眠《ねむ》っていて、ベッドの｜母子三人《ぼしさんにん》もまだ｜眠《ねむ》っている。｜起《お》きているのは、テーブルのそばに｜座《すわ》った｜小林智子《こばやしともこ》だけだ。

**ナレーション**：｜彼女《かのじょ》は、｜李杰《りけつ》が｜目《め》を｜覚《さ》ましたのを｜見《み》て、｜静《しず》かに｜声《こえ》をかけた。

**小林智子**：（｜小声《こごえ》で）｜目《め》が｜覚《さ》めましたか？　｜何《なに》か｜召《め》し｜上《あ》がってください。

**ナレーション**：｜李杰《りけつ》は｜体《からだ》を｜起《お》こし、テーブルの｜上《うえ》に、｜簡単《かんたん》な｜食《た》べ｜物《もの》が｜並《なら》んでいるのを｜見《み》た。パンと、｜木《こ》の｜実《み》のようなものがいくつか。

**ナレーション**：そばには｜陶器《とうき》の｜椀《わん》もあり、｜中《なか》には｜温《あたた》かいスープが｜入《はい》っている。ほのかな｜香《かお》りが｜漂《ただよ》っていた。

**李杰**：（テーブルのそばへ｜行《い》って｜座《すわ》り）これって……

**小林智子**：｜台所《だいどころ》に｜食材《しょくざい》があったので。あなたはこのあとまた｜出《で》ていくのだからと｜思《おも》って、｜簡単《かんたん》なスープを｜作《つく》ったんです。

**李杰**：ありがとうございます。

**ナレーション**：｜李杰《りけつ》は｜椀《わん》を｜持《も》ち｜上《あ》げ、｜一口《ひとくち》｜飲《の》んだ。スープは｜淡白《たんぱく》だったが、｜温《あたた》かい｜液体《えきたい》が｜胃《い》に｜流《なが》れ｜込《こ》み、ずいぶん｜楽《らく》になった。

**小林智子**：（｜真剣《しんけん》に｜李杰《りけつ》を｜見《み》つめて）｜李杰《りけつ》さん、｜本当《ほんとう》に……｜心《こころ》から｜感謝《かんしゃ》しています。あなたがいなければ、わたしはもしかしたら……

**小林智子**：それにあなたは、｜主人《しゅじん》を｜探《さが》すのまで｜手伝《てつだ》ってくださる……どうお｜礼《れい》をすればいいのか、｜本当《ほんとう》に｜分《わ》かりません。

**李杰**：（｜首《くび》を｜振《ふ》って）そんなことは｜言《い》わないでください。｜俺《おれ》は、やるべきことをやっただけです。

**小林智子**：どうか｜気《き》をつけて。もし……もし｜危険《きけん》すぎるようなら、｜無理《むり》はしないでください。あなたには、もう｜十分《じゅうぶん》すぎるほど｜助《たす》けていただきました。

**李杰**：そうします。

**ナレーション**：｜李杰《りけつ》は｜手早《てばや》くテーブルの｜食《た》べ｜物《もの》を｜食《た》べ｜終《お》え、｜体力《たいりょく》が｜少《すこ》し｜戻《もど》ったのを｜感《かん》じた。｜立《た》ち｜上《あ》がり、｜戸口《とぐち》へ｜向《む》かう。

**小林智子**：（｜立《た》ち｜上《あ》がって）｜李杰《りけつ》さん……お｜願《ねが》いします。

**ナレーション**：｜李杰《りけつ》はうなずき、｜扉《とびら》を｜押《お》して｜出《で》ていった。

**ナレーション**：｜外《そと》の｜霧《きり》は｜相変《あいか》わらず｜濃《こ》いが、さっきよりほんの｜少《すこ》し｜薄《うす》くなったようだった。｜少《すく》なくとも｜視界《しかい》は、いくらかよくなっている。

**ナレーション**：｜李杰《りけつ》は｜深《ふか》く｜息《いき》を｜吸《す》い、｜先《さき》ほど｜見《み》つけた｜足跡《あしあと》に｜沿《そ》って、さらに｜北《きた》へ｜歩《ある》き｜出《だ》した。

**ナレーション**：｜今度《こんど》は｜支《ささ》えなければならない｜相手《あいて》がいないので、ずっと｜速《はや》く｜進《すす》める。｜足跡《あしあと》は｜土《つち》の｜上《うえ》にくっきりと｜見《み》え、｜方向《ほうこう》を｜示《しめ》してくれていた。

**ナレーション**：｜彼《かれ》は｜北《きた》へ｜向《む》かい、｜林《はやし》を｜抜《ぬ》け、｜小川《おがわ》を｜越《こ》えた。｜時間《じかん》は｜歩《ある》くうちに｜過《す》ぎていったが、｜正確《せいかく》にどれほどたったのかは｜分《わ》からなかった。

**ナレーション**：やがて、｜前方《ぜんぽう》に｜分《わ》かれ｜道《みち》が｜現《あらわ》れた。

**ナレーション**：｜主《おも》な｜道《みち》は｜北《きた》へ｜続《つづ》いているが、｜左《ひだり》には、やや｜細《ほそ》い｜支道《しどう》があった。｜目立《めだ》たず、｜霧《きり》と｜木々《きぎ》にほとんど｜隠《かく》されている。

**ナレーション**：｜李杰《りけつ》はしゃがみ｜込《こ》み、｜足跡《あしあと》を｜念入《ねんい》りに｜調《しら》べた。｜男性《だんせい》の｜足跡《あしあと》は、ここで｜左《ひだり》の｜支道《しどう》へ｜折《お》れていた。

**李杰**：（｜心《こころ》の｜声《こえ》）｜彼《かれ》はこの｜道《みち》を｜行《い》ったのか……

**ナレーション**：｜李杰《りけつ》は｜立《た》ち｜上《あ》がり、｜足跡《あしあと》に｜続《つづ》いて｜支道《しどう》へ｜入《はい》ろうとした。

**ナレーション**：だがそのとき、その｜支道《しどう》の｜霧《きり》の｜中《なか》に、｜人影《ひとかげ》が｜現《あらわ》れた。

**ナレーション**：｜一人《ひとり》の｜男《おとこ》が、｜支道《しどう》から｜歩《ある》いて｜出《で》てきた。｜足取《あしど》りはやや｜覚束《おぼつか》なく、ひどく｜疲《つか》れているように｜見《み》える。

**ナレーション**：｜男《おとこ》が｜近《ちか》づいたとき、｜李杰《りけつ》はその｜顔《かお》をはっきりと｜見《み》た。

**李杰**：（｜驚《おどろ》いて）あなたは……

**ナレーション**：それは、｜李杰《りけつ》の｜見覚《みおぼ》えのある｜顔《かお》だった。｜列車《れっしゃ》の｜中《なか》で、｜子《こ》どもを｜抱《いだ》いていた、あの｜落《お》ち｜着《つ》いた｜男《おとこ》。｜陽菜《ひな》と｜翔太《しょうた》の｜父親《ちちおや》だ。

**ナレーション**：｜男《おとこ》も｜李杰《りけつ》に｜気《き》づき、｜顔《かお》に｜同《おな》じ｜驚《おどろ》きがよぎった。

**中年の男**：あなたは……｜列車《れっしゃ》に｜乗《の》っていた……

**ナレーション**：｜二人《ふたり》は｜分《わ》かれ｜道《みち》で｜出会《であ》い、｜霧《きり》が｜二人《ふたり》の｜間《あいだ》をゆっくりと｜流《なが》れた。

**ナレーション**：｜運命《うんめい》の｜歯車《はぐるま》が、この｜瞬間《しゅんかん》、ふたたび｜回《まわ》り｜始《はじ》めた。
