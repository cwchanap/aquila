# 第十五幕：分かれ道での出会い

**ナレーション**：｜二人《ふたり》は｜霧《きり》の｜中《なか》で｜数秒《すうびょう》、｜見《み》つめ｜合《あ》った。どちらも｜相手《あいて》の｜顔《かお》に、｜驚《おどろ》きを｜見《み》て｜取《と》った。

**李杰**：｜俺《おれ》は｜李杰《りけつ》といいます。あなたは……｜陽菜《ひな》ちゃんと｜翔太《しょうた》くんのお｜父《とう》さんですね？

**中年の男**：（きょとんとして、それからうなずき）ええ……｜小林雄大《こばやしゆうだい》といいます。あなたは……どうしてこんなところに？

**李杰**：あなたを｜探《さが》しに｜来《き》たんです。｜奥《おく》さんがとても｜心配《しんぱい》していますよ。

**小林雄大**：（｜顔色《かおいろ》が｜変《か》わって）｜智子《ともこ》が？　あいつは……｜無事《ぶじ》ですか？　｜子《こ》どもたちは？

**李杰**：｜子《こ》どもたちは｜無事《ぶじ》です。ただ｜奥《おく》さんは……あなたを｜探《さが》しに｜出《で》て、｜途中《とちゅう》で｜転《ころ》んで、｜足首《あしくび》をひねってしまって。

**小林雄大**：（｜顔《かお》によぎる｜自責《じせき》の｜色《いろ》）｜何《なん》だって？　あいつが｜怪我《けが》を？

**李杰**：｜奥《おく》さんはもう｜小屋《こや》まで｜送《おく》り｜届《とど》けました。いまは｜子《こ》どもたちと｜一緒《いっしょ》で、｜安全《あんぜん》です。

**小林雄大**：（｜深《ふか》く｜頭《あたま》を｜下《さ》げて）｜本当《ほんとう》に……ありがとうございます。｜俺《おれ》は……こんなに｜時間《じかん》がかかるとは、｜思《おも》ってもみなかったんです……

**ナレーション**：｜李杰《りけつ》はそこで｜初《はじ》めて｜気《き》づいた。｜小林雄大《こばやしゆうだい》は｜背中《せなか》に｜巨大《きょだい》なリュックを｜背負《せお》っているだけでなく、｜腰《こし》には｜錆《さ》びた｜剣《けん》まで｜下《さ》げている。

**李杰**：その｜剣《けん》は……どこで｜手《て》に｜入《い》れたんですか？

**小林雄大**：（｜腰《こし》の｜剣《けん》を｜見下《みお》ろして）ああ、これか……｜駅《えき》を｜調《しら》べているときに｜見《み》つけたんだ。

**小林雄大**：｜列車《れっしゃ》を｜降《お》りたあと、｜駅《えき》の｜中《なか》をあちこち｜探《さが》して、｜何《なに》か｜使《つか》えるものがないか｜見《み》て｜回《まわ》った。｜警備室《けいびしつ》でこの｜剣《けん》と、｜地図《ちず》を｜一枚《いちまい》｜見《み》つけたんだ。

**李杰**：（｜驚《おどろ》いて）｜地図《ちず》？　｜駅《えき》で｜見《み》つけたんですか？

**小林雄大**：ああ。｜地図《ちず》には｜付近《ふきん》の｜道筋《みちすじ》といくつかの｜場所《ばしょ》が｜書《か》いてあった。この｜支道《しどう》の｜先《さき》に｜建物《たてもの》があると｜書《か》いてあったのを｜見《み》て、ここへ｜来《き》てみることにしたんだ。

**李杰**：（｜心《こころ》の｜声《こえ》）なるほど……｜駅《えき》で｜見《み》かけた、あの｜物色《ぶっしょく》された｜跡《あと》は、この｜人《ひと》が｜残《のこ》したものか。｜道理《どうり》で、｜俺《おれ》は｜何《なに》も｜見《み》つからなかったわけだ……

**ナレーション**：｜李杰《りけつ》はこの｜考《かんが》えを｜口《くち》にせず、ただうなずいた。

**ナレーション**：｜小林雄大《こばやしゆうだい》が｜背負《せお》った｜巨大《きょだい》なリュックは、ずっしりと｜重《おも》そうで、ぱんぱんに｜膨《ふく》らんでいる。

**李杰**：｜背負《せお》っているのは……

**小林雄大**：（｜体《からだ》の｜向《む》きを｜変《か》え、｜支道《しどう》を｜指《ゆび》さして）この｜道《みち》に｜沿《そ》って｜進《すす》んだら、｜突《つ》き｜当《あ》たりにもう｜一軒《いっけん》、｜家《いえ》があったんだ。

**小林雄大**：その｜家《いえ》には｜食《た》べ｜物《もの》がたくさんあった！　パン、｜干《ほ》し｜肉《にく》、｜木《こ》の｜実《み》、それに｜水《みず》も……｜大《おお》きなリュックいっぱいに｜詰《つ》めてきたよ。

**小林雄大**：｜長《なが》く｜歩《ある》いて｜疲《つか》れていたから、そこで｜少《すこ》し｜休《やす》んだんだが……どうも｜寝過《ねす》ごしてしまったらしくてな……

**小林雄大**：｜目《め》が｜覚《さ》めたときには、どれくらいたったのか｜分《わ》からなくて、｜慌《あわ》てて｜引《ひ》き｜返《かえ》してきた……まさか｜智子《ともこ》にこんなに｜心配《しんぱい》をかけていたとは……

**ナレーション**：｜小林雄大《こばやしゆうだい》の｜口《くち》ぶりは、｜自責《じせき》の｜念《ねん》に｜満《み》ちていた。｜自分《じぶん》の｜行動《こうどう》が｜妻《つま》をこれほど｜心配《しんぱい》させるとは、｜思《おも》っていなかったのだろう。

**李杰**：｜食《た》べ｜物《もの》が｜見《み》つかったのなら｜何《なに》よりです。｜奥《おく》さんも｜子《こ》どもたちも｜待《ま》っています、｜早《はや》く｜戻《もど》ってあげてください。

**小林雄大**：ああ！　いますぐ……｜待《ま》ってくれ、｜君《きみ》は？　どこへ｜行《い》くんだ？

**李杰**：あなたがいま｜言《い》った、あの｜家《いえ》へ｜行《い》こうと｜思《おも》います。

**小林雄大**：｜何《なん》だって？　どうして？　あの｜小屋《こや》は、ほら……

**李杰**：｜今《いま》あの｜小屋《こや》には、あなたの｜奥《おく》さんと｜二人《ふたり》のお｜子《こ》さん、それにもう｜一人怪我人《ひとりけがにん》がいます。｜窮屈《きゅうくつ》すぎます。

**李杰**：ご｜家族《かぞく》は｜一緒《いっしょ》にいるべきです。｜俺《おれ》は、｜別《べつ》の｜家《いえ》に｜行《い》くほうがいいでしょう。

**小林雄大**：（｜首《くび》を｜振《ふ》り）だめだ！　そんなこと……｜君《きみ》は｜俺《おれ》たちのために、もう｜十分《じゅうぶん》すぎるほどやってくれたのに……

**李杰**：｜構《かま》いません。どうせ｜俺《おれ》は｜一人《ひとり》ですから、どこにいても｜同《おな》じです。

**小林雄大**：だが……

**ナレーション**：｜小林雄大《こばやしゆうだい》は｜李杰《りけつ》の｜揺《ゆ》るがない｜眼差《まなざ》しを｜見《み》て、｜説得《せっとく》できないと｜悟《さと》った。しばらく｜黙《だま》り｜込《こ》んでから、リュックの｜中《なか》から｜食《た》べ｜物《もの》の｜大《おお》きな｜包《つつ》みを｜取《と》り｜出《だ》した。

**小林雄大**：それなら……せめて、｜食《た》べ｜物《もの》を｜少《すこ》し｜持《も》っていってくれ。さっき｜見《み》つけたものだ。

**ナレーション**：｜彼《かれ》は｜布《ぬの》で｜包《つつ》んだ｜包《つつ》みを｜李杰《りけつ》に｜差《さ》し｜出《だ》した。｜受《う》け｜取《と》ると、ずっしりとした｜重《おも》みが｜伝《つた》わってくる。

**小林雄大**：｜中《なか》にはパンと｜干《ほ》し｜肉《にく》と、｜木《こ》の｜実《み》が｜入《はい》っている。しばらくは｜足《た》りるはずだ。

**小林雄大**：それに、あの｜家《いえ》にはまだ｜食《た》べ｜物《もの》がたくさんあるんだ、｜全部《ぜんぶ》は｜持《も》ってこなかった。あそこへ｜行《い》けば、｜食《た》べ｜物《もの》に｜困《こま》ることはないだろう。

**李杰**：ありがとうございます。

**小林雄大**：（｜真剣《しんけん》に）｜礼《れい》を｜言《い》うのは｜俺《おれ》のほうだ。｜君《きみ》がいなかったら……｜俺《おれ》は｜本当《ほんとう》にどうしていいか｜分《わ》からなかった。

**ナレーション**：｜李杰《りけつ》はうなずき、ふと｜何《なに》かを｜思《おも》い｜出《だ》した。

**李杰**：そうだ、｜小屋《こや》にはもう｜一人《ひとり》、｜斎藤蓮《さいとうれん》という｜人《ひと》がいます。｜彼《かれ》も｜足《あし》を｜怪我《けが》していて、しばらく｜歩《ある》けません。

**李杰**：｜足《あし》が｜治《なお》ったら、こちらの｜家《いえ》に｜俺《おれ》を｜訪《たず》ねてくるよう、｜伝《つた》えてもらえませんか。そうすれば、ご｜家族《かぞく》ももっと｜広《ひろ》く｜使《つか》えますから。

**小林雄大**：｜斎藤《さいとう》……ああ、｜分《わ》かった、｜伝《つた》えておこう。｜歩《ある》けるようになったら、｜君《きみ》のところへ｜行《い》かせるよ。

**李杰**：｜俺《おれ》はその｜家《いえ》を｜拠点《きょてん》にします。｜何《なに》か｜助《たす》けが｜必要《ひつよう》なときは、いつでも｜来《き》てください。｜同《おな》じように、｜俺《おれ》も｜何《なに》か｜必要《ひつよう》になったら、あなたたちを｜訪《たず》ねます。

**小林雄大**：（うなずき）ああ。｜連絡《れんらく》を｜取《と》り｜合《あ》おう。

**ナレーション**：｜小林雄大《こばやしゆうだい》はしばらく｜黙《だま》ってから、｜顔《かお》を｜上《あ》げて｜李杰《りけつ》を｜見《み》た。

**小林雄大**：｜李杰《りけつ》……｜君《きみ》は、どうやって｜帰《かえ》るか｜考《かんが》えたことはあるか？　｜帰《かえ》る……｜俺《おれ》たちのもとの｜世界《せかい》へ。

**ナレーション**：｜李杰《りけつ》は｜一瞬《いっしゅん》きょとんとして、それから｜首《くび》を｜振《ふ》った。

**李杰**：｜分《わ》かりません。｜俺《おれ》もそのことを｜考《かんが》えていました。たぶん……あちこち｜探《さが》し｜回《まわ》って、｜何《なに》か｜手《て》がかりが｜見《み》つかるか、｜試《ため》すしかないでしょう。

**小林雄大**：｜俺《おれ》もそう｜考《かんが》えていた。この｜近《ちか》くを｜探索《たんさく》して、｜何《なに》か｜見《み》つかるかどうか｜見《み》てみるよ。

**小林雄大**：もし｜重要《じゅうよう》な｜手《て》がかりが｜見《み》つかったら……｜定期的《ていきてき》に｜情報《じょうほう》を｜交換《こうかん》しよう。｜帰《かえ》る｜方法《ほうほう》が｜見《み》つかるかもしれない。

**李杰**：ええ、それはいい｜考《かんが》えです。

**小林雄大**：（｜真剣《しんけん》に）｜礼《れい》を｜言《い》うのは｜俺《おれ》のほうだ。｜君《きみ》がいなかったら……｜俺《おれ》は｜本当《ほんとう》にどうしていいか｜分《わ》からなかった。

**ナレーション**：そして｜李杰《りけつ》は｜身《み》をひるがえし、あの｜未知《みち》へ｜通《つう》じる｜支道《しどう》へ｜足《あし》を｜踏《ふ》み｜入《い》れた。

**ナレーション**：｜支道《しどう》は｜本道《ほんどう》よりずっと｜狭《せま》く、｜両側《りょうがわ》の｜木々《きぎ》はいっそう｜茂《しげ》っている。｜霧《きり》もさらに｜濃《こ》くなったようで、｜視界《しかい》はいっそう｜悪《わる》くなった。

**ナレーション**：だが｜地面《じめん》の｜足跡《あしあと》はまだはっきりしている――｜小林雄大《こばやしゆうだい》が｜行《い》き｜来《き》したときの｜痕跡《こんせき》だ。｜行《い》きの｜足跡《あしあと》と｜帰《かえ》りの｜足跡《あしあと》は｜少《すこ》し｜重《かさ》なっているが、おおよその｜方向《ほうこう》ははっきりしていた。

**ナレーション**：｜李杰《りけつ》は｜足跡《あしあと》に｜沿《そ》って｜進《すす》んだ。｜支道《しどう》は｜曲《ま》がりくねり、｜林《はやし》の｜間《あいだ》を｜縫《ぬ》っていく。｜時間《じかん》は｜歩《ある》くうちに｜過《す》ぎていったが、｜正確《せいかく》にどれほどたったのかは｜分《わ》からなかった。

**ナレーション**：｜三十分《さんじゅっぷん》。｜四十分《よんじゅっぷん》。｜一時間《いちじかん》。

**ナレーション**：ついに、｜前方《ぜんぽう》の｜霧《きり》の｜中《なか》に、｜一軒《いっけん》の｜家《いえ》の｜輪郭《りんかく》がしだいに｜現《あらわ》れた。

**ナレーション**：それは｜木造《もくぞう》の｜小屋《こや》で、｜造《つく》りは｜先《さき》ほどのものに｜似《に》ているが、｜明《あき》らかにひとまわり｜小《ちい》さい。｜一階建《いっかいだ》てで、｜屋根《やね》も｜低《ひく》めだった。

**ナレーション**：だが、｜手入《てい》れはやはり｜行《い》き｜届《とど》いていた。｜木材《もくざい》は｜腐《くさ》っておらず、｜窓《まど》は｜無傷《むきず》で、｜煙突《えんとつ》はまっすぐに｜立《た》っている。

**李杰**：（｜心《こころ》の｜声《こえ》）ここだな。

**ナレーション**：｜李杰《りけつ》は｜前《まえ》へ｜進《すす》み、｜手《て》を｜伸《の》ばして｜扉《とびら》を｜押《お》した。｜鍵《かぎ》はかかっておらず、｜軽《かる》く｜押《お》しただけで｜開《あ》いた。

**ナレーション**：｜室内《しつない》の｜間取《まど》りは｜簡単《かんたん》だった。｜小《ちい》さな｜木《き》のテーブルに｜椅子《いす》が｜二脚《にきゃく》、｜隅《すみ》には｜小《ちい》さな｜暖炉《だんろ》。｜壁際《かべぎわ》には｜一人用《ひとりよう》のベッドがあり、ベッドのそばには｜粗末《そまつ》な｜戸棚《とだな》がある。

**ナレーション**：｜台所《だいどころ》の｜調理台《ちょうりだい》には、たくさんの｜食《た》べ｜物《もの》が｜並《なら》べてあった。パン、｜干《ほ》し｜肉《にく》、｜木《こ》の｜実《み》、それに｜穀物《こくもつ》か｜何《なに》かが｜入《はい》っているらしい｜陶器《とうき》の｜壺《つぼ》がいくつか。

**ナレーション**：｜小林雄大《こばやしゆうだい》の｜言《い》うとおり――ここの｜食《た》べ｜物《もの》は｜本当《ほんとう》に｜多《おお》かった。｜彼《かれ》が｜一部《いちぶ》を｜持《も》っていったあとでも、｜残《のこ》りだけで、｜一人《ひとり》が｜長《なが》いあいだ｜暮《く》らすには｜十分《じゅうぶん》だ。

**李杰**：（｜心《こころ》の｜声《こえ》）この｜食《た》べ｜物《もの》……それに、さっきの｜家《いえ》にあった｜毛布《もうふ》も……いったい｜誰《だれ》が｜用意《ようい》したんだ？

**ナレーション**：だがいまは、｜疲労《ひろう》がふたたび｜胸《むね》に｜押《お》し｜寄《よ》せてきた。｜李杰《りけつ》は、｜休息《きゅうそく》が｜必要《ひつよう》だと｜分《わ》かっていた。
