# 第十六幕：銀月湖へ

**ナレーション**：｜李杰《りけつ》は｜自分《じぶん》がどれだけ｜眠《ねむ》ったのか｜分《わ》からなかった。ふたたび｜目《め》を｜開《あ》けると、｜窓《まど》の｜外《そと》は｜相変《あいか》わらず、あの｜永遠《えいえん》の｜紫《むらさき》の｜月光《げっこう》だった。

**ナレーション**：｜彼《かれ》は｜体《からだ》を｜起《お》こし、こわばった｜体《からだ》を｜少《すこ》し｜動《うご》かした。ぐっすり｜眠《ねむ》れて、｜体《からだ》の｜疲《つか》れはずいぶん｜回復《かいふく》した。

**李杰**：（｜心《こころ》の｜声《こえ》）そろそろ｜出発《しゅっぱつ》しないと。

**ナレーション**：｜彼《かれ》はポケットから、｜斎藤《さいとう》から｜手《て》に｜入《い》れた｜地図《ちず》を｜取《と》り｜出《だ》し、じっくりと｜眺《なが》めた。

**ナレーション**：｜地図《ちず》には、いくつかの｜主要《しゅよう》な｜地点《ちてん》がはっきり｜示《しめ》されている。いま｜彼《かれ》がいる｜場所《ばしょ》は、「｜幽冥《ゆうめい》の｜都《みやこ》」と｜記《しる》された｜駅《えき》の｜近《ちか》くだ。

**ナレーション**：｜北《きた》へ｜向《む》かう｜主要《しゅよう》な｜道《みち》は「｜亡者《もうじゃ》の｜峡谷《きょうこく》」へ｜通《つう》じていて、そこにはもう｜一《ひと》つ｜駅《えき》がある。そして｜地図《ちず》の｜西側《にしがわ》には、やや｜細《ほそ》い｜支道《しどう》があり、「｜銀月湖《ぎんげつこ》」という｜場所《ばしょ》へ｜続《つづ》いていた。

**李杰**：（｜低《ひく》くつぶやいて）｜銀月湖《ぎんげつこ》……

**ナレーション**：その｜名前《なまえ》は｜美《うつく》しく｜響《ひび》き、まわりの｜不吉《ふきつ》な｜気配《けはい》に｜満《み》ちた｜地名《ちめい》とは、まるで｜違《ちが》っていた。

**李杰**：（｜心《こころ》の｜声《こえ》）｜亡者《もうじゃ》の｜峡谷《きょうこく》のほうは、｜小林《こばやし》さんが｜探索《たんさく》するだろう。｜情報交換《じょうほうこうかん》をしようと｜言《い》ったんだ、あの｜道《みち》は｜彼《かれ》に｜任《まか》せよう。

**李杰**：（｜心《こころ》の｜声《こえ》）｜俺《おれ》は｜銀月湖《ぎんげつこ》を｜見《み》てくる。｜何《なに》か｜手《て》がかりが｜見《み》つかるかもしれない。

**ナレーション**：｜決断《けつだん》すると、｜李杰《りけつ》は｜荷物《にもつ》をまとめ｜始《はじ》めた。あたりを｜見回《みまわ》し、｜斎藤《さいとう》に｜伝言《でんごん》を｜残《のこ》せるものを｜探《さが》した。

**ナレーション**：｜台所《だいどころ》の｜引《ひ》き｜出《だ》しに｜古《ふる》い｜紙《かみ》が｜何枚《なんまい》かあり、｜一枚《いちまい》｜取《と》り｜出《だ》した。だが｜字《じ》を｜書《か》こうとして、｜問題《もんだい》に｜気《き》づいた――ペンがない。

**李杰**：（｜引《ひ》き｜出《だ》しや｜戸棚《とだな》をひっくり｜返《かえ》して）くそ……｜何《なに》もない……

**ナレーション**：｜彼《かれ》は｜家《いえ》じゅうを｜探《さが》し｜回《まわ》ったが、｜字《じ》を｜書《か》ける｜道具《どうぐ》はどこにもなかった。ペンも、｜炭《すみ》の｜筆記具《ひっきぐ》も、｜何《なに》もない。

**李杰**：（｜心《こころ》の｜声《こえ》）まあいい……｜斎藤《さいとう》の｜足《あし》の｜怪我《けが》はあんなに｜重《おも》い、すぐには｜来《こ》られないだろう。｜歩《ある》けるようになるころには、｜俺《おれ》はもう｜戻《もど》っているかもしれない。

**ナレーション**：｜李杰《りけつ》は｜伝言《でんごん》を｜残《のこ》すことを｜諦《あきら》め、｜食《た》べ｜物《もの》と｜水《みず》の｜整理《せいり》を｜始《はじ》めた。｜雄大《ゆうだい》からもらった｜食《た》べ｜物《もの》に、｜家《いえ》の｜中《なか》で｜見《み》つけた｜補給品《ほきゅうひん》を｜加《くわ》えて、すべて｜一《ひと》つの｜布袋《ぬのぶくろ》に｜詰《つ》める。

**ナレーション**：｜水筒《すいとう》にもきれいな｜水《みず》を｜満《み》たした。｜地図《ちず》と｜食《た》べ｜物《もの》が｜揃《そろ》っていることを｜確《たし》かめてから、｜扉《とびら》を｜押《お》して｜外《そと》へ｜出《で》た。

**ナレーション**：｜霧《きり》は｜相変《あいか》わらず｜濃《こ》いが、｜最初《さいしょ》のころに｜比《くら》べればずっと｜薄《うす》くなった。｜少《すく》なくとも、｜十数《じゅうすう》メートル｜先《さき》の｜景色《けしき》は｜見《み》えるようになっている。

**ナレーション**：｜李杰《りけつ》は｜地図《ちず》に｜示《しめ》された｜道筋《みちすじ》に｜沿《そ》って、｜西《にし》へ｜向《む》かった。｜支道《しどう》で、｜主要《しゅよう》な｜道《みち》よりずっと｜狭《せま》いが、｜路面《ろめん》は｜意外《いがい》にも｜平《たい》らだった。

**ナレーション**：｜足《あし》もとは｜固《かた》い｜土《つち》と｜砂利《じゃり》で、｜両側《りょうがわ》には｜鬱蒼《うっそう》とした｜林《はやし》が｜続《つづ》く。｜木々《きぎ》は｜霧《きり》の｜中《なか》に｜見《み》え｜隠《かく》れし、ときおり｜風《かぜ》が｜葉《は》を｜揺《ゆ》らす｜音《おと》がする。

**ナレーション**：｜李杰《りけつ》は｜警戒《けいかい》を｜保《たも》ち、｜歩《ある》きながらあたりを｜観察《かんさつ》した。だが｜道中《どうちゅう》はずっと｜穏《おだ》やかで、｜危険《きけん》には｜何《なに》も｜出《で》くわさなかった。

**ナレーション**：｜時間《じかん》は｜歩《ある》くうちに｜過《す》ぎていく。｜一時間《いちじかん》。｜一時間半《いちじかんはん》。｜二時間《にじかん》。

**ナレーション**：ついに、｜前方《ぜんぽう》の｜林《はやし》がまばらになってきた。｜木々《きぎ》の｜幹《みき》の｜隙間《すきま》から、｜李杰《りけつ》は｜開《ひら》けた｜空間《くうかん》と、｜銀青色《ぎんせいしょく》の｜光《ひかり》のきらめきを｜目《め》にした。

**李杰**：（｜足《あし》を｜止《と》めて）｜着《つ》いた。

**ナレーション**：｜彼《かれ》は｜森《もり》を｜出《で》て、｜目《め》の｜前《まえ》の｜光景《こうけい》に｜息《いき》をのんだ。

**ナレーション**：｜銀月湖《ぎんげつこ》は、｜谷《たに》の｜中《なか》に｜静《しず》かに｜横《よこ》たわっていた。｜巨大《きょだい》な｜鏡《かがみ》のように、｜空《そら》に｜浮《う》かぶ｜二《ふた》つの｜月《つき》を｜完璧《かんぺき》に｜映《うつ》している。｜湖水《こすい》は｜夢《ゆめ》のような｜銀青色《ぎんせいしょく》で、｜月光《げっこう》に｜照《て》らされて、やわらかな｜光《ひかり》を｜放《はな》っていた。

**ナレーション**：｜湖面《こめん》には、｜光《ひかり》を｜放《はな》つ｜花《はな》がたくさん｜浮《う》かんでいた。｜睡蓮《すいれん》のようでいて、ほのかな｜銀色《ぎんいろ》の｜光《ひかり》を｜放《はな》っている。｜湖面《こめん》で｜静《しず》かに｜揺《ゆ》れ、｜湖《みずうみ》｜全体《ぜんたい》に、｜神秘的《しんぴてき》で｜聖《せい》なる｜気配《けはい》を｜添《そ》えていた。

**ナレーション**：｜湖《みずうみ》のまわりには｜開《ひら》けた｜草地《くさち》が｜広《ひろ》がり、｜青草《あおくさ》がそよ｜風《かぜ》に｜静《しず》かに｜揺《ゆ》れている。｜空気《くうき》にはほのかな｜花《はな》の｜香《かお》りが｜漂《ただよ》い、｜清々《すがすが》しく｜穏《おだ》やかで、｜疲《つか》れた｜心身《しんしん》がたちまち｜解《と》きほぐされていく。

**ナレーション**：ここは、｜彼《かれ》がこれまで｜経験《けいけん》してきた、あの｜陰惨《いんさん》で｜恐《おそ》ろしい｜場所《ばしょ》とはまるで｜違《ちが》った。｜空《そら》に｜不気味《ぶきみ》な｜二《ふた》つの｜紫《むらさき》の｜月《つき》がかかっていなければ、まるで｜桃源郷《とうげんきょう》のようだった。

**ナレーション**：｜李杰《りけつ》があたりを｜見回《みまわ》すと、｜湖畔《こはん》にいくつかの｜小屋《こや》が｜点在《てんざい》しているのが｜見《み》えた。｜簡素《かんそ》な｜木造《もくぞう》の｜建物《たてもの》で、さっきまで｜泊《と》まっていた｜家《いえ》に｜似《に》ている。

**李杰**：（｜心《こころ》の｜声《こえ》）ここにも｜家《いえ》がある……この｜一帯《いったい》は、｜旅人《たびびと》が｜休《やす》むために｜用意《ようい》されているのか。

**ナレーション**：｜彼《かれ》は、まずこれらの｜家《いえ》を｜調《しら》べて、｜何《なに》か｜使《つか》えるものが｜見《み》つかるか｜確《たし》かめることにした。

**ナレーション**：｜李杰《りけつ》は｜湖畔《こはん》を、いちばん｜近《ちか》い｜小屋《こや》へ｜向《む》かって｜歩《ある》いた。だが｜近《ちか》づいたとき、｜遠《とお》くの｜湖畔《こはん》に、｜二《ふた》つの｜人影《ひとかげ》が｜座《すわ》っているのに｜気《き》づいた。

**ナレーション**：それは｜二人《ふたり》の｜若者《わかもの》で、｜湖畔《こはん》の｜草地《くさち》に｜並《なら》んで｜座《すわ》り、｜何《なに》か｜話《はな》しているようだった。

**李杰**：（｜心《こころ》の｜声《こえ》）｜人《ひと》がいる？

**ナレーション**：｜李杰《りけつ》は｜足《あし》を｜速《はや》めて｜歩《あゆ》み｜寄《よ》った。｜後《うし》ろ｜姿《すがた》からすると、｜若《わか》い｜男女《だんじょ》の｜二人《ふたり》が、｜湖畔《こはん》の｜草地《くさち》に｜並《なら》んで｜座《すわ》っている。

**ナレーション**：｜二人《ふたり》は｜物音《ものおと》を｜聞《き》いて、はっと｜振《ふ》り｜返《かえ》った。

**ナレーション**：｜彼《かれ》らが｜振《ふ》り｜向《む》いたとき、｜李杰《りけつ》はその｜顔《かお》を｜見《み》て｜取《と》った――｜一人《ひとり》は｜黒《くろ》い｜長髪《ちょうはつ》の｜小柄《こがら》な｜少女《しょうじょ》、｜清水恵美《しみずえみ》、｜彼《かれ》が｜霧《きり》の｜中《なか》で｜出会《であ》った、あの｜女《おんな》の｜子《こ》だ。

**ナレーション**：もう｜一人《ひとり》は｜快活《かいかつ》で｜明《あか》るい｜青年《せいねん》で、｜二十歳《はたち》くらいに｜見《み》え、やはり｜列車《れっしゃ》の｜乗客《じょうきゃく》の｜一人《ひとり》だった。

**ナレーション**：｜李杰《りけつ》を｜見《み》た｜瞬間《しゅんかん》、｜二人《ふたり》の｜顔《かお》に｜驚《おどろ》きがよぎった。

**清水恵美**：（｜立《た》ち｜上《あ》がり、｜驚《おどろ》いて）｜李《り》さん？

**おしゃべりな男子大学生**：（すぐに｜笑顔《えがお》になり、｜手《て》を｜差《さ》し｜出《だ》して）なるほど！　｜俺《おれ》は｜田中健太《たなかけんた》！

**李杰**：（｜握手《あくしゅ》して）｜李杰《りけつ》。
