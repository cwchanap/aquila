# 第十七幕：湖畔の再会

**ナレーション**：｜三人《さんにん》は｜銀月湖《ぎんげつこ》のほとりに｜立《た》ち、｜空気《くうき》はやや｜気《き》まずかった。｜李杰《りけつ》は｜清水恵美《しみずえみ》を｜見《み》ながら、｜霧《きり》の｜中《なか》での、あの｜短《みじか》い｜出会《であ》いを｜思《おも》い｜出《だ》した。

**李杰**：｜清水《しみず》さん、あのあとどこへ｜行《い》ってたんだ？　あの｜人《ひと》の｜傷《きず》の｜手当《てあ》てを｜終《お》えて｜十字路《じゅうじろ》に｜戻《もど》ったら、｜君《きみ》が｜見《み》つからなかった。

**清水恵美**：（うつむき、｜少《すこ》し｜申《もう》し｜訳《わけ》なさそうに）ごめんなさい……わたし……

**ナレーション**：｜彼女《かのじょ》の｜声《こえ》は｜小《ちい》さく、｜自分《じぶん》が｜離《はな》れたことを｜悔《く》いているようだった。

**清水恵美**：そのとき｜何《なに》か｜物音《ものおと》が｜聞《き》こえて……｜誰《だれ》かが｜転《ころ》んだみたいで……それで、｜音《おと》のほうへ｜歩《ある》いていったんです……

**清水恵美**：そうしたら、｜田中《たなか》さんが｜地面《じめん》に｜倒《たお》れていて……｜走《はし》っているときに、うっかり｜転《ころ》んだみたいで……

**田中健太**：（｜苦笑《くしょう》して｜頭《あたま》をかき）ああ、｜本当《ほんとう》に｜恥《は》ずかしいよ。あんな｜状況《じょうきょう》で｜転《ころ》ぶなんてさ……

**清水恵美**：（｜続《つづ》けて）｜田中《たなか》さんが｜怪我《けが》をしていなくて、よかったです……でも、｜戻《もど》ろうとしたら……｜霧《きり》が｜濃《こ》すぎて、｜帰《かえ》り｜道《みち》が｜分《わ》からなくなって……

**清水恵美**：｜霧《きり》の｜中《なか》を｜長《なが》いこと｜歩《ある》いて……｜最後《さいご》に、ここに｜着《つ》いたんです……

**ナレーション**：｜恵美《えみ》の｜口調《くちょう》には｜少《すこ》し｜自責《じせき》の｜色《いろ》がにじんでいた。｜勝手《かって》に｜離《はな》れてしまったことを、｜悔《く》いているのは｜明《あき》らかだった。

**李杰**：｜構《かま》わない。あの｜状況《じょうきょう》なら、｜誰《だれ》でも｜迷《まよ》うさ。｜大事《だいじ》なのは、｜君《きみ》が｜無事《ぶじ》だったことだ。

**清水恵美**：（｜顔《かお》を｜上《あ》げ、｜小《ちい》さな｜声《こえ》で）ありがとう……

**田中健太**：（｜李杰《りけつ》を｜見《み》て）｜李《り》さん、さっき……｜誰《だれ》かの｜傷《きず》の｜手当《てあ》てをしたって｜言《い》いましたよね？　｜何《なに》があったんですか？

**李杰**：｜十字路《じゅうじろ》で、｜列車《れっしゃ》にいた｜眼鏡《めがね》の｜男《おとこ》に｜会《あ》ったんだ。｜足《あし》を｜怪我《けが》してたから、｜手当《てあ》てしてやった。

**田中健太**：（うなずき）ああ、あの｜人《ひと》、｜覚《おぼ》えてますよ……｜大丈夫《だいじょうぶ》なんですか？

**李杰**：いまのところ｜命《いのち》に｜別状《べつじょう》はない。いまごろは｜近《ちか》くの｜家《いえ》で｜休《やす》んでいるはずだ。

**ナレーション**：｜李杰《りけつ》は｜斎藤《さいとう》のことを｜詳《くわ》しくは｜話《はな》さず、｜簡単《かんたん》に｜済《す》ませた。｜彼《かれ》は｜田中健太《たなかけんた》のほうを｜見《み》た。

**李杰**：｜田中《たなか》さんは？　どうやってここへ？

**田中健太**：（ため｜息《いき》をついて）｜話《はな》せば……あんまり｜楽《たの》しくない｜経験《けいけん》でさ。

**ナレーション**：｜田中健太《たなかけんた》は｜草《くさ》の｜上《うえ》に｜腰《こし》を｜下《お》ろし、｜二人《ふたり》にも｜座《すわ》るよう｜促《うなが》した。｜李杰《りけつ》と｜恵美《えみ》は｜隣《となり》に｜座《すわ》り、｜彼《かれ》が｜話《はなし》を｜続《つづ》けるのを｜待《ま》った。

**田中健太**：｜俺《おれ》たち｜四人《よにん》――｜俺《おれ》と｜美咲《みさき》と｜拓海《たくみ》と｜明日香《あすか》は、「｜寂海《じゃっかい》」｜駅《えき》で｜一緒《いっしょ》に｜降《お》りたんだ。

**田中健太**：｜降《お》りたら、｜駅《えき》のそばに｜道《みち》が｜二本《にほん》あるのが｜見《み》えた。｜一本《いっぽん》は｜広《ひろ》い｜主要《しゅよう》な｜道《みち》で、もう｜一本《いっぽん》は｜木立《こだち》の｜陰《かげ》に｜隠《かく》れた、｜目立《めだ》たない｜小道《こみち》だった。

**田中健太**：（｜苦笑《くしょう》して）あのとき｜俺《おれ》は｜思《おも》ったんだ……こんな｜変《へん》なところに｜来《き》たんだから、｜大通《おおどお》りを｜行《い》ったって｜何《なに》に｜出《で》くわすか｜分《わ》からない、｜小道《こみち》を｜試《ため》してみたら、｜何《なに》か｜違《ちが》う｜発見《はっけん》があるかもって。

**李杰**：それで、｜君《きみ》たちは｜小道《こみち》を｜選《えら》んだのか。

**田中健太**：（うなずき）ああ。あのとき、おじさんが、｜主要《しゅよう》な｜道《みち》のほうが｜安全《あんぜん》だって｜止《と》めてくれたのに、｜俺《おれ》は｜聞《き》かなかった……いま｜思《おも》えば、あの｜人《ひと》の｜言《い》うことを｜聞《き》いておくべきだったよ。

**田中健太**：｜最初《さいしょ》は｜平気《へいき》だったんだ。｜道《みち》は｜狭《せま》かったけど、｜四人一緒《よにんいっしょ》だったから、そんなに｜怖《こわ》くなくて。でも｜歩《ある》いてるうちに、｜霧《きり》が｜濃《こ》くなってきた。

**田中健太**：ずいぶん｜歩《ある》いて、みんな｜疲《つか》れてた。｜拓海《たくみ》が、｜前《まえ》の｜小道《こみち》の｜突《つ》き｜当《あ》たりに｜空《あ》き｜地《ち》があるから、そこで｜休《やす》もうって｜言《い》って。

**ナレーション**：｜田中健太《たなかけんた》の｜表情《ひょうじょう》が、｜真剣《しんけん》なものに｜変《か》わった。

**田中健太**：でも、｜小道《こみち》を｜抜《ぬ》けたばかりのところで……｜美咲《みさき》が｜突然《とつぜん》、｜悲鳴《ひめい》を｜上《あ》げたんだ。

**清水恵美**：（｜緊張《きんちょう》して）｜何《なに》があったんですか？

**田中健太**：（｜真剣《しんけん》な｜表情《ひょうじょう》で）｜木《き》の｜上《うえ》から、｜何《なに》かが｜飛《と》び｜降《お》りてきた。｜見《み》たところ……エルフ？　｜尖《とが》った｜耳《みみ》で、｜緑《みどり》の｜服《ふく》を｜着《き》てた。

**田中健太**：｜弓《ゆみ》を｜持《も》ってて、｜何《なん》の｜警告《けいこく》もなく、いきなり｜美咲《みさき》に｜矢《や》を｜射《い》った。｜矢《や》は｜美咲《みさき》の｜脚《あし》に｜当《あ》たって、｜美咲《みさき》はその｜場《ば》に｜倒《たお》れた。

**清水恵美**：（｜怯《おび》えて｜口《くち》を｜押《お》さえ）そんな……

**田中健太**：（｜続《つづ》ける。｜口調《くちょう》は｜張《は》り｜詰《つ》めて）それからもう｜一人《ひとり》、エルフが｜現《あらわ》れて、｜剣《けん》を｜持《も》って、こっちへ｜突《つ》っ｜込《こ》んできた。

**田中健太**：｜俺《おれ》はそのとき｜完全《かんぜん》にびびっちまって、｜反射的《はんしゃてき》に「｜逃《に》げろ」って｜叫《さけ》んだ。それから、｜俺《おれ》も｜必死《ひっし》で｜走《はし》り｜出《だ》して……

**ナレーション**：｜李杰《りけつ》は｜何《なに》も｜言《い》わず、ただ｜黙《だま》って｜聞《き》いていた。｜表情《ひょうじょう》は｜静《しず》かで、｜何《なん》の｜異変《いへん》も｜見《み》せなかった。

**田中健太**：（うつむき）｜走《はし》りながら｜美咲《みさき》がどこにいるか｜振《ふ》り｜返《かえ》ろうとして、｜足《あし》もとに｜気《き》づかなくて、｜何《なに》かにつまずいて……｜思《おも》いっきり｜転《ころ》んだんだ。

**田中健太**：｜起《お》き｜上《あ》がったときには、まわりに｜誰《だれ》もいなかった。｜霧《きり》で｜何《なに》も｜見《み》えなくて、｜遠《とお》くからかすかな｜叫《さけ》び｜声《ごえ》が｜聞《き》こえるだけだった。

**田中健太**：その｜場《ば》で｜長《なが》いこと｜呼《よ》んだけど、｜誰《だれ》も｜答《こた》えなかった。どっちへ｜行《い》けばいいか｜分《わ》からなくなったとき、｜近《ちか》くで｜足音《あしおと》が｜聞《き》こえた。

**田中健太**：｜声《こえ》をかけたら、｜恵美《えみ》さんの｜返事《へんじ》が｜聞《き》こえたんだ。

**清水恵美**：（うなずき）わたしも、あのとき｜迷《まよ》っていて……｜田中《たなか》さんの｜声《こえ》が｜聞《き》こえたので、そちらへ｜歩《ある》いていきました……

**田中健太**：お｜互《たが》いを｜見《み》つけたあと、｜一緒《いっしょ》に｜行《い》くことにしたんだ。｜一人《ひとり》で｜霧《きり》の｜中《なか》をうろつくよりましだからさ。

**田中健太**：さらに｜何時間《なんじかん》か｜歩《ある》いたら、｜霧《きり》が｜少《すこ》しずつ｜晴《は》れてきて、この｜湖《みずうみ》が｜見《み》えた。

**田中健太**：（｜銀月湖《ぎんげつこ》を｜見《み》て）｜正直《しょうじき》、こんなに｜美《うつく》しい｜場所《ばしょ》を｜見《み》て、やっとほっとしたよ。｜少《すく》なくとも、しばらくは｜安全《あんぜん》だって。

**ナレーション**：｜李杰《りけつ》はしばらく｜黙《だま》ってから、｜口《くち》を｜開《ひら》いた。

**李杰**：ほかの｜仲間《なかま》は……まだ｜見《み》つかっていないのか？

**田中健太**：（｜首《くび》を｜振《ふ》り、やや｜重《おも》い｜表情《ひょうじょう》で）｜分《わ》からない。｜湖《みずうみ》のほとりにしばらくいたけど、あいつらの｜姿《すがた》は｜見《み》てない。

**田中健太**：みんなも、｜安全《あんぜん》な｜場所《ばしょ》を｜見《み》つけててくれるといいんだけど……

**ナレーション**：｜田中健太《たなかけんた》は｜口調《くちょう》こそ｜穏《おだ》やかだったが、｜固《かた》く｜握《にぎ》りしめたこぶしから、｜仲間《なかま》への｜心配《しんぱい》が｜見《み》て｜取《と》れた。

**清水恵美**：（｜李杰《りけつ》を｜見《み》て、｜小声《こごえ》で）それで……｜李《り》さんは？　どうしてここへ？

**李杰**：（｜穏《おだ》やかに）｜降《お》りたあと、｜俺《おれ》もいろいろあってね。そのあと｜道中《どうちゅう》で、ある｜一家《いっか》に｜出会《であ》って、その｜人《ひと》たちが｜安全《あんぜん》な｜場所《ばしょ》を｜見《み》つけるのを｜手伝《てつだ》ったんだ。

**李杰**：そのあと、｜地図《ちず》にここが｜載《の》っているのを｜見《み》て、｜来《き》てみたってわけさ。

**田中健太**：｜一家《いっか》？

**李杰**：（｜手短《てみじか》に）｜夫婦《ふうふ》と、｜二人《ふたり》の｜子《こ》どもだ。いまは｜北《きた》のほうの｜家《いえ》にいる。

**田中健太**：それはよかった……｜少《すく》なくとも、｜家族一緒《かぞくいっしょ》にいられてるんですね。

**ナレーション**：｜李杰《りけつ》は｜自分《じぶん》の｜経験《けいけん》を｜詳《くわ》しくは｜話《はな》さず、｜簡単《かんたん》に｜済《す》ませた。｜田中《たなか》と｜恵美《えみ》も、それ｜以上《いじょう》は｜尋《たず》ねなかった。

**ナレーション**：｜三人《さんにん》はしばし｜沈黙《ちんもく》に｜沈《しず》んだ。｜銀月湖《ぎんげつこ》の｜水面《すいめん》は｜紫《むらさき》の｜月《つき》に｜照《て》らされて｜静《しず》かに｜揺《ゆ》れ、｜光《ひか》る｜花《はな》が｜湖面《こめん》に｜浮《う》かび、この｜奇怪《きかい》な｜世界《せかい》に、｜一抹《いちまつ》の｜美《うつく》しさを｜添《そ》えていた。

**ナレーション**：｜三人《さんにん》の｜見知《みし》らぬ｜者《もの》たちは、この｜世界《せかい》の｜別々《べつべつ》の｜片隅《かたすみ》でもがきながら｜生《い》き｜延《の》び、ついに｜銀月湖《ぎんげつこ》のほとりで｜出会《であ》った。

**ナレーション**：だが｜彼《かれ》らがそれぞれ｜探《さが》している｜答《こた》え――どうやってここを｜出《で》るか、｜散《ち》り｜散《ぢ》りになった｜仲間《なかま》をどうやって｜見《み》つけるか――は、いまもまだ｜見《み》つかっていない。
