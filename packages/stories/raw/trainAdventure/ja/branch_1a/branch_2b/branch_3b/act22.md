# 第二十二幕：道具が要る

**ナレーション**：リー・ジエは｜空洞《くうどう》のレンガの｜前《まえ》にしゃがみ｜込《こ》み、｜手《て》でこじ｜開《あ》けようとした。

**ナレーション**：レンガの｜縁《ふち》に｜指《ゆび》をかけ、｜力《ちから》を｜入《い》れられそうな｜隙《すき》｜間《あいだ》を｜探《さぐ》る。だがレンガと｜床《ゆか》のあいだにはほとんど｜隙《すき》｜間《あいだ》がなく、にかわで｜固《かた》めたようにぴったりと｜詰《つ》まっていた。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）くそ……きつすぎる。

**ナレーション**：｜今度《こんど》は｜力《ちから》いっぱいレンガの｜表面《ひょうめん》を｜押《お》し｜込《こ》んでみた。｜何《なに》か｜仕掛《しか》けが｜作動《さどう》するかもしれない。だがレンガはびくともせず、｜何《なん》の｜反応《はんのう》もなかった。

**ナレーション**：リー・ジエは｜立《た》ち｜上《あ》がって｜警備室《けいびしつ》を｜見回《みまわ》した。レンガをこじ｜開《あ》けるのに｜使《つか》える｜道具《どうぐ》が｜何《なに》かないか。

**ナレーション**：だが｜部屋《へや》には、｜蹴《け》り｜開《あ》けられたあの｜鉄製《てつせい》の｜戸棚《とだな》のほかには｜何《なに》もない。しかも｜戸棚《とだな》は｜大《おお》きく｜重《おも》すぎて、とても｜道具《どうぐ》には｜使《つか》えなかった。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）バールの｜一本《いっぽん》でもあればな……

**ナレーション**：リー・ジエはもう｜一度《いちど》しゃがみ、まわりのレンガをじっくり｜観察《かんさつ》しはじめた。

**ナレーション**：レンガは｜整然《せいぜん》と｜何列《なんれつ》にも｜並《なら》び、｜一枚一枚《いちまいいちまい》のあいだに｜細《ほそ》く｜均一《きんいつ》な｜隙《すき》｜間《あいだ》がある。どれもごく｜普通《ふつう》のレンガで、これといって｜変《か》わったところはなかった。

**ナレーション**：ただ、あの｜空洞《くうどう》のレンガだけが、｜中身《なかみ》の｜詰《つ》まったレンガの｜中《なか》で、ひどく｜浮《う》いて｜見《み》える。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）｜並《なら》びに｜特別《とくべつ》な｜決《き》まりがあるようには｜見《み》えない……ただの｜床《ゆか》のレンガだ。

**ナレーション**：リー・ジエはさらにいくつか、｜別《べつ》のやり｜方《かた》を｜試《ため》した。｜足《あし》で｜踏《ふ》み、｜拳《こぶし》で｜叩《たた》き、｜体重《たいじゅう》をかけて｜押《お》し｜込《こ》みさえした。

**ナレーション**：だがレンガは｜相《あい》｜変《か》わらず、｜床《ゆか》にしっかりとはまったままで、わずかにも｜緩《ゆる》む｜気配《けはい》はなかった。

**ナレーション**：リー・ジエは｜立《た》ち｜上《あ》がった。｜今度《こんど》は｜急《きゅう》に｜立《た》ちすぎて、｜目《め》の｜前《まえ》が｜真《ま》っ｜暗《くら》になり、｜頭《あたま》がくらくらした。

**リー・ジエ**：（｜壁《かべ》に｜手《て》をついて）……

**ナレーション**：しゃがんでいた｜時間《じかん》が｜長《なが》すぎて、｜血《ち》のめぐりが｜悪《わる》くなり、めまいがしたのだ。

**ナレーション**：リー・ジエは｜壁《かべ》にもたれて、めまいが｜引《ひ》くのを｜待《ま》った。｜頭《あたま》の｜中《なか》では、｜考《かんが》えが｜素早《すばや》く｜巡《めぐ》っている。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）｜手《て》だけじゃ、どうやっても｜開《ひら》かない。｜仕掛《しか》けがあるか、｜道具《どうぐ》が｜要《い》るかのどちらかだ。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）だが、｜俺《おれ》には｜道具《どうぐ》なんて｜何《なに》もない……

**ナレーション**：そのとき、ひとつの｜考《かんが》えが｜頭《あたま》をよぎった。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）｜待《ま》てよ……｜小林《こばやし》さんだ！

**ナレーション**：リー・ジエは｜小林雄大《こばやしゆうだい》のことを｜思《おも》い｜出《だ》した。｜霧《きり》の｜中《なか》で｜出会《であ》ったとき、｜彼《かれ》は｜腰《こし》に｜錆《さ》びた｜剣《けん》を｜下《さ》げていた。

**ナレーション**：ひどく｜古《ふる》びた｜剣《けん》ではあるが、｜少《すく》なくとも｜金属《きんぞく》でできている。レンガをこじ｜開《あ》けるには、それで｜足《た》りるはずだ。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）｜小林《こばやし》さんに、あの｜剣《けん》を｜借《か》りに｜行《い》かないと。

**ナレーション**：リー・ジエは｜踵《かかと》を｜返《かえ》して｜警備室《けいびしつ》を｜出《で》ると、｜駅《えき》をあとにした。

**ナレーション**：｜幽冥《ゆうめい》の｜都駅《みやこえき》から｜小林《こばやし》｜一家《いっか》の｜小屋《こや》まで、リー・ジエはもう｜何度《なんど》も｜歩《ある》いている。｜今回《こんかい》はいっそう｜足《あし》が｜速《はや》く、｜一時間《いちじかん》もかからずに｜目的地《もくてきち》に｜着《つ》いた。

**ナレーション**：｜小屋《こや》は｜霧《きり》の｜中《なか》に｜変《か》わらずたたずんでいて、｜窓《まど》からかすかな｜明《あ》かりがもれている。

**ナレーション**：リー・ジエは｜進《すす》み｜出《で》て、｜扉《とびら》をノックした。

**ナレーション**：「コンコンコン」――

**小林智子**：（｜家《いえ》の｜中《なか》から｜声《こえ》がして）はーい！

**ナレーション**：｜扉《とびら》はすぐに｜開《ひら》いた。｜戸口《とぐち》に｜立《た》った｜小林智子《こばやしともこ》は、リー・ジエを｜見《み》て｜驚《おどろ》いた｜表情《ひょうじょう》を｜浮《う》かべた。

**小林智子**：リーさん！　あなただったんですね。さあ、どうぞ｜入《はい》ってください。

**リー・ジエ**：お｜邪魔《じゃま》します。

**ナレーション**：リー・ジエは｜家《いえ》の｜中《なか》に｜入《はい》った。｜部屋《へや》は｜暖《あたた》かく、｜暖炉《だんろ》に｜火《ひ》が｜燃《も》えている。

**ナレーション**：｜翔太《しょうた》と｜陽菜《ひな》は｜床《ゆか》に｜座《すわ》って、｜何《なに》か｜遊《あそ》びをしているようだった。リー・ジエが｜入《はい》ってくると、｜二人《ふたり》とも｜顔《かお》を｜上《あ》げた。

**小林翔太**：（はしゃいで）リー・ジエお｜兄《にい》ちゃんだ！

**小林陽菜**：（｜微笑《ほほえ》んで）リー・ジエさん、こんにちは。

**リー・ジエ**：（うなずき）こんにちは。

**ナレーション**：リー・ジエは｜部屋《へや》を｜見回《みまわ》したが、｜雄大《ゆうだい》の｜姿《すがた》はなかった。

**リー・ジエ**：｜小林《こばやし》さんは｜留守《るす》ですか？

**小林智子**：（うなずき）｜探索《たんさく》に｜出《で》かけてるんです。｜何《なに》か｜役《やく》に｜立《た》つ｜手《て》がかりが｜見《み》つからないかって。

**小林智子**：あの｜人《ひと》に｜用《よう》ですか？　とりあえず｜座《すわ》って｜待《ま》たれては？　そんなに｜遅《おそ》くはならないはずです。

**リー・ジエ**：いつもは、どのくらいで｜戻《もど》りますか？

**小林智子**：（｜考《かんが》えて）ふだんなら……｜二《に》、｜三時間《さんじかん》くらいでしょうか。

**小林智子**：でも｜今日《きょう》は、もう｜少《すこ》し｜遠《とお》くまで｜行《い》ってみるって｜言《い》ってました。｜線路《せんろ》づたいに、｜北《きた》へ｜歩《ある》いてみるって。だから、｜遅《おそ》くなるかもしれません。

**リー・ジエ**：（｜眉《まゆ》をひそめて）｜線路《せんろ》か……

**リー・ジエ**：そうだ、｜小林《こばやし》さんはあの｜剣《けん》を｜持《も》っていってますか？

**小林智子**：（うなずき）ええ。｜外《そと》では｜何《なに》か｜危《あぶ》ないことがあるかもしれないから、｜必《かなら》ず｜持《も》っていくって。

**ナレーション**：リー・ジエはしばし｜黙《だま》り｜込《こ》んだ。｜雄大《ゆうだい》が｜剣《けん》を｜持《も》って｜遠《とお》くまで｜行《い》ったのなら、｜長《なが》く｜待《ま》つことになるかもしれない。

**リー・ジエ**：それなら、｜俺《おれ》が｜捜《さが》しに｜行《い》きます。

**小林智子**：（｜首《くび》を｜振《ふ》って）いま｜行《い》くのは、あまりよくないと｜思《おも》います。どのあたりにいるのかわからないでしょう？　｜霧《きり》もこんなに｜濃《こ》いし、すれ｜違《ちが》ってしまいますよ。

**小林智子**：それに……リーさんも、お｜疲《つか》れのようです。まずここで｜少《すこ》し｜休《やす》まれては？

**ナレーション**：｜小林智子《こばやしともこ》は｜台所《だいどころ》を｜指《ゆび》さした。

**小林智子**：いま、｜子《こ》どもたちのお｜昼《ひる》を｜作《つく》ってるんです。｜簡単《かんたん》なものですけど、｜足《た》りると｜思《おも》います。

**小林智子**：リーさんも、ご｜一緒《いっしょ》にどうぞ。｜食《た》べ｜終《お》わるころには、｜主人《しゅじん》が｜戻《もど》ってくるかもしれませんし。

**ナレーション**：リー・ジエは｜窓《まど》の｜外《そと》の｜濃《こ》い｜霧《きり》を｜見《み》て、それから｜部屋《へや》の｜暖《あたた》かい｜暖炉《だんろ》に｜目《め》をやった。

**ナレーション**：たしかに、｜闇雲《やみくも》に｜雄大《ゆうだい》を｜捜《さが》しに｜出《で》るのはいい｜考《かんが》えではない。それに、｜彼《かれ》も｜腹《はら》が｜減《へ》っていた。

**リー・ジエ**：（うなずき）では、お｜言葉《ことば》に｜甘《あま》えます。

**小林智子**：（｜微笑《ほほえ》んで）いえいえ。お｜礼《れい》を｜言《い》うのは、｜私《わたし》たちのほうですから。

**ナレーション**：リー・ジエはテーブルの｜席《せき》についた。｜翔太《しょうた》と｜陽菜《ひな》はまた｜遊《あそ》びに｜戻《もど》り、ときおり｜笑《わら》い｜声《ごえ》が｜聞《き》こえてくる。

**ナレーション**：｜小林智子《こばやしともこ》は｜台所《だいどころ》で｜忙《いそが》しく｜立《た》ち｜働《はたら》いている。｜鍋《なべ》から｜煮《に》える｜音《おと》がして、ほのかにいい｜香《かお》りが｜漂《ただよ》ってきた。

**ナレーション**：リー・ジエは｜椅子《いす》の｜背《せ》にもたれて、｜窓《まど》の｜外《そと》を｜眺《なが》めた。あの｜謎《なぞ》めいた｜空洞《くうどう》のレンガは、いまも｜駅《えき》で｜彼《かれ》を｜待《ま》っている。

**ナレーション**：そして、そこに｜隠《かく》された｜秘密《ひみつ》を｜解《と》き｜明《あ》かすには、あの｜錆《さ》びた｜剣《けん》が｜要《い》るのだ。
