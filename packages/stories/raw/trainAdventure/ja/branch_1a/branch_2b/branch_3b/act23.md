# 第二十三幕：あたたかな昼ごはん

**ナレーション**：｜台所《だいどころ》から｜鍋《なべ》や｜椀《わん》の｜触《ふ》れ｜合《あ》う｜音《おと》が｜聞《き》こえてきて、｜空気《くうき》に｜料理《りょうり》の｜匂《にお》いが｜広《ひろ》がった。

**小林智子**：｜簡単《かんたん》なものですけど、｜気《き》になさらないでくださいね。

**小林翔太**：（はしゃいで）ママのごはんが｜一番《いちばん》おいしい！

**小林陽菜**：（リー・ジエに）リー・ジエさんも｜一緒《いっしょ》に｜食《た》べましょう。

**ナレーション**：リー・ジエはうなずいて、スプーンを｜手《て》に｜取《と》った。｜温《あたた》かい｜汁《しる》が、｜疲《つか》れた｜体《からだ》にしみわたる。

**ナレーション**：この｜不気味《ぶきみ》な｜世界《せかい》では、こんなにほのぼのとした｜光景《こうけい》は、とりわけ｜貴重《きちょう》に｜思《おも》えた。

**小林智子**：（｜食《た》べながら）リーさん、｜前《まえ》から｜聞《き》きたかったんですけど、ご｜出身《しゅっしん》はどちらなんですか？

**リー・ジエ**：｜上海《しゃんはい》で｜育《そだ》ちました。｜五年前《ごねんまえ》に、｜仕事《しごと》で｜東京《とうきょう》に｜来《き》たんです。

**小林智子**：そうなんですね。ご｜両親《りょうしん》は、まだ｜上海《しゃんはい》に？

**リー・ジエ**：（うなずき）ええ。ずっと｜向《む》こうで｜暮《く》らしています。

**小林智子**：（やさしく）それは、さぞ｜会《あ》いたいでしょうね。

**リー・ジエ**：（しばし｜黙《だま》って）……はい。

**小林智子**：（｜微笑《ほほえ》んで）｜帰《かえ》れたら、ぜひ｜会《あ》いに｜行《い》ってあげてくださいね。

**リー・ジエ**：そうします。

**ナレーション**：リー・ジエは｜汁《しる》をひと｜口《くち》｜飲《の》んで、｜話題《わだい》を｜変《か》えた。

**リー・ジエ**：お｜宅《たく》は、｜東京《とうきょう》にお｜住《す》まいなんですか？

**小林智子**：｜立川《たちかわ》です。｜都心《としん》からは、ちょっと｜離《はな》れてるんですけどね。

**小林智子**：あの｜夜《よる》は｜親戚《しんせき》の｜家《いえ》の｜集《あつ》まりに｜行《い》ったんですが、｜話《はなし》が｜弾《はず》んで｜遅《おそ》くなってしまって、｜終電《しゅうでん》を｜逃《のが》したんです。

**小林智子**：｜次《つぎ》の｜電車《でんしゃ》を｜待《ま》つつもりだったのに……｜気《き》づいたら、あの｜不気味《ぶきみ》な｜列車《れっしゃ》に｜乗《の》っていて。

**リー・ジエ**：（｜納得《なっとく》してうなずき）そういうことでしたか。

**小林翔太**：（｜口《くち》をはさんで）あの｜日《ひ》、すっごく｜楽《たの》しかったんだよ！　いとこのお｜兄《にい》ちゃんが、｜新《あたら》しいゲームを｜教《おし》えてくれたの！

**小林陽菜**：（やさしく）｜翔太《しょうた》、ごはんのときは、そんなにしゃべらないの。

**ナレーション**：｜智子《ともこ》は｜二人《ふたり》の｜子《こ》どもを｜見《み》つめて、やさしい｜笑《え》みを｜浮《う》かべた。

**小林智子**：｜私《わたし》は｜専業主婦《せんぎょうしゅふ》で、｜主人《しゅじん》は｜貿易会社《ぼうえきかいしゃ》で｜部長《ぶちょう》をしています。

**小林智子**：｜子《こ》どもたちは｜二人《ふたり》とも｜小学生《しょうがくせい》です。｜翔太《しょうた》が｜二年生《にねんせい》で、｜陽菜《ひな》が｜四年生《よんねんせい》。

**リー・ジエ**：ご｜主人《しゅじん》のお｜仕事《しごと》は、お｜忙《いそが》しいんですか？

**小林智子**：（｜首《くび》を｜振《ふ》って）そうでもありません。｜急《きゅう》な｜用事《ようじ》がたまにありますけど、たいていは｜定時《ていじ》に｜帰《かえ》ってきます。

**小林智子**：｜週末《しゅうまつ》は、よく｜家族《かぞく》みんなで｜出《で》かけるんです。｜公園《こうえん》や｜博物館《はくぶつかん》、それに｜郊外《こうがい》へ｜散歩《さんぽ》に｜行《い》ったり。

**小林陽菜**：（｜微笑《ほほえ》んで）パパが、アイスも｜買《か》ってくれました。

**ナレーション**：リー・ジエはこの｜一家《いっか》を｜見《み》ていて、｜胸《むね》に｜複雑《ふくざつ》な｜思《おも》いが｜込《こ》み｜上《あ》げてきた。

**ナレーション**：｜彼《かれ》らはあまりにも｜普通《ふつう》で、あまりにもあたたかい。どこにでもいる、ありふれた｜家族《かぞく》と｜変《か》わらない。

**ナレーション**：なのにいま、｜彼《かれ》らはこの｜不気味《ぶきみ》な｜世界《せかい》に｜閉《と》じ｜込《こ》められ、いつ｜帰《かえ》れるのかもわからない。

**小林智子**：リーさんは、ふだんどんなご｜趣味《しゅみ》が？

**リー・ジエ**：ゲームをしたり、アニメを｜見《み》たりするのが｜好《す》きです。

**小林翔太**：（｜目《め》を｜輝《かがや》かせて）ゲーム！　リー・ジエお｜兄《にい》ちゃんは、どんなゲームやるの？

**小林翔太**：ぼくもゲーム｜好《す》き！　でもママが、あんまり｜長《なが》くやっちゃだめって……

**リー・ジエ**：（｜口《くち》の｜端《はし》を｜上《あ》げて）たまにジムに｜行《い》ったり、｜山《やま》に｜登《のぼ》ったりもします。

**小林智子**：｜帰《かえ》れたら、｜挑戦《ちょうせん》してみようかしら。

**ナレーション**：「｜帰《かえ》れたら」――その｜言葉《ことば》が、｜空気《くうき》の｜中《なか》に｜響《ひび》いた。

**ナレーション**：その｜日《ひ》がいつ｜来《く》るのか、｜誰《だれ》にもわからない。それでもいまは、まだ｜希望《きぼう》を｜抱《いだ》いている。
