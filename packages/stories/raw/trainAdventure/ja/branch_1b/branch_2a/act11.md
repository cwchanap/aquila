# 第十一幕：峡谷の亡者

**ナレーション**：リー・ジエはホームに｜駆《か》け｜上《あ》がり、｜息《いき》を｜切《き》らして｜足《あし》を｜止《と》めた。だが、｜目《め》の｜前《まえ》の｜光景《こうけい》に、｜胸《むね》がずしりと｜沈《しず》んだ。

**ナレーション**：「｜亡者《もうじゃ》の｜峡谷《きょうこく》」と｜名《な》づけられたこの｜駅《えき》は、「｜幽冥《ゆうめい》の｜都《みやこ》」よりもさらに｜荒涼《こうりょう》としていた。｜建物《たてもの》は｜何一《なにひと》つない――｜待合室《まちあいしつ》も、｜切符《きっぷ》｜売《う》り｜場《ば》も、｜警備室《けいびしつ》もない。

**ナレーション**：あるのは、むき｜出《だ》しのコンクリートのホームと、ぽつんと｜立《た》つ｜駅名標《えきめいひょう》だけ。ホームの｜縁《ふち》はそのまま｜峡谷《きょうこく》で、｜底《そこ》の｜知《し》れない｜闇《やみ》が｜下《した》で｜大口《おおぐち》を｜開《あ》けていた。

**リー・ジエ**：（あたりを｜見回《みまわ》して）｜何《なに》もない……

**ナレーション**：｜紫《むらさき》の｜月明《つきあ》かりがホームに｜降《ふ》りそそぎ、すべてを｜不気味《ぶきみ》な｜紫黒色《しこくしょく》に｜染《そ》めている。｜峡谷《きょうこく》の｜底《そこ》から｜吹《ふ》き｜上《あ》げる｜風《かぜ》は、｜骨身《ほねみ》に｜刺《さ》さる｜冷《つめ》たさを｜帯《お》びていた。

**ナレーション**：｜彼《かれ》は｜駅名標《えきめいひょう》の｜下《した》へ｜歩《ある》いた。｜同《おな》じ｜黒《くろ》い｜木《き》でできた｜標識《ひょうしき》には、｜尖《とが》った｜字体《じたい》でこう｜刻《きざ》まれている――

**ナレーション**：｜前《まえ》の｜駅《えき》：「｜幽冥《ゆうめい》の｜都《みやこ》」

**ナレーション**：｜次《つぎ》の｜駅《えき》：「｜終焉《しゅうえん》の｜祭壇《さいだん》」

**リー・ジエ**：（｜低《ひく》く｜読《よ》み｜上《あ》げて）｜終焉《しゅうえん》の｜祭壇《さいだん》……

**ナレーション**：やはり、｜帰《かえ》り｜道《みち》はとっくに｜断《た》たれている。｜列車《れっしゃ》は｜東京《とうきょう》へは｜戻《もど》らず、｜未知《みち》のさらに｜奥《おく》へと｜進《すす》みつづけるのだ。

**ナレーション**：そのとき、ホームの｜中央《ちゅうおう》にある｜黒《くろ》い｜影《かげ》が、｜彼《かれ》の｜目《め》を｜引《ひ》いた。

**ナレーション**：｜人影《ひとかげ》だった。うつ｜伏《ぶ》せに｜倒《たお》れ、ぴくりとも｜動《うご》かない。

**リー・ジエ**：（｜鼓動《こどう》が｜速《はや》まって）あれは……

**ナレーション**：｜彼《かれ》はすぐに｜駆《か》け｜寄《よ》った。その｜下《した》には、｜半《なか》ば｜固《かた》まった｜暗赤色《あんせきしょく》の｜血《ち》だまりが｜広《ひろ》がり、｜紫《むらさき》の｜月明《つきあ》かりの｜下《した》で｜不気味《ぶきみ》にぬめっている。｜血《ち》は｜体《からだ》の｜下《した》から｜広《ひろ》がり、コンクリートの｜上《うえ》に｜歪《いびつ》な｜形《かたち》を｜描《えが》いていた。

**リー・ジエ**：（しゃがんで｜手《て》を｜伸《の》ばし）おい！　｜大丈夫《だいじょうぶ》か！

**ナレーション**：リー・ジエは｜男《おとこ》の｜肩《かた》をつかみ、｜力《ちから》を｜込《こ》めてひっくり｜返《かえ》した。その｜顔《かお》を｜見《み》た｜瞬間《しゅんかん》、｜彼《かれ》の｜息《いき》は｜一秒《いちびょう》｜止《と》まった。

**ナレーション**：あの｜怒《おこ》りっぽい｜中年《ちゅうねん》の｜男《おとこ》だった――｜車内《しゃない》で｜罵《ののし》り、｜愚痴《ぐち》をこぼし、みんなと｜言《い》い｜争《あらそ》っていた｜男《おとこ》。

**ナレーション**：だがいま、その｜顔《かお》は｜紙《かみ》のように｜青白《あおじろ》く、｜目《め》は｜半《なか》ば｜開《ひら》いて、うつろに｜濁《にご》っていた。｜口《くち》はわずかに｜開《ひら》き、｜何《なに》か｜言《い》いかけて、｜二度《にど》と｜言《い》えなくなったかのようだ。

**ナレーション**：｜後頭部《こうとうぶ》には｜恐《おそ》ろしい｜傷《きず》があり、｜頭蓋骨《ずがいこつ》は｜陥没《かんぼつ》して、｜血《ち》と｜脳漿《のうしょう》が｜混《ま》ざり｜合《あ》っている。｜何《なに》か｜鈍器《どんき》で｜強《つよ》く｜殴《なぐ》られたのは｜明《あき》らかだった。

**リー・ジエ**：（｜手《て》を｜伸《の》ばし、｜鼻先《はなさき》に｜当《あ》ててみる）……

**ナレーション**：｜息《いき》はない。｜体《からだ》はもう｜冷《つめ》たくなりはじめていた。

**リー・ジエ**：（ゆっくりと｜手《て》を｜下《お》ろし、｜低《ひく》く）｜死《し》んでる……

**ナレーション**：リー・ジエは｜地面《じめん》に｜膝《ひざ》をつき、その｜遺体《いたい》を｜見《み》つめた。｜一時間前《いちじかんまえ》にはまだ｜生《い》きていた｜人間《にんげん》が、いまは｜冷《つめ》たい｜骸《むくろ》になっている。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）だが……｜小林《こばやし》さんのご｜主人《しゅじん》は？

**ナレーション**：｜彼《かれ》は｜勢《いきお》いよく｜立《た》ち｜上《あ》がり、あたりを｜見回《みまわ》した。ホームはがらんとして、｜自分《じぶん》とこの｜遺体《いたい》のほかには｜誰《だれ》もいない。｜列車《れっしゃ》はとうに｜姿《すがた》を｜消《け》していた。

**ナレーション**：｜彼《かれ》は｜自分《じぶん》に｜落《お》ち｜着《つ》けと｜言《い》い｜聞《き》かせ、｜状況《じょうきょう》を｜分析《ぶんせき》しはじめた。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）これまでの｜規則《きそく》どおりなら、｜列車《れっしゃ》がこの｜駅《えき》に｜着《つ》いたとき、｜半分《はんぶん》の｜人間《にんげん》が｜降《お》りるはずだ。｜車内《しゃない》にはもともと｜四人《よんにん》いたから、｜二人《ふたり》が｜降《お》りることになる。

**ナレーション**：｜彼《かれ》は｜頭《あたま》の｜中《なか》で、｜車内《しゃない》にいた｜人《ひと》たちを｜思《おも》い｜返《かえ》した――あの｜臆病《おくびょう》な｜男《おとこ》、あの｜中年《ちゅうねん》の｜夫婦《ふうふ》、そして｜小林《こばやし》さんのご｜主人《しゅじん》。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）いまこの｜男《おとこ》がここで｜死《し》んでいる……なら、｜降《お》りたもう｜一人《ひとり》は、ご｜主人《しゅじん》のはずだ。｜家族《かぞく》を｜探《さが》しに｜戻《もど》るために、｜必《かなら》ず｜降《お》りる。

**ナレーション**：｜彼《かれ》は、｜暗闇《くらやみ》の｜彼方《かなた》へ｜延《の》びる｜遠《とお》くの｜線路《せんろ》を｜見《み》やった。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）｜列車《れっしゃ》はもう｜行《い》ってしまった。｜車内《しゃない》に｜残《のこ》っているのは｜二人《ふたり》のはず……あの｜臆病《おくびょう》な｜男《おとこ》と、あの｜不安《ふあん》げな｜妻《つま》だ。

**ナレーション**：｜冷酷《れいこく》な｜推論《すいろん》が、｜彼《かれ》の｜頭《あたま》の｜中《なか》で｜形《かたち》になっていった。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）あの｜臆病《おくびょう》な｜男《おとこ》……「｜生贄説《いけにえせつ》」を｜言《い》い｜出《だ》したのはあいつだ。この｜駅《えき》で｜二人《ふたり》が｜降《お》りなければならないことを、｜知《し》っていた。

**ナレーション**：リー・ジエは｜地面《じめん》の｜遺体《いたい》を｜見《み》つめた。｜後頭部《こうとうぶ》の｜傷《きず》は、｜石《いし》か｜何《なに》か｜重《おも》いもので｜殴《なぐ》られたようだ。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）ご｜主人《しゅじん》は｜何《なに》があっても｜家族《かぞく》を｜探《さが》しに｜降《お》りる。それでひと｜枠《わく》が｜埋《う》まる。そしてあの｜臆病《おくびょう》な｜男《おとこ》……あいつの｜狙《ねら》いは、｜生《い》きて｜列車《れっしゃ》に｜残《のこ》ること。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）だから、｜確実《かくじつ》に｜自分《じぶん》が｜列車《れっしゃ》に｜残《のこ》るために、｜家族《かぞく》を｜探《さが》したがっていたご｜主人《しゅじん》と｜手《て》を｜組《く》んで、｜一緒《いっしょ》に……

**ナレーション**：｜彼《かれ》の｜視線《しせん》が、ふたたびあの｜恐《おそ》ろしい｜傷《きず》に｜落《お》ちた。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）……いちばん｜脅威《きょうい》になりそうなこの｜男《おとこ》を｜殺《ころ》した。そのあとご｜主人《しゅじん》が｜降《お》りて｜去《さ》り、あの｜臆病《おくびょう》な｜男《おとこ》は｜安全《あんぜん》に｜列車《れっしゃ》に｜残《のこ》れる。

**ナレーション**：この｜推論《すいろん》は｜筋《すじ》が｜通《とお》り、｜目《め》の｜前《まえ》のすべてを｜説明《せつめい》してくれる。だが、｜背筋《せすじ》が｜凍《こお》る｜思《おも》いがした。

**リー・ジエ**：（つぶやくように）｜人間《にんげん》は、｜追《お》いつめられると……｜何《なん》でもするものなんだな……

**ナレーション**：｜彼《かれ》は｜深《ふか》く｜息《いき》を｜吸《す》って、｜身《み》を｜翻《ひるがえ》し、ホームを｜後《あと》にした。ご｜主人《しゅじん》を｜見《み》つけなければ。｜無事《ぶじ》を｜確《たし》かめて、｜一緒《いっしょ》に｜戻《もど》り、｜家族《かぞく》と｜再会《さいかい》させなければ。

**ナレーション**：リー・ジエは、｜来《き》た｜道《みち》の｜線路《せんろ》に｜踏《ふ》み｜入《い》った。｜線路《せんろ》の｜両側《りょうがわ》は｜底《そこ》なしの｜峡谷《きょうこく》で、｜歩《ある》ける｜路盤《ろばん》は｜狭《せま》い｜帯《おび》だけ。｜砂利《じゃり》が｜散《ち》らばり、ひどく｜歩《ある》きにくい。

**ナレーション**：｜彼《かれ》はできるかぎり｜足《あし》を｜速《はや》め、｜線路《せんろ》をたどって｜引《ひ》き｜返《かえ》した。｜紫《むらさき》の｜月明《つきあ》かりは｜弱《よわ》く、｜線路《せんろ》は｜闇《やみ》の｜中《なか》に｜延《の》び、｜未知《みち》へ｜続《つづ》く｜一匹《いっぴき》の｜銀色《ぎんいろ》の｜長《なが》い｜蛇《へび》のようだった。

**ナレーション**：｜十分《じゅっぷん》。｜二十分《にじゅっぷん》。｜三十分《さんじゅっぷん》。｜脚《あし》はもうほとんど｜感覚《かんかく》がなかったが、｜止《と》まるわけにはいかなかった。

**ナレーション**：｜一時間《いちじかん》｜近《ちか》く｜経《た》って、｜前方《ぜんぽう》の｜線路《せんろ》の｜上《うえ》に、｜倒《たお》れた｜人影《ひとかげ》が｜見《み》えた。

**リー・ジエ**：（｜胸《むね》が｜締《し》めつけられて）あれは……

**ナレーション**：｜彼《かれ》は｜急《いそ》いで｜駆《か》け｜寄《よ》った。｜見覚《みおぼ》えのある｜服《ふく》を｜着《き》たその｜人《ひと》は、｜小林《こばやし》さんのご｜主人《しゅじん》だった。

**リー・ジエ**：（ひざまずき、｜体《からだ》をひっくり｜返《かえ》して）｜小林《こばやし》さん！

**ナレーション**：だが、ご｜主人《しゅじん》の｜様子《ようす》を｜見《み》たとたん、｜心臓《しんぞう》を｜冷《つめ》たい｜手《て》でぎゅっとつかまれたような｜気《き》がした。

**ナレーション**：ご｜主人《しゅじん》は、すでに｜死《し》んでいた。｜目《め》は｜閉《と》じ、｜顔《かお》は｜青白《あおじろ》く、｜口《くち》の｜端《はし》には｜固《かた》まった｜血《ち》の｜筋《すじ》が｜残《のこ》っている。

**ナレーション**：だが、リー・ジエが｜本当《ほんとう》に｜衝撃《しょうげき》を｜受《う》けたのは、｜胸《むね》の｜傷《きず》だった。

**ナレーション**：それは｜凄惨《せいさん》な｜傷《きず》で、ちょうど｜心臓《しんぞう》の｜位置《いち》にあった。｜傷口《きずぐち》の｜縁《ふち》は｜平《たい》らできれいで、ひどく｜鋭《するど》い｜武器《ぶき》で｜一撃《いちげき》のもとに｜貫《つらぬ》かれたようだ。

**ナレーション**：｜拳《こぶし》による｜鈍《にぶ》い｜打撃《だげき》でも、｜石《いし》による｜殴打《おうだ》でもなく、これは――

**リー・ジエ**：（｜震《ふる》える｜手《て》で｜傷口《きずぐち》の｜縁《ふち》に｜触《ふ》れ）これは……｜剣《けん》の｜傷《きず》か？

**ナレーション**：｜長剣《ちょうけん》が｜正面《しょうめん》から｜突《つ》き｜刺《さ》さり、｜心臓《しんぞう》を｜貫《つらぬ》いている。きれいで｜無駄《むだ》がない。｜一撃《いちげき》で｜絶命《ぜつめい》だ。

**リー・ジエ**：（その｜場《ば》に｜立《た》ち｜尽《つ》くして）まさか……

**ナレーション**：これは｜格闘《かくとう》でついた｜傷《きず》ではなく、｜言《い》い｜争《あらそ》いの｜末《すえ》の｜過失《かしつ》でもない。｜意図的《いとてき》で、｜正確《せいかく》な｜殺《ころ》しだ。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》、｜衝撃《しょうげき》を｜受《う》けて）これは……｜殺《ころ》されたんだ。しかも、｜凶器《きょうき》は｜剣《けん》……

**ナレーション**：｜彼《かれ》は｜自分《じぶん》に｜落《お》ち｜着《つ》けと｜言《い》い｜聞《き》かせ、｜状況《じょうきょう》をもう｜一度《いちど》｜考《かんが》え｜直《なお》した。
