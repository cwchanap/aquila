# 第十二幕：もぬけの殻

**ナレーション**：リー・ジエは｜漆黒《しっこく》の｜森《もり》を｜全力《ぜんりょく》で｜駆《か》けた。｜脚《あし》の｜筋肉《きんにく》が｜燃《も》えるようで、｜肺《はい》は｜破裂《はれつ》しそうで、｜息《いき》をするたびに｜刺《さ》すように｜痛《いた》む。

**ナレーション**：だが、｜止《と》まるわけにはいかない。｜絶対《ぜったい》に。

**ナレーション**：｜頭《あたま》の｜中《なか》に、あの｜剣《けん》の｜傷《きず》が｜浮《う》かびつづける――きれいで、｜無駄《むだ》がなく、｜一撃《いちげき》で｜絶命《ぜつめい》。あの｜謎《なぞ》の｜第三者《だいさんしゃ》は、この｜森《もり》にいる。そして｜小林智子《こばやしともこ》と｜子《こ》どもたちは、その｜人物《じんぶつ》の｜家《いえ》にいるのだ。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》、｜焦《あせ》って）｜急《いそ》げ……もっと｜急《いそ》げ……

**ナレーション**：｜視界《しかい》がかすみはじめ、｜両脚《りょうあし》はほとんど｜感覚《かんかく》を｜失《うしな》った。｜体力《たいりょく》はとうに｜限界《げんかい》を｜超《こ》え、ただ｜意志《いし》の｜力《ちから》だけで｜体《からだ》を｜支《ささ》えている。

**ナレーション**：｜十分《じゅっぷん》。｜二十分《にじゅっぷん》。｜三十分《さんじゅっぷん》。｜時間《じかん》が｜止《と》まったかのようで、｜森《もり》は｜永遠《えいえん》に｜終《お》わらないかに｜思《おも》えた。

**ナレーション**：ついに、｜一時間《いちじかん》｜近《ちか》く｜走《はし》りつづけて、あの｜森《もり》の｜小屋《こや》がふたたび｜視界《しかい》に｜現《あらわ》れた。

**リー・ジエ**：（｜息《いき》を｜切《き》らして）｜着《つ》いた……

**ナレーション**：｜彼《かれ》は｜三段《さんだん》｜飛《と》ばしで｜扉《とびら》の｜前《まえ》に｜駆《か》け｜寄《よ》り、｜力《ちから》のかぎり｜扉《とびら》を｜押《お》した。

**リー・ジエ**：（｜叫《さけ》ぶ）｜小林《こばやし》さん！

**ナレーション**：｜扉《とびら》はびくともしない。

**リー・ジエ**：（さらに｜強《つよ》く｜押《お》し）｜陽菜《ひな》ちゃん！　｜翔太《しょうた》くん！

**ナレーション**：｜扉《とびら》はやはり｜何《なん》の｜反応《はんのう》も｜返《かえ》さない。ただ｜施錠《せじょう》されているだけでなく、｜何《なに》か｜重《おも》いものが｜内側《うちがわ》からつっかえているらしいと、｜彼《かれ》は｜気《き》づいた。

**リー・ジエ**：（｜肩《かた》で｜扉《とびら》に｜体当《たいあ》たりして）｜開《あ》けてくれ！　｜俺《おれ》だ！　リー・ジエだ！

**ナレーション**：「どん！」｜鈍《にぶ》い｜衝撃音《しょうげきおん》が｜森《もり》に｜響《ひび》いた。だが｜分厚《ぶあつ》い｜木《き》の｜扉《とびら》はわずかに｜震《ふる》えただけで、とても｜押《お》し｜破《やぶ》れない。

**リー・ジエ**：（なおも｜叫《さけ》ぶ）｜小林《こばやし》さん！　｜中《なか》にいるんですか！　｜返事《へんじ》をしてください！

**ナレーション**：｜返事《へんじ》はない。｜小屋《こや》の｜中《なか》は、｜死《し》んだように｜静《しず》まり｜返《かえ》っている。

**ナレーション**：リー・ジエは｜数歩《すうほ》｜下《さ》がり、｜鍵《かぎ》のあたりを｜力《ちから》いっぱい｜蹴《け》りつけた。｜一度《いちど》、｜二度《にど》、｜三度《さんど》。｜木《き》の｜扉《とびら》は｜鈍《にぶ》い｜音《おと》を｜立《た》てるが、やはり｜微動《びどう》だにしない。

**リー・ジエ**：（｜動《うご》きを｜止《と》め、｜荒《あら》く｜息《いき》をついて）くそ……

**ナレーション**：｜不吉《ふきつ》な｜予感《よかん》が、｜氷水《こおりみず》のように｜頭《あたま》のてっぺんから｜浴《あ》びせられた。｜彼《かれ》はすぐに｜小屋《こや》の｜脇《わき》に｜回《まわ》り、｜窓《まど》の｜前《まえ》に｜出《で》た。

**ナレーション**：ガラス｜越《ご》しに、｜紫《むらさき》の｜月明《つきあ》かりが、かろうじて｜室内《しつない》を｜照《て》らしている。

**ナレーション**：リー・ジエの｜心《こころ》は、｜一瞬《いっしゅん》で｜谷底《たにそこ》へ｜沈《しず》んだ。

**ナレーション**：｜小屋《こや》の｜中《なか》には、｜誰《だれ》もいなかった。

**リー・ジエ**：（｜低《ひく》く、｜信《しん》じられずに）どうして……

**ナレーション**：｜彼《かれ》は｜窓《まど》に｜手《て》をかけて｜押《お》してみた。｜窓《まど》には｜鍵《かぎ》がなく、｜軽《かる》く｜押《お》しただけで｜開《ひら》いた。

**ナレーション**：リー・ジエはもうためらわず、｜両手《りょうて》で｜窓枠《まどわく》を｜押《お》さえて、｜身《み》をひるがえして｜屋内《おくない》に｜飛《と》び｜込《こ》んだ。｜両足《りょうあし》が｜着地《ちゃくち》した｜瞬間《しゅんかん》、｜危《あや》うく｜倒《たお》れそうになった――｜脚《あし》はすっかり｜麻痺《まひ》していたのだ。

**ナレーション**：だが、そんなことを｜気《き》にしている｜暇《ひま》はない。｜彼《かれ》の｜視線《しせん》は、｜部屋《へや》じゅうを｜素早《すばや》く｜走《はし》った。

**ナレーション**：｜誰《だれ》もいない。｜本当《ほんとう》に、｜誰《だれ》もいない。

**リー・ジエ**：（｜大声《おおごえ》で）｜小林《こばやし》さん！　｜陽菜《ひな》ちゃん！　｜翔太《しょうた》くん！

**ナレーション**：｜空《から》っぽの｜屋内《おくない》に、｜自分《じぶん》の｜声《こえ》だけが｜響《ひび》いた。

**ナレーション**：リー・ジエは｜自分《じぶん》に｜落《お》ち｜着《つ》けと｜言《い》い｜聞《き》かせ、｜屋内《おくない》のあらゆる｜細部《さいぶ》を｜注意《ちゅうい》｜深《ふか》く｜観察《かんさつ》しはじめた。

**ナレーション**：まずは｜正面《しょうめん》の｜扉《とびら》。｜太《ふと》い｜木《き》の｜棒《ぼう》が｜扉《とびら》の｜内側《うちがわ》に｜横《よこ》たえられ、｜扉板《とびらいた》と｜壁《かべ》のあいだにしっかりとつっかえている。だから｜押《お》しても｜開《ひら》かなかったのだ――｜内側《うちがわ》から｜閂《かんぬき》がかかっていた。

**リー・ジエ**：（｜扉《とびら》に｜近《ちか》づいて、｜木《き》の｜棒《ぼう》を｜調《しら》べ）｜内側《うちがわ》からふさいである……

**ナレーション**：｜次《つぎ》に、｜一人用《ひとりよう》のベッド。｜毛布《もうふ》には｜誰《だれ》かが｜横《よこ》になったことがはっきりわかる｜跡《あと》があり、まるで｜二《ふた》つの｜小《ちい》さな｜体《からだ》が｜身《み》を｜寄《よ》せ｜合《あ》っていたかのようだった。だが｜毛布《もうふ》は｜乱雑《らんざつ》に｜脇《わき》へめくられ、｜誰《だれ》かが｜慌《あわ》てて｜起《お》き｜上《あ》がったようにも｜見《み》える。

**ナレーション**：リー・ジエは｜台所《だいどころ》へ｜行《い》った。テーブルの｜上《うえ》にはパンが｜一切《ひとき》れ、｜数口《すうくち》かじった｜跡《あと》があり、｜水《みず》が｜半分《はんぶん》｜入《はい》ったコップもある。そばの｜戸棚《とだな》の｜扉《とびら》は｜開《ひら》いたままだった――｜彼《かれ》が｜補給品《ほきゅうひん》を｜取《と》るときに｜開《あ》けたものだ。

**ナレーション**：｜何《なに》もかもが、ここにはついさっきまで｜人《ひと》がいたことを｜示《しめ》していた。｜食《た》べ｜物《もの》を｜口《くち》にし、｜子《こ》どもたちは｜眠《ねむ》っていた。だがいま、｜彼《かれ》らは｜消《き》えている。

**リー・ジエ**：（｜部屋《へや》の｜中央《ちゅうおう》に｜立《た》ち、あたりを｜見回《みまわ》して）いったい……｜何《なに》が｜起《お》きたんだ？

**ナレーション**：｜彼《かれ》は｜頭《あたま》の｜中《なか》で｜手《て》がかりをつなぎ｜合《あ》わせはじめた。｜大《おお》きな、｜説明《せつめい》のつかない｜矛盾《むじゅん》が｜浮《う》かび｜上《あ》がってくる。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》、｜考《かんが》えながら）｜扉《とびら》が｜内側《うちがわ》から｜閂《かんぬき》で｜閉《と》ざされている。これは｜明《あき》らかだ――｜屋外《おくがい》からの｜危険《きけん》を｜避《さ》けていたんだ。｜俺《おれ》の｜言《い》ったとおり、｜鍵《かぎ》をかけて、｜誰《だれ》にも｜開《あ》けなかったんだろう。

**ナレーション**：｜彼《かれ》は｜窓《まど》の｜前《まえ》に｜行《い》き、｜自分《じぶん》が｜押《お》し｜開《あ》けた｜窓《まど》を｜見《み》つめた。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）だが……｜人《ひと》は｜消《き》えた。なのに、｜扉《とびら》は｜内側《うちがわ》から｜塞《ふさ》がれたままだ。｜唯一《ゆいいつ》の｜出口《でぐち》は、この｜鍵《かぎ》のかかっていない｜窓《まど》だけ。

**ナレーション**：｜彼《かれ》はこの｜矛盾《むじゅん》を｜理解《りかい》しようと｜努《つと》めた。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）｜自分《じぶん》たちで｜出《で》ていったのなら……なぜ｜窓《まど》から｜這《は》い｜出《で》た？　｜小林《こばやし》さんは｜二人《ふたり》の｜子《こ》どもを｜連《つ》れている。｜窓《まど》からでは｜危険《きけん》で、｜骨《ほね》も｜折《お》れる。なぜ｜扉《とびら》から｜出《で》なかった？

**ナレーション**：だが、もう｜一《ひと》つの｜可能性《かのうせい》のほうが、｜彼《かれ》をいっそう｜不安《ふあん》にさせた。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）もし、ご｜主人《しゅじん》を｜殺《ころ》した｜人間《にんげん》が｜押《お》し｜入《い》って、｜無理《むり》やり｜連《つ》れ｜去《さ》ったのなら……

**ナレーション**：｜彼《かれ》の｜視線《しせん》が、ふたたび｜屋内《おくない》を｜走《はし》った。テーブルも｜椅子《いす》もきちんと｜並《なら》び、｜倒《たお》れてはいない。｜床《ゆか》に｜引《ひ》きずった｜跡《あと》はない。｜壁《かべ》にぶつかった｜跡《あと》もない。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）……なぜ、｜室内《しつない》に｜争《あらそ》った｜形跡《けいせき》がまったくない？

**ナレーション**：｜彼《かれ》はベッドのそばに｜行《い》き、｜乱《みだ》れた｜毛布《もうふ》を｜見《み》た。｜子《こ》どもを｜守《まも》ろうとする｜小林智子《こばやしともこ》の｜決意《けつい》からして、｜誰《だれ》かが｜押《お》し｜入《い》れば、｜必死《ひっし》に｜抵抗《ていこう》したはずだ。だが、ここには｜何《なに》もない。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）｜静《しず》かすぎる。あまりにも……｜穏《おだ》やかだ。まるで、ただ｜起《お》き｜上《あ》がって、それから……

**ナレーション**：それから、｜何《なん》だ？　｜窓《まど》から｜出《で》ていく？　なぜ？　どこへ？

**リー・ジエ**：（｜低《ひく》く、｜困惑《こんわく》して）まったく｜筋《すじ》が｜通《とお》らない……

**ナレーション**：どちらの｜可能性《かのうせい》にも、｜大《おお》きな｜矛盾《むじゅん》があった。｜室内《しつない》の｜異様《いよう》なほどの｜静《しず》けさと、｜彼《かれ》らの｜奇妙《きみょう》な｜消《き》え｜方《かた》は、まるで｜噛《か》み｜合《あ》わない。

**ナレーション**：｜彼《かれ》らは、まるで……｜空気《くうき》の｜中《なか》へ｜蒸発《じょうはつ》してしまったかのようだった。

**ナレーション**：リー・ジエは｜空《から》っぽの｜小屋《こや》の｜中《なか》に｜立《た》ち、これまでにない｜困惑《こんわく》を｜覚《おぼ》えていた。｜周囲《しゅうい》の｜静寂《せいじゃく》が｜彼《かれ》を｜圧迫《あっぱく》し、ほとんど｜考《かんが》えることもできない。

**リー・ジエ**：（｜深《ふか》く｜息《いき》を｜吸《す》って）｜落《お》ち｜着《つ》け……｜落《お》ち｜着《つ》かないと……

**ナレーション**：｜彼《かれ》は、｜乱《みだ》れる｜思考《しこう》を｜無理《むり》やり｜静《しず》めた。その｜場《ば》で｜憶測《おくそく》を｜重《かさ》ねても｜意味《いみ》がない。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）｜手《て》がかりを｜探《さが》しに｜外《そと》へ｜出《で》るしかない。｜何《なに》か｜痕跡《こんせき》を｜残《のこ》していないか、｜確《たし》かめるんだ。

**ナレーション**：｜彼《かれ》は｜台所《だいどころ》へ｜戻《もど》り、テーブルに｜残《のこ》っていた｜半分《はんぶん》のコップの｜水《みず》を｜自分《じぶん》の｜水筒《すいとう》に｜注《そそ》いだ。それからリュックの｜中《なか》の｜補給品《ほきゅうひん》を｜確《たし》かめた――パンはまだ｜少《すこ》しあり、｜水《みず》も｜足《た》りている。

**ナレーション**：リー・ジエは｜戸口《とぐち》へ｜行《い》き、あの｜重《おも》い｜木《き》の｜棒《ぼう》をどけた。｜棒《ぼう》は｜床《ゆか》に｜落《お》ちて、｜鈍《にぶ》い｜音《おと》を｜立《た》てた。

**ナレーション**：｜彼《かれ》が｜扉《とびら》を｜押《お》し｜開《あ》けると、｜冷《つめ》たい｜夜風《よかぜ》が｜屋内《おくない》に｜流《なが》れ｜込《こ》んだ。｜外《そと》の｜森《もり》は｜真《ま》っ｜暗《くら》で、｜紫《むらさき》の｜月《つき》だけが、かすかな｜光《ひかり》を｜投《な》げている。

**リー・ジエ**：（｜手《て》の｜中《なか》の｜剣《けん》を｜握《にぎ》りしめて）｜必《かなら》ず、｜見《み》つけ｜出《だ》す。

**ナレーション**：｜彼《かれ》は｜謎《なぞ》に｜満《み》ちた｜空《から》っぽの｜小屋《こや》を｜後《あと》にして、｜果《は》てしない｜夜《よる》の｜森《もり》の｜中《なか》へ｜消《き》えていった。

**ナレーション**：｜背後《はいご》で、｜小屋《こや》の｜扉《とびら》が｜風《かぜ》の｜中《なか》でかすかに｜揺《ゆ》れ、「ぎい」ときしむ｜音《おと》を｜立《た》てた。｜誰《だれ》も｜知《し》らない｜秘密《ひみつ》を、｜語《かた》っているかのように。
