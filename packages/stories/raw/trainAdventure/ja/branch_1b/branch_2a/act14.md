# 第十四幕：十字路の決断

**ナレーション**：リー・ジエは｜遺体《いたい》のそばにひざまずき、｜頭《あたま》の｜中《なか》は｜混乱《こんらん》していた。｜無数《むすう》の｜疑問《ぎもん》が｜波《なみ》のように｜押《お》し｜寄《よ》せてくる。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）なぜ……なぜこの｜子《こ》がここに？

**ナレーション**：｜彼女《かのじょ》は｜間違《まちが》いなく「｜寂海《じゃっかい》」｜駅《えき》で｜降《お》りたはずだ。あのおじさん、あの｜眼鏡《めがね》の｜男《おとこ》、そして｜残《のこ》りの｜三人《さんにん》の｜大学生《だいがくせい》と｜一緒《いっしょ》に。それはもう｜何時間《なんじかん》も｜前《まえ》のことだ。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）「｜寂海《じゃっかい》」からここまで……この｜小径《こみち》を｜歩《ある》けば、たしかに｜着《つ》ける。だが、なぜ｜彼女《かのじょ》がここに？　｜誰《だれ》と｜一緒《いっしょ》だったんだ？

**ナレーション**：さらに｜彼《かれ》を｜戸惑《とまど》わせたのは――｜小林智子《こばやしともこ》と｜子《こ》どもたちは、いったいどこへ｜行《い》ったのかということだ。｜小屋《こや》を｜出《で》たのが｜小林智子《こばやしともこ》でなかったのなら、｜彼女《かのじょ》たちはどうやって｜消《き》えたのか。

**ナレーション**：｜彼《かれ》は｜立《た》ち｜上《あ》がって、あたりを｜見回《みまわ》した。｜森《もり》は｜真《ま》っ｜暗《くら》で、｜紫《むらさき》の｜月《つき》がかすかな｜光《ひかり》を｜投《な》げているだけだ。

**リー・ジエ**：（｜深《ふか》く｜息《いき》を｜吸《す》って）｜落《お》ち｜着《つ》け……｜慎重《しんちょう》に｜調《しら》べないと。

**ナレーション**：｜彼《かれ》は｜自分《じぶん》を｜落《お》ち｜着《つ》かせ、この｜林《はやし》の｜空《あ》き｜地《ち》を｜注意《ちゅうい》｜深《ふか》く｜調《しら》べはじめた。

**ナレーション**：｜地面《じめん》の｜足跡《あしあと》はぐちゃぐちゃだった。もとはくっきりしていた｜二列《にれつ》の｜足跡《あしあと》も、ここでは｜入《い》り｜乱《みだ》れ、ほかの｜多《おお》くの｜足跡《あしあと》と｜絡《から》み｜合《あ》っている。

**ナレーション**：リー・ジエはしゃがんで、｜一《ひと》つひとつ｜見分《みわ》けていった。｜踵《かかと》が｜深《ふか》く｜食《く》い｜込《こ》んだ｜跡《あと》は、｜誰《だれ》かが｜急《きゅう》に｜立《た》ち｜止《ど》まったか、｜振《ふ》り｜向《む》いたかのようだ。｜引《ひ》きずった｜跡《あと》は、｜誰《だれ》かがもがいたかのようだった。

**ナレーション**：｜地面《じめん》の｜落《お》ち｜葉《ば》は｜広《ひろ》い｜範囲《はんい》でめくれ｜上《あ》がり、｜下《した》の｜黒《くろ》い｜土《つち》が｜見《み》えている。｜折《お》れた｜枝《えだ》が｜何本《なんぼん》か、｜地面《じめん》に｜散《ち》らばっていた。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）ここで、｜少《すこ》し｜前《まえ》に｜争《あらそ》いが……あるいは、｜追跡《ついせき》があったんだ。

**ナレーション**：｜彼《かれ》はこの｜混乱《こんらん》の｜中《なか》から｜何人《なんにん》が｜関《かか》わったのかを｜見分《みわ》けようとしたが、｜足跡《あしあと》の｜重《かさ》なりがひどすぎて、まったく｜判断《はんだん》がつかない。

**ナレーション**：ただ｜一《ひと》つ｜確《たし》かなのは――ここまで｜追《お》ってきたあの｜二列《にれつ》のはっきりした｜足跡《あしあと》が、ここでぷっつり｜途切《とぎ》れていることだ。｜北《きた》へ｜延《の》びる｜痕跡《こんせき》もなく、ほかの｜方角《ほうがく》へ｜延《の》びる｜痕跡《こんせき》もない。

**ナレーション**：まるで、｜空気《くうき》の｜中《なか》へ｜消《き》えてしまったようだった。

**リー・ジエ**：（｜立《た》ち｜上《あ》がり、｜眉《まゆ》をひそめて）｜消《き》えるわけがない……｜何《なに》か｜見落《みお》としているはずだ……

**ナレーション**：｜彼《かれ》は｜女《おんな》の｜子《こ》の｜遺体《いたい》のそばに｜行《い》き、しゃがんで、その｜靴《くつ》を｜注意《ちゅうい》｜深《ふか》く｜観察《かんさつ》した。

**ナレーション**：おしゃれなスニーカーで、｜白《しろ》く、｜泥《どろ》と｜血《ち》で｜汚《よご》れている。｜彼《かれ》はサイズを｜推《お》し｜量《はか》った。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）このサイズ……

**ナレーション**：｜彼《かれ》は、あの｜二列《にれつ》の｜足跡《あしあと》を｜思《おも》い｜出《だ》した――｜浅《あさ》い｜女性《じょせい》の｜足跡《あしあと》と、｜深《ふか》い｜男性《だんせい》の｜足跡《あしあと》。

**ナレーション**：リー・ジエの｜心臓《しんぞう》が、ずしりと｜沈《しず》んだ。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》、｜衝撃《しょうげき》を｜受《う》けて）このサイズ……｜俺《おれ》が｜追《お》ってきた、あの｜女性《じょせい》の｜足跡《あしあと》と｜同《おな》じだ！

**ナレーション**：｜恐《おそ》ろしい｜事実《じじつ》に、｜彼《かれ》は｜突然《とつぜん》｜気《き》づいた。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）｜俺《おれ》はずっと、あの｜女性《じょせい》の｜足跡《あしあと》は｜小林智子《こばやしともこ》のものだと｜思《おも》っていた……だが、｜実際《じっさい》にはこの｜子《こ》の｜足跡《あしあと》だったんだ！

**ナレーション**：つまり、この｜女《おんな》の｜子《こ》はかつて｜小屋《こや》に｜来《き》ていたということだ。｜彼女《かのじょ》は、あの｜謎《なぞ》の｜男《おとこ》と｜一緒《いっしょ》に、｜小屋《こや》を｜出《で》て、ここまで｜来《き》たのだ。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）なら……｜小林《こばやし》さんは？　｜彼女《かのじょ》と｜子《こ》どもたちは……いったいどこへ｜行《い》った？　この｜子《こ》が｜来《く》る｜前《まえ》に｜消《き》えていたのか？　それとも……

**ナレーション**：｜彼《かれ》はさらに｜手《て》がかりを｜探《さが》そうとしたが、この｜主要《しゅよう》な｜小径《こみち》を｜外《はず》れると、｜森《もり》には｜茂《しげ》みと｜木々《きぎ》が｜密生《みっせい》するばかりで、｜痕跡《こんせき》などまるで｜見《み》つからない。

**リー・ジエ**：（｜低《ひく》く、｜落胆《らくたん》して）これでは、｜彼女《かのじょ》たちは｜見《み》つからない……

**ナレーション**：｜彼《かれ》はその｜場《ば》に｜立《た》ち、｜女《おんな》の｜子《こ》の｜遺体《いたい》を｜見《み》つめた。この｜若《わか》い｜命《いのち》は、こうして｜見知《みし》らぬ｜森《もり》の｜中《なか》で｜終《お》わったのだ。

**ナレーション**：リー・ジエは｜深《ふか》くため｜息《いき》をついた。｜剣《けん》を｜地面《じめん》に｜突《つ》き｜立《た》て、｜両手《りょうて》でそばの｜柔《やわ》らかい｜土《つち》を｜掘《ほ》りはじめる。

**ナレーション**：｜爪《つめ》の｜下《した》に｜泥《どろ》が｜溜《た》まり、｜手《て》のひらは｜荒《あら》い｜木《き》の｜根《ね》で｜切《き》れた。それでも、｜彼《かれ》は｜止《と》まらない。ひとすくい、またひとすくい。ゆっくりと｜浅《あさ》い｜穴《あな》が｜掘《ほ》れていく。

**ナレーション**：｜十分後《じゅっぷんご》、｜穴《あな》ができた。｜深《ふか》くはないが、｜一人《ひとり》を｜納《おさ》めるには｜足《た》りる。

**ナレーション**：リー・ジエは、｜女《おんな》の｜子《こ》をそっと｜抱《だ》き｜上《あ》げた。｜体《からだ》はすでに｜冷《つめ》たく、｜硬《かた》くなっている。｜彼女《かのじょ》を｜穴《あな》にそっと｜横《よこ》たえ、できるだけ｜安《やす》らかに｜見《み》えるようにした。

**ナレーション**：それから、｜土《つち》をかけはじめた。ひとすくい、またひとすくい。あの｜若《わか》い｜顔《かお》を｜覆《おお》い、あのうつろな｜目《め》を｜覆《おお》い、あの｜恐《おそ》ろしい｜傷《きず》を｜覆《おお》う。

**ナレーション**：｜最後《さいご》に、その｜上《うえ》に｜小《ちい》さな｜土《つち》の｜山《やま》を｜盛《も》り、まわりを｜数個《すうこ》の｜石《いし》で｜囲《かこ》った。

**リー・ジエ**：（｜低《ひく》く）せめて……｜安《やす》らかに｜眠《ねむ》ってくれ。

**ナレーション**：｜彼《かれ》は、その｜粗末《そまつ》な｜墓《はか》の｜前《まえ》で、しばし｜黙《だま》って｜立《た》っていた。ふいに、｜線路《せんろ》の｜上《うえ》に｜置《お》き｜去《ざ》りにした｜小林《こばやし》さんのご｜主人《しゅじん》のことを｜思《おも》い｜出《だ》した。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）あのときは、｜小屋《こや》に｜戻《もど》ることしか｜頭《あたま》になかった……｜何《なに》かしてやるべきだったのに、すっかり｜忘《わす》れていた。

**ナレーション**：｜胸《むね》に、｜罪悪感《ざいあくかん》がこみ｜上《あ》げた。だがいまは、｜引《ひ》き｜返《かえ》すときではない。｜小林智子《こばやしともこ》と｜子《こ》どもたちはどこにいるのかもわからない。｜探《さが》しつづけなければならない。

**リー・ジエ**：（｜墓《はか》に｜向《む》かって）すまない……

**ナレーション**：｜彼《かれ》は｜手《て》の｜泥《どろ》を｜払《はら》い、｜地面《じめん》に｜刺《さ》さっていた｜剣《けん》を｜引《ひ》き｜抜《ぬ》いて、｜完全《かんぜん》に｜気持《きも》ちを｜落《お》ち｜着《つ》けた。

**ナレーション**：リー・ジエは｜小径《こみち》に｜立《た》ち、｜前《まえ》にも｜後《うし》ろにも｜延《の》びる｜道《みち》を｜見《み》た。｜選《えら》ばなければならない。

**ナレーション**：｜南《みなみ》は、｜来《き》た｜方角《ほうがく》だ――｜小屋《こや》へ｜戻《もど》り、「｜幽冥《ゆうめい》の｜都《みやこ》」へ｜戻《もど》る。｜小林智子《こばやしともこ》と｜子《こ》どもたちは、まだその｜方角《ほうがく》にいる｜可能性《かのうせい》が｜高《たか》い。｜見《み》つけなければならない。

**ナレーション**：｜北《きた》は、「｜亡者《もうじゃ》の｜峡谷《きょうこく》」の｜方角《ほうがく》だ。この｜女《おんな》の｜子《こ》と｜謎《なぞ》の｜男《おとこ》は、この｜方角《ほうがく》から｜来《き》た。｜向《む》こうに｜行《い》けば、さらに｜手《て》がかりが｜見《み》つかるかもしれない。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）｜戻《もど》るか？　それとも、このまま｜進《すす》むか？

**ナレーション**：｜一方《いっぽう》は、｜小屋《こや》に｜戻《もど》って｜小林智子《こばやしともこ》と｜子《こ》どもたちの｜行方《ゆくえ》を｜探《さが》すこと。もう｜一方《いっぽう》は、「｜亡者《もうじゃ》の｜峡谷《きょうこく》」へ｜向《む》かい、この｜女《おんな》の｜子《こ》と｜謎《なぞ》の｜男《おとこ》の｜出《で》どころを｜突《つ》き｜止《と》めること。

**ナレーション**：どちらの｜選択《せんたく》も｜危険《きけん》に｜満《み》ちていて、どちらも｜間違《まちが》いかもしれない。それでも、｜彼《かれ》はどちらかを｜選《えら》ばなければならない。

**ナレーション**：｜紫《むらさき》の｜月《つき》が｜空《そら》をゆっくり｜動《うご》き、｜長《なが》い｜影《かげ》を｜落《お》とす。｜森《もり》は｜闇《やみ》の｜中《なか》で、｜彼《かれ》の｜決断《けつだん》を｜待《ま》っていた。

**リー・ジエ**：（｜手《て》の｜中《なか》の｜剣《けん》を｜握《にぎ》りしめて）……

**ナレーション**：｜時間《じかん》はあまりない。｜選《えら》ばなければならない。
