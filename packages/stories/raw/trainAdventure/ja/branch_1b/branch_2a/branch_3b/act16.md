# 第十六幕：終焉の祭壇

**ナレーション**：リー・ジエは、｜陵墓《りょうぼ》のような｜壮大《そうだい》な｜建築《けんちく》の｜前《まえ》に｜立《た》ち、その｜巨大《きょだい》な｜輪郭《りんかく》を｜見上《みあ》げていた。

**ナレーション**：｜建物《たてもの》を｜成《な》す｜黒《くろ》い｜岩《いわ》は｜鏡《かがみ》のようになめらかで、｜表面《ひょうめん》にはざらつきひとつない。｜紫《むらさき》の｜月《つき》に｜照《て》らされても、｜光《ひかり》を｜反射《はんしゃ》せず、むしろあらゆる｜光《ひかり》を｜吸《す》い｜込《こ》んで、｜夜《よる》よりもなお｜深《ふか》い｜闇《やみ》になっていた。

**リー・ジエ**：（｜低《ひく》い｜声《こえ》で）ここは……｜本当《ほんとう》に、｜駅《えき》なのか？

**ナレーション**：｜巨大《きょだい》なアーチの｜入口《いりぐち》は、｜静《しず》かに｜口《くち》を｜開《あ》けていた。｜獲物《えもの》が｜自分《じぶん》から｜飛《と》び｜込《こ》んでくるのを｜待《ま》つ、｜巨獣《きょじゅう》の｜口《くち》のように。アーチの｜上《うえ》の｜紋様《もんよう》は、かすかな｜月明《つきあ》かりの｜中《なか》で｜見《み》え｜隠《かく》れし、｜彼《かれ》には｜理解《りかい》できない｜形《かたち》にねじれている。

**ナレーション**：｜彼《かれ》は｜手《て》の｜中《なか》の｜剣《けん》を｜握《にぎ》りしめ、｜掌《てのひら》に｜伝《つた》わる｜冷《つめ》たい｜感触《かんしょく》を｜確《たし》かめた。｜深《ふか》く｜息《いき》を｜吸《す》い、ゆっくりと｜入口《いりぐち》へ｜歩《ふ》を｜進《すす》める。

**ナレーション**：｜一歩《いっぽ》｜足《あし》を｜踏《ふ》み｜入《い》れた｜瞬間《しゅんかん》、｜周囲《しゅうい》のあらゆる｜音《おと》が｜消《き》えた。

**ナレーション**：｜森《もり》の｜風《かぜ》の｜音《おと》も、｜遠《とお》い｜峡谷《きょうこく》のこだまも｜消《き》え、｜自分《じぶん》の｜呼吸《こきゅう》の｜音《おと》さえ、｜弱々《よわよわ》しくなった。｜代《か》わりにあるのは、｜息《いき》の｜詰《つ》まるような、｜古《ふる》い｜墓所《ぼしょ》の｜死《し》の｜静《しず》けさだった。

**リー・ジエ**：（｜足《あし》を｜止《と》めて、｜辺《あた》りを｜見回《みまわ》し）……

**ナレーション**：｜待合《まちあい》の｜大広間《おおひろま》は、あきれるほど｜広《ひろ》かった。｜巨大《きょだい》な｜石《いし》の｜柱《はしら》が｜何本《なんぼん》も、｜床《ゆか》から、｜見《み》えない｜天井《てんじょう》のドームへと｜伸《の》びていて、どの｜柱《はしら》にも、｜奇妙《きみょう》な｜文様《もんよう》が｜彫《ほ》られている。その｜文様《もんよう》は、｜紫《むらさき》の｜月《つき》のかすかな｜光《ひかり》の｜下《した》で、かすかにまたたいているようだったが、じっくり｜見《み》ようとすると、ふたたび｜死《し》んだように｜光《ひかり》を｜失《うしな》った。

**ナレーション**：｜空気《くうき》は｜冷《つめ》たく｜薄《うす》く、｜息《いき》をするたび、｜氷《こおり》を｜吸《す》い｜込《こ》むように｜痛《いた》んだ。｜空気《くうき》には、｜古《ふる》い｜岩《いわ》とオゾンの｜匂《にお》いが｜満《み》ちていて、それに、｜長《なが》く｜閉《と》ざされた｜空間《くうかん》に｜特有《とくゆう》の、｜言《い》い｜表《あらわ》しがたい、｜黴《か》びたような｜気配《けはい》が｜混《ま》じっている。

**ナレーション**：｜床《ゆか》は、なめらかな｜黒《くろ》い｜石《いし》が｜敷《し》かれていて、｜彼《かれ》の｜姿《すがた》をくっきりと｜映《うつ》し｜出《だ》す。リー・ジエは、｜床《ゆか》の｜上《うえ》のその｜孤独《こどく》な｜姿《すがた》を｜眺《なが》め、どちらが｜本物《ほんもの》の｜自分《じぶん》なのか、しばらくわからなくなった。

**ナレーション**：｜広間《ひろま》の｜突《つ》き｜当《あ》たりには、ホームへの｜出口《でぐち》のほかに、｜建物《たてもの》のさらに｜奥《おく》へ｜続《つづ》く、｜薄暗《うすぐら》い｜回廊《かいろう》があった。

**ナレーション**：その｜回廊《かいろう》は、｜底《そこ》｜知《し》れない｜傷口《きずぐち》のように、｜建物《たてもの》の｜体内《たいない》から｜裂《さ》けていた。｜中《なか》には｜光源《こうげん》が｜一《ひと》つもなく、｜闇《やみ》は｜実体《じったい》を｜持《も》つかのように｜濃《こ》く、｜胸《むね》をざわつかせるような｜冷気《れいき》を｜放《はな》っている。

**リー・ジエ**：（｜回廊《かいろう》を｜見《み》つめて、｜心《こころ》の｜声《こえ》）あそこが……この｜建物《たてもの》の｜核心《かくしん》だ。

**ナレーション**：だが、｜彼《かれ》は｜自分《じぶん》に｜言《い》い｜聞《き》かせて、｜体《からだ》の｜向《む》きを｜変《か》えた。いまは｜探索《たんさく》の｜時《とき》ではない。まず、ホームの｜様子《ようす》を｜確《たし》かめなければ。

**リー・ジエ**：（｜低《ひく》い｜声《こえ》で）まず、ホームだ。

**ナレーション**：｜彼《かれ》はがらんとした｜広間《ひろま》を｜横切《よこぎ》った。｜一歩《いっぽ》｜一歩《いっぽ》の｜足音《あしおと》が｜限《かぎ》りなく｜増幅《ぞうふく》され、｜石《いし》の｜柱《はしら》の｜間《あいだ》にうつろに｜反響《はんきょう》する。まるで、｜目《め》に｜見《み》えない｜無数《むすう》の｜自分《じぶん》が、｜闇《やみ》の｜中《なか》で、｜彼《かれ》と｜同《おな》じ｜歩調《ほちょう》で｜歩《ある》いているようだった。

**ナレーション**：｜広間《ひろま》を｜出《で》ると、｜目《め》の｜前《まえ》の｜光景《こうけい》に、リー・ジエは｜息《いき》をのんだ。

**リー・ジエ**：（｜足《あし》を｜止《と》めて、｜衝撃《しょうげき》を｜受《う》け）これは、まさか……

**ナレーション**：ホームは｜並外《なみはず》れて｜広《ひろ》く、すべて｜黒《くろ》い｜石《いし》でできていた。だが、｜峡谷《きょうこく》の｜上《うえ》に｜張《は》り｜出《だ》しているのではなく、｜巨大《きょだい》な｜湖面《こめん》の｜上《うえ》へ｜伸《の》びていた。

**ナレーション**：それは、この｜壮大《そうだい》な｜建物《たてもの》の｜内部《ないぶ》にある｜湖《みずうみ》だった。｜湖水《こすい》は｜澄《す》んだ｜翠緑色《すいりょくしょく》をしていて、｜溶《と》けた｜翡翠《ひすい》のように、やわらかな、｜神々《こうごう》しい｜光《ひかり》を｜放《はな》っている。

**ナレーション**：｜建物《たてもの》のドームのいちばん｜高《たか》い｜所《ところ》には、｜聖《せい》なる｜光源《こうげん》が｜懸《か》かっていた。ふつうの｜炎《ほのお》ではなく、｜温《あたた》かな｜銀白色《ぎんはくしょく》の｜光《ひかり》を｜放《はな》つ｜魔法《まほう》の｜炎《ほのお》で、｜煙《けむり》ひとつ｜立《た》てず、｜静《しず》かに｜燃《も》えつづけている。

**ナレーション**：｜銀白《ぎんはく》の｜光《ひかり》が｜翠緑《すいりょく》の｜湖面《こめん》に｜降《ふ》りそそぎ、｜空間全体《くうかんぜんたい》を、｜聖《せい》なる、｜安《やす》らかな｜色合《いろあ》いに｜染《そ》めていた。｜光《ひかり》と｜水《みず》が｜織《お》りなして、｜荘厳《そうごん》で｜神聖《しんせい》な｜雰囲気《ふんいき》をつくり｜出《だ》し、まるで、ここが｜何《なに》か｜古《ふる》い｜種族《しゅぞく》の｜聖地《せいち》であるかのようだった。

**リー・ジエ**：（｜遠《とお》くを｜見《み》て、｜小声《こごえ》で）きれいだ……

**ナレーション**：｜彼《かれ》は｜目《め》を｜細《ほそ》めて、｜湖《みずうみ》の｜果《は》てを｜見《み》きわめようとした。｜線路《せんろ》はまっすぐに｜伸《の》び、｜遠《とお》く、｜銀《ぎん》の｜光《ひかり》と｜翠緑《すいりょく》の｜境目《さかいめ》へ｜消《き》えている。

**ナレーション**：だが、｜湖《みずうみ》の｜縁《ふち》も、この｜建物《たてもの》の｜果《は》ても、まったく｜見《み》えない。まるで、この｜空間《くうかん》が｜果《は》てしなく｜広《ひろ》がっていて、｜終《お》わりがないかのようだった。

**ナレーション**：ホームの｜中央《ちゅうおう》に、｜巨大《きょだい》な｜石碑《せきひ》が｜立《た》っていた。

**ナレーション**：その｜石碑《せきひ》は、｜大人二人《おとなふたり》を｜積《つ》み｜上《あ》げたよりも｜高《たか》く、｜全体《ぜんたい》が｜漆黒《しっこく》で、｜表面《ひょうめん》は｜鏡《かがみ》のようになめらかだった。そこには、｜深《ふか》く｜力強《ちからづよ》い｜筆致《ひっち》で、｜三《みっ》つの｜大《おお》きな｜文字《もじ》が｜刻《きざ》まれている――

**ナレーション**：「｜終焉《しゅうえん》の｜祭壇《さいだん》」

**リー・ジエ**：（｜石碑《せきひ》に｜近《ちか》づき、｜見上《みあ》げて｜読《よ》み）……

**ナレーション**：｜大《おお》きな｜文字《もじ》の｜下《した》には、｜小《ちい》さな｜文字《もじ》で｜一行《いっこう》、｜刻《きざ》まれていた：

**ナレーション**：｜前《まえ》の｜駅《えき》：「｜亡者《もうじゃ》の｜峡谷《きょうこく》」

**ナレーション**：｜次《つぎ》の｜駅《えき》：「｜永遠《えいえん》の｜森《もり》」

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）｜永遠《えいえん》の｜森《もり》……まだ、｜終点《しゅうてん》ではないのか。

**ナレーション**：｜彼《かれ》は、｜列車《れっしゃ》の｜上《うえ》での｜法則《ほうそく》を｜思《おも》い｜返《かえ》した。「｜亡者《もうじゃ》の｜峡谷《きょうこく》」では、｜四人《よんにん》のうち｜二人《ふたり》が｜降《お》りた。｜法則《ほうそく》が｜続《つづ》くなら、ここでは、｜残《のこ》る｜二人《ふたり》のうち｜一人《ひとり》が、さらに｜降《お》りるはずだ。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）あの｜気弱《きよわ》な｜眼鏡《めがね》の｜男《おとこ》と、あの｜不安《ふあん》そうな｜中年《ちゅうねん》の｜女性《じょせい》……｜法則《ほうそく》どおりなら、｜一人《ひとり》が｜降《お》りて、｜一人《ひとり》は｜先《さき》へ｜進《すす》むはずだ。

**ナレーション**：これが、いまのところ｜唯一《ゆいいつ》、｜信頼《しんらい》できそうな｜法則《ほうそく》だった。しかし――

**リー・ジエ**：（ホームを｜見回《みまわ》して）｜人《ひと》は？

**ナレーション**：｜彼《かれ》は、｜広《ひろ》いホームを｜念入《ねんい》りに｜探《さが》しはじめた。ホームの｜端《はし》から｜端《はし》まで｜歩《ある》き、｜隅々《すみずみ》を｜調《しら》べる。

**ナレーション**：｜石碑《せきひ》の｜裏《うら》へ｜回《まわ》り、｜誰《だれ》かが｜隠《かく》れていないか｜確《たし》かめた。しゃがみ｜込《こ》んで、｜床《ゆか》に｜血《ち》の｜跡《あと》や｜争《あらそ》った｜形跡《けいせき》がないか｜調《しら》べた。ホームの｜縁《ふち》へそっと｜歩《ある》いていって、｜下《した》の｜澄《す》んだ｜湖面《こめん》をのぞき｜込《こ》みさえした。

**ナレーション**：｜湖水《こすい》は｜澄《す》みきって｜透明《とうめい》で、｜聖《せい》なる｜光《ひかり》に｜照《て》らされ、｜水面下《すいめんか》｜数《すう》メートルのところでゆっくり｜揺《ゆ》れる｜水草《みずくさ》が｜見《み》える。だが、さらにその｜下《した》は、｜底《そこ》｜知《し》れない｜翠緑《すいりょく》の｜深淵《しんえん》だった。

**ナレーション**：けれど、｜何《なに》もなかった。

**ナレーション**：ホーム｜全体《ぜんたい》が、できたばかりのように｜清潔《せいけつ》で、｜遺体《いたい》も、｜血《ち》の｜跡《あと》も、｜争《あらそ》った｜形跡《けいせき》も、｜置《お》き｜忘《わす》れられた｜持《も》ち｜物《もの》も、｜何一《なにひと》つなかった。

**ナレーション**：ここには、｜一度《いちど》も｜訪《おとず》れた｜者《もの》がいないかのようだった。

**リー・ジエ**：（｜足《あし》を｜止《と》めて、｜困惑《こんわく》して）どういうことだ？

**ナレーション**：｜強《つよ》い｜不安《ふあん》が、｜胸《むね》にこみ｜上《あ》げた。「｜幽冥《ゆうめい》の｜都《みやこ》」から「｜亡者《もうじゃ》の｜峡谷《きょうこく》」まで、どの｜駅《えき》にも｜遺体《いたい》があり、｜誰《だれ》かが｜降《お》りた｜痕跡《こんせき》があった。だが、ここには、｜何《なに》もない。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）｜法則《ほうそく》が、｜破《やぶ》られたのか？　それとも……｜二人《ふたり》とも、｜列車《れっしゃ》に｜残《のこ》ったのか？

**ナレーション**：｜二人《ふたり》とも｜降《お》りなかったのなら、それは、｜列車《れっしゃ》の｜規則《きそく》が｜変《か》わったということだ。だが、なぜ？

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）まさか、「｜永遠《えいえん》の｜森《もり》」に｜何《なに》か｜特別《とくべつ》なことがあって、｜列車《れっしゃ》の｜規則《きそく》を｜変《か》えさせたのか？
