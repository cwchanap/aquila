# 第十七幕：永遠の森のエルフ

**ナレーション**：リー・ジエはホームと｜広間《ひろま》の｜境目《さかいめ》に｜立《た》ち、まったく｜違《ちが》う｜二《ふた》つの｜道《みち》を｜見《み》つめていた。

**ナレーション**：｜結局《けっきょく》、｜行方《ゆくえ》のわからない｜最後《さいご》の｜二人《ふたり》の｜乗客《じょうきゃく》への｜好奇心《こうきしん》と、｜未知《みち》の｜行《ゆ》く｜手《て》を｜探《さぐ》りたい｜気持《きも》ちが、｜引《ひ》き｜返《かえ》して｜調《しら》べようという｜思《おも》いを｜押《お》さえ｜込《こ》んだ。

**リー・ジエ**：（｜手《て》の｜中《なか》の｜剣《けん》を｜握《にぎ》りしめて）｜先《さき》へ｜進《すす》もう。

**ナレーション**：｜彼《かれ》は｜踵《かかと》を｜返《かえ》し、ホームを｜離《はな》れる｜線路《せんろ》へ｜踏《ふ》み｜出《だ》して、「｜永遠《えいえん》の｜森《もり》」の｜方向《ほうこう》へ｜歩《ある》きだした。

**ナレーション**：この｜道《みち》のりは、すべて「｜終焉《しゅうえん》の｜祭壇《さいだん》」の｜建物《たてもの》の｜内部《ないぶ》にあった。｜線路《せんろ》は、｜巨大《きょだい》な｜湖《みずうみ》を｜横切《よこぎ》る｜石橋《いしばし》の｜上《うえ》に｜敷《し》かれている。

**ナレーション**：｜足《あし》の｜下《した》の｜石橋《いしばし》は｜広《ひろ》く｜頑丈《がんじょう》で、｜黒《くろ》い｜石材《せきざい》が、｜銀白《ぎんはく》の｜光《ひかり》に｜照《て》らされて｜深《ふか》い｜艶《つや》を｜帯《お》びていた。｜両側《りょうがわ》に｜手《て》すりはなく、あるのは｜虚空《こくう》と、あの｜澄《す》んだ｜翠緑《すいりょく》の｜湖水《こすい》だけだ。

**ナレーション**：｜自分《じぶん》の｜足音《あしおと》が、この｜巨大《きょだい》な｜空間《くうかん》に｜響《ひび》くのが｜聞《き》こえる。｜一歩《いっぽ》ごとに、はっきりと、そして｜孤独《こどく》に。｜湖面《こめん》は｜鏡《かがみ》のように｜静《しず》かで、ドームの｜聖《せい》なる｜火《ひ》と、｜彼《かれ》のひとりぼっちの｜影《かげ》を｜映《うつ》していた。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）ここは……｜何《なに》かの｜儀式《ぎしき》の｜場《ば》のようだ。

**ナレーション**：｜彼《かれ》は｜歩《ある》きつづけた。｜周囲《しゅうい》の｜空間《くうかん》は｜静《しず》かで｜神聖《しんせい》で、｜聞《き》こえるのは｜自分《じぶん》の｜息《いき》づかいと｜足音《あしおと》だけ。ここでは｜時間《じかん》が｜意味《いみ》を｜失《うしな》ったようで、どれだけ｜歩《ある》いたのかもわからなかった。

**ナレーション**：｜十分《じゅっぷん》。｜二十分《にじゅっぷん》。｜三十分《さんじゅっぷん》。

**ナレーション**：ようやく、｜前方《ぜんぽう》に｜巨大《きょだい》なアーチの｜出口《でぐち》が｜現《あらわ》れた。それがこの｜建物《たてもの》の｜終《お》わりであり、｜外《そと》の｜世界《せかい》への｜門《もん》だった。

**ナレーション**：アーチをくぐった｜瞬間《しゅんかん》、｜温《あたた》かくまぶしい｜金色《きんいろ》の｜陽光《ようこう》が、｜彼《かれ》の｜体《からだ》に｜降《ふ》りそそいだ。

**リー・ジエ**：（｜思《おも》わず｜手《て》を｜上《あ》げて｜目《め》をかばい）うっ……

**ナレーション**：｜光《ひかり》はあまりにもまぶしく、｜闇《やみ》に｜長《なが》く｜慣《な》れた｜目《め》に、｜突然《とつぜん》の｜明《あか》るさが｜刺《さ》さるように｜痛《いた》んだ。｜涙《なみだ》が｜勝手《かって》にあふれ、｜視界《しかい》がぼやける。

**ナレーション**：けれどそれは、｜生理的《せいりてき》な｜涙《なみだ》で、｜悲《かな》しみのものではなかった。それは……｜再生《さいせい》の｜涙《なみだ》だった。

**ナレーション**：この｜世界《せかい》に｜来《き》てから、｜三十時間《さんじゅうじかん》｜近《ちか》くを｜経《へ》て、｜彼《かれ》は｜初《はじ》めて、｜陽《ひ》の｜光《ひかり》を｜見《み》た。

**リー・ジエ**：（ゆっくり｜手《て》を｜下《お》ろし、｜陽光《ようこう》を｜感《かん》じて）｜陽《ひ》の｜光《ひかり》……｜本物《ほんもの》の、｜陽《ひ》の｜光《ひかり》だ……

**ナレーション**：｜温《あたた》かな｜光《ひかり》が｜肌《はだ》に｜降《ふ》りそそぎ、｜久《ひさ》しぶりのぬくもりをもたらす。｜全身《ぜんしん》の｜細胞《さいぼう》が｜歓声《かんせい》を｜上《あ》げているのがわかり、｜長《なが》く｜眠《ねむ》っていた｜体《からだ》が、ようやく｜目《め》を｜覚《さ》ましたかのようだった。

**ナレーション**：｜永遠《えいえん》の｜夜《よる》が、ようやく｜過《す》ぎ｜去《さ》った。｜胸《むね》に｜重《おも》くのしかかっていたものが、｜陽光《ようこう》の｜下《した》で、ずいぶん｜軽《かる》くなった。

**リー・ジエ**：（｜手足《てあし》を｜伸《の》ばして）……

**ナレーション**：｜彼《かれ》は｜思《おも》わず、こわばった｜体《からだ》を｜伸《の》ばした。｜肩《かた》も、｜腰《こし》も、｜両脚《りょうあし》も、すべての｜筋肉《きんにく》が、｜長《なが》いあいだの｜緊張《きんちょう》に｜抗議《こうぎ》している。

**ナレーション**：｜彼《かれ》は｜深《ふか》く｜息《いき》を｜吸《す》った。｜空気《くうき》には｜草《くさ》と｜土《つち》の｜香《かお》りがあり、｜花《はな》の｜甘《あま》い｜匂《にお》いもまじっている。｜陽光《ようこう》の｜下《した》にだけある、｜生命力《せいめいりょく》に｜満《み》ちた｜気配《けはい》だった。

**リー・ジエ**：（｜低《ひく》く）｜生《い》きてるって……いいな。

**ナレーション**：｜彼《かれ》は｜線路《せんろ》に｜沿《そ》って｜歩《ある》きつづけた。

**ナレーション**：｜今度《こんど》は、｜線路《せんろ》の｜両側《りょうがわ》に、｜陰鬱《いんうつ》な｜峡谷《きょうこく》はなく、｜神聖《しんせい》で｜静《しず》かな｜湖《みずうみ》の｜祭壇《さいだん》もなく、｜生気《せいき》にあふれた｜広大《こうだい》な｜森《もり》が｜広《ひろ》がっていた。

**ナレーション**：｜高《たか》い｜木々《きぎ》が｜両側《りょうがわ》に｜伸《の》び、｜葉《は》は｜陽光《ようこう》の｜下《した》で、｜翠緑《すいりょく》の｜輝《かがや》きを｜放《はな》っている。｜地面《じめん》には｜柔《やわ》らかな｜青草《あおくさ》が｜敷《し》きつめられ、さまざまな｜色《いろ》の｜野《の》の｜花《はな》――｜黄色《きいろ》、｜紫《むらさき》、｜白《しろ》――が、そよ｜風《かぜ》に｜静《しず》かに｜揺《ゆ》れていた。

**ナレーション**：｜澄《す》んだ｜鳥《とり》のさえずりが｜四方八方《しほうはっぽう》から｜聞《き》こえ、｜重《かさ》なり｜合《あ》って、｜陽気《ようき》な｜楽曲《がっきょく》を｜合唱《がっしょう》しているようだった。｜色鮮《いろあざ》やかな｜蝶《ちょう》が｜花《はな》の｜間《あいだ》を｜舞《ま》い、｜羽《はね》が｜陽光《ようこう》に、｜虹《にじ》のような｜輝《かがや》きをきらめかせる。

**ナレーション**：ときおり、ふさふさした｜尻尾《しっぽ》をなびかせたリスが、｜木《き》の｜上《うえ》を「チチッ」と｜鳴《な》きながら｜駆《か》け｜抜《ぬ》け、｜葉《は》の｜間《あいだ》へ｜消《き》えていった。

**リー・ジエ**：（｜足《あし》を｜止《と》めて、｜辺《あた》りを｜見回《みまわ》し）ここが……

**ナレーション**：これほど｜多《おお》くの｜不可思議《ふかしぎ》で｜恐《おそ》ろしい｜出来事《できごと》を｜経《へ》たあとで、｜目《め》の｜前《まえ》の、この｜活気《かっき》に｜満《み》ちた｜光景《こうけい》は、｜彼《かれ》に｜現実感《げんじつかん》のなさを｜覚《おぼ》えさせた。

**ナレーション**：これは｜本当《ほんとう》に、｜同《おな》じ｜世界《せかい》なのか？　あの｜死《し》も、｜恐怖《きょうふ》も、｜謎《なぞ》も、まるで｜別《べつ》の｜次元《じげん》の｜出来事《できごと》のようだ。

**ナレーション**：さらにしばらく｜歩《ある》いて、｜二十分《にじゅっぷん》ほど｜経《た》ったころ、｜彼《かれ》をもっと｜驚《おどろ》かせる｜光景《こうけい》が｜現《あらわ》れた。

**ナレーション**：｜線路《せんろ》からそう｜遠《とお》くない｜林《はやし》の｜中《なか》の｜空《あ》き｜地《ち》に、｜天然《てんねん》の｜岩《いわ》に｜囲《かこ》まれた｜温泉《おんせん》があったのだ。

**リー・ジエ**：（｜近《ちか》づき、しゃがんで｜手《て》を｜入《い》れてみて）｜温泉《おんせん》？

**ナレーション**：｜湯《ゆ》はゆらゆらと｜白《しろ》い｜湯気《ゆげ》を｜立《た》て、｜空気《くうき》にはかすかに｜硫黄《いおう》の｜匂《にお》いが｜漂《ただよ》っている。｜指《ゆび》を｜入《い》れてみると、｜熱《ねつ》すぎず、ぬるすぎず、ちょうどいい｜温度《おんど》だった。

**ナレーション**：｜湯《ゆ》は｜底《そこ》まで｜澄《す》んでいて、｜池《いけ》の｜底《そこ》のなめらかな｜小石《こいし》が｜見《み》える。｜陽光《ようこう》が｜木《こ》の｜葉《は》の｜隙《すき》｜間《あいだ》から｜降《ふ》りそそぎ、｜水面《すいめん》にまだらな｜光《ひかり》と｜影《かげ》を｜落《お》としていた。

**リー・ジエ**：（｜立《た》ち｜上《あ》がって、｜温泉《おんせん》を｜見《み》つめ）こんな｜広《ひろ》い｜森《もり》の｜中《なか》で……これは、｜奇跡《きせき》みたいなものだ。

**ナレーション**：｜彼《かれ》は｜辺《あた》りを｜見回《みまわ》し、｜近《ちか》くに｜危険《きけん》の｜気配《けはい》がないことを｜確《たし》かめた。それからリュックを｜下《お》ろし、｜剣《けん》を｜手《て》の｜届《とど》くところに｜置《お》いて、｜埃《ほこり》と｜汗《あせ》にまみれた｜服《ふく》を｜脱《ぬ》ぎはじめた。

**ナレーション**：｜温泉《おんせん》に｜身《み》を｜沈《しず》めた｜瞬間《しゅんかん》、｜心地《ここち》よいため｜息《いき》が、｜思《おも》わず｜喉《のど》からもれた。

**リー・ジエ**：（｜目《め》を｜閉《と》じて）……

**ナレーション**：｜温《あたた》かな｜湯《ゆ》が、｜疲《つか》れきった｜体《からだ》を｜包《つつ》み、｜毛穴《けあな》の｜一《ひと》つひとつにまでしみ｜込《こ》んでいく。こわばった｜筋肉《きんにく》がしだいにゆるみ、｜痛《いた》みが、ゆっくりと｜引《ひ》いていった。

**ナレーション**：｜彼《かれ》は｜池《いけ》の｜縁《ふち》の｜岩《いわ》にもたれ、｜梢《こずえ》から｜降《ふ》りそそぐ｜陽光《ようこう》を｜仰《あお》いだ。そよ｜風《かぜ》が｜吹《ふ》き、｜木《こ》の｜葉《は》が、さわさわと、ささやくような｜音《おと》を｜立《た》てる。

**ナレーション**：この、｜得《え》がたい｜安《やす》らぎのひとときに、｜頭《あたま》の｜中《なか》の｜乱《みだ》れた｜思考《しこう》は、ふたたび｜動《うご》きだした。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）「｜寂海《じゃっかい》」｜駅《えき》で｜降《お》りた｜人《ひと》たちは……

**ナレーション**：｜彼《かれ》は、あの｜落《お》ち｜着《つ》いたおじさんを｜思《おも》い｜出《だ》した。｜真《ま》っ｜先《さき》に｜列車《れっしゃ》を｜降《お》り、｜責任感《せきにんかん》と｜覚悟《かくご》を｜見《み》せた｜人《ひと》。あの｜物静《ものしず》かな｜少女《しょうじょ》は、その｜人《ひと》についていって、｜一緒《いっしょ》に｜探索《たんさく》することを｜選《えら》んだ。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）いま、どこにいるんだろう？　｜何《なに》か｜手《て》がかりは｜見《み》つけたのか？

**ナレーション**：それに、あの｜大学生《だいがくせい》たち。すべてを｜冒険《ぼうけん》だと｜思《おも》って、｜顔《かお》にまだ｜笑《え》みを｜浮《う》かべていた。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）なぜ、そのうちの｜一人《ひとり》が、「｜亡者《もうじゃ》の｜峡谷《きょうこく》」へ｜通《つう》じる｜小径《こみち》で｜死《し》んでいたんだ？　｜一《ひと》つの｜森《もり》から｜別《べつ》の｜森《もり》へ、どうやって｜走《はし》ってきたんだ？

**ナレーション**：｜疑問《ぎもん》は｜頭《あたま》の｜中《なか》を｜巡《めぐ》るばかりで、｜答《こた》えは｜見《み》つからない。

**ナレーション**：｜彼《かれ》はまた、あの｜壊《こわ》れてしまった｜家族《かぞく》を｜思《おも》い｜出《だ》した。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）｜小林《こばやし》さんのご｜主人《しゅじん》……｜胸《むね》の、あの｜剣《けん》の｜傷《きず》……

**ナレーション**：あまりにもきれいな｜傷口《きずぐち》で、｜一撃《いちげき》で｜命《いのち》を｜奪《うば》っている。｜犯人《はんにん》は｜誰《だれ》なのか？　｜使《つか》われた｜武器《ぶき》は｜何《なん》なのか？

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）それに、｜小林《こばやし》さんと｜子《こ》どもたちは……｜小屋《こや》から、あんなふうに｜消《き》えてしまった。いったいどこへ｜行《い》ったんだ？　まだ｜生《い》きているのか？

**ナレーション**：｜考《かんが》えれば｜考《かんが》えるほど、すべてが｜矛盾《むじゅん》に｜満《み》ちているように｜思《おも》えた。どの｜手《て》がかりも｜別《べつ》の｜方向《ほうこう》を｜指《さ》し、どの｜謎《なぞ》も｜解《と》けない。

**リー・ジエ**：（｜低《ひく》く、ひとりごとのように）この｜全部《ぜんぶ》の｜裏《うら》に、いったい｜何《なん》のつながりがあるんだ？

**ナレーション**：そのとき、かすかな｜物音《ものおと》が、｜彼《かれ》の｜思考《しこう》をさえぎった。

**リー・ジエ**：（はっと｜目《め》を｜開《あ》け、｜体《からだ》をこわばらせて）……
