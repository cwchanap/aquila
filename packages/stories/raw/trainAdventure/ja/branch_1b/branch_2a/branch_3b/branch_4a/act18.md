**エルフ**：そういうことですか。

**ナレーション**：｜彼《かれ》の｜構《かま》えは｜少《すこ》しゆるんだが、それでも｜警戒《けいかい》は｜解《と》いていない。

**ナレーション**：リー・ジエは、｜心《こころ》の｜中《なか》で｜驚《おどろ》いた。

**ナレーション**：｜驚《おどろ》いたのは、｜相手《あいて》の｜態度《たいど》が｜変《か》わったことではなく、｜二《ふた》つのことだった。｜一《ひと》つは、この｜異種族《いしゅぞく》の｜言葉《ことば》が、｜母語《ぼご》のように｜自然《しぜん》に、｜完全《かんぜん》に｜聞《き》き｜取《と》れること。もう｜一《ひと》つは、このエルフが、｜列車《れっしゃ》の｜存在《そんざい》を｜知《し》っていることだ。

**リー・ジエ**：はい……｜俺《おれ》は、あの｜列車《れっしゃ》の｜乗客《じょうきゃく》です。

**ナレーション**：｜彼《かれ》は｜少《すこ》しためらってから、｜心《こころ》にある｜疑問《ぎもん》を｜口《くち》にした。

**リー・ジエ**：あなたは、あの｜列車《れっしゃ》の｜来歴《らいれき》を｜知《し》っていますか？

**エルフ**：（｜首《くび》を｜振《ふ》って）｜私《わたし》たちは、その｜起源《きげん》を｜知《し》りません。

**ナレーション**：｜彼《かれ》のまなざしが、いくらか｜重《おも》くなった。

**エルフ**：わかっているのは、｜二年《にねん》ごとに、あれが｜時間《じかん》どおりに、この｜森《もり》を｜通《とお》り｜抜《ぬ》けるということだけです。｜村《むら》には｜古《ふる》い｜言《い》い｜伝《つた》えがあって、この｜列車《れっしゃ》の｜終点《しゅうてん》は｜地獄《じごく》だというのです。

**エルフ**：ですから｜長老《ちょうろう》たちは、｜誰《だれ》であれ、あれに｜乗《の》ることを｜固《かた》く｜禁《きん》じています。

**ナレーション**：エルフの｜視線《しせん》が｜遠《とお》くなり、かすかな｜悲《かな》しみを｜帯《お》びた。

**エルフ**：ですが、｜四年前《よんねんまえ》、｜村《むら》の｜若《わか》い｜同胞《どうほう》の｜一人《ひとり》が……｜言《い》い｜伝《つた》えを｜信《しん》じなかったのです。

**ナレーション**：｜彼《かれ》は｜言葉《ことば》を｜切《き》った。｜何《なに》か、つらい｜昔《むかし》のことを｜思《おも》い｜出《だ》しているようだった。

**エルフ**：｜列車《れっしゃ》の｜秘密《ひみつ》を｜探《さぐ》ろうとして、｜彼《かれ》は｜一人《ひとり》であれに｜乗《の》り｜込《こ》み……それきり、｜二度《にど》と｜戻《もど》ってきませんでした。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》、｜衝撃《しょうげき》を｜受《う》けて）エルフが｜乗《の》ったこともあったのか……

**ナレーション**：この｜知《し》らせで、リー・ジエは、この｜列車《れっしゃ》の｜影響《えいきょう》が｜及《およ》ぶ｜範囲《はんい》が、｜思《おも》っていたよりずっと｜広《ひろ》いことを｜悟《さと》った。

**エルフ**：それ｜以来《いらい》、｜私《わたし》たちは、あれをますます｜畏《おそ》れるようになりました。

**ナレーション**：｜彼《かれ》は｜顔《かお》を｜上《あ》げて、リー・ジエを｜見《み》た。

**エルフ**：｜列車《れっしゃ》は、たいてい｜空《そら》のままやってきます。ですが、｜二年前《にねんまえ》にまた｜到着《とうちゃく》したときは、ひどく｜異様《いよう》でした……

**リー・ジエ**：（｜問《と》いただして）｜何《なに》が｜異様《いよう》だったんです？

**エルフ**：｜車内《しゃない》に、｜人間《にんげん》の｜遺体《いたい》があったのです。

**ナレーション**：リー・ジエの｜呼吸《こきゅう》が、｜一瞬《いっしゅん》｜止《と》まった。

**リー・ジエ**：｜人間《にんげん》の……｜遺体《いたい》？

**エルフ**：（うなずいて）｜列車《れっしゃ》の｜上《うえ》で「｜人《ひと》」を｜見《み》たのは、あれが｜初《はじ》めてでした。ですから、｜私《わたし》が｜驚《おどろ》いた｜理由《りゆう》も、おわかりでしょう。

**エルフ**：あなたたちは、｜人間《にんげん》であるばかりか、｜生《い》きている｜人間《にんげん》だ。これは、｜前代未聞《ぜんだいみもん》のことなのです。

**ナレーション**：リー・ジエはしばらく｜黙《だま》って、この｜莫大《ばくだい》な｜情報量《じょうほうりょう》を｜飲《の》み｜込《こ》もうとしていた。

**ナレーション**：｜一人《ひとり》のエルフが｜列車《れっしゃ》に｜乗《の》って、｜行方不明《ゆくえふめい》になった。｜二年後《にねんご》、｜車内《しゃない》に｜人間《にんげん》の｜遺体《いたい》が｜現《あらわ》れた。そして｜今《いま》、さらに｜二年後《にねんご》、｜生《い》きた｜人間《にんげん》たちが、ここへ｜連《つ》れてこられた。

**ナレーション**：ここには、きっと｜何《なに》かの｜法則《ほうそく》がある。｜何《なに》か、｜恐《おそ》ろしい｜法則《ほうそく》が。

**エルフ**：｜知《し》りません。
