# 第十八幕：貯蔵室の白い剣

**ナレーション**：リー・ジエは｜分岐点《ぶんきてん》の｜中央《ちゅうおう》に｜立《た》ち、｜残《のこ》る｜二《ふた》つの｜道《みち》を｜見《み》た。｜上《うえ》へ｜向《む》かう｜石段《いしだん》は、より｜高《たか》い｜場所《ばしょ》へ｜通《つう》じていて、まっすぐ｜前《まえ》へ｜延《の》びる｜廊下《ろうか》は、｜闇《やみ》の｜中《なか》へ｜続《つづ》いている。

---

**リー・ジエ**：（その｜剣《けん》を｜見《み》て、｜目《め》を｜輝《かがや》かせ）あれは……
