# 第九幕：迷霧の森

**優しい母親**：（リー・ジエのほうを｜見《み》て）あなたも……｜一緒《いっしょ》に｜来《き》てくれますか？

**ナレーション**：リー・ジエは｜黙《だま》ったまま、｜目《め》の｜前《まえ》の｜母子《おやこ》｜三人《さんにん》を｜見《み》つめた。｜母親《ははおや》の｜膝《ひざ》の｜傷《きず》からはまだ｜血《ち》がにじみ、｜二人《ふたり》の｜子《こ》どもは｜彼女《かのじょ》の｜手《て》をぎゅっと｜握《にぎ》りしめている。その｜目《め》は、｜恐怖《きょうふ》と｜不安《ふあん》でいっぱいだった。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）この｜人《ひと》たちについて、｜亡者《もうじゃ》の｜峡谷《きょうこく》へ？　｜怪我《けが》をした｜母親《ははおや》に、｜幼《おさな》い｜子《こ》どもが｜二人《ふたり》……こんなろくでもない｜場所《ばしょ》じゃ、｜足手《あしで》まといになるだけだ。

**ナレーション**：｜彼《かれ》は、さっき｜駅《えき》の｜中《なか》で｜見《み》つけた｜地図《ちず》のことを｜思《おも》い｜出《だ》した。そこには｜三《みっ》つのルートがはっきりと｜記《しる》されていた――｜北《きた》の「｜亡者《もうじゃ》の｜峡谷《きょうこく》」、｜南《みなみ》の「｜迷霧《めいむ》の｜森《もり》」、そして｜西《にし》の「｜銀月湖《ぎんげつこ》」。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）｜知《し》り｜合《あ》ってまだ｜数時間《すうじかん》も｜経《た》っていない。｜結局《けっきょく》のところ、ただの｜他人《たにん》だ。いつ｜命《いのち》を｜落《お》としてもおかしくないこの｜状況《じょうきょう》で｜彼《かれ》らを｜連《つ》れていけば、｜自分《じぶん》まで｜危険《きけん》にさらすことになる。

**ナレーション**：リー・ジエは｜深《ふか》く｜息《いき》を｜吸《す》い、｜決断《けつだん》を｜下《くだ》した。ポケットから｜黄《き》ばんだ｜地図《ちず》を｜取《と》り｜出《だ》し、｜広《ひろ》げて｜母親《ははおや》に｜見《み》せる。

**リー・ジエ**：（｜落《お》ち｜着《つ》いた｜声《こえ》で）これは｜駅《えき》の｜中《なか》で｜見《み》つけた｜地図《ちず》です。｜線路《せんろ》に｜沿《そ》って｜歩《ある》けば、たしかに｜亡者《もうじゃ》の｜峡谷《きょうこく》には｜着《つ》きます。でも、あの｜道《みち》は｜吹《ふ》きさらしで、｜身《み》を｜隠《かく》せるものが｜何《なに》もありません。

**優しい母親**：（｜顔《かお》を｜上《あ》げ、｜目《め》にかすかな｜希望《きぼう》を｜浮《う》かべて）じゃあ……ほかに｜道《みち》はあるんですか？

**リー・ジエ**：（｜地図《ちず》を｜指差《ゆびさ》して）｜森《もり》の｜中《なか》を｜大《おお》きな｜道《みち》が｜一本《いっぽん》｜通《とお》っていて、それも｜北《きた》の｜亡者《もうじゃ》の｜峡谷《きょうこく》へ｜続《つづ》いています。そっちのほうが、｜線路《せんろ》｜沿《ぞ》いよりは｜少《すこ》し｜安全《あんぜん》なはずです。｜少《すく》なくとも、｜木《き》が｜身《み》を｜隠《かく》してくれる。

**優しい母親**：（ありがたそうにうなずいて）ありがとうございます……｜本当《ほんとう》に、ありがとうございます。

**リー・ジエ**：（｜地図《ちず》をしまって）ただ、｜一緒《いっしょ》には｜行《い》きません。こっちにも｜考《かんが》えがあるので。

**ナレーション**：｜母親《ははおや》は｜一瞬《いっしゅん》きょとんとしたが、すぐに｜彼《かれ》の｜言《い》わんとすることを｜理解《りかい》した。｜落胆《らくたん》も｜非難《ひなん》も｜見《み》せず、ただ｜静《しず》かにうなずいた。

**優しい母親**：（｜小《ちい》さな｜声《こえ》で）わかりました。｜教《おし》えてくださって、ありがとうございます……それだけで、もう｜十分《じゅうぶん》｜助《たす》けていただきました。

**しっかり者の姉**：（｜母親《ははおや》の｜手《て》を｜引《ひ》いて、｜小声《こごえ》で）お｜兄《にい》ちゃんは、｜一緒《いっしょ》に｜来《こ》ないの？

**優しい母親**：（｜娘《むすめ》の｜頭《あたま》を｜優《やさ》しくなでて）お｜兄《にい》ちゃんには、お｜兄《にい》ちゃんのやることがあるの。パパは、ママたちだけで｜探《さが》しに｜行《い》こうね。ね？

**しっかり者の姉**：（こくりとうなずき、リー・ジエを｜見《み》て）じゃあ……お｜兄《にい》ちゃんも、｜気《き》をつけてね。

**無邪気な弟**：（｜一緒《いっしょ》に｜手《て》を｜振《ふ》って）バイバイ、お｜兄《にい》ちゃん。

**リー・ジエ**：（｜小《ちい》さくうなずいて）そっちもな。｜気《き》をつけて。

**ナレーション**：｜母親《ははおや》は｜二人《ふたり》の｜子《こ》どもの｜手《て》を｜引《ひ》き、｜森《もり》を｜北《きた》へと｜歩《ある》き｜出《だ》した。｜紫《むらさき》の｜月明《つきあ》かりの｜下《した》、その｜背中《せなか》は｜少《すこ》し｜頼《たよ》りなく｜見《み》えたが、それでもまっすぐに｜伸《の》びていた。｜二《ふた》つの｜小《ちい》さな｜影《かげ》が、ぴたりと｜彼女《かのじょ》に｜寄《よ》り｜添《そ》っている。

**ナレーション**：ほどなくして、｜三人《さんにん》の｜姿《すがた》は｜森《もり》の｜闇《やみ》の｜中《なか》に｜消《き》えた。ホームに｜残《のこ》されたのは、リー・ジエただ｜一人《ひとり》だった。

**リー・ジエ**：（｜小声《こごえ》で、｜独《ひと》り｜言《ごと》のように）｜幸運《こううん》を｜祈《いの》るよ。

**ナレーション**：｜彼《かれ》は｜踵《かかと》を｜返《かえ》し、｜地図《ちず》に｜記《しる》された｜南《みなみ》――｜迷霧《めいむ》の｜森《もり》のほうを｜見《み》た。｜名前《なまえ》は｜縁起《えんぎ》でもないが、｜少《すく》なくとも「｜亡者《もうじゃ》の｜峡谷《きょうこく》」のように、｜死《し》の｜気配《けはい》をむき｜出《だ》しにしてはいない。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）｜一人《ひとり》なら、｜自由《じゆう》に｜動《うご》ける。｜足手《あしで》まといもいないし、｜誰《だれ》かの｜安全《あんぜん》に｜責任《せきにん》を｜負《お》う｜必要《ひつよう》もない。こんな｜場所《ばしょ》では、これがいちばん｜合理的《ごうりてき》な｜選択《せんたく》だ。

**ナレーション**：｜彼《かれ》は｜錆《さ》びた｜剣《けん》を｜握《にぎ》りしめ、ホームを｜南側《みなみがわ》の｜出口《でぐち》へと｜向《む》かった。そこには｜雑草《ざっそう》に｜覆《おお》われた｜小道《こみち》が｜一本《いっぽん》あり、かつて｜人《ひと》が｜通《とお》った｜跡《あと》がかすかに｜見《み》て｜取《と》れる。

**ナレーション**：リー・ジエは｜小道《こみち》に｜足《あし》を｜踏《ふ》み｜入《い》れた。｜背後《はいご》で、「｜幽冥《ゆうめい》の｜都《みやこ》」の｜荒《あ》れ｜果《は》てた｜駅《えき》が｜少《すこ》しずつ｜遠《とお》ざかっていく。｜二《ふた》つの｜紫《むらさき》の｜月《つき》は｜相変《あいか》わらず｜空《そら》にかかり、｜彼《かれ》の｜影《かげ》を｜長《なが》く｜引《ひ》き｜伸《の》ばしていた。

**ナレーション**：｜森《もり》の｜空気《くうき》は｜冷《つめ》たく｜湿《しめ》っていて、｜腐《くさ》った｜落《お》ち｜葉《ば》と｜湿《しめ》った｜土《つち》の｜匂《にお》いがした。｜頭上《ずじょう》に｜生《お》い｜茂《しげ》る｜樹冠《じゅかん》がほとんどの｜光《ひかり》を｜遮《さえぎ》り、｜紫《むらさき》の｜月明《つきあ》かりがその｜隙間《すきま》からわずかに｜差《さ》し｜込《こ》んで、｜地面《じめん》にまだらな｜光《ひかり》と｜影《かげ》を｜落《お》としている。

**ナレーション**：｜小道《こみち》は｜曲《ま》がりくねり、ときに｜倒木《とうぼく》に｜塞《ふさ》がれ、ときにはびこる｜蔓《つる》に｜覆《おお》われていた。リー・ジエは｜行《い》く｜手《て》を｜阻《はば》む｜枝葉《えだは》を｜慎重《しんちょう》にかき｜分《わ》け、｜一歩《いっぽ》ずつ｜進《すす》んでいった。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）この｜道《みち》、もう｜長《なが》いこと｜誰《だれ》も｜通《とお》ってないな……でも、｜方角《ほうがく》はまだわかる。

**ナレーション**：｜森《もり》は｜恐《おそ》ろしいほど｜静《しず》かだった。｜虫《むし》の｜声《こえ》も、｜鳥《とり》の｜鳴《な》き｜声《ごえ》もない。｜風《かぜ》が｜葉《は》を｜揺《ゆ》らす｜音《おと》さえ、うつろで｜遠《とお》く｜聞《き》こえる。｜耳《みみ》に｜届《とど》くのは、｜落《お》ち｜葉《ば》を｜踏《ふ》むリー・ジエ｜自身《じしん》の｜足音《あしおと》――「カサッ、カサッ」という｜音《おと》だけだった。

**ナレーション**：しばらく｜歩《ある》くうちに、｜周囲《しゅうい》の｜様子《ようす》が｜変《か》わりはじめた。｜空気《くうき》の｜湿《しめ》り｜気《け》がはっきりと｜増《ま》し、｜薄《うす》い｜霧《きり》が｜林《はやし》の｜間《あいだ》を｜漂《ただよ》いだす。

**リー・ジエ**：（｜足《あし》を｜止《と》め、｜警戒《けいかい》して）｜霧《きり》？

**ナレーション**：｜霧《きり》は｜濃《こ》くなく、｜薄絹《うすぎぬ》のように｜木々《きぎ》の｜間《あいだ》にかかって、｜視界《しかい》をぼんやりとさせているだけだった。それでも、リー・ジエに｜警戒《けいかい》を｜強《つよ》めさせるには｜十分《じゅうぶん》だった。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）｜迷霧《めいむ》の｜森《もり》……｜名前《なまえ》どおりってわけか。もっと｜気《き》をつけないと。

**ナレーション**：｜彼《かれ》は｜進《すす》みつづけた。｜霧《きり》は｜次第《しだい》に｜濃《こ》くなり、｜淡《あわ》い｜薄霧《うすきり》から、｜五《ご》メートル｜先《さき》も｜見通《みとお》せない｜白《しろ》い｜霧《きり》の｜壁《かべ》へと｜変《か》わっていく。｜木々《きぎ》の｜輪郭《りんかく》はぼやけ、｜遠《とお》くの｜景色《けしき》は｜真《ま》っ｜白《しろ》な｜霧《きり》の｜中《なか》に｜完全《かんぜん》に｜消《き》えた。

**ナレーション**：さらにしばらく｜歩《ある》いたところで、リー・ジエは｜不意《ふい》に｜足《あし》を｜止《と》めた。｜前方《ぜんぽう》で、｜小道《こみち》が｜行《い》き｜止《ど》まりになっているように｜見《み》えたのだ。

**リー・ジエ**：（｜眉《まゆ》をひそめて）これは、いったい……

**ナレーション**：｜近《ちか》づいてみると、そこは｜四《よ》つ｜辻《つじ》だった。｜小道《こみち》はここで｜四本《よんぽん》に｜分《わ》かれている――｜前方《ぜんぽう》、｜左《ひだり》、｜右《みぎ》、そして｜来《き》た｜道《みち》。

**ナレーション**：どの｜道《みち》も｜濃《こ》い｜霧《きり》に｜包《つつ》まれていて、｜違《ちが》いはまるで｜見分《みわ》けがつかない。リー・ジエは｜慌《あわ》ててポケットから｜地図《ちず》を｜取《と》り｜出《だ》し、どちらへ｜進《すす》むべきか｜確《たし》かめようとした。

**ナレーション**：だが、｜地図《ちず》を｜広《ひろ》げた｜途端《とたん》、｜胸《むね》が｜沈《しず》んだ。｜描《えが》かれているのは｜駅《えき》の｜周辺《しゅうへん》のおおまかなルートだけで、｜森《もり》の｜奥《おく》の｜細《こま》かな｜様子《ようす》は｜何《なに》ひとつ｜記《しる》されていない。

**リー・ジエ**：（｜小声《こごえ》で）くそ……｜地図《ちず》に、ここは｜載《の》ってない。

**ナレーション**：｜彼《かれ》は｜周囲《しゅうい》を｜見回《みまわ》し、｜何《なに》か｜手《て》がかりになるものを｜探《さが》した。だが、｜濃霧《のうむ》がすべてを｜覆《おお》い｜隠《かく》し、｜三本《さんぽん》の｜道《みち》はどれもまったく｜同《おな》じに｜見《み》える。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）どっちへ｜行《い》く？　｜適当《てきとう》に｜選《えら》ぶのか？　もし｜間違《まちが》えたら……

**ナレーション**：｜彼《かれ》が｜迷《まよ》っていた、そのときだった。｜左側《ひだりがわ》の｜霧《きり》の｜中《なか》で、｜不意《ふい》に｜何《なに》かが｜動《うご》いた。

**ナレーション**：｜黒《くろ》い｜影《かげ》が、ゆっくりと｜霧《きり》の｜中《なか》から｜浮《う》かび｜上《あ》がってきた。｜霧《きり》が｜濃《こ》すぎて、それが｜何《なん》なのかはまるで｜見分《みわ》けられない。ただ、｜切《き》り｜絵《え》のような｜真《ま》っ｜黒《くろ》な｜輪郭《りんかく》だけが｜見《み》える。

**ナレーション**：｜影《かげ》の｜形《かたち》は｜人《ひと》のようにも｜見《み》えたが、｜霧《きり》にゆがめられて、ひどく｜不気味《ぶきみ》で、｜現実味《げんじつみ》がなかった。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》、｜警戒《けいかい》して）｜何《なん》だ？

**ナレーション**：リー・ジエの｜本能《ほんのう》が｜告《つ》げた――あれは、｜友好的《ゆうこうてき》な｜存在《そんざい》ではない。｜黒《くろ》い｜影《かげ》から｜漂《ただよ》う｜気配《けはい》に、｜全身《ぜんしん》の｜産毛《うぶげ》が｜逆立《さかだ》った。

**リー・ジエ**：（｜心《こころ》の｜声《こえ》）まずい……｜隠《かく》れないと。

**ナレーション**：｜彼《かれ》はすばやく｜周囲《しゅうい》を｜見回《みまわ》し、｜四《よ》つ｜辻《つじ》のそばに｜茂《しげ》った｜藪《やぶ》があるのを｜見《み》つけた。｜何《なに》も｜考《かんが》えず、すぐに｜身《み》をかがめて｜飛《と》び｜込《こ》み、｜枝葉《えだは》の｜陰《かげ》で｜体《からだ》を｜丸《まる》める。
