# 第二十幕：長老との対話

**ナレーション**：｜翌朝《よくあさ》。

**ナレーション**：｜陽光《ようこう》が｜窓《まど》から｜差《さ》し｜込《こ》み、｜温《あたた》かく、｜明《あか》るい。

**高橋美咲**：（｜目《め》を｜開《あ》け、｜目《め》をこすりながら）おはよう、リーさん。

**リー・ジエ**：（すでに｜起《お》きていて、｜窓辺《まどべ》に｜座《すわ》って）おはよう。

**高橋美咲**：（｜体《からだ》を｜起《お》こして）よく｜眠《ねむ》れた？

**リー・ジエ**：（｜首《くび》を｜振《ふ》って）まあまあだ。

**ナレーション**：そのとき、｜扉《とびら》の｜外《そと》から｜足音《あしおと》が｜聞《き》こえた。

**ナレーション**：｜一人《ひとり》ではない。

**ナレーション**：ガチャリと｜音《おと》がして、｜扉《とびら》の｜鍵《かぎ》が｜開《ひら》く。

**エルフの衛兵A**：（｜扉《とびら》を｜押《お》し｜開《あ》けて、エルフ｜語《ご》で）｜長老《ちょうろう》エリシアがおまえたちに｜会《あ》いたいと｜仰《おお》せだ。ついてこい。

**リー・ジエ**：（｜立《た》ち｜上《あ》がって）｜今《いま》からか？

**エルフの衛兵A**：（うなずいて、エルフ｜語《ご》で）｜今《いま》すぐだ。

**高橋美咲**：（｜緊張《きんちょう》して｜立《た》ち｜上《あ》がり）リーさん、あの｜人《ひと》、｜何《なん》て｜言《い》ったの？

**リー・ジエ**：（｜彼女《かのじょ》に）｜長老《ちょうろう》が｜俺《おれ》たちに｜会《あ》いたいそうだ。

**高橋美咲**：（｜緊張《きんちょう》して）｜長老《ちょうろう》？

**ナレーション**：｜二人《ふたり》の｜衛兵《えいへい》は、リー・ジエと｜美咲《みさき》を｜牢《ろう》の｜外《そと》へ｜連《つ》れ｜出《だ》した。

**ナレーション**：｜廊下《ろうか》を｜抜《ぬ》け、｜精緻《せいち》な｜模様《もよう》が｜彫《ほ》られた｜木《き》の｜扉《とびら》の｜前《まえ》にたどり｜着《つ》く。

**エルフの衛兵A**：（｜扉《とびら》をたたいて、エルフ｜語《ご》で）｜長老《ちょうろう》、｜連《つ》れてまいりました。

**ナレーション**：｜扉《とびら》の｜内側《うちがわ》から、｜穏《おだ》やかな｜女性《じょせい》の｜声《こえ》が｜聞《き》こえた。

**エリシア**：（エルフ｜語《ご》で）どうぞ、お｜入《はい》りなさい。

**ナレーション**：｜衛兵《えいへい》は｜扉《とびら》を｜押《お》し｜開《あ》け、リー・ジエと｜美咲《みさき》に｜入《はい》るよう｜促《うなが》した。

**ナレーション**：リー・ジエと｜美咲《みさき》は｜部屋《へや》に｜入《はい》った。

**ナレーション**：｜部屋《へや》は｜広々《ひろびろ》として、｜壁《かべ》には｜絵《え》が｜何枚《なんまい》か｜掛《か》かり、｜床《ゆか》にはやわらかな｜絨毯《じゅうたん》が｜敷《し》かれている。｜中央《ちゅうおう》には｜長《なが》いテーブルが｜置《お》かれ、その｜上《うえ》には、さまざまな｜食《た》べ｜物《もの》が｜並《なら》んでいた――｜新鮮《しんせん》な｜果物《くだもの》、｜焼《や》いた｜肉《にく》、パン、そして｜飲《の》み｜物《もの》の｜入《はい》った｜壺《つぼ》がいくつか。

**ナレーション**：テーブルの｜上座《かみざ》には、｜一人《ひとり》のエルフの｜女性《じょせい》が｜座《すわ》っていた。

**ナレーション**：｜年《とし》のころは｜四十代《よんじゅうだい》に｜見《み》え、｜淡《あわ》い｜金色《きんいろ》の｜長《なが》い｜髪《かみ》と、やさしい｜緑《みどり》の｜瞳《ひとみ》をしている。｜淡《あわ》い｜青《あお》のローブをまとい、｜腰《こし》には｜銀色《ぎんいろ》の｜帯《おび》を｜締《し》めていた。

**ナレーション**：その｜表情《ひょうじょう》は｜穏《おだ》やかだが、｜眼差《まなざ》しには、｜知恵《ちえ》と｜威厳《いげん》がにじんでいる。

**エリシア**：（｜微笑《ほほえ》んで、エルフ｜語《ご》で）ようこそ。どうぞ、おかけなさい。

**リー・ジエ**：（｜少《すこ》しためらって、テーブルへ｜向《む》かう）

**高橋美咲**：（リー・ジエのあとについて、｜小声《こごえ》で）リーさん？

**リー・ジエ**：（｜小声《こごえ》で）｜座《すわ》ってくれ、と｜言《い》ってる。

**ナレーション**：｜二人《ふたり》はテーブルのそばに｜腰《こし》を｜下《お》ろした。｜衛兵《えいへい》は｜部屋《へや》を｜出《で》て、｜扉《とびら》を｜閉《し》めた。

**エリシア**：（｜二人《ふたり》を｜見《み》つめ、｜穏《おだ》やかに、エルフ｜語《ご》で）｜私《わたし》はエリシア、この｜村《むら》の｜長老《ちょうろう》です。さぞかし、つらい｜旅《たび》だったことでしょう。

**リー・ジエ**：（うなずいて、エルフ｜語《ご》で）はい。

**エリシア**：（｜微笑《ほほえ》んで）どうぞ、お｜食事《しょくじ》をなさって。｜遠《とお》くから｜来《き》た｜客人《きゃくじん》には、｜最上《さいじょう》の｜食《た》べ｜物《もの》を｜用意《ようい》する――それが、｜私《わたし》たちエルフの｜習《なら》わしなのです。

**ナレーション**：｜彼女《かのじょ》はテーブルの｜皿《さら》を、そっと｜押《お》し｜出《だ》した。

**エリシア**：（｜申《もう》し｜訳《わけ》なさそうに、エルフ｜語《ご》で）まず、お｜詫《わ》びを｜言《い》わせてください。｜昨夜《さくや》は、｜牢《ろう》に｜入《い》れてしまって、さぞ｜不快《ふかい》だったでしょう。

**リー・ジエ**：（｜驚《おどろ》いて）あなたが、｜謝《あやま》るのか？

**エリシア**：（うなずいて）ええ。あなた｜方《かた》は｜何《なに》も｜悪《わる》いことをしていません。ですが、｜私《わたし》たちの｜衛兵《えいへい》が｜動転《どうてん》して、あなた｜方《かた》を｜閉《と》じ｜込《こ》めてしまった。そのことを、｜申《もう》し｜訳《わけ》なく｜思《おも》います。

**高橋美咲**：（リー・ジエに｜小声《こごえ》で）あの｜人《ひと》、｜何《なん》て｜言《い》ってるの？

**リー・ジエ**：（｜彼女《かのじょ》に）｜昨夜《さくや》のことを｜謝《あやま》ってるんだ。

**高橋美咲**：（｜驚《おどろ》いて）｜謝《あやま》る？

**リー・ジエ**：（エリシアに、｜眉《まゆ》をひそめて、エルフ｜語《ご》で）エルフは｜人間《にんげん》を｜邪悪《じゃあく》な｜存在《そんざい》だと｜考《かんが》えている、と｜聞《き》いた。

**エリシア**：（｜微笑《ほほえ》んで、エルフ｜語《ご》で）それは、｜長《なが》い｜話《はなし》になります。けれど、その｜話《はなし》をする｜前《まえ》に、まずは｜食事《しょくじ》をいただいてください。お｜腹《なか》も｜空《あ》いているでしょう。

**ナレーション**：｜彼女《かのじょ》は｜皿《さら》を｜一枚《いちまい》｜取《と》り、リー・ジエに｜差《さ》し｜出《だ》した。

**エリシア**：（｜穏《おだ》やかに、エルフ｜語《ご》で）お｜上《あ》がりなさい。そのあとで、ゆっくりお｜話《はな》ししましょう。

**リー・ジエ**：（｜皿《さら》を｜受《う》け｜取《と》り、テーブルの｜上《うえ》の｜食《た》べ｜物《もの》を｜見《み》つめる）

**ナレーション**：テーブルの｜上《うえ》の｜食《た》べ｜物《もの》は、とてもおいしそうだった。｜新鮮《しんせん》な｜果物《くだもの》は｜甘《あま》い｜香《かお》りを｜放《はな》ち、｜焼《や》いた｜肉《にく》は｜黄金色《こがねいろ》でこんがりと｜香《こう》ばしく、パンはふんわりとやわらかい。

**ナレーション**：｜昨夜《さくや》の｜囚人《しゅうじん》の｜食事《しょくじ》とは、まるで｜違《ちが》っていた。

**高橋美咲**：（｜食《た》べ｜物《もの》を｜見《み》つめ、ごくりと｜唾《つば》をのむ）

**リー・ジエ**：（｜美咲《みさき》に）｜食《た》べなさい、と｜言《い》ってる。

**高橋美咲**：（｜小声《こごえ》で）ほんとに、いいのかな？

**リー・ジエ**：（うなずいて）たぶん、｜大丈夫《だいじょうぶ》だ。

**ナレーション**：｜二人《ふたり》は｜食《た》べはじめた。

**ナレーション**：｜食《た》べ｜物《もの》の｜味《あじ》は、とてもよかった。｜果物《くだもの》は｜甘《あま》くてみずみずしく、｜焼《や》いた｜肉《にく》は｜柔《やわ》らかくて｜香《こう》ばしく、パンはふわふわで、ほのかにハーブの｜風味《ふうみ》がした。

**ナレーション**：エリシアは｜微笑《ほほえ》みながら｜二人《ふたり》を｜見《み》つめ、｜何《なに》も｜言《い》わなかった。

**ナレーション**：｜彼女《かのじょ》は｜静《しず》かに｜待《ま》っていた。｜二人《ふたり》が｜満腹《まんぷく》になって、｜本題《ほんだい》に｜入《はい》るのを。
