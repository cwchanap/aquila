# 第十四幕：地図の導き

**ナレーション**：ちょうどそのとき、｜李杰《りけつ》はふと｜何《なに》かを｜思《おも》い｜出《だ》した。ポケットに｜手《て》を｜伸《の》ばす。

**李杰**：（はっとして）そうだ！　｜最後《さいご》の｜家《いえ》で｜地図《ちず》を｜見《み》つけたんだった。｜冊子《さっし》に｜気《き》を｜取《と》られて、もう｜少《すこ》しで｜忘《わす》れるところだった。

**鈴木明日香**：（うれしそうに）｜地図《ちず》？　｜早《はや》く｜出《だ》して｜見《み》せて！

**ナレーション**：｜李杰《りけつ》はポケットから｜折《お》りたたまれた｜羊皮紙《ようひし》を｜取《と》り｜出《だ》し、｜草《くさ》の｜上《うえ》にそっと｜広《ひろ》げた。それと｜同時《どうじ》に、｜以前《いぜん》｜幽冥《ゆうめい》の｜都《みやこ》｜駅《えき》で｜見《み》つけた｜古《ふる》い｜地図《ちず》も｜取《と》り｜出《だ》した。

**李杰**：（｜二枚《にまい》の｜地図《ちず》を｜並《なら》べて）この｜二枚《にまい》を｜比《くら》べてみよう……

**ナレーション**：｜二枚《にまい》の｜地図《ちず》は｜描《か》き｜方《かた》が｜似《に》ていて、どちらもエルフ｜文字《もじ》で｜書《か》き｜込《こ》みがされている。｜古《ふる》い｜地図《ちず》には｜幽冥《ゆうめい》の｜都《みやこ》から｜延《の》びる｜主《おも》な｜道《みち》が｜何本《なんぼん》か｜示《しめ》されているだけだが、｜新《あたら》しい｜地図《ちず》はずっと｜詳《くわ》しかった。

**李杰**：（｜念入《ねんい》りに｜照《て》らし｜合《あ》わせながら）この｜新《あたら》しい｜地図《ちず》は……｜描《えが》かれている｜範囲《はんい》が｜広《ひろ》いな。｜銀月湖《ぎんげつこ》は、｜地図《ちず》の｜真《ま》ん｜中《なか》あたりにあるみたいだ。

**鈴木明日香**：（｜顔《かお》を｜寄《よ》せて）なんて｜書《か》いてあるの？

**李杰**：（｜地図《ちず》の｜北《きた》を｜指《ゆび》さして）｜北《きた》に｜行《い》くと……「｜終焉《しゅうえん》の｜祭壇《さいだん》」という｜場所《ばしょ》がある。

**鈴木明日香**：（｜眉《まゆ》をひそめて）｜終焉《しゅうえん》の｜祭壇《さいだん》？　なんだか｜怖《こわ》そう……

**李杰**：（うなずき、それから｜地図《ちず》の｜南《みなみ》を｜指《ゆび》さして）それで、｜南《みなみ》には……ここに｜書《か》いてあるのは……

**ナレーション**：｜彼《かれ》の｜声《こえ》がふいに｜途切《とぎ》れた。その｜目《め》は、｜地図《ちず》の｜文字《もじ》にじっと｜釘付《くぎづ》けになっている。

**鈴木明日香**：（｜不思議《ふしぎ》そうに）どうしたの？

**李杰**：（｜驚《おどろ》きのにじむ｜声《こえ》で）｜南《みなみ》のほうには……「｜月光《げっこう》の｜林《はやし》」って｜書《か》いてある。

**鈴木明日香**：（きょとんとして）｜月光《げっこう》の｜林《はやし》……その｜名前《なまえ》って……

**李杰**：（エルフの｜冊子《さっし》を｜手《て》に｜取《と》り、｜三《みっ》つの｜村《むら》が｜記《しる》されたページを｜開《ひら》いて）｜冊子《さっし》に｜出《で》てきたやつだ！　エルフ｜族《ぞく》の｜三大《さんだい》｜村落《そんらく》のひとつ、｜永遠《えいえん》の｜森《もり》の｜北部《ほくぶ》にある｜月光《げっこう》の｜林《はやし》！

**鈴木明日香**：（｜愕然《がくぜん》として）じゃ……じゃあ、｜月光《げっこう》の｜林《はやし》はあたしたちの｜南《みなみ》にあるってこと？

**李杰**：（｜考《かんが》え｜込《こ》んで）｜地図《ちず》が｜正《ただ》しければ……そういうことになる。でも｜問題《もんだい》は……

**ナレーション**：｜彼《かれ》は｜二枚《にまい》の｜地図《ちず》を｜細《こま》かく｜見比《みくら》べ、さらに｜手《て》がかりを｜探《さが》そうとした。だが、どちらの｜地図《ちず》にも、｜永遠《えいえん》の｜森《もり》や｜碧翠《へきすい》の｜島《しま》の｜門《もん》の｜位置《いち》は｜何《なに》ひとつ｜記《しる》されていなかった。

**李杰**：（｜眉《まゆ》をひそめて）おかしいな……この｜地図《ちず》には｜永遠《えいえん》の｜森《もり》の｜位置《いち》が｜載《の》っていないし、｜碧翠《へきすい》の｜島《しま》へ｜通《つう》じる｜門《もん》のことも｜書《か》いていない。

**鈴木明日香**：（｜戸惑《とまど》って）どうしてだろう？

**李杰**：（｜考《かんが》えながら）もしかしたら……この｜地図《ちず》に｜描《えが》かれているのは、この｜異世界《いせかい》の｜一部《いちぶ》だけなのかもしれない。｜永遠《えいえん》の｜森《もり》も｜門《もん》も、もっと｜遠《とお》くにあるのかもな。

**李杰**：（｜地図《ちず》の「｜月光《げっこう》の｜林《はやし》」を｜見《み》つめて）でも……もしこの｜月光《げっこう》の｜林《はやし》が、｜本当《ほんとう》に｜冊子《さっし》に｜出《で》てきたエルフの｜村《むら》なら……

**鈴木明日香**：（｜言葉《ことば》を｜継《つ》いで）エルフはこの｜世界《せかい》でも｜本当《ほんとう》に｜生《い》きられる、ってこと？

**李杰**：（うなずいて）あるいは……この「｜月光《げっこう》の｜林《はやし》」は、｜冊子《さっし》のものと｜名前《なまえ》が｜同《おな》じなだけの｜別《べつ》の｜場所《ばしょ》なのかもしれない。なにしろ、この｜地図《ちず》がどこまでの｜範囲《はんい》を｜描《えが》いているのか、｜俺《おれ》たちにはわからないんだから。

**ナレーション**：｜李杰《りけつ》はもう｜一度《いちど》｜地図《ちず》を｜丹念《たんねん》に｜調《しら》べ、ほかに｜手《て》がかりがないか｜探《さが》した。だが、「｜終焉《しゅうえん》の｜祭壇《さいだん》」と「｜月光《げっこう》の｜林《はやし》」の｜二《ふた》つを｜除《のぞ》けば、｜目印《めじるし》になりそうな｜場所《ばしょ》は｜何《なに》も｜描《えが》かれていなかった。

**李杰**：（ため｜息《いき》をついて）この｜地図《ちず》からわかることは｜限《かぎ》られてるな。｜北《きた》へ｜行《い》けば｜終焉《しゅうえん》の｜祭壇《さいだん》、｜南《みなみ》へ｜行《い》けば｜月光《げっこう》の｜林《はやし》。でも……

**鈴木明日香**：（｜小声《こごえ》で）でも、どっちの｜道《みち》が｜正《ただ》しいのかはわからない……

**李杰**：（｜彼女《かのじょ》を｜見《み》て）それでも、｜少《すく》なくとも｜選択肢《せんたくし》は｜二《ふた》つできた。｜南《みなみ》の｜月光《げっこう》の｜林《はやし》に｜行《い》けば、そこが｜本当《ほんとう》にエルフの｜村《むら》なのか｜確《たし》かめられるかもしれない。

**李杰**：（｜続《つづ》けて）｜北《きた》の｜終焉《しゅうえん》の｜祭壇《さいだん》のほうは……どんな｜場所《ばしょ》かはわからないけど、｜地図《ちず》にわざわざ｜載《の》っている｜以上《いじょう》、それなりに｜重要《じゅうよう》な｜場所《ばしょ》のはずだ。

**鈴木明日香**：（｜心配《しんぱい》そうに）じゃあ、どっちを｜選《えら》べばいいの？

**李杰**：（しばらく｜考《かんが》え｜込《こ》んで）｜月光《げっこう》の｜林《はやし》……もしそこが｜本当《ほんとう》にエルフの｜村《むら》なら、｜何《なに》か｜答《こた》えが｜見《み》つかるかもしれない。｜冊子《さっし》には、アイラルは｜追放《ついほう》されたけど、｜一部《いちぶ》の｜同胞《どうほう》も｜彼《かれ》について｜去《さ》ったと｜書《か》いてあった。

**李杰**：（｜地図《ちず》を｜見《み》つめて）もしこの｜月光《げっこう》の｜林《はやし》が、アイラルと｜彼《かれ》に｜従《したが》った｜者《もの》たちが｜築《きず》いた｜新《あたら》しい｜村《むら》だとしたら……それなら｜説明《せつめい》がつく。｜彼《かれ》らは｜永遠《えいえん》の｜森《もり》を｜離《はな》れて、この｜異世界《いせかい》に｜来《き》たんだ。

**鈴木明日香**：（はっとして）でも、｜冊子《さっし》には、この｜世界《せかい》はエルフにとって｜命取《いのちと》りだって｜書《か》いてあったよね……

**李杰**：（うなずいて）ああ、そこが｜矛盾《むじゅん》しているところなんだ。もしかしたら……もしかしたら｜彼《かれ》らは、ここで｜生《い》き｜延《の》びる｜方法《ほうほう》を｜見《み》つけたのかもしれない。あるいは……

**ナレーション**：｜彼《かれ》はそこで｜言葉《ことば》を｜切《き》り、いっそう｜深《ふか》く｜眉《まゆ》を｜寄《よ》せた。

**李杰**：（｜低《ひく》い｜声《こえ》で）あるいは、そこにはもう｜生《い》きたエルフなんて｜一人《ひとり》もいなくて……ただの｜廃村《はいそん》になっているのかもしれない。

**鈴木明日香**：（｜怯《おび》えて）じゃ……じゃあ、｜行《い》くの？

**李杰**：（｜地図《ちず》を｜見《み》つめたまま、｜長《なが》いこと｜考《かんが》え｜込《こ》んで）ちょっと、じっくり｜考《かんが》えさせてくれ……

**ナレーション**：｜二人《ふたり》は｜湖畔《こはん》に｜静《しず》かに｜座《すわ》っていた。｜李杰《りけつ》は｜地図《ちず》をにらみながら、｜頭《あたま》の｜中《なか》でさまざまな｜可能性《かのうせい》を｜考《かんが》え｜続《つづ》けている。｜明日香《あすか》は｜湖面《こめん》を｜眺《なが》めながら、｜彼《かれ》の｜決断《けつだん》を｜待《ま》っていた。

**ナレーション**：｜銀月湖《ぎんげつこ》の｜水面《みなも》は｜変《か》わらず｜鏡《かがみ》のように｜凪《な》ぎ、｜光《ひか》る｜花《はな》が｜湖面《こめん》でそっと｜揺《ゆ》れている。｜紫《むらさき》の｜月光《げっこう》が｜二人《ふたり》に｜降《ふ》り｜注《そそ》ぎ、｜草《くさ》の｜上《うえ》に｜長《なが》い｜影《かげ》を｜落《お》としていた。

**ナレーション**：｜北《きた》の｜終焉《しゅうえん》の｜祭壇《さいだん》か、｜南《みなみ》の｜月光《げっこう》の｜林《はやし》か――まったく｜異《こと》なる｜二《ふた》つの｜道《みち》が、｜二人《ふたり》の｜前《まえ》に｜横《よこ》たわっている。そしてどちらの｜道《みち》も、｜未知《みち》の｜危険《きけん》へと｜続《つづ》いているかもしれないし、｜家《いえ》へ｜帰《かえ》る｜希望《きぼう》へと｜続《つづ》いているかもしれない。

**ナレーション**：｜選択《せんたく》のときが、｜迫《せま》っていた。
