# 第九幕：銀月への道

**優しい母親**：（｜李杰《りけつ》のほうを｜見《み》て）あなたも……｜一緒《いっしょ》に｜来《き》てくれますか？

**ナレーション**：｜李杰《りけつ》は｜黙《だま》ったまま、｜目《め》の｜前《まえ》の｜母子《おやこ》｜三人《さんにん》を｜見《み》つめた。｜母親《ははおや》の｜膝《ひざ》の｜傷《きず》からはまだ｜血《ち》がにじみ、｜二人《ふたり》の｜子《こ》どもは｜彼女《かのじょ》の｜手《て》をぎゅっと｜握《にぎ》りしめている。その｜目《め》は、｜恐怖《きょうふ》と｜不安《ふあん》でいっぱいだった。

**李杰**：（｜心《こころ》の｜声《こえ》）この｜人《ひと》たちについて、｜亡者《もうじゃ》の｜峡谷《きょうこく》へ？　｜怪我《けが》をした｜母親《ははおや》に、｜幼《おさな》い｜子《こ》どもが｜二人《ふたり》……こんなろくでもない｜場所《ばしょ》じゃ、｜足手《あしで》まといになるだけだ。

**ナレーション**：｜彼《かれ》は、さっき｜駅《えき》の｜中《なか》で｜見《み》つけた｜地図《ちず》のことを｜思《おも》い｜出《だ》した。そこには｜三《みっ》つのルートがはっきりと｜記《しる》されていた――｜北《きた》の「｜亡者《もうじゃ》の｜峡谷《きょうこく》」、｜南《みなみ》の「｜迷霧《めいむ》の｜森《もり》」、そして｜西《にし》の「｜銀月湖《ぎんげつこ》」。

**李杰**：（｜心《こころ》の｜声《こえ》）｜知《し》り｜合《あ》ってまだ｜数時間《すうじかん》も｜経《た》っていない。｜結局《けっきょく》のところ、ただの｜他人《たにん》だ。いつ｜命《いのち》を｜落《お》としてもおかしくないこの｜状況《じょうきょう》で｜彼《かれ》らを｜連《つ》れていけば、｜自分《じぶん》まで｜危険《きけん》にさらすことになる。

**ナレーション**：｜李杰《りけつ》は｜深《ふか》く｜息《いき》を｜吸《す》い、｜決断《けつだん》を｜下《くだ》した。ポケットから｜黄《き》ばんだ｜地図《ちず》を｜取《と》り｜出《だ》し、｜広《ひろ》げて｜母親《ははおや》に｜見《み》せる。

**李杰**：（｜落《お》ち｜着《つ》いた｜声《こえ》で）これは｜駅《えき》の｜中《なか》で｜見《み》つけた｜地図《ちず》です。｜線路《せんろ》に｜沿《そ》って｜歩《ある》けば、たしかに｜亡者《もうじゃ》の｜峡谷《きょうこく》には｜着《つ》きます。でも、あの｜道《みち》は｜吹《ふ》きさらしで、｜身《み》を｜隠《かく》せるものが｜何《なに》もありません。

**優しい母親**：（｜顔《かお》を｜上《あ》げ、｜目《め》にかすかな｜希望《きぼう》を｜浮《う》かべて）じゃあ……ほかに｜道《みち》はあるんですか？

**李杰**：（｜地図《ちず》を｜指差《ゆびさ》して）｜森《もり》の｜中《なか》を｜大《おお》きな｜道《みち》が｜一本《いっぽん》｜通《とお》っていて、それも｜北《きた》の｜亡者《もうじゃ》の｜峡谷《きょうこく》へ｜続《つづ》いています。そっちのほうが、｜線路《せんろ》｜沿《ぞ》いよりは｜少《すこ》し｜安全《あんぜん》なはずです。｜少《すく》なくとも、｜木《き》が｜身《み》を｜隠《かく》してくれる。

**優しい母親**：（ありがたそうにうなずいて）ありがとうございます……｜本当《ほんとう》に、ありがとうございます。

**李杰**：（｜地図《ちず》をしまって）ただ、｜一緒《いっしょ》には｜行《い》きません。こっちにも｜考《かんが》えがあるので。

**ナレーション**：｜母親《ははおや》は｜一瞬《いっしゅん》きょとんとしたが、すぐに｜彼《かれ》の｜言《い》わんとすることを｜理解《りかい》した。｜落胆《らくたん》も｜非難《ひなん》も｜見《み》せず、ただ｜静《しず》かにうなずいた。

**優しい母親**：（｜小《ちい》さな｜声《こえ》で）わかりました。｜教《おし》えてくださって、ありがとうございます……それだけで、もう｜十分《じゅうぶん》｜助《たす》けていただきました。

**しっかり者の姉**：（｜母親《ははおや》の｜手《て》を｜引《ひ》いて、｜小声《こごえ》で）お｜兄《にい》ちゃんは、｜一緒《いっしょ》に｜来《こ》ないの？

**優しい母親**：（｜娘《むすめ》の｜頭《あたま》を｜優《やさ》しくなでて）お｜兄《にい》ちゃんには、お｜兄《にい》ちゃんのやることがあるの。パパは、ママたちだけで｜探《さが》しに｜行《い》こうね。ね？

**しっかり者の姉**：（こくりとうなずき、｜李杰《りけつ》を｜見《み》て）じゃあ……お｜兄《にい》ちゃんも、｜気《き》をつけてね。

**無邪気な弟**：（｜一緒《いっしょ》に｜手《て》を｜振《ふ》って）バイバイ、お｜兄《にい》ちゃん。

**李杰**：（｜小《ちい》さくうなずいて）そっちもな。｜気《き》をつけて。

**ナレーション**：｜母親《ははおや》は｜二人《ふたり》の｜子《こ》どもの｜手《て》を｜引《ひ》き、｜森《もり》を｜北《きた》へと｜歩《ある》き｜出《だ》した。｜紫《むらさき》の｜月明《つきあ》かりの｜下《した》、その｜背中《せなか》は｜少《すこ》し｜頼《たよ》りなく｜見《み》えたが、それでもまっすぐに｜伸《の》びていた。｜二《ふた》つの｜小《ちい》さな｜影《かげ》が、ぴたりと｜彼女《かのじょ》に｜寄《よ》り｜添《そ》っている。

**ナレーション**：ほどなくして、｜三人《さんにん》の｜姿《すがた》は｜森《もり》の｜闇《やみ》の｜中《なか》に｜消《き》えた。ホームに｜残《のこ》されたのは、｜李杰《りけつ》ただ｜一人《ひとり》だった。

**李杰**：（｜小声《こごえ》で、｜独《ひと》り｜言《ごと》のように）｜幸運《こううん》を｜祈《いの》るよ。

**ナレーション**：｜彼《かれ》は｜振《ふ》り｜返《かえ》り、｜地図《ちず》に｜記《しる》された｜西《にし》――｜銀月湖《ぎんげつこ》のほうを｜見《み》やった。それほど｜物騒《ぶっそう》には｜聞《き》こえない｜場所《ばしょ》だ。｜少《すく》なくとも「｜亡者《もうじゃ》の｜峡谷《きょうこく》」や「｜迷霧《めいむ》の｜森《もり》」よりは、いくらかましに｜聞《き》こえる。

**李杰**：（｜心《こころ》の｜声《こえ》）｜一人《ひとり》なら、｜自由《じゆう》に｜動《うご》ける。｜足手《あしで》まといもいないし、｜誰《だれ》かの｜安全《あんぜん》に｜責任《せきにん》を｜負《お》う｜必要《ひつよう》もない。こんな｜場所《ばしょ》では、これがいちばん｜合理的《ごうりてき》な｜選択《せんたく》だ。

**ナレーション**：｜彼《かれ》は｜錆《さ》びた｜剣《けん》を｜握《にぎ》りしめ、ホームを｜西側《にしがわ》の｜出口《でぐち》へと｜歩《ある》いていった。そこには｜雑草《ざっそう》に｜覆《おお》われた｜小道《こみち》があり、かつて｜誰《だれ》かが｜通《とお》った｜跡《あと》が、かすかに｜見《み》て｜取《と》れた。

**ナレーション**：｜李杰《りけつ》は｜小道《こみち》に｜足《あし》を｜踏《ふ》み｜入《い》れた。｜背後《はいご》で、「｜幽冥《ゆうめい》の｜都《みやこ》」の｜荒《あ》れ｜果《は》てた｜駅《えき》が｜少《すこ》しずつ｜遠《とお》ざかっていく。｜二《ふた》つの｜紫《むらさき》の｜月《つき》は｜相変《あいか》わらず｜空《そら》にかかり、｜彼《かれ》の｜影《かげ》を｜長《なが》く｜引《ひ》き｜伸《の》ばしていた。

**ナレーション**：｜森《もり》の｜空気《くうき》は｜冷《つめ》たく｜湿《しめ》っていて、｜腐《くさ》った｜落《お》ち｜葉《ば》と｜湿《しめ》った｜土《つち》の｜匂《にお》いがした。｜頭上《ずじょう》に｜生《お》い｜茂《しげ》る｜樹冠《じゅかん》がほとんどの｜光《ひかり》を｜遮《さえぎ》り、｜紫《むらさき》の｜月明《つきあ》かりがその｜隙間《すきま》からわずかに｜差《さ》し｜込《こ》んで、｜地面《じめん》にまだらな｜光《ひかり》と｜影《かげ》を｜落《お》としている。

**李杰**：（｜心《こころ》の｜声《こえ》）この｜道《みち》、もう｜長《なが》いこと｜誰《だれ》も｜通《とお》ってないな……でも、｜方角《ほうがく》はまだわかる。

**李杰**：（｜息《いき》を｜切《き》らしながら、｜小声《こごえ》で）この｜森《もり》……｜思《おも》ってたより｜深《ふか》いな。

**ナレーション**：｜彼《かれ》はポケットから｜地図《ちず》を｜取《と》り｜出《だ》し、かすかな｜月明《つきあ》かりを｜頼《たよ》りに｜確《たし》かめた。｜地図《ちず》によれば、｜駅《えき》から｜銀月湖《ぎんげつこ》まではそれほど｜遠《とお》くない。だが、｜実際《じっさい》に｜歩《ある》いてみると、｜予想《よそう》よりはるかに｜骨《ほね》が｜折《お》れた。

**李杰**：（｜心《こころ》の｜声《こえ》）｜地図《ちず》の｜上《うえ》ではほんの｜少《すこ》しの｜距離《きょり》に｜見《み》えるのに、この｜険《けわ》しい｜山道《やまみち》じゃ……｜何時間《なんじかん》もかかりそうだ。

**ナレーション**：｜地図《ちず》をしまい、｜彼《かれ》はふたたび｜歩《ある》き｜出《だ》した。｜時間《じかん》は｜刻一刻《こくいっこく》と｜過《す》ぎていく。だが、この｜永遠《えいえん》の｜紫《むらさき》の｜夜空《よぞら》の｜下《した》では、どれだけ｜経《た》ったのかまるでわからなかった。

**ナレーション**：｜二時間《にじかん》。｜三時間《さんじかん》。｜李杰《りけつ》の｜両脚《りょうあし》は｜痛《いた》み｜始《はじ》め、｜喉《のど》も｜渇《かわ》きで｜締《し》めつけられるようだった。いくつ｜小《ちい》さな｜坂《さか》を｜越《こ》え、いくつ｜巨木《きょぼく》を｜回《まわ》り｜込《こ》んだのか、もう｜覚《おぼ》えていない。

**李杰**：（｜心《こころ》の｜声《こえ》）まさか、｜道《みち》を｜間違《まちが》えたんじゃ……いや、｜小道《こみち》はまだ｜続《つづ》いてる。この｜道《みち》をたどっていけば、たぶん｜大丈夫《だいじょうぶ》だ……

**ナレーション**：この｜道《みち》は｜本当《ほんとう》に｜銀月湖《ぎんげつこ》に｜通《つう》じているのか――そう｜疑《うたが》いかけたそのとき、｜前方《ぜんぽう》の｜木々《きぎ》が｜不意《ふい》にまばらになった。｜幹《みき》の｜隙間《すきま》から、いくらか｜開《ひら》けた｜空《あ》き｜地《ち》が｜見《み》える。

**ナレーション**：そして、その｜空《あ》き｜地《ち》の｜真《ま》ん｜中《なか》に、｜一軒《いっけん》の｜木造《もくぞう》の｜家《いえ》が｜建《た》っていた。

**ナレーション**：｜彼《かれ》は｜錆《さ》びた｜剣《けん》を｜握《にぎ》りしめ、｜警戒《けいかい》しながら｜小屋《こや》に｜近《ちか》づいた。｜一歩《いっぽ》ごとに｜細心《さいしん》の｜注意《ちゅうい》を｜払《はら》う。｜触《ふ》れてはならない｜何《なに》かを、｜呼《よ》び｜覚《さ》ましてしまわないように。
